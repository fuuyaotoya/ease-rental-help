> **対象画面:** Shopify管理画面 > 注文 > 下書き
> **URL:** `https://admin.shopify.com/store/ease-site/orders/drafts`

![下書き注文一覧画面](/images/shopify-admin/draft-orders-list.png)

## 概要

Shopify管理画面の「下書き注文」ページでは、ストアのカートから自動作成された下書き注文の状況を確認できます。

:::caution[操作はEASE管理画面で]
下書き注文に関連する伝票操作は、**EASE Rentalの管理画面**で行ってください。Shopify管理画面での直接操作は推奨しません。
:::

---

## ページへのアクセス

```
手順:
1. Shopify管理画面を開く
2. 左サイドバーの「注文」をクリック
3. 「下書き」タブをクリック
```

![下書きタブ](/images/shopify-admin/draft-orders-nav.png)

---

## 下書き注文の流れ

```
カートで予約 → 下書き注文を自動作成
    ↓
お客様が支払いリンクから決済 → 正式な注文に変更
    ↓
または カートを放置 → 自動キャンセル
```

### ステータスの意味

| ステータス | 意味 |
|-----------|------|
| **受付中** | 支払い待ち |
| **請求書送信済み** | 支払いリンクが送信済み |
| **完了** | 支払いが完了し、正式な注文に変更された |
| **期限切れ** | 支払い期限が切れている |

---

## 確認できる情報

### 一覧画面

| 列 | 内容 |
|----|------|
| **下書き注文** | 下書き注文番号（例: `#D1234`） |
| **日付** | 作成日時 |
| **ステータス** | 受付中 / 請求書送信済み / 完了 / 期限切れ |
| **顧客** | 注文者の氏名 |
| **合計** | 合計金額 |
| **支払い** | 支払い状況 |

### 詳細画面

下書き注文番号をクリックすると詳細を確認できます。

![下書き注文の詳細画面](/images/shopify-admin/draft-orders-detail.png)

| 項目 | 内容 |
|------|------|
| **商品明細** | 商品名・バリアント・数量・単価 |
| **顧客情報** | 氏名・メール・電話番号 |
| **配送先** | 配送先住所 |
| **メタフィールド** | レンタル日付・レンタル期間などの情報 |
| **アクティビティ** | 送信履歴・ステータス変更のタイムライン |

## よくある確認シーン

### 顧客から「支払いリンクが届かない」と問い合わせがあった場合

```
1. 下書き注文一覧を開く
2. 顧客名で該当の下書き注文を検索
3. 詳細画面を開く
4. 「アクティビティ」セクションで送信履歴を確認
5. ステータスが「請求書送信済み」になっているか確認
```

### 下書き注文が期限切れになったか確認したい場合

```
1. 下書き注文一覧を開く
2. フィルターでステータス「期限切れ」を設定
3. 該当の下書き注文を確認
```

:::tip[自動キャンセルについて]
カート経由の未決済予約は、カートを放置してから135分を目安に自動キャンセルされます。レンタル開始日を基準にした自動キャンセルは停止中です。詳細は [自動キャンセルの仕組み](/appendix/auto-cancellation/) を参照してください。
:::

---

## 注意事項

- **下書き注文の直接キャンセル・削除**は避けてください。EASEの伝票と一致しなくなる可能性があります
- 支払いリンクの再送信が必要な場合は、EASE管理画面から操作してください
- 支払いが完了した後は、Shopify管理画面の「注文」で確認できます
