> **対象画面:** Shopify管理画面 > 注文（Orders）
> **URL:** `https://admin.shopify.com/store/ease-site/orders`

![注文一覧画面](/images/shopify-admin/orders-list.png)

## 概要

Shopify管理画面の「注文」ページでは、テーマ経由で作成された注文（Order）や下書き注文（Draft Order）の状況を確認できます。

:::caution[操作はBE管理画面で]
注文に紐づく伝票操作（キャンセル・返金・ステータス変更など）は、**EASE RentalのBE管理画面**で行ってください。Shopify管理画面での直接操作は推奨しません。
:::

---

## ページへのアクセス

```
手順:
1. Shopify管理画面を開く（https://admin.shopify.com/store/ease-site）
2. 左サイドバーの「注文」をクリック
3. 注文一覧が表示される
```

![サイドバーから注文へ](/images/shopify-admin/orders-nav.png)

---

## 注文一覧の見方

### 各項目の説明

| 列 | 内容 |
|----|------|
| **注文** | 注文番号（例: `#1234`）。クリックで詳細画面へ |
| **日付** | 注文が作成された日時 |
| **ステータス** | 未払い（Unpaid）/ 支払済み（Paid）/ 返金済み（Refunded）/ 確認待ちなど |
| **顧客** | 注文者の氏名 |
| **支払い** | 決済方法と支払い状況 |
| **合計** | 注文の合計金額 |

### ステータスの意味

| ステータス | 意味 |
|-----------|------|
| **未払い（Unpaid）** | Draft Orderから作成されたが、まだ支払いが完了していない |
| **支払済み（Paid）** | 決済が完了している |
| **一部返金（Partially refunded）** | 一部金額が返金されている |
| **返金済み（Refunded）** | 全額返金済み |

## 注文の検索・フィルター

### 検索バー

ページ上部の検索バーに注文番号や顧客名を入力して検索できます。

```
手順:
1. 検索バーをクリック
2. 注文番号（例: #1234）または顧客名を入力
3. Enterキーで検索実行
```

### フィルター

「フィルター」ボタンから条件を絞り込めます：

- **支払いステータス**: 支払済み / 未払い / 返金済み
- **配送ステータス**: 未配送 / 配送済み
- **日付範囲**: 特定期間の注文を表示
- **タグ**: 特定タグが付いた注文

## 注文詳細の確認

注文番号をクリックすると、詳細画面が表示されます。

![注文詳細画面](/images/shopify-admin/orders-detail.png)

### 確認できる主な情報

| 項目 | 内容 |
|------|------|
| **注文明細** | 商品名・バリアント・数量・金額 |
| **支払い情報** | 決済方法・支払いステータス・取引ID |
| **配送情報** | 配送先住所・配送状況・追跡番号 |
| **顧客情報** | 氏名・メール・電話番号 |
| **タイムライン** | 注文に関する全イベントの履歴 |

## よくある確認シーン

### 顧客から「注文したか確認したい」と問い合わせがあった場合

```
1. 注文一覧ページを開く
2. 検索バーに顧客名または注文番号を入力
3. 該当注文をクリックして詳細確認
4. 支払いステータスと配送ステータスを確認
```

### 支払いが完了しているか確認したい場合

```
1. 該当注文の詳細画面を開く
2. 「支払い」セクションを確認
3. ステータスが「支払済み」であれば決済完了
```

---

## 注意事項

- **注文のキャンセル・返金操作**は、EASE RentalのBE管理画面から行ってください（在庫連携のため）
- Shopify管理画面で直接キャンセルすると、BE側とステータスが乖離する可能性があります
- 注文データの変更はWebhook経由で自動的にBE管理画面に同期されます
