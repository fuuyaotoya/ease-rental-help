> **対象画面:** Shopify管理画面 > 商品（Products）
> **URL:** `https://admin.shopify.com/store/ease-site/products`

![商品一覧画面](/images/shopify-admin/products-list.png)

## 概要

Shopify管理画面の「商品」ページでは、レンタル商品の登録・編集・CSV一括操作・在庫設定・タグ管理を行います。

商品管理は**Shopify管理画面で直接操作**する重要な業務です（他の注文・顧客画面とは異なり、BE管理画面ではなくShopify側で管理します）。

---

## ページへのアクセス

```
手順:
1. Shopify管理画面を開く
2. 左サイドバーの「商品」をクリック
3. 商品一覧が表示される
```

---

## 商品一覧の見方

| 列 | 内容 |
|----|------|
| **商品** | 商品画像・名前。クリックで編集画面へ |
| **ステータス** | アクティブ / 下書き / アーカイブ |
| **在庫** | 在庫数（追跡しない設定の場合は「SKUs」や「--」） |
| **タグ** | 商品に設定されているタグ |
| **商品タイプ** | 商品タイプ（例: レンタル） |
| **ベンダー** | メーカー・ブランド名 |

## 商品の新規登録

### 個別登録

```
手順:
1. 商品一覧ページ右上の「商品を追加する」ボタンをクリック
2. 商品情報を入力（下記の入力項目を参照）
3. 「保存」をクリック
```

![商品追加画面](/images/shopify-admin/products-add.png)

#### 入力項目

| 項目 | 説明 | 入力例 |
|------|------|--------|
| **タイトル** | 商品名 | `104ダイニングテーブルダークブラウンアンティーク` |
| **説明** | 商品説明文（HTML可） | レンタル商品の特徴・仕様など |
| **メディア** | 商品画像 | 商品の写真（複数枚可） |
| **価格** | 販売価格・比較価格 | レンタル料金 |
| **在庫** | SKU・バーコード・在庫数 | 下記「在庫設定」を参照 |
| **配送** | 配送料・重量 | 商品の重量・サイズ |
| **バリアント** | サイズ・色など | 在庫管理の最小単位 |
| **SEO** | ページタイトル・メタディスクリプション | 検索エンジン向け |
| **商品タイプ** | 商品の分類 | `レンタル` |
| **ベンダー** | メーカー名 | 供应元の名前 |
| **タグ** | 検索・分類用 | 下記「タグ設定」を参照 |

## CSV一括登録

多数の商品を一括で登録・更新する場合、CSVファイルを使用します。

### CSVのダウンロード（テンプレート取得）

```
手順:
1. 商品一覧ページを開く
2. 「エクスポート」ボタンをクリック
3. 「すべての商品」/ 「選択した商品」を選択
4. 「商品をエクスポートする」をクリック
5. CSVファイルがダウンロードされる
```

![CSVエクスポート](/images/shopify-admin/products-csv-export.png)

:::tip[初回は既存データをエクスポート]
初めてCSV操作を行う場合は、まず既存商品をエクスポートしてフォーマットを確認してください。このフォーマットに合わせて新規商品を追加します。
:::

### CSVファイルの主要カラム

| カラム名 | 説明 | 必須 |
|----------|------|------|
| `Handle` | 商品の識別子（URL用）。英数字とハイフン | ✅ |
| `Title` | 商品名 | ✅（新規時） |
| `Body (HTML)` | 商品説明 | |
| `Vendor` | ベンダー名 | |
| `Type` | 商品タイプ | |
| `Tags` | タグ（カンマ区切り） | |
| `Published` | 公開状態（`TRUE` / `FALSE`） | |
| `Option1 Name` | バリアントオプション名（例: `サイズ`） | |
| `Option1 Value` | バリアント値（例: `大`） | |
| `Variant SKU` | SKUコード | ✅ |
| `Variant Grams` | 重量（グラム） | |
| `Variant Inventory Tracker` | 在庫追跡サービス | ✅ |
| `Variant Inventory Qty` | 在庫数 | |
| `Variant Price` | 販売価格 | ✅ |
| `Variant Compare At Price` | 比較価格 | |
| `Image Src` | 商品画像URL | |
| `Image Alt Text` | 画像の代替テキスト | |

### CSV一括登録の手順

```
手順:
1. テンプレートCSVをダウンロード（既存商品のエクスポート）
2. CSVファイルに新規商品の行を追加
   - Handle: URL用の識別子（例: 10202071-01）
   - Title: 商品名
   - Variant SKU: SKUコード
   - Variant Inventory Tracker: 空欄（在庫追跡しない）
   - Variant Price: 販売価格
3. CSVファイルを保存（UTF-8エンコーディング）
4. 商品一覧ページの「インポート」ボタンをクリック
5. CSVファイルをアップロード
6. プレビューで内容を確認
7. 「インポート」を実行
```

![CSVインポート](/images/shopify-admin/products-csv-import.png)

### CSV編集時の注意

- **Handle**: 同じHandleの行は1つの商品としてまとめられます。バリアントを追加する場合は同じHandleで行を追加
- **UTF-8エンコーディング**: 日本語を含む場合は必ずUTF-8で保存
- **バックアップ**: インポート前に既存データをエクスポートしてバックアップを取ってください
- **大量データ**: 数百件以上の場合、時間がかかることがあります（バックグラウンドで処理されます）

## 在庫設定

### 在庫追跡しない設定

EASE Rentalの在庫管理は**BEシステムで行う**ため、Shopify側では在庫追跡を**無効**にします。

```
手順（個別商品）:
1. 商品編集画面を開く
2. 「在庫」セクションの「在庫を追跡する」チェックボックスをオフにする
3. 「保存」をクリック
```

![在庫追跡しない設定](/images/shopify-admin/products-inventory-tracking.png)

### CSVでの在庫追跡しない設定

CSVファイルで `Variant Inventory Tracker` カラムを**空欄**にすると、在庫追跡がオフになります。

| カラム | 値 | 説明 |
|--------|-----|------|
| `Variant Inventory Tracker` | （空欄） | **在庫追跡しない** ← 推奨 |
| `Variant Inventory Tracker` | `shopify` | Shopifyで在庫追跡する |

:::warning[在庫追跡を有効にしないでください]
`Variant Inventory Tracker` を `shopify` に設定すると、Shopifyが在庫数を管理します。EASE RentalではBEシステムで在庫を管理するため、**空欄（追跡しない）**に設定してください。追跡を有効にすると、カートでの在庫チェックと競合する可能性があります。
:::

## タグ設定

タグは商品の分類・検索・フィルタリングに使用します。

### 個別設定

```
手順:
1. 商品編集画面を開く
2. 「タグ」セクションを見つける
3. タグを入力（Enterで追加）
4. 「保存」をクリック
```

![タグ設定](/images/shopify-admin/products-tags.png)

### EASE Rentalで使用するタグ

| タグ | 用途 | 説明 |
|------|------|------|
| `rental` | レンタル商品識別 | レンタル対象商品に付与 |
| `active` | 貸出可能 | 現在貸し出し可能な商品 |
| `maintenance` | メンテナンス中 | メンテナンス中で貸し出し不可 |
| `damaged` | 破損 | 破損品で貸し出し不可 |

### CSVでのタグ設定

CSVファイルの `Tags` カラムにカンマ区切りでタグを指定します：

```
例: rental,active
```

:::tip[タグ命名ルール]
- 英小文字とハイフンを使用（例: `category-chair`）
- スペースは使わない
- 既存タグと同じ文字列を使うと自動的に紐付く（大文字小文字は区別されない）
:::

## バリアント管理

バリアントは商品のサイズ・色などのバリエーションです。レンタルでは、**1バリアント = 1つの在庫単位**として扱います。

### バリアントの追加

```
手順:
1. 商品編集画面を開く
2. 「バリアント」セクションの「バリアントを追加」をクリック
3. オプション名（例: 通し番号）と値を入力
4. 価格・SKUを設定
5. 「保存」をクリック
```

![バリアント設定](/images/shopify-admin/products-variants.png)

### バリアントと在庫の関係

EASE Rentalでは「バリアント数 = 在庫上限」として計算します：
- 商品に5つのバリアントがある → 最大5つまで同時レンタル可能
- 詳細は [商品予約状況照会](/product-reservation-inquiry/) を参照

## メタフィールド（Metafields）

EASE Rentalのレンタル機能で使用する拡張データは、メタフィールドとして管理されます。

### メタフィールドの確認

```
手順:
1. 商品編集画面を開く
2. 画面下部の「メタフィールド」セクションを確認
```

![商品メタフィールド](/images/shopify-admin/products-metafields.png)

### レンタル関連の主なメタフィールド

| メタフィールド名 | namespace | 説明 |
|-----------------|-----------|------|
| レンタルステータス | `rental` | `available` / `maintenance` / `damaged` |
| レンタル価格 | `rental` | 1日あたりのレンタル料金 |
| メンテナンス終了日 | `rental` | メンテナンス期間終了予定日 |

## 商品のステータス管理

| ステータス | 説明 |
|-----------|------|
| **アクティブ（Active）** | ストアに表示され、購入可能 |
| **下書き（Draft）** | ストアに非表示。準備中の商品 |
| **アーカイブ（Archived）** | ストアに非表示。過去の商品 |

### ステータスの変更

```
手順:
1. 商品一覧で該当商品にチェックを入れる
2. 「ステータスを変更」ドロップダウンから選択
3. 確認して実行
```

## トラブルシューティング

### CSVインポートでエラーになる

| エラー | 原因 | 対処 |
|--------|------|------|
| `Handle is blank` | Handle列が空 | 商品識別子（英数字ハイフン）を入力 |
| `Price is blank` | 価格列が空 | Variant Priceを入力 |
| `Encoding error` | 文字エンコーディング | UTF-8で保存し直す |
| `Duplicate handle` | 同じHandleが重複 | バリアント行は同じHandleで統一 |

### 商品がストアに表示されない

1. **ステータス確認**: 「アーカイブ」や「下書き」になっていないか
2. **販売チャネル確認**: 「Online Store」にチェックが入っているか
3. **公開日確認**: 公開日が未来になっていないか

---

## 注意事項

- **在庫追跡はオフ**にしてください（BEシステムで在庫管理するため）
- **SKUコード**は必ず設定してください（BEとの連携に使用）
- CSV編集前は必ず**バックアップ**（エクスポート）を取ってください
- 商品画像は事前に準備してから登録すると効率的です
