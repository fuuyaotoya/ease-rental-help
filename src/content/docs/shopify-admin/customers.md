> **対象画面:** Shopify管理画面 > 顧客（Customers）
> **URL:** `https://admin.shopify.com/store/ease-site/customers`

![顧客一覧画面](/images/shopify-admin/customers-list.png)

## 概要

Shopify管理画面の「顧客」ページでは、登録されている顧客情報を確認できます。顧客の基本情報・注文履歴・タグ・メタフィールドなどを閲覧可能です。

:::caution[操作はFE管理画面で]
顧客情報の編集（住所・請求先・プロフィールなど）は、**EASE RentalのFE管理画面**で行ってください。Shopify管理画面での直接編集は推奨しません。
:::

---

## ページへのアクセス

```
手順:
1. Shopify管理画面を開く
2. 左サイドバーの「顧客」をクリック
3. 顧客一覧が表示される
```

---

## 顧客一覧の見方

### 各項目の説明

| 列 | 内容 |
|----|------|
| **名前** | 顧客の氏名。クリックで詳細画面へ |
| **メール** | 登録メールアドレス |
| **場所** | 住所（都道府県） |
| **注文数** | 過去の注文回数 |
| **金額** | 累計注文金額 |
| **最終購入日** | 直近の注文日 |
| **タグ** | 顧客に設定されているタグ |

---

## 顧客の検索

### 検索バー

ページ上部の検索バーから、名前・メールアドレス・電話番号で検索できます。

```
手順:
1. 検索バーをクリック
2. 名前、メール、または電話番号を入力
3. 検索結果から該当顧客をクリック
```

### フィルター

「フィルター」ボタンから条件絞り込み：

- **タグ**: 特定タグが付いた顧客
- **日付**: 特定期間に登録・購入した顧客
- **購入金額**: 累計金額で絞り込み

---

## 顧客詳細の確認

顧客名をクリックすると、詳細画面が表示されます。

![顧客詳細画面](/images/shopify-admin/customers-detail.png)

### 確認できる情報

| タブ / セクション | 内容 |
|------------------|------|
| **概要** | 基本情報（氏名・メール・電話・住所） |
| **注文履歴** | 過去の注文一覧 |
| **タグ** | 設定されているタグ一覧 |
| **メタフィールド** | EASE Rentalの拡張データ（レンタル顧客情報など） |
| **メモ** | スタッフによるメモ書き |

### メタフィールドの確認

顧客詳細画面の下部に「メタフィールド」セクションがあります。EASE Rentalで使用する顧客メタフィールドを確認できます。

![顧客メタフィールド](/images/shopify-admin/customers-metafields.png)

---

## よくある確認シーン

### 顧客が「登録されているか」確認したい場合

```
1. 顧客一覧ページを開く
2. 検索バーにメールアドレスを入力
3. 検索結果に表示されれば登録済み
```

### 顧客のタグを確認したい場合

```
1. 該当顧客の詳細画面を開く
2. 「タグ」セクションを確認
3. タグの内容を確認（例: "wholesale", "vip" など）
```

:::tip[タグについて]
顧客タグは、BE管理画面（FE）から設定されます。Shopify管理画面では閲覧のみ推奨します。
:::

---

## 注意事項

- **顧客情報の編集**（名前・住所・タグなど）は、EASE RentalのFE管理画面から行ってください
- Shopify管理画面で直接編集すると、BE側とデータが乖離する可能性があります
- 新規顧客はテーマのアカウント登録画面またはBE管理画面から登録されます
