> **パス:** `/reservation-inquiry`
> **メニュー:** 予約管理 > 予約状況照会

## 概要

商品の予約状況・修理状況をカレンダー形式で確認する画面です。特定の商品を選択して、月間カレンダーで予約の有無を視覚的に把握できます。

## アクセス方法

- サイドバーから: 「予約管理」>「予約状況照会」をクリック
- URL直接: `/reservation-inquiry`

## 画面構成

### 商品検索セクション

| 項目 | 種類 | 説明 | 必須 |
|------|------|------|------|
| 商品コード/商品名 | テキスト | 商品コードまたは商品名で検索 | ※1 |
| カテゴリ | セレクト | カテゴリでフィルタリング | - |
| タグ | テキスト | タグでフィルタリング | - |

※1: いずれかの検索条件を入力する必要があります

### 検索結果テーブル

| 項目 | 種類 | 説明 |
|------|------|------|
| 選択 | ラジオボタン | カレンダー表示する商品を選択 |
| 商品コード | テキスト | 商品のSKUコード |
| 商品名 | テキスト | 商品の名称 |
| 名称カナ | テキスト | 商品名の読み方（カナ） |
| カテゴリ | テキスト | 商品カテゴリ |
| タグ | テキスト | 商品に付与されたタグ |
| 操作 | ボタン | 「照会」「伝票に追加」ボタン |

### 予約状況カレンダー

| 項目 | 種類 | 説明 |
|------|------|------|
| 商品画像 | 画像 | 選択した商品の画像 |
| 商品コード | テキスト | 選択した商品のSKU |
| 商品名 | テキスト | 選択した商品名 |
| カテゴリ | テキスト | 商品カテゴリ |
| タグ | テキスト | 商品タグ |
| 表示内容フィルタ | チェックボックス | 予約/修理・メンテナンス/在庫ありの表示切替 |
| 月移動ボタン | ボタン | 前月/次月への移動 |

#### カレンダー凡例

| 色 | 種類 | 説明 |
|----|------|------|
| 青 | 予約済み | 既に予約が入っている日 |
| 赤 | 修理・メンテナンス | メンテナンス中の日 |
| 緑 | 在庫あり | 貸出可能な日 |

## 操作手順

### 手順1: 商品を検索する

1. 「商品コード/商品名」欄に検索キーワードを入力、または「カテゴリ」「タグ」を選択
2. 「検索」ボタンをクリック
3. 検索結果が一覧表示されます

**期待される結果:**
- 検索条件に一致する商品がテーブルに表示される
- 件数がトーストメッセージで通知される

### 手順2: カレンダーで予約状況を確認する

1. 検索結果から商品を選択（ラジオボタンまたは「照会」ボタンをクリック）
2. 予約状況カレンダーが自動的にスクロールして表示されます
3. 「◀」「▶」ボタンで月を移動できます
4. 「表示内容」チェックボックスで表示する情報を切り替えられます

**期待される結果:**
- 選択した商品の予約状況がカレンダー形式で表示される
- 各日の予約状況が色分けされて表示される

### 手順3: 予約詳細を確認する

1. カレンダー上の予約イベントをクリック
2. 予約詳細モーダルが表示されます
3. 予約番号、ステータス、日付、メモを確認できます

**期待される結果:**
- クリックした予約の詳細情報がモーダルで表示される

### 手順4: 伝票に追加する

1. 検索結果またはカレンダーセクションの「伝票に追加」ボタンをクリック
2. 新しいタブで伝票作成画面が開きます（商品コードが自動入力済み）

**期待される結果:**
- 新しいタブで `/booking-compact?product={商品コード}` が開く
