## 概要

レンタル商品の修理・メンテナンス状況を一元管理する画面です。修理の登録から完了までのステータス管理、修理業者の情報管理、費用の記録を行います。

## アクセス方法

- サイドバー: **在庫管理** > **修理管理**
- 直接URL: `/repairs`

## 画面構成

### ページヘッダー

| 項目 | 説明 |
|------|------|
| タイトル | 「修理管理」 |
| サブタイトル | 「商品の修理・メンテナンス状況を管理」 |
| 最終更新時刻 | データの最終更新日時 |
| 更新ボタン | データを手動で再読み込み |
| 修理登録ボタン | 新しい修理記録を作成（緑色の「+ 修理登録」ボタン） |

### 統計カード

画面上部に5つの統計カードが表示されます。

| 項目 | 色 | 説明 |
|------|-----|------|
| 合計 | 白 | 全修理記録の総数 |
| 保留中 | 黄 | ステータスが「報告済」の件数 |
| 修理中 | 青 | ステータスが「修理中」の件数 |
| 完了 | 緑 | ステータスが「完了」の件数 |
| キャンセル | グレー | ステータスが「キャンセル」の件数 |

### フィルター

修理記録を絞り込むための検索条件を設定できます。

| フィルター項目 | 説明 |
|--------------|------|
| ステータス | 報告済 / 修理中 / 完了 / キャンセル から選択 |
| 修理種別 | 破損修理 / メンテナンス / 検査 / その他 から選択 |
| 優先度 | 低 / 通常 / 高 から選択 |
| 商品名 | テキスト入力で部分一致検索 |

- **検索** ボタン: 設定した条件で絞り込み
- **リセット** ボタン: 全フィルターをクリアし全件表示に戻す

### 修理記録一覧テーブル

| 列名 | ソート | 説明 |
|------|--------|------|
| 報告日 | 可能 | 修理記録の作成日（JST） |
| 商品名 | 可能 | 修理対象の商品名 |
| SKU | 不可 | 商品のSKUコード |
| 種類 | 不可 | 修理種別（破損修理/メンテナンス/検査/その他） |
| 優先度 | 可能 | 優先度（低/通常/高） |
| ステータス | 可能 | 現在のステータス（カラーバッジ付き） |
| 予想費用 | 可能 | 見積もり費用（円表記） |
| アクション | 不可 | 「編集」「削除」ボタン |

列ヘッダーをクリックすると、昇順/降順でソートが切り替わります。

## 手順

### 手順1: 修理を登録する

1. ページ右上の **「+ 修理登録」** ボタンをクリック
2. 修理登録モーダルが開く
3. 以下の情報を入力:

**商品情報セクション:**

| 項目 | 入力 | 説明 |
|------|------|------|
| 商品名 | 自動入力 | 対象商品の名前 |
| SKU | 自動入力 | 対象商品のSKU |

**修理詳細セクション:**

| 項目 | 入力 | 必須 | 説明 |
|------|------|------|------|
| 修理種別 | 選択 | 必須 | 破損修理 / メンテナンス / 検査 / その他 |
| 優先度 | 選択 | - | 低 / 通常（初期値） / 高 |
| メンテナンス開始日 | 日付 | - | 修理・メンテナンスの開始予定日 |
| メンテナンス終了日 | 日付 | - | 修理完了予定日（未入力で期限なし） |
| 破損・故障詳細 | テキスト | - | 破損や故障の状況説明 |
| 見積費用 | 数値 | - | 修理費用の見積もり金額（円） |

**業者情報セクション:**

| 項目 | 入力 | 説明 |
|------|------|------|
| 業者名 | テキスト | 修理業者の名前 |
| 業者連絡先 | テキスト | 電話番号やメールアドレス |

**備考セクション:**

| 項目 | 入力 | 説明 |
|------|------|------|
| 修理メモ（顧客向け） | テキスト | 顧客に表示されるメモ |
| 社内メモ | テキスト | 社内のみで共有するメモ |

4. **「登録」** ボタンをクリック

**期待される結果:**
- 「修理を登録しました」の通知が表示
- 一覧テーブルに新しいレコードが追加される
- 統計カードの数値が更新される

**注意:** 終了日のみを入力して開始日を空にすることはできません。

### 手順2: 修理記録を編集する

1. 修理記録一覧で対象行の **「編集」** ボタンをクリック
2. 修理編集モーダルが開く
3. 以下の項目を変更可能:

| 項目 | 説明 |
|------|------|
| 修理種別 | 破損修理 / メンテナンス / 検査 / その他 |
| 優先度 | 低 / 通常 / 高 |
| 破損・故障詳細 | 破損や故障の状況 |
| 見積費用 | 修理費用の見積もり |
| 実費用 | 修理完了後の実際の費用 |
| 業者名 | 修理業者の名前 |
| 業者連絡先 | 電話番号やメール |
| 修理メモ | 修理に関するメモ |
| 社内メモ | 社内のみで共有するメモ |
| 担当者名 | 担当スタッフの名前 |

4. **「更新」** ボタンをクリック

**期待される結果:**
- 「修理記録を更新しました」の通知が表示
- 一覧テーブルの該当レコードが更新される

### 手順3: 修理記録を削除する

1. 修理記録一覧で対象行の **「削除」** ボタンをクリック
2. 削除確認ダイアログが表示される
3. 対象の修理記録（商品名、SKU、修理種別）を確認
4. **「削除する」** ボタンをクリック

**期待される結果:**
- 「修理記録を削除しました」の通知が表示
- 一覧テーブルから該当レコードが消える

> **警告:** 削除操作は取り消せません。データは完全に削除されます。

### 手順4: データを更新する

1. ページヘッダーの更新ボタン（↻）をクリック
2. ローディング表示中にデータが再取得される

**期待される結果:**
- 最終更新時刻が更新される
- 統計カードと一覧テーブルに最新データが反映される

## ステータス一覧

| ステータス | ラベル | バッジ色 | 説明 |
|-----------|--------|---------|------|
| REPORTED | 報告済 | オレンジ | 修理が報告され、対応待ちの状態 |
| IN_PROGRESS | 修理中 | 青 | 修理・メンテナンスが実施中の状態 |
| COMPLETED | 完了 | 緑 | 修理・メンテナンスが完了した状態 |
| CANCELLED | キャンセル | グレー | 修理がキャンセルされた状態 |

## 修理種別

| 種別 | 説明 |
|------|------|
| 破損修理 | 商品の破損・故障に対する修理 |
| メンテナンス | 定期メンテナンスや保守点検 |
| 検査 | 商品の状態確認・検品 |
| その他 | 上記以外の修理・対応 |

## 優先度

| 優先度 | 説明 |
|--------|------|
| 高 | 早急な対応が必要 |
| 通常 | 通常の対応（初期値） |
| 低 | 急ぎではない対応 |

- [ ] 修理登録モーダルで新規レコードを作成できる
- [ ] 終了日のみの入力でバリデーションエラーが表示される
- [ ] 修理編集モーダルで既存レコードを更新できる
- [ ] 削除確認ダイアログが表示され、削除後にレコードが消える
- [ ] 更新ボタンでデータが再取得される

## 備考

- 修理登録時、商品の在庫ロックが自動で行われます（修理完了・キャンセルで解除）
- 実費用は編集時のみ入力可能です（登録時は見積費用のみ）
- 修理メモと社内メモは用途が異なります。修理メモは顧客向け、社内メモは内部確認用です
- 費用の表示は日本円（整数）です
