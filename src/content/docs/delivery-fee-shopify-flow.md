## 概要

配送料が0円でShopifyに注文が作成される場合、配送料確定後にShopifyへ別途請求を行う必要があります。本手順書では、バックエンド管理画面から配送料を確定し、Shopify経由で顧客へ請求書メールを送信するまでの流れを説明します。

## 前提条件

- 対象伝票はすでに出荷済みであること
- 配送料金が確定していること
- 顧客のメールアドレスが登録されていること
- 顧客の支払方法がクレジットカードであること

## 処理フロー

### Step 1: メニューを開く

バックエンド管理画面のサイドバーから「**配送料確定（クレカ）**」メニューを開きます。

### Step 2: 伝票一覧で対象を選択

![配送料確定一覧](/images/uat/shipping-fee-list.png)

一覧は以下の **6列構成**（コンパクト表示）になっています:

| 列 | 内容 |
|----|------|
| 伝票No. | クリックで booking-compact 詳細ページへ遷移 |
| 顧客No. | Shopify 顧客コード |
| 顧客名 | 顧客名 |
| 会社名 | 会社名（個人の場合は「-」または「個人」） |
| 配送数 | 当該伝票の配送レコード数（往路+復路） |
| 操作 | 「配送料確認」ボタン |

> **Issue #994 改善:** 旧版で表示されていた **部署名列は廃止** されました。横スクロールを抑え、ボタンが切れないコンパクトな表示に変更されています。

### Step 3: 配送料確認画面で金額を入力

![配送料確定詳細画面](/images/uat/shipping-fee-detail.png)

「配送料確認」ボタン押下後、専用ページ (`/bookings-shipping-fee/[id]`) に遷移します。

**画面構成:**

- **伝票情報**: 伝票番号・顧客名・会社名・レンタル期間・配送先住所
- **配送明細・料金確定**: 往路（搬入）と復路（搬出）それぞれに配送料入力欄
- **追加料金**: 「+追加」ボタンで任意の追加料金を登録可能
- **小計（税抜）/ 消費税 / 合計（税込）**: 自動計算

配送料金を入力後、「**Shopifyへ送信**」ボタンを押下します。

### Step 4: 送信完了を確認

画面に「**Shopifyに送信しました**」と表示されれば、Shopify側への送信は完了です。

### Step 5: 請求書メールの送信を確認

Shopifyから顧客のメールアドレス宛に請求書メールが自動送信されます。顧客はメール内のリンクから決済可能です。

## 確認ポイント

| 項目         | 説明                                    |
| ------------ | --------------------------------------- |
| 伝票番号     | バックエンド側で作成される              |
| 請求書メール | Shopifyから自動送信。伝票番号が含まれる |
| 決済リンク   | 顧客はメール内リンクから決済可能        |
| 対象支払方法 | クレジットカード（銀行振込は別フロー）  |

## よくある質問

### Q: 銀行振込の顧客の場合はどうすればよいですか？

銀行振込の顧客は本フローの対象外です。銀行振込注文の下書き仕様に従って別途処理してください。

### Q: 配送料を修正したい場合はどうすればよいですか？

Shopifyへ送信前であれば、再度配送料を入力し直すことができます。送信後の修正は、Shopify管理画面からDraft Orderを編集してください。

### Q: 顧客がメールを受け取っていない場合は？

1. 顧客のメールアドレスが正しく登録されているか確認
2. 迷惑メールフォルダを確認するよう顧客へ連絡
3. Shopify管理画面から請求書を再送信

## 追加請求（Draft Order③）との違い

本フローは **Draft Order②（配送料確定請求）** です。返却後に発生する延長料金・破損料金・調整項目（駐車場代等）は **Draft Order③** として **[返却・金額確定](/bookings-return/)** ページの「📝 追加請求を作成」ボタンで別途請求します。

| Draft Order | タイミング | 内容 | 操作画面 |
|------------|-----------|------|---------|
| ① | 注文時 | 商品レンタル料金 | （Shopify ストア側） |
| ② | 配送料確定時 | 配送料金 | このページ（配送料確定（クレカ）） |
| ③ | 金額確定時 | 延長料金・破損料金・調整項目 | [返却・金額確定](/bookings-return/) |
