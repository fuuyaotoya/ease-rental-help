> ⚠️ **仕様変更（2026年7月）:** 後払いクレジットカードでは配送料を個別に請求せず、本体分と合わせて一括（「金額確定」ボタン）で請求します。配送キャンセル料も後払い伝票では本体分に統合されます。配送料・キャンセル料を別立てで請求するのは前払いクレカのみです。最新は [決済方法別伝票作成フロー](/appendix/payment-method-flows/) を参照。

> **区分:** 【スタッフ用】
>
> **用語の説明:** クレジットカード顧客への追加請求は、Shopify の「下書き注文」（カード決済用の仮注文）を使って行われます。伝票画面の「請求チャネル」には、何回目の決済かを番号で表示します — **①本体分（レンタル料＋配送料）/ ②配送料 / ③追加料金（延長・破損など）/ ④追加商品 / ⑤配送キャンセル料**。本ページの説明で「請求チャネル②」などの表記は、この番号を指します。

![配送料確定・Shopify請求画面](/images/bookings-shipping-fee.png)

## 概要

配送料が0円でShopifyに注文が作成される場合、配送料確定後にShopifyへ別途請求を行う必要があります。本手順書では、管理画面から配送料を確定し、Shopify経由で顧客へ請求書メールを送信するまでの流れを説明します。

## 前提条件

- 対象伝票はすでに出荷済みであること
- 配送料金が確定していること
- 顧客のメールアドレスが登録されていること
- 顧客の支払方法がクレジットカードであること

## 処理フロー

### Step 1: メニューを開く

管理画面のサイドバーから「**配送料確定（クレカ）**」メニューを開きます。

### Step 2: 伝票一覧で対象を選択

![配送料確定一覧](/images/uat/shipping-fee-list.png)

一覧は以下の構成（コンパクト表示）になっています:

| 列 | 内容 |
|----|------|
| 伝票No. | クリックで伝票詳細ページへ遷移 |
| 顧客No. | Shopify 顧客コード |
| 顧客名 | 顧客名 |
| 会社名 | 会社名（個人の場合は「-」または「個人」） |
| 開始日 | レンタル開始日 |
| 配送数 | 当該伝票の配送レコード数（往路+復路） |
| 前日請求 | 前日請求セット済みバッジ（下記参照） |
| 操作 | 「配送料確認」ボタン |

> **表示の改善:** 旧版で表示されていた **部署名列は廃止** されました。横スクロールを抑え、ボタンが切れないコンパクトな表示に変更されています。

> **滞留伝票を見つけやすくする改善（開始日列＋前日請求バッジ＋超過ハイライト）:**
> - **開始日列** を追加し、レンタル開始日が近い・経過済みの伝票を並べ替えずに確認できます。
> - **前日請求バッジ**: 後払いクレカで前日請求セット済みの伝票に「前日請求」バッジを表示。レンタル開始日を過ぎても自動送信されていない（送信漏れの可能性）場合は **「⚠前日請求滞留」** と赤強調されます → 「請求書送付」ボタンで手動送信してください。
> - **超過ハイライト**: 開始日経過の伝票行は赤ハイライトで強調されます。

### Step 3: 配送料確認画面で金額を入力

![配送料確定詳細画面](/images/uat/shipping-fee-detail.png)

「配送料確認」ボタン押下後、専用ページに遷移します。

**画面構成:**

- **伝票情報**: 伝票番号・顧客名・会社名・レンタル期間・配送先住所
- **配送明細・料金確定**: 往路（搬入）と復路（搬出）それぞれに配送料入力欄と料金区分
- **小計（税抜）/ 消費税 / 合計（税込）**: 自動計算（配送料本体のみ集計）

> **画面を開いた直後に自動計算:** 配送料が未確定でグループ区分が設定されている配送は、画面を開いた時点で自動的に料金が計算・表示されます（区分を選び直す必要はありません）。すでに金額が入力済みの配送は上書きされません。

> **後払いクレカ伝票は2ボタン選択式:** 後払いクレジットカード伝票では「**前日請求**」（青・デフォルト／レンタル開始前日の18時頃に自動送信・取り消し可能）と「**請求書送付**」（赤・例外／即時送付・不可逆）の2ボタンが表示されます。前日請求をセットすると琥珀色バッジと「前日請求を取り消す」ボタンが表示され、送付済みは緑の「金額確定済み（請求書送付済）」ラベルになります（前払いクレカは従来通り「Shopifyへ送信」1ボタン）。

配送料金を入力後、「**Shopifyへ送信**」ボタンを押下します。

> **駐車場代・高速代の欄は廃止:** これまで別途入力できていた **駐車場代・高速代の欄は廃止** されました（請求しない方針）。実費を回収したい場合は配送料欄に含めて入力してください。また、配送の料金区分が未設定の場合は **BASIC をデフォルト** として表示します（伝票編集の配送モーダルと同一挙動）。
>
> **手入力した配送料は優先されます:** 配送料欄に手入力した金額は、エリア料金設定があっても **手入力値が優先** されます。保存時にエリア料金で上書きされることはありません。

### Step 4: 送信完了を確認

画面に「**Shopifyに送信しました**」と表示されれば、Shopify側への送信は完了です。

### Step 5: 請求書メールの送信を確認

Shopifyから顧客のメールアドレス宛に請求書メールが自動送信されます。顧客はメール内のリンクから決済可能です。

## 確認ポイント

| 項目         | 説明                                    |
| ------------ | --------------------------------------- |
| 伝票番号     | システム側で作成される              |
| 請求書メール | Shopifyから自動送信。伝票番号が含まれる |
| 決済リンク   | 顧客はメール内リンクから決済可能        |
| 対象支払方法 | クレジットカード（銀行振込は別フロー）  |

## よくある質問

### Q: 銀行振込の顧客の場合はどうすればよいですか？

銀行振込の顧客は本フローの対象外です。銀行振込注文は別の処理（請求書発行→入金確認）を行ってください。

### Q: 配送料を修正したい場合はどうすればよいですか？

Shopifyへ送信前であれば、再度配送料を入力し直すことができます。送信後の修正は、Shopify管理画面から下書き注文を編集してください。

### Q: 顧客がメールを受け取っていない場合は？

1. 顧客のメールアドレスが正しく登録されているか確認
2. 迷惑メールフォルダを確認するよう顧客へ連絡
3. Shopify管理画面から請求書を再送信

## 追加請求（請求チャネル③）との違い

本フローは **請求チャネル②（配送料確定請求）** です。返却後に発生する延長料金・破損料金・調整項目（駐車場代等）は **請求チャネル③** として **[返却・金額確定](/bookings-return/)** ページの「📝 追加請求を作成」ボタンで別途請求します。

| 請求チャネル | タイミング | 内容 | 操作画面 |
|------------|-----------|------|---------|
| ① | 注文時 | 商品レンタル料金 | （Shopify ストア側） |
| ② | 配送料確定時 | 配送料金 | このページ（配送料確定（クレカ）） |
| ③ | 金額確定時 | 延長料金・破損料金・調整項目 | [返却・金額確定](/bookings-return/) |
| ⑤ | 配送キャンセル時（※配送料の請求②未作成の場合のみ） | 配送キャンセル料 | [伝票作成・編集](/booking-compact/)（下記「配送キャンセル料」） |

## 配送キャンセル料のクレカ後課金

クレジットカード決済の伝票で **配送がキャンセルされた** 場合、そのキャンセル料を別途回収するためのカード決済（請求チャネル⑤）を発行します。

> **伝票全体キャンセル時の配送料:** 伝票全体をキャンセルする場合は、まだキャンセルされていない（有効な）配送料にも **キャンセル料率（当日100%/前日30%）** のキャンセル料が別途計上されます。料率の詳細と計算機は [付録: キャンセル料率](/appendix/fee-calculation/) を参照。

### 対象シナリオ（すべて満たす必要があります）

- 先払いクレジットカード決済の伝票である（後払いクレカの統合伝票ではキャンセル料の個別作成ができないためボタン非表示）
- 配送がキャンセルされ、**キャンセル料が0円超で入力されている**
- **配送料のカード決済（請求チャネル②）をまだ送信していない**（請求チャネルの②が「--」）
- 伝票が「完了」「キャンセル」状態ではない
- 顧客のメールアドレスが登録されている

> **⚠️ 配送料の請求（②）を「すでに送信済み」の場合は対象外**
> 本機能は **配送料をまだShopifyに送っていない** 伝票のみ対象です。配送料送信済み（請求チャネル②が「送信済」）の場合はボタンが表示されません。
> - **②が未入金で残っている場合**: 伝票ページの請求チャネル②欄にある「**取消**」ボタンから取り消せます。取り消すとShopifyの下書き注文が削除され、システムのステータスが「--」に戻って **キャンセル料請求ボタンが再表示** されます（下記FAQ参照）。
> - **②が入金済みの場合**: 削除できません。キャンセル料は別途（Shopifyで手動により下書き注文を作成する等）で回収してください。

### 手順

1. [伝票作成・編集](/booking-compact/) ページで対象伝票を開く
2. 「請求チャネル」欄の近くに「**キャンセル料を請求する**」ボタンが表示される（上記条件を満たす場合のみ）
3. ボタンクリック → 確認ダイアログで **対象配送数** と **請求額**（各配送のキャンセル料合計・税込・システム算出）を確認
4. 必要に応じて **メモ**（500文字以内・Shopifyの下書き注文のメモに反映）を入力
5. 「**請求を作成**」をクリック

### 作成経路（バックグラウンド処理）

「請求を作成」を押すと、システムが **バックグラウンド処理** を登録し、即座に「作成しました（決済待ち）」と表示されます。実際のShopify処理はバックグラウンドで行われます。

```
ボタン押下
  ↓
システム: 入力内容を確認 → バックグラウンド処理を登録 → 即時に「作成しました（決済待ち）」と表示
  ↓ (バックグラウンドで処理)
各配送のキャンセル料から請求額を算出
  → Shopifyに下書き注文（キャンセル料）を作成
  → 伝票に記録（請求チャネル⑤欄が「送信済」に変更）
  → 顧客へ決済リンクメールを自動送信
  ↓
顧客: メール内リンクからクレカ決済 → 決済完了で伝票に入金反映
```

> ボタン押下時点では「決済待ち」です。処理完了（数秒〜数十秒）後に伝票を再読み込みすると、請求チャネル⑤欄が「送信済」に変わります。
> ※キャンセル料（⑤）は配送料（②）とは独立した管理枠で保持されます。1伝票で②と⑤をそれぞれ1つずつ保持できます。

### よくある質問

#### Q: 配送料の請求をすでに送信済みですが、キャンセル料も請求したい

本機能は配送料の請求（②）未作成の伝票のみ対象です。②送信済み（請求チャネル②が「送信済」）の場合はボタンが表示されません。ただし **②が未入金（決済待ち）** であれば、伝票ページから取り消してキャンセル料を請求できます。

> **配送料請求（②）の取消手順:**
> 1. [伝票作成・編集](/booking-compact/) ページで対象伝票を開く
> 2. 「請求チャネル」表の **② 配送料** 行に「**取消**」ボタンが表示される（未入金かつShopify側で注文化されていない場合のみ）
> 3. ボタンクリック → 確認ダイアログで「**未払いの配送料請求を取り消します。Shopify の下書き注文を削除します。よろしいですか？**」に同意
> 4. Shopifyの下書き注文が削除され、システムの②ステータスが「--」にリセットされる → **キャンセル料請求ボタンが再表示** される
>
> ※取り消しは **決済待ち** の②のみ可能です。入金済み・キャンセル済みの②は取り消せません。

#### Q: ボタンが表示されません

以下を確認してください:
- 支払方法がクレジットカード（Shopify）か
- 配送がキャンセルされ、キャンセル料が0円超で入力されているか
- 配送料の請求②が未作成（請求チャネル②が「--」）か
- 伝票が「完了」「キャンセル」状態でないか
- 顧客のメールアドレスが登録されているか

#### Q: キャンセル料の金額はどこで決まりますか

各配送のキャンセル料（配送編集モーダルで入力した金額）の合計です。システムが算出するため、金額を送信する必要はありません。
