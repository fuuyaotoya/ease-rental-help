## 概要

EASE Rental では、新規登録を廃止し**会員制（承認制）**へ移行しました。新規希望者は会員申込ページから審査申請を行い、スタッフの審査を経て承認されると、Shopify からアカウント有効化の招待メールが届きます。承認された方のみレンタルをご利用いただけます。

```md
新規希望者 → 会員申込（書類添付） → スタッフ審査 → 承認 → 招待メール → アカウント有効化 → レンタル利用開始
```

## お客様向け：会員申込の流れ

### 1. 申込ページにアクセス

会員申込ページ（`/pages/membership-apply`）にアクセスし、必要事項を入力します。

### 2. 入力項目

| 項目 | 内容 |
|------|------|
| 会社名 | 法人の場合は正式名称 |
| 担当者名 | ご担当者様のお名前 |
| メールアドレス | 招待メールの送信先（必須） |
| 電話番号・住所 | ご連絡先情報 |
| 業種・部署・役職 | 任意 |
| 名刺・身分証 | **JPG / PNG**（※PDFは現在フォームで選択できません）・10MB以下で添付（必須） |
| 利用規約への同意 | ページ内の利用規約を確認のうえ、同意チェック（必須・未チェックでは送信できません） |
| メッセージ | ご要望等があれば任意で入力 |

> **請求先について（仕様）:** 会員申込フォームに **請求先入力欄はありません**。これは意図的な仕様です — 初回はクレジットカード決済のため申請時点では請求先は使われず、**承認時に申請者の基本情報から請求先が自動作成**されます（詳しくは [顧客管理 > 請求先管理](/customer-management/) の「承認時の自動作成」）。

### 3. 送信後

- 送信が完了すると「申込を受け付けました」の画面が表示されます
- スタッフによる審査に入ります（数日かかる場合があります）
- **審査結果はメールでご連絡**します
- 承認されると、Shopify から**アカウント有効化のご案内メール**が届きます

### 4. アカウント有効化

- 招待メールの URL を開き、パスワードを設定します
- 有効化後、レンタルのご予約が可能になります
- URL の有効期限は**発行から30日間**です

:::tip[メールが届かない場合]
迷惑メールフォルダをご確認ください。30日以上経過している場合は、お手数ですがお問い合わせください。
:::

## 管理者向け：審査・承認

審査・承認は **[顧客管理](/customer-management/) 画面（`/customer-management`）の「承認待ち」タブ** で行います。タブを開くと **「承認待ちの会員申込」** という見出しで、審査待ちの申込件数と一覧が表示されます。

![顧客管理画面の「承認待ち」タブ（申込0件時の表示例）](/images/customer-management-approval.png)

### 審査待ちリスト

申込が届くと、スタッフ宛に通知メールが送信されます（申込者情報＋添付書類のURL付き）。「承認待ち」タブを開くと、審査待ちの申込が件数付きで一覧表示されます（例：「N件の申込が承認待ちです。行をクリックして詳細を確認し、承認/却下してください。」）。

### 承認フロー

1. **申込を開く** — 一覧の対象**行をクリック**して、詳細（申込者情報・添付書類）を表示します
2. **書類確認** — 名刺・身分証（Shopify Files に保存）が申込内容と整合しているか確認します
3. **承認** — **承認** を実行します
   - Shopify に顧客アカウントが作成されます
   - **「請求先へコピー」チェックボックス（デフォルトON）** — 申請者の基本情報からデフォルト請求先が1件自動作成されます（伝票作成に請求先が必須なため・[#1324](https://github.com/iziz-system/ease-rental-frontend/issues/1324)）。請求先を別に登録したい場合はチェックを外してください
   - 申込者へ**アカウント有効化URL付きの招待メール**が自動送信されます
4. **完了** — 申込者は招待メールからアカウントを有効化できます

### 却下

審査の結果お断りする場合は、詳細から **却下** を実行して記録に残します（申込者への自動通知はありません。個別にご連絡ください）。

:::caution[書類の取り扱い]
名刺・身分証は Shopify Files に保存され、審査時に確認できます。添付書類は個人情報を含むため、取り扱いにご注意ください。
:::

## Phase C：既存顧客の一括招待（会員制移行・#2342）

会員制への移行に伴い、**既存顧客**（旧システムから取り込んだ顧客マスタ）へアカウント有効化の招待メールを一括送信します。これは新規申込（上記フロー）とは別の経路です — 審査を経ず、Shopify の標準機能で一括送信します。

### 手順

1. Shopify admin > 設定 > 顧客アカウント で **legacy customer accounts** が有効であることを確認
2. Shopify 管理画面の顧客一覧を開き、招待対象を全選択
3. **「アカウント招待メールを送信」** を実行（Shopify 標準の「Customer account invitation」テンプレート）
4. 下記の文面を Shopify admin > 設定 > 通知 > Customer account invitation テンプレートに設定しておく

### 招待メール文面（既存顧客向け）

**件名:** `【EASE Rental】会員登録のご案内（アカウント有効化のお願い）`

```
{companyName} ご担当者様

平素は格別のお引き立てを賜り、厚く御礼申し上げます。

この度、ご予約手続きをよりご利用いただきやすくするため、
会員制のオンライン予約システム「EASE Rental」へ移行いたしました。
今後はお客様専用のアカウントから、24時間オンラインでご予約・ご確認いただけます。

つきましては、お手数ですが、下記URLよりアカウントの有効化（パスワード設定）を
お願い申し上げます。

{activationUrl}

【ご登録にあたってのお願い】
・1つのメールアドレスにつき登録できるアカウントは1つです。
　複数のアカウントを同一メールアドレスでご登録いただくことはできませんので、
　あらかじめご了承ください。（メールアドレスごとの登録となります）
・このURLの有効期限は発行から30日間です。期限が切れた場合は
　お手数ですが再度ご連絡ください。

ご不明な点がございましたら、本メールへのご返信にてお問い合わせください。
今後とも変わらぬご愛顧を賜りますようお願い申し上げます。

□■--------------------------------------------------------------
〒141-0031 東京都品川区西五反田3-1-1
TEL: 03-5759-8266　FAX: 03-5759-8262
サイト: http://www.iziz.co.jp
メールアドレス: shop@iziz.co.jp
営業時間: 9:30～18:30(月～金)・9:30～17:00(土)

```

:::caution[注意書き「メールアドレスごとの登録」の背景]
「1つのメールアドレスにつき1アカウント」は Shopify の仕様です。Phase B（既存顧客マスタ取り込み）で、同一メールアドレスの複数会社は**代表1件に集約**されています（法人優先→スコア高→コード昇順）。集約されなかった会社の担当者は別メールアドレスでの登録が必要なため、この注意書きで案内しています（#2342・問い合わせ削減が目的）。
:::

### 代替：BE スクリプトで送信

Shopify 管理画面の一括送信ではなく、BE スクリプト（`customerSendAccountInviteEmail` ループ）で送信することも可能です。その場合は上記文面を BE 側に実装します（現在は未実装・主経路は Shopify 標準テンプレート）。

## よくある質問

### 申込後に修正したい

> 申込ページから再度申込を行うと、**審査待ち（PENDING）の間** は最新の内容で上書きされます。それ以外の状態では上書きできず、状態に応じたメッセージが表示されます（[#2557](https://github.com/iziz-system/ease-rental-backend/issues/2557)）。承認済みの場合は「このメールアドレスはすでにアカウントが作成されています」と案内され、承認処理中・却下の場合は「このメールアドレスでは会員申込をお受けできませんでした」と案内されます（セキュリティ上、どちらの状態かはお知らせしません）。

### 承認までどのくらいかかりますか？

通常 数営業日以内です。内容によってはお時間をいただく場合があります。

### 招待メールの有効期限は？

発行から30日間です。期限切れの場合は再送信の依頼が必要です。
