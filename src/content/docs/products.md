## 概要

Shopifyと同期された商品データの閲覧・管理。商品検索、レンタル登録状況の確認、Shopify管理画面へのアクセスが可能。

## アクセス方法

- サイドバー: **顧客・商品・マスタ** > **商品管理**
- 直接URL: `/products`

## 画面構成

### 📋 新規SKU番号ガイド

Shopifyに新商品を追加する際、次に採番すべきSKUを生成・コピーできます。

1. **5桁のプレフィックス** を入力します（例: `10106`・カテゴリごとの接頭辞）
2. **検索** ボタンをクリックすると、そのプレフィックスの **次のSKU** が生成されます
3. **コピーアイコン** でクリップボードにコピーするか、**「Shopify新規登録画面を開く（SKUコピー済み）」** ボタンで Shopify の新規商品作成画面に直接進めます

### 商品一覧テーブル

| 項目 | 説明 |
|------|------|
| 商品ID | Shopify Product ID（**クリックでShopify管理画面を開く**） |
| SKU | Stock Keeping Unit |
| 商品名 | 商品タイトル |
| カテゴリ | 商品カテゴリ |
| 単価 | 基本価格 |
| 修理 | メンテナンス期間設定モーダルを開く |
| ステータス | 商品ステータス（active / archived / draft） |

> **🔧 メンテナンス期間設定（修理ボタン）:** 商品一覧の「修理」ボタンからメンテナンス期間設定モーダルを開けます。モーダルには商品名・SKU・バリアントが表示され、単一在庫商品（バリアントが "Default Title"）でも対象が判別できます。設定した期間中は対象商品の在庫が自動でロックされます。

## 手順

### 手順1: 新商品のSKUを取得

1. **顧客・商品・マスタ** > **商品管理** に移動
2. **📋 新規SKU番号ガイド** に5桁プレフィックスを入力して **検索**
3. 次のSKUが生成されるので、コピーアイコンでコピー（または「Shopify新規登録画面を開く」で直接進む）
4. Shopify管理画面で新商品を作成し、SKUフィールドに貼り付け

**期待される結果:**
- プレフィックスの命名規則に従ったSKUが採番される
- 連番が維持される

### 手順2: Shopify商品を同期

1. ページヘッダーの **Shopify商品を同期** ボタンをクリック
2. 同期完了まで待機
3. 商品一覧が自動的に更新

**期待される結果:**
- 同期完了の通知が表示
- 最新のShopifyデータが反映

### 手順3: 商品を検索

1. 検索ボックスにキーワードを入力
   - 商品ID / 商品名 / SKU / カテゴリ
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果がテーブルに表示

**期待される結果:** 条件に一致する商品が表示

### 手順4: Shopify管理画面で商品を開く

1. 商品一覧から対象商品を探す
2. **商品ID** をクリック（Shopify管理画面で開くリンク）
3. 新しいタブでShopify管理画面が開く

**期待される結果:**
- 新しいブラウザタブが開く
- Shopify商品編集ページが表示

### 手順5: ページ移動

1. 画面下部のページネーションを使用
2. **前へ** または **次へ** ボタンをクリック
3. 現在のページ番号が表示

## レンタル登録状況の確認

「レンタル登録（登録済み/未登録）」の状態は [マスタ管理 > 商品マスタ](/master-data/) で確認・編集します（この画面の一覧には含まれません）。

| ステータス | 説明 |
|------------|------|
| 登録済み | 日額が設定され、レンタル可能 |
| 未登録 | 日額未設定、レンタル予約に使用不可 |

## 確認チェックリスト

- [ ] 商品同期が正常に完了
- [ ] 検索で期待通りの結果が表示
- [ ] Shopify管理画面リンクが正常に動作
- [ ] ページネーションが正常に動作
- [ ] 登録済み商品に日額が表示

## 注意事項

- 商品データはEASE内では読み取り専用（編集はShopifyで行う）
- レンタル登録には**原則として日額設定が必須**ですが、旧システム（iziz）から移行した 0 円商品（`price=0` ＆ `daily_rate=0` で `rentable=true`）が約 600 件残存しています（GAP-PROD-ZERO-PRICE・実データ 634 件）。これらもレンタル対象として扱われますが、必要に応じて日額を設定し直してください
- 同期は手動実行（最新データを取得するには同期ボタンをクリック）
- 商品データにはレンタル設定用のShopifyメタフィールドが含まれる
- 商品マスタには週額・月額フィールドも存在しますが、**現在のレンタル計算では使用していません**（日額ベースのみで計算・GAP-PROD-DEAD-RATE）

## 在庫ロックの仕様（重要）

> 出典:  調査結果（2026-05-23）+ UAT 検証

### ロック解放の条件

レンタル商品の在庫ロックは以下のタイミングで解放されます:

| トリガー | 解放動作 |
|---------|---------|
| **返却完了 (`RETURN_COMPLETED` イベント)** | ✅ 解放される |
| **end_date 到達** | ❌ 解放されない |
| **伝票キャンセル** | ✅ `releaseInventoryBatch()` で一括解放 |

**重要:** 返却受付されない限り、end_date を過ぎても商品は引き続きロックされます。これにより、顧客がレンタル商品を持ったまま返却されていない期間も、別の顧客に同じ商品を予約させない仕様になっています。

### Shopify との同期方向

- **一方通行**: EASE Rental システムが在庫管理の本体（正しいデータの持ち主）
- Shopify の在庫数は **参照のみ**（システムから Shopify への自動反映はありません）
- Shopify 側の在庫数表示と、実際の予約可否は異なる場合があります

### 在庫判定の確認方法

| 用途 | 機能 |
|------|------|
| 期間内の予約可否 | 商品予約状況照会 (`/product-reservation-inquiry`) |
| 伝票作成時のリアルタイム判定 | 貸出伝票作成 (`/booking-compact`) の在庫チェック表示 |
| API レベル | `POST /bookings/validate-availability` |

### UI 表示の注意

商品予約状況照会のカレンダーには **end_date までの予約のみ表示** されます。
未返却で end_date を過ぎた商品のロック状態はカレンダー上では見えませんが、`validate-availability` API では正しくロック判定されます。
このため、新規予約フローでは「予約不可」と判定されることがあります。
