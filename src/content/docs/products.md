## 概要

Shopifyと同期された商品データの閲覧・管理。商品検索、レンタル登録状況の確認、Shopify管理画面へのアクセスが可能。

## アクセス方法

- サイドバー: **顧客・商品・マスタ** > **商品管理**
- 直接URL: `/products`

## 画面構成

### 📋 新規SKU番号ガイド

Shopifyに新商品を追加する際、次に採番すべきSKUを生成・コピーできます。

1. **5桁のプレフィックス** を入力します（例: `10106`・カテゴリごとの接頭辞）
2. **検索** ボタンをクリックすると、そのプレフィックスの **次のSKU** が生成されます
3. **コピーアイコン** でクリップボードにコピーするか、**「Shopify新規登録画面を開く（SKUコピー済み）」** ボタンで Shopify の新規商品作成画面に直接進めます

### 商品一覧テーブル

| 項目 | 説明 |
|------|------|
| 商品ID | Shopifyの商品ID（**クリックでShopify管理画面を開く**） |
| SKU | 商品を識別する番号 |
| 商品名 | 商品タイトル |
| カテゴリ | 商品カテゴリ |
| 単価 | 基本価格 |
| 修理 | メンテナンス期間設定モーダルを開く |
| ステータス | 商品の状態（現在は **有効** の商品のみ表示されます） |

> **🔧 メンテナンス期間設定（修理ボタン）:** 商品一覧の「修理」ボタンからメンテナンス期間設定モーダルを開けます。モーダルには商品名・SKU・バリアントが表示され、単一在庫商品（バリアントが "Default Title"）でも対象が判別できます。設定した期間中は対象商品の在庫が自動でロックされます。

## 手順

### 手順1: 新商品のSKUを取得

1. **顧客・商品・マスタ** > **商品管理** に移動
2. **📋 新規SKU番号ガイド** に5桁プレフィックスを入力して **検索**
3. 次のSKUが生成されるので、コピーアイコンでコピー（または「Shopify新規登録画面を開く」で直接進む）
4. Shopify管理画面で新商品を作成し、SKUフィールドに貼り付け

**期待される結果:**
- プレフィックスの命名規則に従ったSKUが採番される
- 連番が維持される

### 手順2: Shopify商品を同期

1. ページヘッダーの **Shopify商品を同期** ボタンをクリック
2. 同期完了まで待機
3. 商品一覧が自動的に更新

**期待される結果:**
- 同期完了の通知が表示
- 最新のShopifyデータが反映

### 手順3: 商品を検索

1. 検索ボックスにキーワードを入力
   - 商品ID / 商品名 / SKU / カテゴリ
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果がテーブルに表示

**期待される結果:** 条件に一致する商品が表示

### 手順4: Shopify管理画面で商品を開く

1. 商品一覧から対象商品を探す
2. **商品ID** をクリック（Shopify管理画面で開くリンク）
3. 新しいタブでShopify管理画面が開く

**期待される結果:**
- 新しいブラウザタブが開く
- Shopify商品編集ページが表示

### 手順5: ページ移動

1. 画面下部のページネーションを使用
2. **前へ** または **次へ** ボタンをクリック
3. 現在のページ番号が表示

## レンタル登録状況の確認

商品マスタ（[マスタ管理](/master-data/)）に「登録済み／未登録」のステータス列は**ありません**（2026年9月時点）。レンタル可能かどうかは、この画面の**日額（単価）が設定されているか**で確認してください（日額が未設定のものはレンタル予約に使用できません）。

## 確認チェックリスト

- [ ] 商品同期が正常に完了
- [ ] 検索で期待通りの結果が表示
- [ ] Shopify管理画面リンクが正常に動作
- [ ] ページネーションが正常に動作
- [ ] 登録済み商品に日額が表示

## 関連画面

| 画面 | 移動方法 |
|------|----------|
| 伝票作成 | レンタル商品を選択 |
| 予約状況照会 | 商品の空き状況を確認 |
| マスタデータ > 商品マスタ | 「詳細」で商品情報を確認。「在庫台数」でレンタル在庫台数を設定（日額の編集画面ではありません） |

## 注意事項

- 商品データはEASE内では読み取り専用（編集はShopifyで行う）
- レンタル登録には原則として日額設定が必要です。旧システムから移行した0円商品もレンタル対象として残っているため、必要に応じて日額を設定してください
- 同期は手動実行（最新データを取得するには同期ボタンをクリック）
- 商品データにはレンタル設定用のShopifyメタフィールドが含まれる
- **現在のレンタル料金は日額をもとに計算します。** 週額・月額は使用しません。

## 在庫ロックの仕様（重要）

> 出典:  調査結果（2026-05-23）+ UAT 検証

### ロック解放の条件

レンタル商品の在庫ロックは以下のタイミングで解放されます:

| トリガー | 解放動作 |
|---------|---------|
| **返却完了** | ✅ 解放される |
| **返却予定日を過ぎた** | ❌ 解放されない |
| **伝票キャンセル** | ✅ 解放される |

**重要:** 返却受付が終わるまで、返却予定日を過ぎても商品は引き続き確保されます。未返却の商品を別のお客様が予約することを防ぎます。

### Shopify との同期方向

- **一方通行**: EASE Rental システムが在庫管理の本体（正しいデータの持ち主）
- Shopify の在庫数は **参照のみ**（システムから Shopify への自動反映はありません）
- Shopify 側の在庫数表示と、実際の予約可否は異なる場合があります

### SKUごとのレンタル在庫台数（2026年9月追加）

- SKU（サイズ・枝番）ごとに **同時に貸し出せる台数（レンタル在庫台数）** を設定できます（[マスタ管理 > 商品マスタ > 在庫台数](/master-data/)・既定は1台）
- 未設定のSKUは、従来どおり **1台** として扱われます（既存商品の挙動は変わりません）
- 空き状況の判定（⚪/△/×）は「そのSKUの日ごとの予約数合計 vs 設定台数」で行われます。商品単位の表示は、各SKUの台数を合計したものです
- 同じSKUを複数台保有する商品は、枝番を個体ごとに切り直さず、台数を設定して運用します

### 在庫判定の確認方法

| 用途 | 機能 |
|------|------|
| 期間内の予約可否 | **商品予約状況照会** |
| 伝票作成時の判定 | **貸出伝票作成**の在庫チェック表示 |

### 画面表示の注意

商品予約状況照会のカレンダーには、返却予定日までの予約が表示されます。
未返却のまま返却予定日を過ぎた商品の確保状態は、カレンダー上では見えません。伝票作成時には在庫不足として判定されることがあります。

:::dev
旧システムから移行した0円商品には `price=0`、`daily_rate=0`、`rentable=true` のデータがあります。在庫解放は返却完了イベントまたは伝票キャンセルで行います。予約可否の最終確認は `POST /bookings/validate-availability` です。
:::
