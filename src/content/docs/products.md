> **パス:** `/products`
> **メニュー:** 在庫管理 > 商品

## 概要

Shopifyと同期された商品データの閲覧・管理。商品検索、レンタル登録状況の確認、Shopify管理画面へのアクセスが可能。

## アクセス方法

- サイドバー: **在庫管理** > **商品**
- 直接URL: `/products`

## 画面構成

### カテゴリ別SKUガイド

Shopifyに新商品を追加する際、適切なSKUを確認・コピーできます。

| 項目 | 説明 |
|------|------|
| カテゴリ | 商品カテゴリ名 |
| SKU Prefix | このカテゴリのSKU接頭辞 |
| 商品数 | カテゴリ内の商品数 |
| 最終SKU | 直近で使用されたSKU |
| 次のSKU | 新商品に推奨されるSKU（クリックでコピー） |

**ワンクリックコピー:**
- 操作列のコピーアイコンをクリック
- 次のSKUがクリップボードにコピーされます
- Shopify管理画面で新商品作成時に貼り付け

### 商品一覧テーブル

| 項目 | 説明 |
|------|------|
| 商品ID | Shopify Product ID |
| SKU | Stock Keeping Unit |
| 商品名 | 商品タイトル |
| カテゴリ | 商品カテゴリ |
| 単価 | 基本価格 |
| 日額 | レンタル日額 |
| レンタル登録 | 登録済み/未登録ステータス |
| ステータス | 商品ステータス |
| 最終同期 | 最終同期日時 |
| 操作 | Shopify管理画面で開く |

## 手順

### 手順1: 新商品のSKUを取得

1. **在庫管理** > **商品** に移動
2. カテゴリ別SKUガイドで該当カテゴリを探す
3. **次のSKU** 列のコピーアイコンをクリック
4. SKUがクリップボードにコピーされます
5. Shopify管理画面で新商品を作成
6. SKUフィールドに貼り付け

**期待される結果:**
- 「SKUをコピーしました」と通知が表示
- カテゴリの命名規則に従ったSKU
- 連番が維持される

### 手順2: Shopify商品を同期

1. ページヘッダーの **Shopify商品を同期** ボタンをクリック
2. 同期完了まで待機
3. 商品一覧が自動的に更新

**期待される結果:**
- 同期完了の通知が表示
- 最新のShopifyデータが反映

### 手順3: 商品を検索

1. 検索ボックスにキーワードを入力
   - 商品ID / 商品名 / SKU / カテゴリ
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果がテーブルに表示

**期待される結果:** 条件に一致する商品が表示

### 手順4: Shopify管理画面で商品を開く

1. 商品一覧から対象商品を探す
2. 操作列の外部リンクアイコンをクリック
3. 新しいタブでShopify管理画面が開く

**期待される結果:**
- 新しいブラウザタブが開く
- Shopify商品編集ページが表示

### 手順5: ページ移動

1. 画面下部のページネーションを使用
2. **前へ** または **次へ** ボタンをクリック
3. 現在のページ番号が表示

## レンタル登録ステータス

| ステータス | 説明 |
|------------|------|
| 登録済み | 日額が設定され、レンタル可能 |
| 未登録 | 日額未設定、レンタル予約に使用不可 |

## 確認チェックリスト

- [ ] 商品同期が正常に完了
- [ ] 検索で期待通りの結果が表示
- [ ] Shopify管理画面リンクが正常に動作
- [ ] ページネーションが正常に動作
- [ ] 登録済み商品に日額が表示

## 関連画面

| 画面 | 移動方法 |
|------|----------|
| 伝票作成 | レンタル商品を選択 |
| 予約状況照会 | 商品の空き状況を確認 |
| マスタデータ > 商品マスタ | レンタル設定を編集 |

## 注意事項

- 商品データはEASE内では読み取り専用（編集はShopifyで行う）
- レンタル登録には日額設定が必須
- 同期は手動実行（最新データを取得するには同期ボタンをクリック）
- 商品データにはレンタル設定用のShopifyメタフィールドが含まれる
