# 返却・金額確定処理

レンタル商品の返却受付から金額確定までを行う画面です。
次の作業を行います。

1. **返却予定伝票の返却受付** — 返却日、延長料、破損状況を記録
2. **返却期限超過伝票の対応** — 延滞している伝票の処理
3. **返却済み伝票の金額確定** — 最終的な請求金額を確定
4. **請求済伝票の管理** — Shopify送信済み・入金待ちの伝票

このページの「本体分」は、商品を予約したときのレンタル料の請求を指します。後払いでは配送料などもまとめます。

## この画面を開くには

- サイドバーの **「返却・金額確定」** をクリック

## 操作手順

### ステップ1: 返却受付を行う

1. **「返却予定一覧」** または **「超過一覧」** タブを開きます
2. 返却する伝票の **「↩️ 返却受付」** ボタンをクリックします
3. 返却受付モーダルが開きます

> **💡 社内確保の伝票も返却受付できます:** [社内確保](/internal-hold/)の伝票も、通常の伝票と同じように返却受付を行ってください。「返却受付を確定」すると、0円のまま自動で金額確定・完了します（金額確定の操作は不要です）。

![返却予定一覧](/images/bookings-return/br-02-pending-list.png)

#### 返却受付モーダル

![返却受付モーダル](/images/bookings-return/br-03-return-modal.png)

モーダル上部には伝票情報が表示されます。

| 項目 | 説明 |
|------|------|
| 伝票番号 | リンクをクリックすると伝票詳細に遷移 |
| 顧客名 | 顧客の担当者名 |
| 会社名 | 顧客の会社名 |
| 返却予定日 | 元の返却予定日 |

**返却日の設定:**

- 返却日を入力します（デフォルトは今日）
- 返却予定日より遅い日付を入力すると、**延長料金が自動計算**されます
- **貸出開始日または返却予定日より前**の日付を入力して受付しようとすると、**「日付に誤りがないか確認してください」の確認ダイアログが表示されます**（2026年9月追加）。前倒し返却など正当なケースもあるため受付を止めるものではなく、日付の打ち間違いに気づくための確認です。問題なければそのまま続行できます

**商品ごとの設定:**

| 項目 | 説明 |
|------|------|
| チェックボックス | 返却対象に含めるかどうか（全選択/全解除あり） |
| 商品名 | 商品名（「商品ページ↗」リンクでShopify商品ページを開く） |
| SKU | 在庫管理コード |
| 返却予定日 | 元の返却予定日 |
| 実際の返却日 | 実際の返却日 |
| 延長日数 | 延長した日数（自動計算） |
| 延長料金 | 延長料金（自動計算） |
| 破損詳細 | 破損状況の説明（テキスト入力） |
| 🔧 メンテ登録 | メンテナンス期間設定ページへ遷移し、対象商品を自動検索してモーダルを開く（一覧の1ページ目に対象がなくても自動で検索）。見つからない場合は通知が出ます |

> **⚠️ 重要:** 延長日数・延長料金は営業日ベースで計算されます。返却日を変更するとリアルタイムで再計算されます。

**料金内訳:**

モーダル下部にリアルタイムの料金内訳が表示されます。

| 項目 | 説明 |
|------|------|
| レンタル料金（税込） | 商品の基本レンタル料金 |
| 延長料金（適用済み） | 金額確定済みの延長料金（確定済み分がある場合のみ表示） |
| 延長料金合計 | 今回の返却受付で発生した延長料金の合計 |
| **今回の追加料金合計** | **延長料金合計（破損料金・調整項目は金額確定モーダルで集計）** |

> **💡 メモ:** 配送料など他の追加料金は次の「金額確定」画面で設定します。

> **⚠️ 破損・紛失の料金はこの画面の金額に含まれません（2026年9月追加）:** 返却状態に「良好」以外（軽微破損・重大破損・紛失）を選んだ商品があるとき、料金内訳の下に案内が表示されます。
>
> 「⚠ 破損・紛失を選んだ商品の料金は、この画面の金額には含まれません。次の「金額確定」画面の「調整項目」で入力してください。」
>
> 破損の修理・廃棄料金や紛失料金は、次のステップ3の金額確定モーダルで **調整項目** として入力してください（すべて「良好」のときは案内は表示されません）。

#### 調整項目の追加

![調整項目モーダル](/images/bookings-return/br-04-adjustment-modal.png)

**金額確定モーダル**（ステップ3）の料金内にある **「調整項目」** セクション（黄枠・合計金額付き）の **「編集」** ボタンをクリックすると、調整項目モーダルが開きます。

:::tip[返却受付以降〜金額確定前のみ追加可能]
調整項目（マイナス含む）は **返却受付以降〜金額確定前** のタイミングでのみ追加できます。返却受付前の伝票では追加ボタンが押せず、案内「返却受付前の伝票には調整項目を追加できません。料金を追加する場合はカスタム商品、値引きは伝票値引きをご利用ください」が表示されます。金額確定後は伝票が修正ロックされ、調整項目の追加・変更はできません。

**金額確定後** に返金が必要になった場合は、[返金処理の「金額確定後に返金が必要な場合」](/refund/#金額確定後に返金が必要な場合) を参照してください。
:::

**追加できる項目の種類（4種）:**

| 種類 | 用途 |
|------|------|
| 破損・修理 | 破損商品の修理料金 |
| 破損・廃棄 | 破損商品の廃棄料金 |
| 紛失 | 商品紛失の請求 |
| その他調整 | 上記以外の追加料金・値引き |

> **⚠️ 駐車場代・高速利用料金は課金廃止:** 駐車場代・高速代の請求は廃止され、新規追加はできません（既存データに含まれる場合は表示のみ）。

> **💡 値引きはマイナス金額で入力:** 調整項目は金額の符号で課金（+）と値引き（−）を区別します。

**入力項目:**

| 項目 | 説明 |
|------|------|
| 種類 | 上記のプルダウンから選択 |
| 金額 | 金額を入力（円・値引きはマイナス） |
| 説明 | 調整理由を入力（顧客向けに転載されるため適切な文言を） |
| 担当者 | 操作担当者を選択 |

> **⚠️ 最大5項目:** 1回の金額確定で追加できる調整項目は最大5件です。

> **💡 追加・削除は即時に保存されます（2026年9月変更）:** 調整項目モーダルで「項目を追加」を押した時点で保存されます。ダイアログ下部のボタンは「キャンセル」ではなく **「閉じる」** で、閉じても追加・削除は取り消されません（モーダルの合計金額の下にも同じ注記が表示されます）。

> **💡 社内確保の伝票には追加できません:** [社内確保](/internal-hold/)の伝票では、調整項目は追加できません（料金が発生しないためです）。

4. 入力が終わったら **「返却受付を確定」** ボタンをクリックします

#### 一括返却受付

一覧で複数の伝票を選択すると、まとめて返却受付ができます。

1. 返却受付する伝票を複数選択します
2. **「一括返却受付」** ボタンをクリックします
3. 担当者入力ポップアップが表示されるので、受付担当者の **氏名** を入力します
4. 確定すると、入力した氏名が受付担当者として各伝票に記録されます

> **💡 メモ:** 一括受付では延長料金の計算は自動で行われるため、伝票ごとの延長日数入力は省略されます。

> **💡 日付の確認ダイアログ:** 一括返却でも、返却予定日より前の日付で受付する伝票が含まれる場合は、個別受付と同じ「日付に誤りがないか確認してください」の確認が表示されます（2026年9月追加）。

### ステップ2: 超過伝票の対応

![超過一覧](/images/bookings-return/br-05-overdue-tab.png)

返却期限を過ぎている伝票は **「超過一覧」** タブに表示されます。

**操作は返却予定一覧と同じです：**

1. 対象伝票の **「↩️ 返却受付」** ボタンをクリック
2. 返却日を入力（延長料金が自動計算されます）
3. **「返却受付を確定」** をクリック

> **💡 メモ:** 出荷済みの伝票のみ超過一覧に表示されます。未出荷の伝票は「返却できない」ため表示されません。

---

### ステップ3: 金額を確定する

![金額確定待ち一覧](/images/bookings-return/br-06-confirmation-tab.png)

返却受付済みの伝票は **「金額確定待ち一覧」** タブに移動します。

> **💡 返却日を修正する:**
> 返却受付後〜金額確定前であれば、金額確定待ち一覧の **「✏️ 返却受付を修正」** ボタンから返却日と明細を再編集できます。返却日を変更すると延長料金が自動で再計算されます（延長が後から判明した場合などにご利用ください）。破損状況などの明細内容も再設定できます。金額確定後は修正できません（確定後の変更は「金額確定解除」から行ってください）。

1. **「金額確定待ち一覧」** タブを開きます
2. 金額を確定する伝票の **「💰 金額確定」** ボタンをクリックします
3. 金額確定モーダルが開きます

![金額確定モーダル](/images/bookings-return/br-07-amount-confirm-modal.png)

**金額確定モーダルで確認・設定する項目:**

- 返却時の延長料金・破損料金の最終確認
- 配送料の追加（未設定の場合）
- 調整項目の追加・修正
- 最終金額の確認

値引きがある場合は、**「伝票値引き（税込）」**を確認します。今回の試算で適用後の値引きがまだ得られていない場合は、**「入力値引き（税込）」**と表示されます。過去の請求書の値引きではなく、今回の試算内容を確認してください。

4. 内容を確認し **「金額を確定」** ボタンをクリックします

**支払方法ごとの注記（2026年9月変更）:**

金額確定モーダルの請求金額の下には、支払方法に応じて次の内容を確認できます。

| 支払方法 | 注記 |
|---------|------|
| Shopify（クレジットカード） | 決済用の請求に反映されます。配送料を別に請求済みの伝票では、その配送料を本体分へ重ねません |
| 銀行振込 | 請求書に反映されます |
| 店頭支払い・現金など | 確定内容として保存され、請求書を発行するときに反映されます |

> **⚠️ 請求金額が0円の伝票は確定できません（2026年9月変更）:** 0円のまま「金額を確定」を押すと、次の案内が表示されて確定できません。
>
> 「請求金額が0円のため、この伝票は確定できません。0円で終わらせたい伝票は「伝票キャンセル」で処理してください。商品の料金に間違いがある場合は、料金を直してからもう一度確定してください。」
>
> お客様への全額免除（0円の貸し出し）は行わない運用です。在庫だけ押さえておきたい社内利用の伝票は、予約種別 **[「社内確保」](/internal-hold/)** で作成してください。
>
> なお、0円のまま金額確定された伝票（社内確保など）は、最終明細の確定時に **入金・請求書なしで自動的に完了** します（2026年9月変更）。

#### 確定した金額を直す

1. **「請求済一覧」**タブで対象伝票を探します。
2. **「↩ 金額確定解除」**をクリックします。
3. 確認画面の内容を確認して解除します。
4. **「金額確定待ち一覧」**に戻った伝票を開き、調整項目や返却内容を修正します。
5. 再度**「金額を確定」**をクリックします。

- **請求書が発行済みの伝票は解除できません。** 先に[請求書・領収書管理](/invoices-list/)で請求書を取り消してください。
- **入金済みの伝票も解除できません。** 返金を実行しても、解除はできません。

#### 銀行振込の自動請求書

すべての商品の金額確定が終わると、請求書を自動発行し、PDFを添付したメールを請求先へ送ります。一部の商品が未確定の間は送られません。

- **まとめ請求の対象:** 個別の請求書は自動発行しません。月次の[会社まとめ請求](/consolidated-invoices/)で処理します。
- **すでに入金済み:** 請求書は自動発行しません。
- 発行した請求書は[請求書・領収書管理](/invoices-list/)で確認できます。

#### 合計がマイナスで確定できない

値引き・調整項目・配送料を確認し、修正してから金額確定をやり直してください。マイナスのままでは請求書の発行・送信やカード請求も進められません。

### ステップ4: 請求と入金を確認する

#### まだカード支払いがない場合

金額確定に合わせて、決済リンク付きメールが自動送信されます。手動の請求書送付は不要です。お客様が支払うと入金が自動で反映されます。

画面に「延長料・損料などの確定金額は、お客様の支払い時に自動でレンタル料と1枚の請求にまとまります」と表示された場合は、その案内に従ってください。

#### すでにカード支払いがある場合

金額確定後に追加料金があり、**「📝 追加請求を作成」**が表示される場合は、次の操作を行います。

1. 追加請求する金額を確認します。
2. **「📝 追加請求を作成」**をクリックします。
3. 請求の作成状況を確認します。お客様は決済リンク付きメールから支払います。

未決済の追加請求は**「🗑️ 追加請求を取消」**で取り消せます。決済済みの請求は取り消せません。

#### 銀行振込

通常は金額確定時に請求書が自動発行・送信されます。画面には**「送信済み」**と表示されます。まとめ請求対象・入金済みなどの案内も確認してください。

入金は[請求書・領収書管理](/invoices-list/)や[未入金一覧・入金処理](/payment-management/)で登録します。

#### 店頭支払い

受け取った代金を[未入金一覧・入金処理](/payment-management/)で登録します。手動の完了ボタンはありません。返却・金額確定・入金などの必要な処理がそろうと、自動的に完了します。

#### 前倒し請求後の返却

前倒し請求や入金が済んでいても、返却受付は必要です。通常どおり返却受付と金額確定を行ってください。すでに支払い済みの金額は重ねて請求せず、前倒し請求後の延長料などを確認し、追加分を精算します。追加料金が回収済みで、未決済の別請求もなければ完了します。未回収の追加料金や未決済の別請求が残っている間は完了しません。

## 延長料金計算ルール

延長料金は **元の貸出期間を含めた累積日数** で料率が決まります。延長日数だけを1日目から数え直すのではありません。

**計算式:**

```
延長料金 = 延長後の貸出日数で計算したレンタル料金
         − 元の貸出日数で計算したレンタル料金
```

- 元の貸出日数は、貸出開始日から元の返却予定日までの営業日数です。
- 料率は「貸出開始日からの累積日数」で決まります。

**累積日数ごとの料率:**

| 累積日 | 料率 |
|-------|------|
| 1日目 | 基本料金 × 100%（初日基数・延長日には適用されません） |
| 2-6日目 | 基本料金 × 20%/日 |
| 7日目以降 | 基本料金 × 10%/日 |

> **⚠️ 重要:** 延長1日目の料率は 元の貸出日数により変わります。元の貸出日数が1日なら延長1日目は「2日目=20%」ですが、元の貸出日数が6日なら延長1日目は「7日目=10%」になります。「延長1日目=必ず20%」は 元の貸出日数が1日の場合のみ成立します。

**例（基本料金10,000円）:**

| 元の貸出期間 | 延長日数 | 計算 | 延長料金 |
|----------------------|---------|------|---------|
| 1日 | 1日 | 2日目の20% | +2,000円 |
| 5日 | 2日 | 6日目(20%) + 7日目(10%) | +3,000円 |

## トラブルシューティング

### 一部返却について

- 同一伝票の複数商品を複数回に分けて返却可能
- 伝票No.の横に **「一部返却済」** ラベルで進捗確認可

### よくあるエラー

| エラーメッセージ | 原因 | 対処 |
|----------------|------|------|
| 返却する商品を選択してください | 商品が未選択 | チェックボックスで返却対象を選択 |
| 返却日を入力してください | 返却日未入力 | 返却日フィールドに日付を入力 |
| 以下の商品の返却処理に失敗しました | 通信エラー | 再度実行、または個別に処理 |

## 検証チェックリスト

- [ ] 返却受付日が正しく設定されている
- [ ] 返却数量が貸出数量以下
- [ ] 破損がある場合、破損詳細と料金が入力されている
- [ ] 調整項目の説明欄が顧客向け文言として適切（お客様の請求明細にも表示される）
- [ ] 料金内訳の合計が正しい
- [ ] クレカ顧客で追加請求がある場合、「📝 追加請求を作成」を実行済み
- [ ] 銀行振込の場合、自動発行された請求書、またはまとめ請求の対象であることを確認済み
