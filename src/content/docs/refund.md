## 概要

支払済みの伝票に対して、**払い過ぎ・一部キャンセル・誤請求**などの理由で顧客にお金を返す操作です。返金は伝票編集画面の「料金・支払」セクションにある **「返金を記録」** ボタンから行います。

返金方法は2系統あり、**裏側の挙動が異なります**。

| 返金方法 | 何が起きるか | 対象の支払方法 |
| --- | --- | --- |
| **Shopify(クレカ)** | Shopify の返金API（`refundCreate`）を呼び、**実際にクレジットカードへ返金**される | クレカ決済（`shopify` / `credit_card` / `shopify_credit`） |
| **現金** | EASE に**記録するだけ**。実際の返金は店頭・振込など**オフラインで別途**行う | 現金・銀行振込・その他 |

> **重要:** Shopify 側の管理画面で直接返金しても EASE には同期されません（返金用の Webhook がないため）。**返金は必ず EASE から実行**してください（EASE → Shopify の順で反映されます）。

## アクセス方法

1. **伝票検索**（`/slip-search`）で対象の伝票を検索
2. 伝票No. の横の **詳細アイコン**（または「詳細」ボタン）で伝票編集画面を開く
3. 画面下部の **「料金・支払」** セクションへスクロール
4. **「返金」** 行の **「返金を記録」** ボタンをクリック

---

## 操作手順

### 1. 返金額を入力

- 返金したい金額を**円単位**で入力します。
- 「**全額（◯◯）**」ボタンで入金済み金額をワンクリック入力できます。
- 入金済み金額（残高）を**超える額は返金できません**。

### 2. 返金方法を選択

| 選択肢 | 用途 |
| --- | --- |
| **現金** | 店頭返金・銀行振込など、Shopify を通さないオフライン返金の**記録** |
| **Shopify(クレカ)** | クレジットカードへの**実返金**（Shopify API 経由） |

> 未選択の場合は、伝票の**支払方法から自動判定**されます（クレカ決済なら Shopify、それ以外なら現金記録）。

### 3. 返金理由を入力

- 例:「一部キャンセルによる払い過ぎ返金」
- 経理・監査のため、**理由は具体的に**記入してください。

### 4. 顧客への通知（任意）

- 「**顧客に返金通知メールを送信する**」にチェックを入れると、返金完了時に顧客へメールが送られます。

### 5. 「返金を記録」をクリック

- ボタンを押すと返金が実行され、**返金履歴**に記録されます。

## 入力項目一覧

| 項目 | 種類 | 必須 | 説明 |
| --- | --- | --- | --- |
| 返金額 | 数値（円） | はい | 入金済み残高以内 |
| 返金方法 | ラジオ（現金 / Shopify(クレカ)） | 任意 | 未選択時は支払方法から自動判定 |
| 返金理由 | テキスト | 推奨 | 監査・経理のため具体的に |
| 顧客に返金通知メールを送信する | チェックボックス | 任意 | チェック時のみ送信 |

## 返金履歴の見方

「料金・支払」セクションの下に **返金履歴** が一覧表示されます。

![返金履歴の表示](/images/refund-history.png)

| 表示 | 意味 |
| --- | --- |
| （マークなし） | **成功（COMPLETED）** — 返金が成立 |
| **（FAILED）** | **失敗** — 返金は成立していない（後述の原因を確認） |

ヘッダーのバッジは伝票全体の返金状況を表します:

| バッジ | 意味 |
| --- | --- |
| 未払い | 返金実績なし |
| 一部返金 | 入金額の一部を返金済み |
| 全額返金 | 入金額の全額を返金済み |

## よくある失敗と対処

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| Shopify(クレカ)返金が `parent_id` エラーで失敗 | 元のクレジットカード決済（親トランザクション）が特定できていない | 旧バージョンでの既知不具合。最新バージョンでは解消済み（元決済を自動特定して返金） |
| 「返金対象の元決済トランザクションが見つかりません」 | その注文に Shopify 上の**成功した決済（SALE/CAPTURE）が存在しない** | クレカ実決済が行われた注文か確認。未決済・キャンセル済み注文は Shopify 返金不可 |
| 現金返金したのにクレカに返金されない | 「現金」は**記録のみ**でオフライン返金が前提 | クレカに実返金したい場合は「**Shopify(クレカ)**」を選ぶ |
| Shopify 管理画面で返金したが EASE に反映されない | 返金用 Webhook が無く同期されない | **EASE から返金を実行**する |

---

## 注意点

- **返金は必ず EASE から**実行してください（Shopify 直返金は同期されません）。
- **Shopify(クレカ)返金は実際にカードへ返金**されます。テスト時も含め、金額・対象を十分確認してから実行してください。
- 入金済み残高を**超える返金はできません**。
- 失敗（FAILED）の記録が残っても**実際の返金は発生していません**。原因を解消して再実行してください。
