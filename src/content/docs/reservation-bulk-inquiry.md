> **パス:** `/reservation-bulk-inquiry`
> **メニュー:** 予約管理 > 予約状況一括照会

## 概要

複数予約の一括管理・ステータス確認を行う業務効率化ダッシュボードです。予約検索と商品コード検索の2つのタブを切り替えて使用します。

## アクセス方法

- サイドバーから: 「予約管理」>「予約状況一括照会」をクリック
- URL直接: `/reservation-bulk-inquiry`

## 画面構成

### タブナビゲーション

| タブ | 説明 |
|------|------|
| 予約検索 | 予約情報を条件で検索 |
| 商品コード検索 | SKUを一括入力して在庫・予約状況を確認 |

---

## タブ1: 予約検索

### 統計情報カード

| 項目 | 説明 |
|------|------|
| 総予約数 | 現在の検索条件での総件数 |
| 処理中 | PROCESSINGステータスの予約数 |
| 請求待ち | BILLING_PENDINGステータスの予約数 |
| 緊急対応 | 2日以内に開始する予約数 |

### 検索条件モーダル

「検索条件を設定」ボタンをクリックすると表示されます。

| 項目 | 種類 | 説明 | 必須 |
|------|------|------|------|
| 開始日 | 日付 | レンタル開始日のフィルタ | - |
| 終了日 | 日付 | レンタル終了日のフィルタ | - |
| ステータス | セレクト | 予約ステータスでフィルタ | - |
| 予約種別 | セレクト | 仮予約/通常注文/ドラフトオーダー | - |
| 顧客名・電話番号 | テキスト | 顧客情報で検索 | - |
| 商品ID | テキスト | 商品IDでフィルタ | - |
| 緊急対応のみ表示 | チェックボックス | 2日以内開始のみ表示 | - |

#### ステータス選択肢

| 値 | ラベル |
|----|--------|
| (空) | すべて |
| PROCESSING | 処理中 |
| BILLING_PENDING | 請求待ち |
| PAYMENT_PENDING | 入金待ち |
| COMPLETED | 完了 |
| CANCELLED | キャンセル |

### 検索結果テーブル

| 項目 | 説明 |
|------|------|
| 予約ID | 予約の一意識別子（顧客電話番号も表示） |
| 優先度 | 緊急/要注意/通常 |
| ステータス | 予約の現在ステータス |
| 商品ID | Shopify商品ID |
| レンタル期間 | 開始日〜終了日（日数も表示） |
| 開始まで | レンタル開始までの日数 |
| 金額 | レンタル金額（高額案件は「高額」表示） |
| 支払状況 | 完済/未払い |

### ソート機能

「開始日順」「金額順」「作成日順」「ステータス順」から選択可能。昇順/降順を切り替え可能。

### ページネーション

- 1ページあたり50件表示
- ページ番号をクリックして移動

## タブ2: 商品コード検索

### 検索フォーム

| 項目 | 種類 | 説明 | 必須 |
|------|------|------|------|
| 貸出希望日(開始) | 日付 | 希望する貸出開始日 | - |
| 貸出希望日(終了) | 日付 | 希望する貸出終了日 | - |
| 貸出可能なもののみ表示 | チェックボックス | 在庫あり・予約なしのみ表示 | - |
| 商品コード | テキストエリア | 1行につき1つの商品コードを入力（最大100個） | はい |

### 検索結果テーブル

| 項目 | 説明 |
|------|------|
| 商品コード | 商品のSKU（クリックで伝票作成画面へ） |
| 商品名 | 商品の名称 |
| 在庫数 | 現在の在庫数 |
| 予約 | ○: 予約なし / △: 予約あり |
| 予約被り伝票No. | 指定期間で重複する予約の伝票番号 |
| 単価 | 商品の単価 |

### 見つからないSKUの警告

入力した商品コードの一部が見つからない場合、黄色い警告ボックスに該当SKUが表示されます。

## 操作手順

### 手順1: 予約検索を実行する

1. 「予約検索」タブが選択されていることを確認
2. 「検索条件を設定」ボタンをクリック
3. 検索条件を入力
4. 「検索」ボタンをクリック
5. 検索結果がテーブルに表示されます

**期待される結果:**
- 検索条件に一致する予約が表示される
- 統計情報カードが更新される

### 手順2: 検索結果をCSVエクスポートする

1. 検索結果が表示されている状態で「CSVエクスポート」ボタンをクリック
2. CSVファイルがダウンロードされます

**期待される結果:**
- `予約状況一括照会_{日付}.csv` ファイルがダウンロードされる

### 手順3: 商品コード検索を実行する

1. 「商品コード検索」タブをクリック
2. 貸出希望日を入力（任意）
3. 商品コードを1行につき1つ入力
4. 必要に応じて「貸出可能なもののみ表示」にチェック
5. 「検索」ボタンをクリック

**期待される結果:**
- 入力した商品コードの在庫・予約状況が表示される
- 見つからないSKUがある場合は警告が表示される

### 手順4: 商品から伝票を作成する

1. 検索結果の商品コードリンクをクリック
2. 新しいタブで伝票作成画面が開きます

**期待される結果:**
- 新しいタブで `/booking-compact?product={SKU}` が開く
