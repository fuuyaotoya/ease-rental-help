## 概要

個別の請求書を作成します。主に支払方法が「振込」の顧客に対して、未請求の伝票をまとめて請求書として発行します。領収書の作成もこの画面から行えます。

## アクセス方法

- サイドバーから: **請求・入金 > 請求書作成**
- URL直接: `/invoice/create-new`
- 他画面から: 金額確定完了後のリンク、請求一覧の「領収書作成」ボタン

## 画面構成

### タブ構成

| タブ名 | 説明 |
|--------|------|
| 請求書作成 | 新規請求書の作成（6ステップ） |
| 請求書解除 | 既存請求書の解除（キャンセル）処理 |

### 請求書作成のステップ

| ステップ | 名称 | 内容 |
|----------|------|------|
| 1 | 顧客選択 | 請求先顧客の検索・選択 |
| 2 | 伝票選択 | 未請求伝票の選択 |
| 3 | 請求先情報 | 請求先住所・担当者の確認 |
| 4 | 請求情報 | 発行日・支払期限等の設定 |
| 5 | 内容確認 | 請求内容の最終確認 |
| 6 | 完了 | 請求書番号の発行・PDF出力 |

## 操作手順

### 手順1: 顧客選択（ステップ1）

1. 検索条件を入力:
   | 項目 | 種類 | 説明 | 必須 |
   |------|------|------|------|
   | 貸出先コード | テキスト | 顧客コードで検索 | - |
   | 会社名 | テキスト | 会社名で検索（部分一致） | - |
   | 部署 | テキスト | 部署名で検索（部分一致・同一会社の複数部署を区別） | - |
   | 担当者名 | テキスト | 担当者名で検索 | - |
   | 電話番号 | テキスト | 電話番号で検索 | - |
   | 請求先会社名 | テキスト | 請求先マスタの会社名で検索（部分一致） | - |
   | 請求先部署 | テキスト | 請求先マスタの部署名で検索（部分一致） | - |
2. 「検索」ボタンをクリック
3. 検索結果から顧客を選択
   - 結果カードには顧客の部署・請求先（会社名＋部署）が表示され、同一会社の複数部署を区別して選択できます
4. 「次へ」ボタンをクリック

**期待される結果:**
- 顧客情報が設定される
- 請求先住所が自動的に読み込まれる

### 手順2: 伝票選択（ステップ2）

1. 検索条件でフィルタ:
   | 項目 | 種類 | 説明 | 必須 |
   |------|------|------|------|
   | 伝票種別 | セレクト | すべて/レンタル/配送/キャンセル | - |
   | 期間（開始） | 日付 | 貸出日または返却日の開始日 | - |
   | 期間（終了） | 日付 | 貸出日または返却日の終了日 | - |
   | 支払方法 | セレクト | デフォルト: 銀行振込 | - |
2. 未請求伝票一覧から請求対象を選択（チェックボックス）
3. 選択した伝票の合計金額を確認
4. 「次へ」ボタンをクリック

**表示項目:**
- 伝票番号
- 借出先（担当者名）
- 貸出日〜返却日
- 利用料金（税込）
- 前受金
- 請求済額
- 今回請求額

**期待される結果:**
- 選択した伝票の合計金額が表示される
- 消費税が自動計算される

### 手順3: 請求先情報（ステップ3）

請求先情報を確認・編集します。

| 項目 | 種類 | 説明 | 必須 |
|------|------|------|------|
| 請求先名 | テキスト | 請求先の会社名/団体名 | Yes |
| 担当者名 | テキスト | 請求先担当者 | - |
| 部署名 | テキスト | 部署名 | - |
| 郵便番号 | テキスト | 例: 123-4567 | - |
| 都道府県 | セレクト | 都道府県選択 | - |
| 市区町村 | テキスト | 市区町村 | - |
| 番地 | テキスト | 番地 | - |
| 建物名 | テキスト | 建物名・部屋番号 | - |
| 電話番号 | テキスト | 連絡先電話番号 | - |
| FAX | テキスト | FAX番号 | - |
| メール | テキスト | メールアドレス | - |
| 締日 | 数値 | 月次請求の締日（1-31） | - |
| サイト | 数値 | 締日後の支払サイト（日数） | - |
| 備考 | テキストエリア | 請求先に関する備考 | - |

**請求先住所の選択:**
- 顧客に複数の請求先が登録されている場合、ドロップダウンから選択可能
- 選択すると住所情報が自動入力される

### 手順4: 請求情報（ステップ4）

請求書の発行情報を設定します。

| 項目 | 種類 | 説明 | 必須 |
|------|------|------|------|
| 請求書種別 | セレクト | レンタル/配送/キャンセル | Yes |
| 支払条件 | セレクト | 銀行振込/現金/クレジット | Yes |
| 発行日 | 日付 | 請求書発行日 | Yes |
| 請求月 | 月 | 請求対象月（YYYY-MM形式） | - |
| 支払期限 | 日付 | 支払期限日 | - |
| 備考 | テキストエリア | 請求書に記載する備考 | - |

**発行者情報・振込先:**
- 発行者情報（会社名、住所、電話番号等）
- 振込先口座情報（銀行名、支店名、口座番号等）

### 手順5: 内容確認（ステップ5）

請求内容の最終確認を行います。

**確認項目:**
- 請求先情報
- 請求明細（伝票番号、商品名、金額）
- 小計
- 消費税
- 合計金額
- 発行情報

**この画面でできること:**
- 「戻る」ボタンで前のステップに戻って修正
- 「PDFプレビュー」で印刷イメージ確認

### 手順6: 完了（ステップ6）

1. 「請求書を作成」ボタンをクリック
2. 請求書が作成され、請求書番号が発行されます
3. 以下のアクションが可能:
   - **PDFダウンロード**: 請求書PDFをダウンロード
   - **請求一覧へ**: 請求一覧画面へ遷移
   - **新規作成**: 別の請求書を作成

**期待される結果:**
- 請求書が作成される
- 請求書番号が表示される
- 選択した伝票が「請求済み」に更新される

## 請求先未登録チェック

請求書作成ウィザードとは別に、画面上に「**請求先未登録チェック**」パネル（ amber 色）があります。これは請求漏れを防ぐための安全網で、未請求かつ請求先マスタが未登録の伝票を全顧客横断で抽出します。

### 使い方

1. 「請求先未登録チェック」ボタンをクリック
2. 抽出された伝票一覧（伝票No・借主・期間・操作）を確認
3. 各行の「**伝票を開いて請求先を登録**」リンクから該当伝票（伝票詳細画面）を開き、請求先を登録してください

**注意:**
- 対象は銀行振込の伝票のみです
- 上限100件まで表示されます。上限を超える場合は「上限 100 件まで表示しています」の注記が表示されます
- 請求先未登録の伝票がない場合は「請求先未登録の未請求伝票はありません。」と表示されます

## 請求書解除

作成済みの請求書を取り消す（解除する）場合に使います。請求書番号で検索して解除します。

> 請求書データ自体は**削除されず**、ステータスが「キャンセル」に変更されます。紐づく伝票は「請求書作成済」（請求書未送信）ステータスに戻り、再び請求対象として選択できるようになります。

### 手順: 請求書解除

1. 画面上部の「**請求書解除**」タブをクリック
2. 「請求書番号」に解除したい請求書番号を入力（例: `I260401001`）
3. 「**請求書情報呼出し**」ボタンをクリック
4. 表示された請求書情報（ステータス・顧客名・作成日・発行日・支払期限・小計・消費税・合計金額）と関連伝票一覧を確認
5. 「**請求書情報解除**」ボタンをクリック
6. 確認ダイアログで「**解除実行**」をクリック

**期待される結果:**
- 請求書のステータスが「キャンセル」に変更される（データは削除されない）
- 紐づいていた伝票が「請求書作成済（BILLING_PENDING）」に戻る

### 解除できないケース

以下の請求書は「請求書情報解除」ボタンが無効化し、理由が表示されます。

| ケース | 表示される理由 |
|--------|----------------|
| 入金処理済み | 入金処理済みの請求書は解除できません |
| 既に解除済み | この請求書は既に解除（破棄）されています |

> 入金済みの請求書を取り消す場合は、[返金処理](/refund/)を行ってください。

## 通知・エラー

### 成功メッセージ

| メッセージ | タイミング |
|-----------|-----------|
| N件の顧客が見つかりました | 顧客検索完了時 |
| 請求書が正常に作成されました | 請求書作成完了時 |
| 請求書 {請求書番号} を解除しました。関連伝票は「請求書作成済」ステータスに戻されました | 解除完了時 |

### エラーメッセージ

| メッセージ | 原因 | 対処方法 |
|-----------|------|---------|
| 顧客検索に失敗しました | API通信エラー | 条件を変更して再検索 |
| 未請求伝票がありません | 対象伝票なし | 伝票ステータスを確認 |
| 請求書の作成に失敗しました | API通信エラー | 入力内容を確認し再作成 |

## 検証チェックリスト

- [ ] 顧客が正しく選択されている
- [ ] 請求対象の伝票がすべて選択されている
- [ ] 請求先住所が正しい
- [ ] 発行日・支払期限が適切
- [ ] 合計金額が正しい
- [ ] PDFプレビューで内容確認済み
