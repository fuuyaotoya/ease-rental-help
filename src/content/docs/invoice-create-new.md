# 請求書作成 — この画面は廃止しました

:::danger[廃止済み（2026-07・FE #1275）]
個別の請求書を手動作成する「請求書作成」画面（`/invoice/create-new`）は **2026-07-17 に廃止** しました。手動発行の導線は削除されています。
:::

## 現在の請求書発行方法

請求書は以下のいずれかで発行されます。**基本的に手動での新規作成は不要**です。

| ケース | 発行方法 |
|--------|---------|
| 銀行振込の伝票 | **金額確定時に自動発行**（[返却・金額確定](/bookings-return/) で「金額を確定」すると、請求書が自動で作成・メール送信されます・#2260） |
| まとめ請求対象の請求先 | [会社まとめ請求](/consolidated-invoices/) で月次にまとめて発行 |
| クレジットカード（Shopify） | **標準請求書の対象外** — Shopifyの決済リンク（Draft Order）で回収します |

## 請求書の確認・管理

- 発行済みの請求書・領収書の確認・PDF出力・入金処理: [請求書・領収書管理](/invoices-list/)
- 再発行（枝番の新規発番）: [請求書・領収書管理](/invoices-list/) の「再発行」

## 旧画面の内容について

旧「請求書作成」ウィザード（顧客選択→伝票選択→請求先情報→請求情報→内容確認→完了）および「請求先未登録チェック」「請求書解除」の機能は廃止済みです。該当業務は上記の自動発行・会社まとめ請求に集約されています。
