# 社内確保の伝票

**「社内確保」** は、スタッフ名義やグループ会社の名義で **在庫だけを押さえておくための予約種別** です（2026年9月追加）。

展示会の前後在庫の確保・スタジオ備品の利用・社内撮影など、「お客様への貸し出しではないが在庫を塞いでおきたい」伝票に使います。これまで同じ目的で0円の通常伝票が使われていましたが、金額確定のたびに0円扱いの確認が必要だったため、専用の種別として分離されました。

## 作成のしかた

[貸し出し伝票作成](/booking-compact/) 画面で、通常の伝票と同じ手順で作成します。

1. **「予約種別」** で **「社内確保」** を選びます
2. 顧客・商品明細・レンタル期間・配送情報を、通常の伝票と同じように入力します
3. **「保存・計算」** で保存します

> **⚠️ 管理画面からのみ作成できます:** 社内確保は管理画面の伝票作成からのみ作成できます。オンラインストア（お客様のカート）からは作成できません。

> **💡 料金欄の案内表示:** 「社内確保」を選ぶと、料金欄に以下の案内が表示されます。
>
> 「社内確保の伝票です。料金は0円で、請求書・入金はありません。単価・値引き・配送料は0円にしてください（0円以外は保存できません）。返却を受け付けると自動で完了します。」

> **💡 入力ボタンが非表示になります:** 社内確保の伝票では、料金欄の **「前払い金入力」「入金入力」** ボタンは表示されません（入金が発生しないためです）。

## できること・できないこと

| 操作 | 社内確保での扱い |
|------|----------------|
| 在庫を押さえる（他の予約を防ぐ） | ✅ できます（通常予約と同じ） |
| 出荷 → 返却 | ✅ できます（ピッキング一覧にも表示されます） |
| 見積書・伝票PDFの出力 | ✅ できます（料金は0円で印字されます） |
| キャンセル | ✅ できます（キャンセル料は発生しません） |
| 請求書の発行・まとめ請求 | ❌ できません |
| Shopifyの下書き注文・支払いリンクの作成 | ❌ できません |
| 入金登録・一括入金 | ❌ できません |
| 調整項目（延長料金・破損など）の追加 | ❌ できません |
| 料金の入力（単価・値引き・配送料） | ❌ 0円以外では保存できません |

> **💡 料金は常に0円です:** 合計金額・入金・前払金などの金額は、システム側で常に0円に保たれます。

## 伝票のすすみ方

社内確保の伝票は、**出荷したかどうか** で完了の形が変わります。

| 状況 | すすみ方 |
|------|---------|
| 出荷した | 返却を受け付けると、システムが自動で0円の金額確定を行い、伝票は **完了** になります（入金操作は不要です） |
| 出荷しないまま期間が過ぎた | 毎日早朝の自動処理が、期限の過ぎた明細を片付けて伝票を **完了** にします（自動キャンセルではなく自動完了です） |

> **💡 返却受付は通常どおり:** [返却・金額確定](/bookings-return/) 画面で、通常の伝票と同じように返却受付を行ってください。金額確定の操作は不要です（自動で0円確定します）。

---

## 予約種別の切替

すでに作成済みの伝票の予約種別は、以下の条件をすべて満たすときに切り替えられます。

- 出荷登録前である
- 伝票が未完了である
- 入金・料金・請求が一切発生していない

> **⚠️ 切り替えられない組み合わせ:** メンテナンス用の社内予約（修理待ち商品の在庫確保）とは相互に切り替えできません。

---

## 各一覧での扱い

社内確保の伝票は、**お金に関わる一覧には表示されません**（請求が発生しないためです）。

| 一覧・画面 | 社内確保の伝票 |
|-----------|--------------|
| [未入金一覧](/payment-management/)・伝票検索の未入金絞り込み・CSV出力 | ❌ 表示されません |
| 金額確定待ち一覧（[返却・金額確定](/bookings-return/)） | ❌ 表示されません（返却受付で自動完了するため） |
| まとめ請求の対象 | ❌ 含まれません |
| 売上レポート・延滞一覧・[ダッシュボード](/dashboard/)の統計 | ❌ 含まれません |
| [在庫カレンダー](/inventory-calendar/)・在庫の空き状況判定 | ✅ 通常どおり表示されます（在庫を占有するため） |
| 伝票検索（種別で絞り込み） | ✅ 検索できます（予約種別で「社内確保」を選ぶと絞り込めます） |

## 運用のポイント

> **⚠️ 0円でお客様に貸すことはありません:** お客様への全額免除（0円の貸し出し）は行わない運用です。0円で終わらせたい伝票は **伝票キャンセル** で処理してください。社内で在庫だけ押さえたい場合は、この「社内確保」を使います。

> **💡 キャンセル料は発生しません:** 社内確保の伝票をキャンセルしても、キャンセル料は0円です（明細・配送・伝票のどの単位でも0円になります）。PDFの明細行も0円で印字されます。

## よくある質問

### 今までの「0円の通常伝票」と何が違いますか？

通常伝票で金額を0円にした場合は、返却後の金額確定のたびに0円扱いの確認が必要でした。社内確保は専用種別なので、金額確定の操作自体が不要になります（返却受付で自動的に0円確定・完了）。これから在庫だけ押さえたいときは、社内確保を使ってください。

### キャンセルするとキャンセル料はかかりますか？

かかりません。社内確保のキャンセル料は常に0円です。

### 商品のメンテナンス（修理待ち）の在庫確保とは違いますか？

はい。メンテナンス用の社内予約は商品の修理・点検のための記録で、出荷対象になりません。社内確保は出荷・返却を伴う実際の貸し出し（社内利用）のためのものです。ピッキング一覧には、社内確保の伝票は表示されます。

:::dev
- 予約種別の内部値: `internal_hold`（booking_type）。ラベル定義: FE `src/lib/constants.ts` の BOOKING_TYPE_LABELS
- 仕様の正本: バックエンドリポジトリ `.claude/knowledge/specifications/INVARIANTS.md` §3-9（金額列は DB の CHECK 制約で常に0）
- 完了処理: 出荷時は返却受付で自動0円確定。未出荷は毎日 03:10 JST の InternalHoldCleanupCronService が期限切れ明細を internal_hold_expired として処理し完了化
- 未入金絞り込み・CSV からの除外は支払状態フィルタの実装（payment_status は全件 unpaid のまま残る）
- 関連: BE #3030（種別の新設）・#3038（キャンセル料0円の全経路ゲート・PDF明細行0円）・#3040（未入金絞り込み・CSV除外）・FE 87e6ffa8（種別プルダウン・料金欄の案内・入金ボタン非表示）
:::
