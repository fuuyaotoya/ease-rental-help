## 概要

**請求先（会社名＋部署）でまとめた当月の未請求伝票を、顧客をまたいで1枚の請求書に集約して発行**します。

顧客レコードは担当者ごとに登録されているため、基本情報の会社名・部署は担当者ごとにばらつくこと（編集部／雑誌部／フリーランスなど）があります。一方で請求先は経理部などに集約されるのが一般的です。本画面は、**正規化した請求先キー（会社名＋部署）で複数の顧客をまたいでグループ化**し、まとめて1枚の請求書を作成します。

> **請求先のデータソース（Issue #2246）:** グループ化のキーと請求先の表示は、伝票に入力された値ではなく **`billing_addresses` マスタ（顧客マスタの請求先住所）から自動解決** されます。顧客マスタの請求先を正しく保守していれば、伝票ごとの入力ばらつきに関わらず正しくグループ化されます（かつて伝票のスナップショットを直接読んでいたため、請求先未設定の伝票がすべて1グループに潰れる問題がありましたが、#2246 で解消済みです）。

> **一括請求処理との違い:** [一括請求処理](/bulk-invoices)は会社名（`customer_id`）単位で集約するため、**複数の顧客レコード → 1つの請求先**というケースを取りこぼします。会社まとめ請求は請求先キーで顧客横断にまとめるため、この取りこぼしを防げます。部署単位で個別に発行したい場合は[請求書作成](/invoice-create-new)や[一括請求処理](/bulk-invoices)を使用してください。

## アクセス方法

- サイドバーから: **請求・入金 > 会社まとめ請求**
- URL直接: `/consolidated-invoices`

## 画面構成

画面は上下2つのセクションで構成されます。

1. **グループ候補（顧客横断）** — 対象月の未請求伝票を請求先キーでまとめた候補カード
2. **統合請求書一覧** — 作成済みの統合請求書（送信・PDF出力）

### 対象月セレクタ

| 項目   | 種類     | 説明                                                          |
| ------ | -------- | ------------------------------------------------------------- |
| 対象月 | セレクト | **前々月／前月／当月／翌月**の4択。当月は「(当月)」表示（Issue #1215） |

対象月を切り替えると、その月の未請求伝票でグループ候補が再計算されます。

### 請求先検索（会社名／部署）

画面上部の検索欄で**請求先会社名・部署**による絞り込みができます（Issue #1215）。グループ候補が多い場合に、特定の請求先だけを表示して確認できます。検索未入力時は全グループ候補が表示されます。

### グループ候補カード（ヘッダー）

各カードのヘッダーには以下が表示されます。

| 表示             | 説明                                                       |
| ---------------- | ---------------------------------------------------------- |
| 請求先会社名・部署 | グループの請求先                                           |
| 件数 / 合計金額  | **選択中**の伝票の件数と税込合計（チェック操作に追従）       |
| ✉ 送信先メール   | 発行前の送信先確認用に常時表示（Issue #1227）。未設定時は「請求先メール未設定」 |
| ⚠️ 警告バッジ     | 後述の3種（誤合流の注意喚起）                               |
| 「確認済み」バッジ | このグループに過去の仕分け記憶があるとき表示                |
| ▼ / ▲            | クリックで展開／折りたたみ                                  |

> **送信先メールを発行前に確認（Issue #1227）:** グループ候補カードに送信先メールアドレスを常時表示し、誤送信を防ぎます。送信先が「請求先メール未設定」となっている場合は、[顧客マスタ](/customers)の請求先設定を確認してください。

### グループ展開ビュー（確認）

![グループ展開ビュー](/images/consolidated-invoices-expanded.png)

カードを展開すると、グループに含まれる伝票（メンバー）が一覧表示されます。

| 列                   | 説明                                                         |
| -------------------- | ------------------------------------------------------------ |
| チェックボックス     | 請求書に含めるかどうか。チェックを外すとその伝票を除外        |
| 伝票No               | 伝票番号                                                     |
| 請求先会社名         | 解決済みの請求先会社名（Issue #1215）                          |
| 請求先部署           | 解決済みの請求先部署（Issue #1215）                            |
| 基本情報（顧客マスタ） | 借主側の会社名／部署／担当者（顧客コード）                    |
| 利用期間             | 貸出開始日〜返却予定日                                        |
| 金額(税込)           | その伝票の税込金額                                            |
| 記憶                 | 軽量記憶のステータスバッジ（後述）                            |

> **列順について（Issue #1215）:** 伝票No／請求先会社名／請求先部署／基本情報 の順で表示し、請求先と基本情報（借主）を見比べやすくしています。

展開ビュー下部には次の操作があります。

| 項目                         | 説明                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| 支払期限                     | 既定は**翌月末**。日付入力で変更可能                          |
| このグループの記憶を忘れる   | このグループの仕分け記憶を消去                               |
| 請求書を作成（n件）          | 選択中の伝票で請求書を1枚作成                                |

### グループ単位の全選択／全解除（Issue #1215）

展開ビューで**グループに含まれる伝票を一括で全選択／全解除**できます。ヘッダーのチェックボックス、または全選択ボタンを使用してください。件数と合計金額はチェック操作に即座に追従します。

> **1グループあたり最大50件:** 1回の請求書作成で含められる伝票は最大50件です（上限を超えると発行ボタンが無効化されます）。この上限は、作成処理の安定性を保つためのガードです。50件を超えるグループは、対象月を分けるか、一部伝票を除外してから発行してください。

## ⚠️ 3種類の警告

グループに「誤って別の請求先が混ざっているかもしれない」状態を検出すると、警告バッジが表示されます。**警告は発行を止めるものではなく、確認を促すための注意喚起**です。

| 警告               | 意味                                                             |
| ------------------ | ---------------------------------------------------------------- |
| 会社名不一致       | グループ内に「基本情報の会社名 ≠ 請求先会社名」の伝票がある        |
| 住所/郵便番号不一致 | グループ内で請求先の住所または郵便番号が割れている                |
| 顧客コード混在     | グループ内に複数の顧客コードが混在している                        |

警告が出た場合は展開して中身を確認し、別請求先の伝票が紛れ込んでいないかをチェックしてから発行してください。

## 軽量記憶（仕分けを覚える仕組み）

毎月の確認を軽くするため、**「どの伝票をこのグループに含めたか／外したか」を覚えます**。記憶は翌月以降の候補の既定選択に反映されます。

### 記憶バッジの意味

| バッジ     | 意味                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 新規       | 記憶なし（初登場、または未判断）                                      |
| 確認済     | 先月このグループに**含めた（include）**伝票                            |
| 先月除外   | 先月このグループから**外した（exclude）**伝票                          |

> **「先月除外」は既定でチェックが外れています。** 翌月に同じ伝票が現れても自動では選択されないため、「一度弾いた伝票がまた紛れ込む」のを防げます。再び含めたい場合はチェックを入れ直してください。

### 記憶の保存と消去

- **保存:** 「請求書を作成」を押すと、その時点で**表示中メンバーの含める／外すの判断が自動保存**されます（手動操作は不要）。
- **消去:** 「このグループの記憶を忘れる」を押すと、そのグループの記憶がリセットされ、全メンバーが「新規」に戻ります。

## 操作手順

### 手順1: 対象月を選択

1. **対象月**セレクタで請求したい月を選択（既定は当月）
2. その月の未請求伝票で、請求先ごとのグループ候補が表示されます

### 手順2: グループを確認

1. グループカードの件数・合計金額・警告バッジを確認
2. カードをクリックして展開
3. メンバーの**基本情報（顧客マスタ）と請求先**を見比べ、別の請求先が混ざっていないか確認
4. 「先月除外」「確認済」などの記憶バッジを参考に内容を点検

### 手順3: 伝票を除外／再追加（必要な場合）

1. このグループに**含めたくない伝票**はチェックを外す
2. 「先月除外」で既定オフになっている伝票を**含めたい**場合はチェックを入れる
3. グループ単位の**全選択／全解除**を使うと一括で切替えられる（Issue #1215）
4. ヘッダーの件数・合計金額が選択内容に追従します

### 手順4: 請求書を作成

1. **支払期限**を確認（既定は翌月末。必要なら変更）
2. 「請求書を作成（n件）」をクリック
3. 選択中の伝票で統合請求書が1枚作成されます

**期待される結果:**

- 「○○ の請求書を作成しました」と表示
- 下部の**統合請求書一覧**に新しい請求書が追加される
- 仕分けの判断（含める／外す）が**自動で記憶**され、翌月の候補に反映される

### 手順5: 作成済み請求書の送信・PDF

下部の統合請求書一覧から、各請求書を操作できます。

| ボタン | 説明                                                         |
| ------ | ------------------------------------------------------------ |
| 送信   | 請求書をメール送信。**送信先メールはボタンにホバー（またはTab移動）で事前確認**できます（Issue #1227） |
| PDF    | 請求書PDFをダウンロード                                      |

> **送信済み・入金済みの行は再送信できません（Issue #1227）:** ステータスが「送信済み」「入金済み」の請求書は、**送信ボタンが無効化**されます（再送信はシステムで受け付けません）。送信前に送信先メールが正しいか、ホバー表示で必ず確認してください。送信先が「請求先メール未設定」と表示される場合は、[顧客マスタ](/customers)の請求先メール設定を修正してから送信してください。

### 統合請求書一覧の行展開（含有伝票の確認）

統合請求書一覧の各行は**展開可能**で、その請求書に含まれる個別伝票（伝票No／利用期間／金額）を確認できます（Issue #1215）。伝票Noをクリックすると、別タブで伝票編集画面（`/booking-compact`）に遷移します。発行後に伝票内容を差し戻して確認したい場合に使用してください。

> **PDFの構成（Issue #2251）:** 2件以上の伝票をまとめた請求書では、明細部分が **注文（伝票No）ごとに分割** されて出力されます（伝票Noごとに独立したブロック）。複数伝票の明細が1つの表に混在するわけではなく、伝票単位で区切られて確認しやすくなっています。

## 注意事項

- **毎月、発行前に必ず中身を確認してください。** 警告バッジと記憶バッジは確認の補助であり、最終判断はオペレータが行います。
- 「先月除外」の伝票は既定で選択されません。請求対象に含めたい場合は明示的にチェックを入れてください。
- 部署を分けて個別の請求書にしたい場合は、本画面ではなく[請求書作成](/invoice-create-new)を使用してください（[一括請求処理](/bulk-invoices)は現在サイドバー非表示・会社まとめ請求に集約済み：Issue #1215）。
- **送信前に送信先メールを必ず確認してください（Issue #1227）。** グループ候補カードと送信ボタンのホバー表示で送信先を確認できます。
