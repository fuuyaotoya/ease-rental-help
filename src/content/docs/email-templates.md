:::dev
> **管理者/開発者向けリファレンス:** 本ページはシステムが SMTP 送信するメールの本文テンプレート全文です。`${...}` は実行時に値が埋まる変数。実装（`src/modules/email/email.service.ts` / `invoices.service.ts` / `consolidated-invoices.service.ts` / `invoice-reminder-cron.service.ts`）と1:1で照合できます。本文の変更時は本ページの追従が必要です（末尾「鮮度・保守」参照）。
:::

システムは登録された内容に合わせて、お客様や店舗あてにメールを自動で送信します。本ページは **システムが送信する全メールの本文テンプレート**を網羅します（Shopify が送信する注文確認などは対象外 → [メール送信の責任分け](./appendix/email-responsibility)）。

本文は `${変数名}` のプレースホルダ付きで記載しています。`${...}` の部分には送信時に実際の値（お客様名・伝票番号・金額など）が自動で入ります。条件付きで表示される行は `（条件の場合）` と注記しています。

送信タイミング・宛先の一覧は [自動送信メール一覧](./email-notifications) を参照。

## 共通事項

### 送信元アドレス（FROM）— ⚠️ 重要

システムのメールは **2種類の送信元**を使い分けます。

| 送信元 | 性質 | 対象メール |
|--------|------|-----------|
| `rental-info@iziz.co.jp` | **送信専用**（返信不可・監視しない） | 予約確認・リマインダ・キャンセル通知・返金通知・追加決済請求・管理者アラート・お問い合わせ受付 等、**請求書以外の全メール** |
| `keiri@iziz.co.jp` | **経理専用**（返信可・経理チームが受信） | **請求書メールのみ**（標準請求書・まとめ請求書・再請求リマインダー・督促） |

- `rental-info@` 宛の返信は **監視していません**。顧客からの問い合わせは、本文末尾の iziz 会社署名（メール: `shop@iziz.co.jp`／サイト: http://www.iziz.co.jp）をご案内しています。
- 請求書メールだけ `keiri@iziz.co.jp`（経理専用）から送り、**入金・請求に関する返信が経理チームに届く**ようにしています。

:::dev
- 送信元は環境変数で上書き可能: `EMAIL_FROM`（送信専用・デフォルト `rental-info@`）/ `INVOICE_EMAIL_FROM`（請求書用・デフォルト `keiri@`）。本番（Render）は 2026-08-17 に両方を上表のアドレスへ明示設定済み。
- `EMAIL_FROM` が設定されていると**コードのデフォルトより環境変数が優先**されます。2026-07 にコード側は送信専用アドレスへ分岐済みでも、本番環境変数が `EMAIL_FROM=shop@iziz.co.jp` のままだった約1ヶ月間は `shop@` から送信され続けていた実例あり（「コードを直した」＝「本番の差出人が変わった」ではない点に注意）。
- `EMAIL_FROM` 未設定時は起動ログに `EMAIL_FROM is not set — falling back to ...` 警告が出ます。警告が出ていない＝設定済み、であるだけで正しい値である保証はありません（Render ダッシュボードで目視確認が必要）。
:::

### 送信の仕組み

:::dev
- ライブラリ: `nodemailer`（`@nestjs-modules/mailer` 不使用）
- トランスポート: さくらのメールサーバ `iziz.sakura.ne.jp:465`（SMTPS）。認証アカウントは `shop@iziz.co.jp`（`SMTP_USER`）
- 認証アカウントと差出人（FROM）は別で構いません。認証 `shop@`、差出人 `rental-info@` / `keiri@` の構成で送信できることを実測確認済み（2026-08-17・同一 `iziz.co.jp` ドメイン内）
- master switch: `EMAIL_ENABLED`（`false` で全メール送信スキップ・`email_logs.status='skipped_disabled'` 記録）
- 送信履歴: `email_logs` テーブルに subject / recipient / status / email_type を全件記録
:::

### HTML 変換・ロゴ

全メールはプレーンテキスト本文を HTML メールにも変換して送ります。

- プレーン本文を改行保持の HTML でラップ（プレーンテキスト版も同梱）
- ロゴ画像を **本文下部（フッタ）** に配置

### フッタ（共通の iziz 会社署名）

**全顧客向けメール**（予約確認・リマインダ・キャンセル通知・返金通知・追加決済請求・会員招待・標準/まとめ請求書・再請求リマインダー・お問い合わせ受付）は、共通の **iziz 会社署名** を本文末尾に付与します（ロゴ画像は署名の後に配置）。

```
□■--------------------------------------------------------------
〒141-0031 東京都品川区西五反田3-1-1
TEL: 03-5759-8266　FAX: 03-5759-8262
サイト: http://www.iziz.co.jp
メールアドレス: shop@iziz.co.jp
営業時間: 9:30～18:00(月～金)・9:30～17:00(土)
休業日: 日・祝
```

| 種別 | フッタ |
|------|--------|
| 顧客向け（共通） | 上記 iziz 会社署名 |
| 管理者アラート | `---` / `EASE Rental System - Automated Alert` / `Timestamp: ${ISO}` |

:::note[署名の統一について（2026年7月変更）]
- それまで顧客向けメールに付いていた簡易フッタを廃止し、共通の iziz 会社署名に統一しました。
- 標準請求書・まとめ請求書が本文に持っていた独自フッタ（自社名・TEL・FAX）も廃止し、共通署名に統一しました。会社名は**請求書 PDF 本体**に記載されています（メール本文からは会社名表記が消え、iziz 署名のサイト URL・メールアドレスで発行者を明示します）。
- 返金完了通知は従来フッタなしでしたが、共通署名を付与するようにしました。
:::

### 宛名生成ロジック（請求書メールの宛名）

請求書メールの宛名は請求先マスタの情報から生成。4パターン:

| 条件 | 宛名 |
|------|------|
| 会社名＋担当者名 あり | `${会社名}` / `${部署} ${担当者名} 様`（部署なし場合は `${担当者名} 様`） |
| 会社名のみ | `${会社名}` / `ご担当者様` |
| 担当者名のみ | `${担当者名} 様` |
| 両方なし | `ご担当者様` |

請求先マスタ由来の宛名を使うのは**返金通知・標準/まとめ請求書・再請求リマインダー**です。予約確認・リマインダ・キャンセル通知・追加決済請求・会員招待・お問い合わせ受付は `${customerName} 様` 等の顧客名由来の宛名です（「御中」はどのメールでも使用しません）。

## 請求書（keiri@iziz.co.jp から送信）

:::note
請求書メールは **経理専用アドレス `keiri@iziz.co.jp`** から送信されます。入金・請求に関する返信が経理チームに届きます。他のメール（送信専用 `rental-info@`）とは差出人が異なります。
:::

請求書メールはいずれも **銀行振込顧客のみ** が対象（クレジットカード顧客は Shopify の決済リンクで処理）。宛先は注文アカウントではなく **請求先マスタに登録された請求先メールアドレス** です。請求先未登録・メールアドレス空の場合は送信されず、管理者アラートが飛びます（→ 管理者アラート）。
