お客様・請求先・ストアに届くメールを、**M01〜M23 の番号順**に、件名と本文の全文つきで載せています。番号はクライアント様に提出した『EASE Rental メール一覧（本文付き）』と同じです。

- 送られるタイミングの一覧と、お支払い方法ごとの流れは [自動送信メール一覧](/email-notifications/) を参照
- 差込項目は `{伝票番号}` のように波括弧で、条件によって出る行は行末の（○○のときのみ）で示しています
- 本文の［共通署名］［ログインのご案内（共通）］は、下の「共通の部品」の文が入ります

:::note[本稼働前の送信について]
新システムの本稼働前は、お客様宛のメールはテスト用のアドレスにだけ届き、それ以外は送らずに記録だけ残しています。本ページは本稼働後に届く内容です。
:::

## 差出人と返信先

2026-11-16 に、当社システムの差出人を rental-info@ から ease-info@ に変えました。

| 差出人 | 使うメール | 返信が届く先 |
|---|---|---|
| `ease-info@iziz.co.jp` | 請求書・領収書・再請求以外の、当社システムのメールすべて | `shop@iziz.co.jp`（さくらの設定で転送） |
| `keiri@iziz.co.jp` | 請求書・まとめ請求書・まとめ領収書・再請求（M08・M09・M13・M14・M15） | 経理（keiri@） |
| Shopify（ストアの送信元） | M03・M04・M07・M11・M12・M20 | 本文の問い合わせ先は `shop@iziz.co.jp` |

:::dev
- 差出人は環境変数で上書きできます: `EMAIL_FROM`（既定 `ease-info@iziz.co.jp`）/ `INVOICE_EMAIL_FROM`（既定 `keiri@`）。BE #3177（2026-11-16）で一般通知の既定を変更し、本番（Render）の `EMAIL_FROM` も同日 ease-info@ に切替済み（実送信で From を確認）。環境変数がコードの既定より優先されるので、「コードを直した」＝「本番の差出人が変わった」ではありません（2026-07 に `EMAIL_FROM=shop@` のまま約1か月送り続けた実例あり）。
- `ease-info@` はさくらで受信して `shop@iziz.co.jp` に転送しています（2026-11-16 切替時に確認）。「送信専用・返信は誰も読まない」ではありません。
- 送信は `nodemailer` を使用。接続先と認証は `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` で指定します。送信元は認証アカウントから取得しません。
- `EMAIL_ENABLED=false` で全メール送信をスキップ（`email_logs.status='skipped_disabled'`）。送信履歴は `email_logs` に subject / recipient / status / email_type を全件記録。
- 本文はプレーンテキストを改行保持の HTML にも変換して送り、ロゴ画像を署名の後に付けます。
:::

```text

```

## 社内向けの自動アラート（番号なし）

データの不整合などを検知したときに、管理者アドレスへ送る内部通知です。お客様には届かず、共通署名も付きません。

- **件名**: `【EASE Rental Alert】{内容}`
- **差出人**: `ease-info@iziz.co.jp`

| 検知内容 | 件名（`【EASE Rental Alert】` の後） | 対応 |
|---|---|---|
| 請求書メールを送れなかった（請求先の不備） | `【要対応】請求先情報不備により請求書メール送信スキップ` | 請求先マスタの登録・メールアドレスの補完 |
| まとめ請求書メールを送れなかった | `【要対応】請求先情報不備により統合請求書メール送信スキップ` | 同上 |
| Shopify 連携エラー | `【要対応】Shopify連携エラー検出` | エラー内容の確認 |
| 長期間未決済のカード決済案内 | `【警告】長期間 OPEN の DraftOrder が検出されました` | 期限を過ぎた決済案内の確認 |
| 孤立注文 | `[Orphan Order] ...` | システムと Shopify で対応の取れない注文の確認 |
| 二重決済の疑い | `[二重決済疑い] ...` | 振込後のカード二重決済の確認 |

本文の形（共通1種）:

```text
{message}


【詳細情報】
{key}: {value}　（details の各エントリごとに1行。値がオブジェクトのときは整形した JSON）

---
EASE Rental System - Automated Alert
Timestamp: {ISO 日時}
```
:::
