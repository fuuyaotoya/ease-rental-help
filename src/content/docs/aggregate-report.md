## 概要

登録された伝票データから各種統計レポートを生成。CSVまたはPDF形式で、条件を指定して出力可能。

## アクセス方法

- サイドバー: **レポート** > **集計表出力**
- 直接URL: `/aggregate-report`

## 画面構成

### レポート種別（9種類）

| No. | レポート名       | 説明                                                  |
| --- | ---------------- | ----------------------------------------------------- |
| 1   | 月別日計表       | 指定月内の日別レンタル件数・金額                      |
| 2   | 商品別売上表     | 商品ごとのレンタル件数・売上                          |
| 3   | 顧客別売上表     | 顧客ごとのレンタル件数・売上                          |
| 4   | 貸出日数別売上表 | レンタル日数別の売上内訳（当日〜30日以上）            |
| 5   | 配送業者別売上表 | 配送業者ごとの配送件数・料金                          |
| 6   | 受注方法別売上表 | 受注方法別の売上内訳（店頭/電話/FAX/メール/Web）      |
| 7   | 商品利用履歴     | 特定商品の利用履歴（レンタル/返却/メンテナンス/破損） |
| 8   | 延滞一覧         | 返却予定日を過ぎた未返却商品                          |
| 9   | 会計ソフト連携（仕訳CSV） | 指定期間の請求データを会計ソフト取り込み用の仕訳CSVで出力。freee / mf（マネーフォワード） / 弥生 / 汎用 の4形式に対応 |

## 手順

### 手順1: レポートを生成

1. 目的のレポート種別カードをクリック
2. モーダルで条件を設定
3. **CSV出力** または **PDF出力** をクリック
4. ファイルが自動的にダウンロード

**期待される結果:** レポートファイルがダウンロードされます。

### 手順2: 月別日計表の設定

1. **月別日計表** カードをクリック
2. パラメータを設定:
   - **対象月**（必須）: YYYY-MM形式で月を選択
   - **基準日**: レンタル開始日 / 返却日 / 入金日 / 金額確定日
   - **未返却を含む**: 未返却商品を含める場合はチェック
   - **倉庫**: 倉庫を選択または「全て」
3. **CSV出力** または **PDF出力** をクリック

### 手順3: 商品別売上表の設定

1. **商品別売上表** カードをクリック
2. パラメータを設定:
   - **対象期間（FROM/TO）**: 日付範囲
   - **基準日**: フィルタリングの基準日
   - **商品コード（FROM/TO）**: 商品コード範囲
   - **カテゴリ**: 商品カテゴリフィルタ
   - **タグ**: 全てを含む/いずれかを含む
   - **レンタル回数**: 最小レンタル回数のしきい値
   - **倉庫**: 倉庫を選択または「全て」
3. **CSV出力** または **PDF出力** をクリック

### 手順4: 顧客別売上表の設定

1. **顧客別売上表** カードをクリック
2. パラメータを設定:
   - **利用期間（FROM/TO）**: 日付範囲
   - **利用金額**: 最小/最大金額範囲
   - **会社名 / 部署 / 担当者**: 検索フィルタ（部分一致）
   - **倉庫**: 倉庫を選択または「全て」
3. **CSV出力** または **PDF出力** をクリック

### 手順5: 延滞一覧の設定

1. **延滞一覧** カードをクリック
2. パラメータを設定:
   - **基準日**: 延滞計算の基準日
   - **延滞日数**: 最小延滞日数
   - **顧客フィルタ**: 全て / リピーター / 新規顧客
   - **連絡先を含む**: 電話番号/メールをレポートに含める
3. **CSV出力** または **PDF出力** をクリック

### 手順6: 会計ソフト連携CSV（仕訳CSV）を出力

1. **会計ソフト連携（仕訳CSV）** カードをクリック
2. パラメータを設定:
   - **対象期間（FROM/TO）**: 日付範囲
   - **形式**: freee / mf（マネーフォワード） / 弥生 / 汎用
   - **対象**: 出力対象の絞り込み
3. **CSV出力** をクリック（PDF出力は非対応・弥生はShift-JIS）

> **運用メモ:** まとめ請求のデータは **請求確定後** に出力してください。まとめ請求を取り消した場合は、CSVを再生成しないとデータが残ります。

## 出力形式オプション

| 形式 | 用途                        |
| ---- | --------------------------- |
| CSV  | Excelでのデータ分析、加工用 |
| PDF  | 印刷、保管、共有用          |

## 確認チェックリスト

- [ ] レポート種別が正しく選択されている
- [ ] 日付範囲が適切
- [ ] 倉庫フィルタが正しい
- [ ] ファイルが正常にダウンロードされた
- [ ] レポートデータが正確

## 注意事項

- データ量が多い場合、レポート生成に時間がかかる場合があります
- PDF出力はA4印刷に最適化されています
- CSVはExcel互換性のためBOM付きUTF-8エンコーディングを使用
