## 概要

登録された伝票データから各種統計レポートを生成。CSVまたはPDF形式で、条件を指定して出力可能。

## アクセス方法

- サイドバー: **レポート** > **集計表出力**
- 直接URL: `/aggregate-report`

## 画面構成

### レポート種別（8種類）

| No. | レポート名       | 説明                                                  |
| --- | ---------------- | ----------------------------------------------------- |
| 1   | 月単位日別売上表 | 指定月内の日別レンタル件数・金額 |
| 2   | 商品別売上一覧表 | 商品ごとの貸出件数・売上・回転率 |
| 3   | 商品利用履歴一覧表 | 特定商品の貸出・返却・予約履歴 |
| 4   | 延滞一覧表 | 返却予定日を過ぎた未返却商品 |
| 5   | [配送業者別売上一覧表](/reports-delivery-company-sales/) | 配送業者ごとの配送料金売上。カードから専用画面を開きます |
| 6   | 受注方法別売上一覧表 | 受注方法別のレンタル件数・売上 |
| 7   | 顧客カテゴリー別売上 | 顧客カテゴリーごとの月別レンタル件数・売上 |
| 8   | 会計ソフト連携（仕訳CSV） | 指定期間の請求データを会計ソフト取り込み用の仕訳CSVで出力。freee / mf（マネーフォワード） / 弥生 / 汎用 の4形式に対応 |

## 手順

### 手順1: レポートを生成

1. 目的のレポート種別カードをクリック
2. モーダルで条件を設定（配送業者別売上一覧表は専用画面が開きます）
3. **CSV出力** または **PDF出力** をクリック
4. ファイルが自動的にダウンロード

**期待される結果:** レポートファイルがダウンロードされます。

### 手順2: 月単位日別売上表の設定

1. **月単位日別売上表** カードをクリック
2. パラメータを設定:
   - **売上月**（必須）: YYYY-MM形式で月を選択
   - **基準日**: 貸出開始日 / 返却日 / 入金日 / 金額確定日
   - **未返却を含む**: 未返却商品を含める場合はチェック
   - **在庫場所**: 在庫場所を選択または「全て」
3. **CSV出力** または **PDF出力** をクリック

### 手順3: 商品別売上一覧表の設定

1. **商品別売上一覧表** カードをクリック
2. パラメータを設定:
   - **売上月（FROM）**・**売上月（TO）**: 日付範囲
   - **基準日**: フィルタリングの基準日
   - **商品コード（FROM）**・**商品コード（TO）**: 商品コード範囲
   - **商品カテゴリ**: 商品カテゴリを選択
   - **回転率を含む（伝票ベース）**: 回転率を出力する場合はチェック
   - **在庫場所**: 在庫場所を選択または「全て」
3. **CSV出力** または **PDF出力** をクリック

### 手順4: 顧客カテゴリー別売上の設定

1. **顧客カテゴリー別売上** カードをクリック
2. パラメータを設定:
   - **年**・**月**: 集計する年月
   - **基準日**: 貸出開始日 / 返却日 / 入金日 / 金額確定日
3. **CSV出力** または **PDF出力** をクリック

### 手順5: 延滞一覧表の設定

1. **延滞一覧表** カードをクリック
2. パラメータを設定:
   - **基準日**: 延滞計算の基準日
   - **延滞日数**: 最小延滞日数
3. **CSV出力** または **PDF出力** をクリック

### 手順6: 会計ソフト連携CSV（仕訳CSV）を出力

1. **会計ソフト連携（仕訳CSV）** カードをクリック
2. パラメータを設定:
   - **集計期間（開始日）**・**集計期間（終了日）**: 日付範囲
   - **出力形式**: freee 振替伝票 / マネーフォワード / 弥生 汎用CSV / 汎用CSV
   - **対象**: すべて / 単票請求書のみ / まとめ請求のみ
3. **CSV出力** をクリック（PDF出力は非対応・弥生はShift-JIS）

> **運用メモ:** まとめ請求のデータは **請求確定後** に出力してください。まとめ請求を取り消した場合は、CSVを再生成しないとデータが残ります。

## 出力形式オプション

| 形式 | 用途                        |
| ---- | --------------------------- |
| CSV  | Excelでのデータ分析、加工用 |
| PDF  | 印刷、保管、共有用          |

## 確認チェックリスト

- [ ] レポート種別が正しく選択されている
- [ ] 日付範囲が適切
- [ ] 在庫場所の指定が正しい（指定欄がある場合）
- [ ] ファイルが正常にダウンロードされた
- [ ] レポートデータが正確

## 注意事項

- データ量が多い場合、レポート生成に時間がかかる場合があります
- PDF出力はA4印刷に最適化されています
- CSVはExcel互換性のためBOM付きUTF-8エンコーディングを使用
- 売上レポート・延滞一覧に、[社内確保](/internal-hold/)の伝票は含まれません（料金が発生しないためです）

:::dev
### 画面から除外している未対応パラメータ

以下は画面に入力欄を表示せず、送信する設定からも除外している項目です。基準日・商品コード範囲・利用金額範囲・在庫場所を一律に未実装とは扱いません。

| レポート種別 | 除外する設定キー |
| --- | --- |
| 商品別売上一覧表 | `tags`, `rental_count_above` |
| 商品利用履歴一覧表 | `include_maintenance`, `include_damage` |
| 延滞一覧表 | `customer_filter`, `include_contact_info` |

:::
