# EASE Rental 業務フロー

![伝票検索画面（ログイン後に最初に表示される画面）](/images/slip-search/main.png)

EASE Rental では、レンタル商品の受注から返却・入金までの一連の業務をシステム上で管理します。
このページでは、業務の全体像と各作業で使う画面をまとめています。

> **ログイン:** 管理画面には、[マスタ管理 > 担当者管理](/master-data/) に登録されたアカウント（メールアドレスまたはユーザー名）とパスワードでログインします。ログインすると [伝票検索](/slip-search/) 画面が開きます。従来の環境変数による管理者ログインは廃止されました。

## 業務の流れ

レンタル業務は、大きく分けて以下の5つのステップで進みます。

```
1. 商品問い合わせ
   └→ 商品予約状況照会で在庫を確認

2. 受注（貸出伝票の作成）
   └→ 伝票・顧客情報 → レンタル商品 → 配送情報 → 調整項目 → 料金・支払 → 「保存・計算」で登録

3. ピッキング・出荷
   └→ ピッキング対象伝票の確認 → 「即出荷」でピッキングから出荷登録まで一括実行
      （複数の伝票は「一括出荷完了」でまとめて実行）

4. 返却処理
   └→ 返却日の入力 → 延長料の計算 → 金額の確定

5. 入金処理（支払方法によって流れが異なります）
   └→ 店頭支払い: 入金処理を行う
   └→ 銀行振込: 金額確定時に請求書を自動発行 → 入金を確認
   └→ クレジットカード: 決済リンク付きメールでお客様がカード決済 → 決済は自動で反映（入金処理は不要）
```

## 覚えておきたいルール

### 1伝票に登録できる上限

伝票を**新しく作成するとき**の上限です（作成後に明細・配送を追加する場合は上限はありません）。

- **商品明細**: 1つの伝票につき最大 **50件** まで
- **配送先**: 1つの伝票につき最大 **10件** まで

### 支払方法によって処理が変わる

お客様の支払方法によって、あとの入金処理の手順が異なります（支払方法は 店頭支払い / 銀行振込 / Shopify（クレジットカード）の3種）。

| 支払方法 | 伝票作成時の入力 | 入金処理の流れ |
|---------|---------------|-------------|
| 店頭支払い | 支払予定日を入力 | 伝票の入金処理を行う |
| Shopify（クレジットカード） | —（後払いが基本） | 決済リンク付きメールでお客様がカード決済（前日19時の自動送信、または手動で送付）。決済は自動で反映され、入金処理は不要です（[決済方法別フロー](/appendix/payment-method-flows/)参照） |
| 銀行振込 | 銀行振込可の顧客のみ選択可 | 金額確定時に請求書を自動発行 → 入金を確認 |

### 伝票の状態の見え方

伝票の状態は、伝票検索で以下のように表示されます。支払方法によって通る状態が異なります（「未送信」「請求済」は、請求書を発行して入金を待つ伝票＝主に銀行振込で表示されます）。

| 状態 | 説明 |
|------|------|
| 処理中 | 伝票の作成から返却受付までの間（ピッキング・出荷などの工程中を含む） |
| 金額確認待ち | 返却受付後、金額が未確定の状態 |
| 未送信 | 金額確定済みで請求書がまだ送信されていない状態 |
| 請求済 | 請求書が発行され、入金を待っている状態 |
| 完了 | すべての処理（返却・入金）が終わった状態 |
| キャンセル | 伝票がキャンセルされた状態 |

> **💡 ヒント:** 伝票の状態は、伝票検索画面で一覧確認できます。詳しくは[伝票検索](/slip-search/)と[ステータス遷移図](/appendix/status-flow/)のページをご覧ください。
