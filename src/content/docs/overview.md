# EASE Rental 業務フロー

![管理画面ダッシュボード](/images/overview/dashboard.png)

EASE Rental では、レンタル商品の受注から返却・入金までの一連の業務をシステム上で管理します。
このページでは、業務の全体像と各作業で使う画面をまとめています。

## 業務の流れ

レンタル業務は、大きく分けて以下の5つのステップで進みます。

```
1. 商品問い合わせ
   └→ 予約状況一括照会で在庫を確認

2. 受注（貸出伝票の作成）
   └→ 顧客選択 → 伝票情報 → 明細情報 → 配送情報 → 料金確認 → 伝票登録

3. ピッキング・出荷
   └→ ピッキング対象伝票の確認 → ピッキング完了 → 出荷登録

4. 返却処理
   └→ 返却日の入力 → 延長料の計算 → 金額の確定

5. 入金処理
   └→ 現金/クレジット: 入金処理のみ
   └→ 振込: 請求書作成 → 請求書発行 → 入金確認
```

## 覚えておきたいルール

### 1伝票に登録できる上限

- **商品明細**: 1つの伝票につき最大 **50件** まで
- **配送先**: 1つの伝票につき最大 **10件** まで

### 支払方法によって処理が変わる

お客様の支払方法によって、あとの入金処理の手順が異なります。

| 支払方法 | 伝票作成時の入力 | 入金処理の流れ |
|---------|---------------|-------------|
| 現金 | 支払予定日を入力 | 伝票の入金処理だけ行う |
| クレジットカード | 支払予定日を入力 | 伝票の入金処理だけ行う |
| 銀行振込 | 請求先と担当者を選択 | 請求書を作成 → お客様に送付 → 入金を確認 |

### 伝票の進む流れ

伝票は、以下の順番で状態が進みます。

| 状態 | 説明 |
|------|------|
| 処理中 | 伝票を作成した直後の状態 |
| 請求待ち | 金額が確定し、請求の準備ができた状態 |
| 入金待ち | 請求書が発行され、入金を待っている状態 |
| 完了 | すべての処理（返却・入金）が終わった状態 |
| キャンセル | 伝票がキャンセルされた状態 |

> **💡 ヒント:** 伝票の状態は、伝票検索画面で一覧確認できます。詳しくは[伝票検索](/slip-search/)のページをご覧ください。
