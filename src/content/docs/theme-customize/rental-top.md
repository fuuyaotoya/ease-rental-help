# レンタルトップ

![レンタルトップ](/images/theme-customize/rental-top-overview.png)

レンタルトップページは、レンタルサービスの入口です。スライド画像、商品カテゴリ、おすすめ商品などを表示します。

---

## テーマエディタで開くには

1. Shopify管理画面 > **オンラインストア** > **テーマ** > **カスタマイズ**
2. ページセレクターで **ページ** を選択
3. **レンタルトップ** ページを選択

---

## セクション構成

| セクション | 役割 |
|-----------|------|
| メインビルダー | スライド画像・カテゴリ・検索フォーム |
| レンタルカテゴリ | カテゴリ別の商品 |
| レンタル展示グリッド | 展示用の商品一覧 |
| おすすめ商品 | おすすめ商品の横スクロール表示 |
| 記事カルーセル | 関連記事 |
| ご利用ガイド（ステップ） | カテゴリ別の利用手順 |

---

## メインビルダー

複数のブロックを組み合わせてレイアウトします。

### 主なブロックタイプ

| ブロックタイプ | 役割 |
|-------------|------|
| スライダー | 高さ・幅・切り替え速度 |
| スライド | 画像・テキスト・ボタン・動画 |
| カテゴリ | カテゴリの切り替え |
| 表示アイテム | 表示する内容 |
| ブランド | ブランド画像 |

### スライドの主な設定

| 設定 | 説明 |
|-----|------|
| デスクトップ画像・モバイル画像 | 端末ごとの画像 |
| テキスト | スライドに表示する文章 |
| ボタン・リンク | ボタンの文言と移動先 |
| 動画 | 外部動画または動画ファイル |
| コンテンツ位置・配置 | 文章とボタンの位置 |

---

## レンタルカテゴリ

カテゴリ別に商品をタブ表示します。

---

## おすすめ商品

関連商品をカルーセル表示します。

| 設定 | 説明 | 現在の値 |
|-----|------|---------|
| 取得方法 | 商品の選び方 | 自動 |
| 列数 | 一度に表示する列数 | 4 |
| 最大商品数 | 表示する商品の上限 | 6 |
| 自動再生・速度 | 自動で送る間隔 | オン / 5秒 |

## ご利用ガイド（ステップ）を追加する

**ご利用ガイド（ステップ）** は、予約方法などをカテゴリ別の手順で案内するセクションです。新しく追加しただけでは、現在のページには表示されません。

1. テーマエディタでレンタルトップを開きます。
2. **セクションを追加** > **ご利用ガイド（ステップ）** を選びます。
3. **見出しテキスト**と**サブ見出しテキスト**を入力します。
4. **大カテゴリー**を追加し、**カテゴリー名**を入力します。
5. その直後に **ステップ**を追加します。
6. **キャプチャ画像**、**ステップ名**、**説明テキスト**を入力します。
7. 必要な手順を追加し、**保存**を押します。

同じカテゴリーに含めるステップは、次の **大カテゴリー** より前に並べます。パソコンでは4件ずつ表示され、横へ送って確認できます。

## よくある修正パターン

### スライド画像を変更する

1. **メインビルダー**内の変更したいスライドをクリック
2. デスクトップ画像とモバイル画像を変更
3. **保存**

### カテゴリを追加・変更する

1. **メインビルダー**内のカテゴリを確認
2. カテゴリ名や紐付けを変更
3. **保存**

### おすすめ商品の表示数を変更する

1. **おすすめ商品**をクリック
2. **最大商品数**を変更
3. **保存**

---

## 注意事項

- **メインビルダー**はブロック数が多いセクションです。追加・削除・並べ替えで大きく見た目が変わるため、変更前に現在の並びを確認してください
- スライド画像は**PC用とモバイル用で別々に設定**できます。両方アップロードすることを推奨します
- レンタルカテゴリに表示する商品は、[Shopify管理画面 > 商品](https://admin.shopify.com/store/ease-site/products) でコレクションに属するように設定します

:::dev
内部のセクション名は `home-builder`、`rental-categories`、`rental-display-grid`、`carousel-recommend`、`carousel-articles`、`rental-guide-steps` です。
:::
