# テーマカスタマイズ概要

EASE公式サイトのフロントエンドページは、Shopifyの**テーマエディタ**を使ってブラウザ上で編集できます。コードを直接触らずに、画像・テキスト・レイアウトの変更が可能です。

---

## テーマエディタを開くには

1. [Shopify管理画面](https://admin.shopify.com/store/ease-site)にログイン
2. 左サイドバーの **オンラインストア** > **テーマ** をクリック
3. 現在のテーマ（MISELL）の **カスタマイズ** ボタンをクリック
4. テーマエディタが開きます

---

## 基本用語

| 用語 | 説明 |
|------|------|
| **セクション** | ページを構成する大ブロック（例：ヒーロー、ニュース一覧、お問い合わせ） |
| **ブロック** | セクション内の小ブロック（例：スライド画像1枚、サービス紹介カード） |
| **設定** | セクションやブロックのカスタマイズ項目（テキスト、画像、色など） |
| **テンプレート** | ページ種別ごとの定義ファイル（JSON）。どのセクションを配置するか決める |

---

## ページの切り替え方

テーマエディタ上部の**ページセレクター**（ドロップダウン）で編集対象を切り替えます。

| ページ種別 | セレクターの選び方 |
|-----------|-------------------|
| トップページ | 「ホームページ」を選択 |
| コレクションページ | 「コレクション」> 該当コレクション名 |
| 商品ページ | 「商品」> 該当商品名 |
| 固定ページ | 「ページ」> 該当ページタイトル |
| カート | 「カート」を選択 |

> 💡 **ヒント:** セレクターに表示されないページは、ストアフロントで該当ページを開いてからテーマエディタのURL末尾にアクセスしてください。

---

## 編集の基本操作

### セクションを選ぶ
左サイドバーに現在のページのセクション一覧が表示されます。クリックすると設定パネルが開きます。

### 設定を変更する
設定パネルでテキストを入力したり、画像をアップロードしたり、色を選択できます。

### 変更を保存する
右上の **保存** ボタンをクリックすると本番に反映されます。

### セクションの順番を変える
左サイドバーの **☰** アイコンをドラッグ＆ドロップで並べ替えます。

### セクションを非表示にする
セクション名の横の **👁** アイコンをクリックすると、削除せずに非表示にできます。

---

## セクションの追加と削除

### 追加
左サイドバーの **セクションを追加** ボタンをクリックし、一覧から選びます。

### 削除
セクションを選択 > 右上の **⋯** メニュー > **セクションを削除**

> ⚠️ **注意:** 一度削除すると元に戻せません。非表示（👁）で対応できないか検討してください。
