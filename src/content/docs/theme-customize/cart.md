# カートページ

![カートページ](/images/theme-customize/cart-overview.png)

カートでは、商品・数量・レンタル日程・配送方法・請求先を確認します。最後に **予約を確定する** を押すと、注文内容の確認画面が開きます。

## テーマエディタで開くには

1. Shopify管理画面の **オンラインストア** > **テーマ** を開きます。
2. **カスタマイズ** を押します。
3. ページセレクターで **カート** を選びます。

カートの業務機能はテーマエディタから変更できません。表示を大きく変える場合は開発担当へ依頼してください。

## お客様が予約する流れ

1. 商品と数量を確認します。
2. レンタル開始日と終了日を選びます。
3. 配送方法を選びます。展示会配送では、展示会を選ぶと日程と住所が入ります。
4. 請求先を確認します。
5. **予約を確定する** を押します。
6. **注文内容の確認** で内容を確認し、予約を送信します。

銀行振込のお客様には、予約完了後に「請求書は、商品返却後にメールでお送りいたします。チェックアウトでのお支払いは不要です。」と表示されます。

カード払いのお客様には、予約完了後に「ご利用金額は返却後に確定いたします。確定後、お支払いのご案内をメールでお送りいたします。」と表示されます。予約時に支払うボタンは表示されません。

## 数量と在庫

- 商品ページや商品一覧で指定した数量は、カートへ進んでも引き継がれます。
- カートに入れられる数量は、その商品の利用可能な在庫数までです。
- まとめて追加したときに在庫数へ達した商品は追加されません。画面には追加できた件数と、在庫数に達して追加しなかった件数が表示されます。
- 数量を変更した直後に画面を移動しても、変更後の数量が保たれます。

## 「商品状態」が表示されたとき

商品に **商品状態** が登録されている場合、注文内容の確認より前に **商品状態の確認** が開きます。

1. 商品名と **商品状態** を確認します。
2. 内容を了承できる場合は **商品状態を確認し了承しました** を押します。
3. **注文内容の確認** に進みます。

この表示は、商品マスタの一般備考（公開）をお客様向けの **商品状態** として案内するものです。以前の「特記事項」という表記は使いません。

## 展示会配送

展示会配送の選択肢は、[マスタ管理 > 展示会マスタ](/master-data/)で有効になっている展示会から自動で作られます。

展示会を選ぶと、搬入日は会期開始前、搬出日は会期終了後に設定されます。日数は展示会マスタの設定に従い、日曜・祝日・年末年始を除く営業日で数えます。

選んだ展示会が受付終了になっていた場合は「選択した展示会は受付を終了しました。展示会を選び直してください。」と表示されます。展示会を選び直してください。

## 予約できないとき

商品が予約できない場合は、商品の横に理由が表示されます。

- 在庫が不足している
- 展示会の搬入・搬出日に在庫を確保している
- メンテナンス中または修理中
- 前の予約の返却を確認中

「ご予約を確定できませんでした。時間をおいて再度お試しいただくか、お問い合わせください。」と表示された場合は、時間をおいて再度操作してください。繰り返し表示される場合は、表示された文言と商品名を開発担当へ連絡してください。

:::dev
テンプレートは `templates/cart.json`、主なセクションは `main-cart-rental` です。数量上限は `inventory-guard.js` と一括追加処理で商品単位にそろえています。

商品状態は `rental.general_notes` を表示します。`product-condition-gate.liquid` では全顧客向け表示が有効です。
:::
