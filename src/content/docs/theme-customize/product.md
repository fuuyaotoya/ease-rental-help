# 商品ページ

![商品ページ](/images/theme-customize/product-overview.png)

商品ページは商品の詳細情報、レンタル価格、予約状況カレンダー、関連商品を表示します。レンタル業務に特化したカスタムブロックが含まれています。

---

## テーマエディタで開くには

1. Shopify管理画面 > **オンラインストア** > **テーマ** > **カスタマイズ**
2. ページセレクターで **商品** を選択
3. 編集したい商品を選択

---

## セクション構成

| セクション | セクション名（type） | 役割 |
|-----------|---------------------|------|
| 商品情報 | `main-product` | 商品詳細全般（画像・タイトル・価格・カートボタン等） |
| スペーサー | `spacer` | セクション間の余白 |
| 関連商品 | `carousel-related-products` | 関連・おすすめ商品のカルーセル |

---

## 商品情報セクション（main-product）

商品ページのメインセクションです。複数のブロックで構成されています。

### ブロック一覧

| ブロックタイプ | 説明 | 現在の状態 |
|-------------|------|-----------|
| `collections` | 所属コレクションへのリンク | 表示 |
| `border` | 区切り線 | 表示（2箇所） |
| `details` | 商品詳細情報 | 表示 |
| `title` | 商品タイトル | 表示 |
| `description` | 商品説明文 | 表示 |
| `rental_price_logic` | レンタル料金表示 | 表示 |
| `product-availability-display`（app block） | 予約状況カレンダー | 表示 |
| `rental_inventory_summary` | 在庫状況サマリー | 表示 |
| `icon_with_text` | アイコン付きテキスト | **非表示** |
| `options` | バリアント選択 | 表示 |
| `popups` | ポップアップ情報 | **非表示** |
| `buttons_quantity` | カートボタン + 数量 | 表示 |
| `pickup_availability` | 店舗受取可否 | **非表示** |
| `payments` | 決済方法表示 | 表示 |

### レンタル料金（rental_price_logic）

レンタル料金の表示設定です。

| 設定 | 説明 | 現在の値 |
|-----|------|---------|
| `heading` | セクション見出し | レンタル料金（税抜） |
| `base_label` | 基本料金ラベル | 1日（基本料金） |
| `early_range_label` | 早朝期間ラベル | 当日〜6日目 |
| `late_range_label` | 延長期間ラベル | 7日目以降 |
| `note` | 注記 | （空） |

> ⚠️ **注意:** レンタル料金の実際の金額は、商品のバリアント価格（Shopify管理画面の商品設定）から自動取得されます。このブロックで設定するのは**ラベルと見出し**のみです。

### 予約状況カレンダー（product-availability-display）

EASE Rental Systemアプリが提供するブロックです。商品の予約状況をカレンダー形式で表示します。

| 設定 | 説明 | 現在の値 |
|-----|------|---------|
| `enable_availability_display` | 表示有無 | オン |
| `section_title` | セクション見出し | 予約状況 |
| `description` | 説明文 | ご希望の日程の空き状況を確認できます |
| `show_calendar` | カレンダー表示 | オン |
| `show_legend` | 凡例表示 | オン |

### 在庫状況サマリー（rental_inventory_summary）

| 設定 | 説明 | 現在の値 |
|-----|------|---------|
| `heading` | セクション見出し | 在庫状況 |
| `total_label` | 合計ラベル | 合計在庫 |
| `sku_label` | SKUラベル | SKU |
| `subheading` | 説明文 | 同じグループに含まれる在庫数の合計です。 |

### セクション共通設定

| 設定 | 説明 | 現在の値 |
|-----|------|---------|
| `gallery_size` | ギャラリー列数 | 6 |
| `sidebar` | サイドバー表示 | オフ |
| `enable_sticky_sidebar` | スティッキーサイドバー | オン |
| `show_tabs` | タブ表示 | オン |
| `tabs_type` | タブタイプ | tabs |

| 設定 | 説明 | 現在の値 |

## よくある修正パターン

### レンタル料金のラベルを変更する

1. テーマエディタで **商品情報** セクションをクリック
2. `rental_price_logic` ブロックをクリック
3. `heading`、`base_label` 等を変更
4. **保存**

> 💡 **ヒント:** 料金の金額自体は [Shopify管理画面 > 商品](https://admin.shopify.com/store/ease-site/products) のバリアント価格で設定します

### 関連商品の表示数を変更する

1. テーマエディタで **関連商品** セクションをクリック
2. `max_count` を変更（例：6 → 8）
3. **保存**

### 商品説明文を追加する

1. テーマエディタで **商品情報** セクションをクリック
2. `description` ブロックをクリック
3. `content` にテキストを入力
4. **保存**

> 💡 **ヒント:** `content` を空のままにすると、商品の説明文（Shopify管理画面で設定）が自動表示されます

---

## 注意事項

- **予約状況カレンダー**と**在庫状況サマリー**はEASE Rental Systemアプリが提供しています。アプリがアンインストールされると表示されなくなります
- 商品の画像・タイトル・価格は [Shopify管理画面 > 商品](https://admin.shopify.com/store/ease-site/products) で設定します
- ブロックの順序を変えるには、サイドバーでブロックをドラッグ＆ドロップします
- `rental_price_logic` ブロックは**削除しないでください**。レンタル料金の表示に必要です
