# 商品ページ

![商品ページ](/images/theme-customize/product-overview.png)

商品ページには、商品画像・商品説明・レンタル料金・予約状況・在庫状況・商品状態・サイズが表示されます。

## テーマエディタで開くには

1. Shopify管理画面の **オンラインストア** > **テーマ** を開きます。
2. **カスタマイズ** を押します。
3. ページセレクターで **商品** を選びます。
4. 編集したい商品を選びます。

## お客様に表示される情報

### 商品状態

商品に一般備考（公開）が登録されている場合、商品ページに **商品状態** として表示されます。商品一覧には **状態確認** と表示されます。

予約時には **商品状態の確認** が開きます。お客様が **商品状態を確認し了承しました** を押すと、注文内容の確認へ進みます。

商品登録時は、お客様が予約前に確認すべき傷・汚れ・使用上の注意を一般備考（公開）へ入力してください。スタッフだけが使う特記事項（非公開）は表示しません。

### サイズ

商品ページには、登録されている寸法だけが表示されます。

- **SH**: 座面高
- **SD**: 座面奥行
- **SW**: 座面幅

値は cm で表示されます。これらの寸法は、コレクションページの絞り込みにも使われます。

### 数量

商品ページで選べる数量は、その商品の利用可能な在庫数までです。すでにカートへ入っている同じ商品の数量も含めて判定されます。

上限を超えると「この商品は最大○個までレンタル可能です。現在カートに○個あります。」と表示されます。数量を減らしてから、もう一度カートへ追加してください。

## 表示文言を変更する

### レンタル料金の見出しを変更する

1. **商品情報** を開きます。
2. **レンタル料金表示** を開きます。
3. **見出し**、**基本料金ラベル**、**当日〜6日目ラベル**、**7日目以降ラベル**を変更します。
4. **保存** を押します。

ここで変更できるのは表示文言です。金額はShopify管理画面の商品の価格から表示されます。

### 商品説明文を変更する

商品ごとの説明は、Shopify管理画面の **商品** から変更します。テーマエディタの **商品説明** に文章が入力されている場合は、その文章が優先して表示されます。

### 関連商品の表示数を変更する

1. **関連商品** を開きます。
2. **最大商品数**を変更します。
3. **保存** を押します。

:::dev
主なセクションは `main-product` と `carousel-related-products` です。商品状態は `rental.general_notes`、寸法は `size_seat_height`、`size_seat_depth`、`size_seat_width` を参照します。

レンタル料金表示の内部ブロック名は `rental_price_logic` です。予約状況カレンダーはアプリブロック、在庫状況は `rental_inventory_summary` です。
:::
