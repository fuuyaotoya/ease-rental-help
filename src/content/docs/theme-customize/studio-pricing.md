# スタジオ料金一覧

![スタジオ料金一覧](/images/theme-customize/studio-pricing-overview.png)

スタジオ料金一覧ページは、全スタジオの料金を一覧表形式で表示します。**マウスホバーでスタジオのプレビュー画像が表示される**機能があります。

---

## テーマエディタで開くには

1. Shopify管理画面 > **オンラインストア** > **テーマ** > **カスタマイズ**
2. ページセレクターで **ページ** を選択
3. **スタジオ料金一覧**（または pricing）ページを選択

---

## セクション構成

| セクション | セクション名（type） | 役割 |
|-----------|---------------------|------|
| 料金表 | `studio-pricing-table` | エリア別スタジオ料金一覧 |

---

## 料金表セクション（studio-pricing-table）

### ブロック一覧

| ブロックタイプ | 説明 |
|-------------|------|
| `area_header` | エリア見出し（目黒 / 世田谷） |
| `studio` | 各スタジオの料金行 |

### エリア見出し（area_header）

| 設定 | 説明 | 例 |
|-----|------|---|
| `area_name` | エリア名 | MEGURO（7スタジオ） |

### スタジオ行（studio）

| 設定 | 説明 |
|-----|------|
| `studio_name` | スタジオ名（リンクテキスト） |
| `studio_url` | スタジオ詳細ページURL |
| `preview_image` | **ホバー時に表示されるプレビュー画像** |
| `hours_normal` | 通常営業時間 |
| `hours_overtime` | 時間外区分 |
| `min_hours_normal` | 通常時最低利用時間 |
| `min_hours_overtime` | 時間外最低利用時間 |
| `steel_normal` | スチール料金（通常） |
| `steel_overtime` | スチール料金（時間外） |
| `movie_normal` | 動画撮影料金（通常） |
| `movie_overtime` | 動画撮影料金（時間外） |
| `set_plan` | セットプラン（例：＋PARIS STREET） |

---

## ホバー画像プレビュー機能

### 仕組み

料金表のスタジオ名にマウスカーソルを合わせると、**スタジオのプレビュー画像がフローティング表示**されます。

- **設定箇所:** 各 `studio` ブロックの `preview_image`
- **画像サイズ:** 400px幅にリサイズされて表示
- **動作:** スタジオ名にマウスを合わせると画像が表示され、マウスを離すと消えます

### ホバー画像を変更する

1. テーマエディタで料金一覧ページを開く
2. `studio-pricing-table` セクション内の該当スタジオブロックをクリック
3. `preview_image` の画像を選び直す
4. **保存**

> 💡 **ヒント:** プレビュー画像は**スタジオの代表的な写真**を1枚設定します。横長（16:9等）の画像が推奨です。

### ホバー画像を設定しない場合

`preview_image` を空にすると、ホバー時に画像は表示されず、スタジオ名のリンクのみになります。

---

## よくある修正パターン

### 料金を変更する

1. テーマエディタで料金一覧ページを開く
2. 該当スタジオブロックをクリック
3. `steel_normal`、`steel_overtime`、`movie_normal`、`movie_overtime` を変更
4. **保存**

### 新しいスタジオを追加する

1. テーマエディタで料金一覧ページを開く
2. `studio-pricing-table` セクションで **ブロックを追加** > `studio` を選択
3. 各設定項目を入力（スタジオ名、URL、料金等）
4. `preview_image` にスタジオの代表画像を設定
5. ブロックを該当エリア内の適切な位置にドラッグ
6. **保存**

### スタジオを非表示にする

スタジオを完全に削除せず、一時的に非表示にするには：
1. 該当スタジオブロックの **👁** アイコンをクリックして非表示にする
2. **保存**

---

## 注意事項

- 料金表は**2つのエリア**（目黒・世田谷）に分かれています。`area_header` ブロックで区切ります
- スタジオの**並び順**は `block_order` で制御されます。ドラッグ＆ドロップで並べ替えてください
- `set_plan` に値があるスタジオは、他のスタジオとのセットプランがあることを示します
- ホバー画像の画質は元画像に依存します。**高解像度の画像**をアップロードしてください（推奨：1200px以上の幅）
