# 貸し出し伝票作成

![伝票作成画面](/images/booking-compact/main.png)

レンタル商品の予約伝票を作成・編集する画面です。
顧客情報、商品明細、配送情報、料金計算を一つの画面で管理し、**6ステップ**で伝票を完成させます。

## この画面を開くには

- サイドバーの **「伝票管理」＞「新規予約作成」** をクリック
- 伝票検索画面で伝票を選び **「編集」** ボタンをクリック（既存伝票の編集）
- 予約状況照会から **「伝票に追加」** リンクをクリック
- Shopify のオンライン注文から自動で読み込まれる場合があります

---

## 画面のモード

伝票は2つのモードで表示されます。

| モード | できること | なるタイミング |
|--------|----------|-------------|
| 新規作成 | 新しい伝票を作る | 新しく伝票を作る時 |
| 編集 | 既存の伝票を直す | 既存の伝票を開いた時 |

> **💡 編集モード:** 既存の伝票を開くと **編集モード** になり、そのまま編集できます。「編集モードに切り替え」ボタンはありません。
> なお、確定済みなどの編集できない伝票は、編集できない状態で表示されます。

---

## 画面下部のボタン

画面下部のボタンは、画面のモードと状態によって切り替わります。

| ボタン | いつ表示されるか | できること |
|--------|---------------|----------|
| **保存・計算** | 新規作成・編集モード | 入力内容を保存し、料金を計算します |
| **戻る** | 常に | 編集を取り消して前の画面に戻ります |
| **伝票削除** | 既存伝票を編集中のとき | 伝票を削除します（新規作成時には表示されません） |
| **見積出力** | いつでも（保存前でも可） | 見積書をPDFで出力します |
| **伝票出力** | 保存済みの伝票のとき | 伝票をPDFで出力します |

> **💡 ヒント:** 「見積出力」「伝票出力」でPDFを出力できます。生成中はボタンが **「生成中…」** に切り替わります。連打しても二重に出力されません。

## 操作手順（画面の上から順）

> 伝票作成画面は、上から **顧客 → 伝票情報 → 商品 → 配送 → 調整 → 料金** の順に並んでいます。この順番に入力を進めます。

### ステップ1: 顧客を選ぶ

1. **「顧客検索」** フィールドに会社名・担当者名・電話番号・メールのいずれかを入力します
2. **「検索」** ボタンをクリックします
3. 表示された一覧から該当する顧客をクリックします
4. 顧客情報が自動で入力されることを確認します

> **💡 ヒント:** 顧客が一覧に見つからない場合は、モーダル内の **「Shopifyから同期」** ボタンで最新データを取り込めます。

> **⚠️ 既存伝票の顧客情報は自動更新されません:** 一度保存した伝票の顧客情報（担当者名・会社名・部署・役職・電話・住所など）は、保存時点の**スナップショット**として伝票自体に保持されます。後から[顧客管理](/customer-management/)画面で顧客情報を変更しても、既存の伝票には自動反映されません（請求済み伝票の宛名などが勝手に変わらないようにするための仕様です）。
>
> **新しい情報に更新したい場合:**
> 1. 対象の伝票を**編集モード**で開く（確定済みなど編集できない伝票では不可）
> 2. 「顧客を選択」ボタンから**同じ顧客を再度選択**する（最新のShopify／顧客マスタの情報が再読込されます）
> 3. 反映された内容を確認し、**「保存・計算」** をクリックして更新する

### ステップ2: 伝票情報を入力する

伝票情報セクションで、予約種別・レンタル期間・支払方法・備考などを入力します。

#### 予約種別・レンタル期間

1. **「予約種別」** で「通常予約」または「展示会予約」を選びます
2. **展示会予約** の場合、展示会名を選ぶとレンタル期間が自動で入ります
3. **通常予約** の場合、**「開始日」** と **「終了日」** を入力します（レンタル日数は自動計算）

> **💡 確認:** 終了日が開始日より前の日付の場合、警告が表示されます。

#### 支払方法・注文方法

1. **「支払方法」** を選びます
   - **現金** または **クレジットカード** の場合 → **「支払予定日」** を入力
   - **銀行振込** の場合 → **「請求先担当者」** を入力
2. **「注文方法」** を選びます（WEB / TEL / FAX / EMAIL / 来店）
3. 作成担当者は自動で設定されます（入力不要）

> **⚠️ 振込を選ぶときの注意:** 顧客に請求先住所が登録されている必要があります。登録されていない場合は事前に[顧客管理](/customer-management/)画面で登録してください。

#### 備考（2種類のメモ欄）

| メモ欄 | 入る内容 | 編集 |
|--------|---------|------|
| **注文メモ**（Theme カート由来）| 顧客がオンラインカートで入力したメモ。伝票作成時に自動で取り込まれます | 編集モードで編集可 |
| **伝票備考** | 店舗側のメモ。配送・返却の注意点、社内連絡などに使います | 編集モードで編集可 |

### ステップ3: 商品を追加する

商品の追加方法は3通りあります。

#### 方法A: 商品検索から追加（よく使う方法）

1. **「商品検索」** ボタンをクリックします
2. 商品名、SKU、カテゴリ、タグで検索するか、SKUを改行区切りで複数入力します
3. 検索結果から追加したい商品にチェックを入れます
4. **「選択した商品を追加」** ボタンをクリックします

#### 方法B: Shopifyの予約商品から追加

1. 顧客を選んだ後、**「予約商品から選択」** ボタンが表示されます
2. ボタンをクリックして、追加する商品を選びます

#### 方法C: その他商品を手動追加

1. **「その他商品追加」** ボタンをクリックします
2. カテゴリ、商品名、数量、単価を入力します
3. **「追加」** ボタンをクリックします

**商品を追加したら:**
- 金額が自動で計算されます
- 明細点数と合計金額が画面上部に反映されます

#### 在庫ステータスの見方

商品を追加すると、在庫の状態が記号で表示されます。

| 記号 | 意味 | 説明 |
|------|------|------|
| ⚪︎ | 未確認 | まだ在庫確認をしていない |
| 確 | 確保済み | 在庫が確保されている |
| 仮 | 仮押さえ | 一時的に在庫を押さえている |
| △ | 残りわずか | 在庫が少ない |
| × | 在庫切れ | 在庫がない |

> **💡 ヒント:** 在庫確認に失敗した場合は **「再確認」** ボタンが表示されます。クリックすると在庫情報を再取得します。

#### 便利な機能

- **一括設定:** 複数商品の期間・数量・値引きをまとめて設定できます
- **行の複製:** 明細行の右端にあるボタンで同じ内容をコピーできます
- **キーボードショートカット:** `Ctrl+S` で保存、`Ctrl+N` で商品追加

### ステップ4: 配送情報を入力する

1. 配送情報セクションの **「+ 配送追加」** ボタンをクリックします
2. 配送タイプ（**搬入** または **搬出**）を選びます
3. 配送日を入力します
4. 時間指定がある場合は設定します（未定 / 指定 / 午前 / 午後 / 終日）
5. 配送先の住所・担当者名などを入力します
6. 必要に応じて複数の配送を追加します

> **⚠️ 上限:** 1つの伝票につき配送情報は **最大10件** までです。

### ステップ5: 調整項目を確認する（必要な場合）

延長料金・破損・キャンセル料などの調整は、**返却受付時** に入力します。伝票作成時は通常空欄のままで進めてください。

> 調整の入力方法は [返却ダッシュボード](/bookings-return/) を参照してください。

### ステップ6: 料金を確認する

画面下部の料金欄で、請求金額と入金状況を確認します。

| 項目 | 説明 |
|------|------|
| **請求金額** | 小計 ＋ 消費税 |
| **前払金** | すでに受け取った前払い金 |
| **入金済** | 入金済みの金額 |
| **残高** | 請求金額 − 前払金 − 入金済 |

**前払金・入金の入力:** 料金欄の **「前払い金入力」** と **「入金入力」** ボタンから、それぞれダイアログを開いて金額を入力します。入力すると「前払金」「入金済」「残高」に反映されます。

### ステップ7: 保存する

1. 入力内容に間違いがないか確認します
2. 画面下部の **「保存・計算」** ボタンをクリックします
3. 保存完了後の動作は支払方法によって異なります：
   - **現金・クレジットカード:** [伝票検索](/slip-search/)画面に自動で移動します
   - **銀行振込:** [請求書作成](/invoice-create-new/)へのリンクが表示されます

> **💡 確認:** 保存すると伝票番号が自動で割り当てられます。

> **💡 見積出力:** 保存前でも **「見積出力」** ボタンで見積書をPDF出力できます。

## 料金の見方

保存後、料金セクションに以下が表示されます。

| 項目 | 説明 |
|------|------|
| 商品小計 | 商品明細の合計金額 |
| 値引き計 | 各商品の値引き額の合計 |
| 配送料計 | 配送情報の送料合計 |
| 延長料金計 | 返却が遅れた場合の追加料金 |
| キャンセル料計 | キャンセルした商品の料金 |
| 伝票割引 | 伝票全体への割引額（手動入力可） |
| **小計** | **上記の合計** |
| 消費税（10%） | 消費税額 |
| **請求金額** | **小計 + 消費税** |
| 前払金 | すでに受け取った前払い金 |
| 入金済 | 入金済みの金額 |
| 残高 | 請求金額 − 前払金 − 入金済 |
| **返金可能額** | **決済済みクレカ伝票で過払いが発生した場合に表示**（過払い > 0 の時のみ） |

> **💡 過払い返金:** 決済済みクレカ伝票で商品を削除/価格変更して過払いが発生した場合、「返金可能額」カードが表示されます。「返金を実行」ボタンからShopify返金と通知メールを送信できます。

## 決済済みクレカ伝票の編集と精算

決済済みクレジットカード伝票を編集して金額が変更された場合、精算UIが表示されます。

### 過払いが発生した場合

商品を削除したり価格を下げたりして、既に入金済みの金額を上回る返金が必要になった場合:

1. **「返金可能額」** カードが表示されます（過払い額 > 0 の時のみ）
2. **「返金を実行」** ボタンをクリックします
3. 確認モーダルでShopify返金と通知メールの内容を確認します
4. **「返金を確定」** ボタンで実行します

> **⚠️ 重要:** 返金を実行すると、Shopifyで返金処理が行われ、顧客に通知メールが送信されます。取消はできません。

### 商品を追加した場合

決済済みクレカ伝票に商品を追加した場合:

1. **「追加請求」** ボタンが表示されます
2. 追加商品分のDraft Order（DO④）が作成され、請求チャネル表に追加されます
3. 顧客のクレジットカードへ自動課金されます

> **💡 請求チャネル表:** 決済済みクレカ伝票の請求チャネル表には、既存の請求（DO①〜DO③）に加えて、商品追加分のDO④・配送キャンセル料のDO⑤が表示されることがあります。

### 配送をキャンセルした場合（DO⑤）

配送がキャンセルされキャンセル料（0円超）が発生している場合、請求チャネル欄の近くに「**キャンセル料を請求する（DO⑤）**」ボタンが表示されます（※配送料DO②を未送信の場合のみ）。詳しい手順・経路は [配送料確定・Shopify請求 / 配送キャンセル料（DO⑤）](/delivery-fee-shopify-flow/#配送キャンセル料のクレカ後課金draft-order⑤) を参照してください。

## 仮押さえ（仮予約）について

在庫を一時的に確保する「仮押さえ」機能があります。

### 機能の目的

「仮押さえ」は、商品の予約意向を確認中や、最終確定前の段階で在庫を確保しておくための機能です。

**主な使い道:**

- 顧客から「予約したい」という問い合わせがあったが、最終確定前の場合
- 複数の商品を比較検討中で、仮押さえしながら検討する場合
- 予算承認待ちで、承認後に正式予約する場合
- 在庫状況を確認しながら、詳細を詰める場合

### 設定・解除の手順

**設定手順:**

1. 伝票一覧または商品詳細画面で、**「仮」** 列のトグルをオンにします
2. ステータスが **「仮押さえ」** に変わります
3. 在庫が確保されます（他の予約から確保されます）

**解除手順:**

1. **「仮」** 列のトグルをオフにします
2. 伝票が削除されるか、ステータスが変わります
3. 確保されていた在庫が解放されます

### 確定予約との優先順位

仮押さえの在庫は、**確定予約よりも優先度が低い**です。

- 確定予約の依頼が来た場合は、仮押さえの顧客に確認した上で、確定予約を優先します
- 仮押さえ期間中に確定予約が入った場合、在庫確保は解除されます

> **⚠️ 重要:** 仮押さえは「確保」ではなく「仮押さえ」です。確定予約が入った場合、在庫は確保解除されます。

### 無期限保持

仮押さえには**期限がありません**（無期限保持）。

- 時間制限はないため、長期間仮押さえすることも可能です
- ただし、在庫を圧迫するため、早期に確定または解除することを推奨します
- 確定予約の依頼が来た場合は、手動でキャンセルするか、確定予約を優先してください

### 仮予約から確定予約への移行

仮押さえ状態から確定予約への移行手順:

1. 伝票の編集画面を開きます
2. **「編集モードに切り替え」** ボタンをクリックします
3. 顧客情報・商品明細・配送情報を入力します
4. **「保存」** ボタンをクリックします
5. 伝票が確定予約として保存されます

### ステータス表示

| ステータス | 説明 | 優先度 |
|----------|------|--------|
| 仮押さえ | 在庫仮確保中 | 低（確定予約に割り込まれる可能性あり） |
| 確定予約 | 在庫確保済み | 高（仮押さえより優先） |

> **💡 メモ:** 仮押さえ中の伝票は、ステータス列に **「仮」** マークで表示されます。

## 延長料金の計算

レンタル期間が延びた場合、日数に応じて料金が増えます。

**基本ルール:**
- **1〜6日目:** 前日比で基本料金の **20%** ずつ増加
- **7日目以降:** 6日目の金額（基本料金の200%）から、前日比で基本料金の **10%** ずつ増加

**計算例（基本料金 = 1,000円の場合）:**

| 日数 | 金額 | 増分 |
|------|------|------|
| 1日目 | 1,000円 | — |
| 2日目 | 1,200円 | +200円 |
| 3日目 | 1,400円 | +200円 |
| 4日目 | 1,600円 | +200円 |
| 5日目 | 1,800円 | +200円 |
| 6日目 | 2,000円 | +200円 |
| 7日目 | 2,100円 | +100円 |
| 8日目 | 2,200円 | +100円 |

## 伝票の状態の流れ

伝票は以下の順番で状態が進みます。

| 状態 | 説明 |
|------|------|
| 下書き | 仮予約の初期状態 |
| 確定 | 現金・クレジットカードの場合、作成直後にこの状態になります |
| 処理中 | 銀行振込・Shopify注文の場合、作成直後にこの状態になります |
| 金額確認待ち | 返却受付後の状態 |
| 金額確定 | 金額確定処理後の状態 |
| 請求待ち | 請求書の発行待ち |
| 入金待ち | 入金確認待ち |
| 完了 | すべての処理が終わった状態 |
| キャンセル | キャンセルされた状態 |

> **💡 重要:** ピッキングや出荷をしても、伝票の状態は変化しません。それぞれ別のステータスとして管理されます。詳しくは[ステータス遷移図](/appendix/status-flow/)をご覧ください。

## 注意事項

- 商品明細は1伝票につき **最大50件** まで登録できます
- 配送情報は1伝票につき **最大10件** まで登録できます
- SKU一括検索は **最大100個** まで入力できます
- 既存の伝票を開くと **編集モード** になり、そのまま編集できます（確定済みなどの編集できない伝票は除く）
- 振込支払の場合、伝票保存後に[請求書作成](/invoice-create-new/)が別途必要です
- 明細の在庫ステータスが「仮」「△」「×」の場合、保存時に確認ダイアログが表示されます
- 前払金は保存前でも記録できます
