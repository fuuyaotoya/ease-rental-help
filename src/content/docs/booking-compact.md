# 貸し出し伝票作成

![伝票作成画面](/images/booking-compact/main.png)

レンタル商品の予約伝票を作成・編集する画面です。
顧客情報、商品明細、配送情報、料金計算を一つの画面で管理し、**6ステップ**で伝票を完成させます。

## この画面を開くには

- サイドバーの **「受注・予約」＞「貸出伝票作成」** をクリック
- 伝票検索画面で伝票を選び **「編集」** ボタンをクリック（既存伝票の編集）
- [商品予約状況照会](/product-reservation-inquiry/) から **「伝票作成」「伝票へ」** で遷移する
- Shopify のオンライン注文から自動で読み込まれる場合があります
- 旧URL `/bookings/{id}` を開くと、自動的に `/booking-compact?id={id}` へリダイレクトされます（[#1306](https://github.com/iziz-system/ease-rental-frontend/issues/1306)）。伝票のキャンセル・金額確定解除・支払分岐などの状態遷移ボタンと、メール送信履歴もこの画面に集約されています。

---

## 画面の状態

**閲覧モード・編集モードを切り替えるスイッチはありません。** 伝票を開くとそのまま編集できます。

| 状態 | できること | なるタイミング |
|--------|----------|-------------|
| 新規作成 | 新しい伝票を作る | 新しく伝票を作る時 |
| 既存伝票 | 開いてそのまま直せる | 既存の伝票を開いた時 |

> **💡 確認目的の導線からは閲覧モードで開きます（[#1361](https://github.com/iziz-system/ease-rental-frontend/issues/1361)）:** [配送料確定（クレカ顧客）](/bookings-shipping-fee/)の一覧など、内容確認が目的の導線から伝票を開いた場合は **閲覧モード（読み取り専用）** で開きます。誤編集を防ぐためのもので、伝票検索など通常の導線から開けばそのまま編集できます。

> **⚠️ 編集できない伝票:** 金額確定済みなどロックされた伝票は、商品の追加・削除・期間変更ができない状態で表示されます（[#1311](https://github.com/iziz-system/ease-rental-frontend/issues/1311)）。

## 画面下部のボタン

画面下部のボタンは、画面のモードと状態によって切り替わります。

| ボタン | いつ表示されるか | できること |
|--------|---------------|----------|
| **保存・計算** | 新規作成・編集モード | 入力内容を保存し、料金を計算します |
| **戻る** | 常に | 編集を取り消して前の画面に戻ります |
| **伝票削除** | 既存伝票を編集中のとき | 伝票を削除します（新規作成時には表示されません） |
| **見積出力** | いつでも（保存前でも可） | 見積書をPDFで出力します |
| **伝票出力** | 保存済みの伝票のとき | 伝票をPDFで出力します |

> **💡 ヒント:** 「見積出力」「伝票出力」でPDFを出力できます。生成中はボタンが **「生成中…」** に切り替わります。連打しても二重に出力されません。

## 操作手順（画面の上から順）

> 伝票作成画面は、上から **顧客 → 伝票情報 → 商品 → 配送 → 調整 → 料金** の順に並んでいます。この順番に入力を進めます。

### ステップ1: 顧客を選ぶ

1. **「顧客検索」** フィールドに会社名・担当者名・電話番号・メールのいずれかを入力します
2. **「検索」** ボタンをクリックします
3. 表示された一覧から該当する顧客をクリックします
4. 顧客情報が自動で入力されることを確認します

> **💡 ヒント:** 顧客が一覧に見つからない場合は、モーダル内の **「Shopifyから同期」** ボタンで最新データを取り込めます。

> **💡 銀行振込可のバッジ（[#1295](https://github.com/iziz-system/ease-rental-frontend/issues/1295)）:** 顧客選択ダイアログの会社名列に、銀行振込が可能な顧客には緑色の **銀行振込可** バッジが表示されます。このバッジがある顧客のみ「支払方法」で **銀行振込** を選択できます。

> **⚠️ 既存伝票の顧客情報は自動更新されません:** 一度保存した伝票の顧客情報（担当者名・会社名・部署・役職・電話・住所など）は、保存時点の**スナップショット**として伝票自体に保持されます。後から[顧客管理](/customer-management/)画面で顧客情報を変更しても、既存の伝票には自動反映されません（請求済み伝票の宛名などが勝手に変わらないようにするための仕様です）。
>
> **新しい情報に更新したい場合:**
> 1. 対象の伝票を**編集モード**で開く（確定済みなど編集できない伝票では不可）
> 2. 「顧客を選択」ボタンから**同じ顧客を再度選択**する（最新のShopify／顧客マスタの情報が再読込されます）
> 3. 反映された内容を確認し、**「保存・計算」** をクリックして更新する

### ステップ2: 伝票情報を入力する

伝票情報セクションで、予約種別・レンタル期間・支払方法・備考などを入力します。

#### 予約種別・レンタル期間

1. **「予約種別」** で「通常予約」または「展示会予約」を選びます
2. **展示会予約** の場合、展示会名を選ぶとレンタル期間が自動で入ります
3. **通常予約** の場合、**「開始日」** と **「終了日」** を入力します（レンタル日数は自動計算）

> **💡 確認:** 終了日が開始日より前の日付の場合、警告が表示されます。

> **⚠️ 金額確定済み伝票の商品編集ロック（[#1311](https://github.com/iziz-system/ease-rental-frontend/issues/1311)）:** 金額が確定済みの伝票は、商品の追加・削除・数量変更・レンタル期間の変更が **ロック** されます（商品編集ロックは配送料の請求作成/金額確定にも追従）。展示会予約セレクターから期間を変更してもロックは解除されず、期間ロックの迂回はできません。追加・変更は **別伝票（DO④）** で行ってください。

#### 支払方法・注文方法

1. **「支払方法」** を選びます（**店頭支払い / 銀行振込 / Shopify** の3種）
   - **店頭支払い** の場合 → **「支払予定日」** を入力します（Shopify・銀行振込では非表示）
   - **銀行振込** は、顧客選択ダイアログで **銀行振込可** バッジのある顧客のみ選択できます
2. **「注文方法」** を選びます（WEB / TEL / FAX / EMAIL / 来店）
3. 作成担当者は自動で設定されます（入力不要）

> **💡 請求先担当者は自動表示（読取専用）:** 請求先担当者は支払方法にかかわらず常時表示され、請求先マスタに登録された担当者が自動で入ります（伝票画面では編集できません）。修正は[顧客管理](/customer-management/)の請求先タブで行ってください。

> **⚠️ 銀行振込を選ぶときの注意:** 銀行振込は **銀行振込可のタグが付いた顧客** のみ選択できます（初回は全員クレジットカード決済・2回目以降の審査で付与）。

#### 備考（2種類のメモ欄）

| メモ欄 | 入る内容 | 編集 |
|--------|---------|------|
| **注文メモ**（Theme カート由来）| 顧客がオンラインカートで入力したメモ。伝票作成時に自動で取り込まれます | 編集モードで編集可 |
| **伝票備考** | 店舗側のメモ。配送・返却の注意点、社内連絡などに使います | 編集モードで編集可 |

### ステップ3: 商品を追加する

商品の追加方法は3通りあります。

#### 方法A: 商品検索から追加（よく使う方法）

1. **「商品検索」** ボタンをクリックします
2. 商品名、SKU、カテゴリ、タグで検索するか、SKUを改行区切りで複数入力します
3. 検索結果から追加したい商品にチェックを入れます
4. **「選択した商品を追加」** ボタンをクリックします

#### 方法B: Shopifyの予約商品から追加（お客様がカートで予約した商品）

お客様が Shopify のオンラインカートで予約した商品（Draft Order）を、伝票の明細に取り込む導線です。

- 伝票作成画面を **`?draft_order_id={ID}` 付きのURLで開くと、該当する予約商品が自動で読み込まれます**（顧客情報・商品明細・配送情報がまとめて反映されます）
- 読み込まれた商品は明細行として追加されるので、通常どおり数量・期間を調整して保存します

> **💡 対象:** 選択中の顧客に紐づく Shopify の Draft Order（未決済の予約）の商品です。該当がない場合は「予約商品が見つかりません」と表示されます。

#### 方法C: その他商品を手動追加

1. **「その他商品追加」** ボタンをクリックします
2. カテゴリ、商品名、数量、単価を入力します
3. **「追加」** ボタンをクリックします

**商品を追加したら:**
- 金額が自動で計算されます
- 明細点数と合計金額が画面上部に反映されます

#### 在庫ステータスの見方

商品を追加すると、在庫の状態が記号で表示されます。

| 記号 | 意味 | 説明 |
|------|------|------|
| ⚪︎ | 未確認 | まだ在庫確認をしていない |
| 確 | 確保済み | 在庫が確保されている |
| 仮 | 仮押さえ | 一時的に在庫を押さえている |
| △ | 残りわずか | 在庫が少ない |
| × | 在庫切れ | 在庫が利用できない（理由が併記されます） |

> **💡 ×の理由メッセージ:** ×になる場合は、選択レンタル期間や商品の状態に応じて理由が表示されます（例：期間に休業日が含まれている・メンテナンス中・修理中・在庫が全て予約済み・他予約の返却遅延により利用不可 など）。表示された理由が納得できない場合は、レンタル期間を変えるか商品担当者にご確認ください。

> **💡 ヒント:** 在庫確認に失敗した場合は **「再確認」** ボタンが表示されます。クリックすると在庫情報を再取得します。

#### 特記事項のある商品（カレンダーアイコンが赤）

商品に特記事項（キズ・破れ・取り扱い上の注意など）が登録されている場合、商品明細の **予約状況カレンダーアイコン（📅）が赤く表示** されます。特記事項のない商品は青のままです。赤いアイコンの商品は、予約前に特記事項をご確認ください。

> **💡 ヒント:** 特記事項の内容は、📅アイコンをクリックして開く予約状況カレンダーのモーダルで確認できます（商品情報エリアに「特記事項」として表示）。詳しくは [商品予約状況照会](/product-reservation-inquiry/) をご覧ください。

#### 便利な機能

- **一括設定:** 複数商品の期間・数量・値引きをまとめて設定できます
- **行の並び替え:** 明細行の左端をドラッグして順番を入れ替えられます
- **在庫の再確認:** 在庫状況の確認に失敗した行は「再確認」ボタンで取得し直せます

> **💡 登録担当者は上書きされません（[#1322](https://github.com/iziz-system/ease-rental-frontend/issues/1322)）:** 既存の明細行の「登録担当者」は、別のスタッフが伝票を保存し直しても **上書きされません**（既存行は更新を省略して保持）。新規に追加した行のみ、保存時のスタッフが登録担当者として記録されます。

### ステップ4: 配送情報を入力する

1. 配送情報セクションの **「+ 配送追加」** ボタンをクリックします
2. 配送タイプ（**搬入** または **搬出**）を選びます
3. 配送日を入力します
4. 時間指定がある場合は設定します（未定 / 指定 / 午前 / 午後 / 終日）
5. 配送先の住所・担当者名などを入力します
6. 必要に応じて複数の配送を追加します

> **⚠️ 上限:** 1つの伝票につき配送情報は **最大10件** までです。

> **💡 手入力した配送料は優先されます（[#1310](https://github.com/iziz-system/ease-rental-frontend/issues/1310)）:** 配送モーダルの配送料は配送先のエリア料金から自動表示されますが、**手入力で変更した場合は手入力値が優先** されます。保存時にエリア料金で上書きされることはありません。

> **金額入力欄の見切れ防止（[#1302](https://github.com/iziz-system/ease-rental-frontend/issues/1302)）:** 配送一覧の配送料・キャンセル料入力欄は、大きな金額でも見切れないように右寄せ・等幅数字で表示されます（入力欄の上下スピナーは非表示）。

### ステップ5: 調整項目を確認する（必要な場合）

延長料金・破損・キャンセル料などの調整は、**返却受付時** に入力します。伝票作成時は通常空欄のままで進めてください。

> 調整の入力方法は [返却ダッシュボード](/bookings-return/) を参照してください。

### ステップ6: 料金を確認する

画面下部の料金欄で、請求金額と入金状況を確認します。

| 項目 | 説明 |
|------|------|
| **請求金額** | 小計 ＋ 消費税 |
| **前払金** | すでに受け取った前払い金 |
| **入金済** | 入金済みの金額 |
| **残高** | 請求金額 − 前払金 − 入金済 |

**前払金・入金の入力:** 料金欄の **「前払い金入力」** と **「入金入力」** ボタンから、それぞれダイアログを開いて金額を入力します。入力すると「前払金」「入金済」「残高」に反映されます。

> 料金内訳の詳細は [料金の見方](#料金の見方) を参照してください。

> **💡 ヘッダーの支払バッジ（[#1309](https://github.com/iziz-system/ease-rental-frontend/issues/1309)）:** 伝票ヘッダーに現在の支払状態（未払い / 一部入金 / 支払済み）を表示します。後払いクレカ伝票で配送料の金額確定のみ完了し Shopify 決済待ちのときは「**DO①金額確定・未決済**」バッジを併記します。

### ステップ7: 保存する

1. 入力内容に間違いがないか確認します
2. 画面下部の **「保存・計算」** ボタンをクリックします
3. 保存が完了すると、画面上部にメッセージが表示されます（支払方法による違いはありません）:
   - **新規作成時:** 「伝票を作成しました（伝票番号）」と表示され、**そのまま同じ画面で作成した伝票を続けて編集できます**（他の画面へ自動移動はしません）
   - **既存伝票の更新時:** 「伝票を更新しました」と表示されます

> **💡 確認:** 保存すると伝票番号が自動で割り当てられます。銀行振込の伝票は、[返却・金額確定](/bookings-return/)のタイミングで請求書が自動発行されます（#2260）。

> **💡 見積出力:** 保存前でも **「見積出力」** ボタンで見積書をPDF出力できます。

> **⚠️ 保存失敗のメッセージは自動で消えません（[#1312](https://github.com/iziz-system/ease-rental-frontend/issues/1312)）:** 「保存・計算」でエラーが発生した場合、理由を書いた赤いトーストが**自動で消えずに画面に残り**、「閉じる」ボタンでしか消えません。保存できたと誤認して次の作業に進むのを防ぐためです。メッセージの原因を取り除いてから再度保存してください。

> **⚠️ 明細キャンセル失敗時のロールバック（[#1307](https://github.com/iziz-system/ease-rental-frontend/issues/1307)）:** 明細のキャンセル処理がサーバ側で拒否（400）された場合、キャンセル取り消し状態を元に戻し、失敗理由を**永続トースト**で表示します。一部だけ成功した場合は「成功 N件 / 失敗 M件」と件数を分けて表示し、成功分は画面が最新化されます。

## 料金の見方

保存後、料金セクションに以下が表示されます。

> **💡 金額は保存前から確定値を表示（[#1355](https://github.com/iziz-system/ease-rental-frontend/issues/1355)・[#1365](https://github.com/iziz-system/ease-rental-frontend/issues/1365)）:** 料金欄の各金額は、サーバーの計算エンジン（dry-run 計算）による **確定値** です。キャンセル保留中の明細や配送キャンセル料がある場合も、保存操作の前に最終的な金額がそのまま表示されます（保存前後で金額が変わることはありません）。

| 項目 | 説明 |
|------|------|
| 商品小計 | 商品明細の合計金額 |
| 値引き計 | 各商品の値引き額の合計 |
| 配送料計 | 配送情報の送料合計 |
| 延長料金計 | 返却が遅れた場合の追加料金 |
| キャンセル料計 | キャンセルした商品の料金 |
| 伝票割引 | 伝票全体への割引額（手動入力可） |
| **小計** | **上記の合計** |
| 消費税（10%） | 消費税額 |
| **請求金額** | **小計 + 消費税** |
| 前払金 | すでに受け取った前払い金 |
| 入金済 | 入金済みの金額 |
| 残高 | 請求金額 − 前払金 − 入金済 |
| **返金可能額** | **決済済みクレカ伝票で過払いが発生した場合に表示**（過払い > 0 の時のみ） |

> **💡 過払い返金:** 決済済みクレカ伝票で商品を削除/価格変更して過払いが発生した場合、「返金可能額」カードが表示されます。「返金を実行」ボタンからShopify返金と通知メールを送信できます。

## 決済済みクレカ伝票の編集と精算

決済済みクレジットカード伝票を編集して金額が変更された場合、精算UIが表示されます。

### 過払いが発生した場合

商品を削除したり価格を下げたりして、既に入金済みの金額を上回る返金が必要になった場合:

1. **「返金可能額」** カードが表示されます（過払い額 > 0 の時のみ）
2. **「返金を実行」** ボタンをクリックします
3. 確認モーダルでShopify返金と通知メールの内容を確認します
4. **「返金を確定」** ボタンで実行します

> **⚠️ 重要:** 返金を実行すると、Shopifyで返金処理が行われ、顧客に通知メールが送信されます。取消はできません。

### 商品を追加した場合

決済済みクレカ伝票に商品を追加した場合:

1. **「追加請求」** ボタンが表示されます
2. 追加商品分のDraft Order（DO④）が作成され、請求チャネル表に追加されます
3. 顧客のクレジットカードへ自動課金されます

> **💡 請求チャネル表:** 決済済みクレカ伝票の請求チャネル表には、既存の請求（DO①〜DO③）に加えて、商品追加分のDO④・配送キャンセル料のDO⑤が表示されることがあります。

> **💡 請求チャネル表の「領収書番号」列（[#1304-D](https://github.com/iziz-system/ease-rental-frontend/issues/1304-D)）:** 決済済みクレジットカード伝票の請求チャネル表には、各決済（DO①〜⑤）に対応する**領収書番号**（伝票番号-NN 形式）が行ごとに表示されます。クレジットカード決済は請求書でなく**支払いごとの領収書**が発行されるため（[BE #1993](https://github.com/iziz-system/ease-rental-backend/issues/1993)）、未決済行や該当なしの行は `--` 表示になります。

> **💡 請求チャネル表の追加表示（[#1301](https://github.com/iziz-system/ease-rental-frontend/issues/1301)・[#1304-B](https://github.com/iziz-system/ease-rental-frontend/issues/1304-B)）:** 後払いクレジットカード伝票で配送料が①に統合されている場合、①は「**請求済（配送料込）**」（amber）・②は「**①統合済**」（slate）と表示されます（伝票検索リストのドットでも同じ表示）。決済が返金済みの①は「**返金済**」（青）、一部返金の場合は「**一部返金**」（紫）で表示されます。

### 配送をキャンセルした場合（DO⑤）

配送がキャンセルされキャンセル料（0円超）が発生している場合、請求チャネル欄の近くに「**キャンセル料を請求する（DO⑤）**」ボタンが表示されます（※配送料DO②を未送信の場合のみ）。詳しい手順・経路は [配送料確定・Shopify請求 / 配送キャンセル料（DO⑤）](/delivery-fee-shopify-flow/#配送キャンセル料のクレカ後課金draft-order⑤) を参照してください。

> **💡 ボタンが表示されないケース（[#1211](https://github.com/iziz-system/ease-rental-frontend/issues/1211)）:** 配送料DO②未送信に加え、**キャンセル料DO⑤を既に作成済み**の伝票でもボタンは表示されません（再作成はBEが400で拒否します）。キャンセル料請求を作成済みの場合は、請求チャネル表の「キャンセル料」行を確認してください。

> **伝票全体をキャンセルする場合（BE [#2506](https://github.com/iziz-system/ease-rental-backend/issues/2506)）:** 伝票全体のキャンセルでは、まだキャンセルされていない（アクティブな）配送料にも **#719 料率（当日100%/前日30%）** のキャンセル料が別途計上されます。事前にキャンセル料の警告ダイアログ（[#2462](https://github.com/iziz-system/ease-rental-backend/issues/2462)）と残アクティブ配送料の警告（[#1320](https://github.com/iziz-system/ease-rental-frontend/issues/1320)）が表示されます。料率と計算機は [付録: キャンセル料率](/appendix/fee-calculation/) を参照。

> **⚠️ キャンセルされない配送の一覧（[#1357](https://github.com/iziz-system/ease-rental-frontend/issues/1357)）:** 伝票全体のキャンセルでは **配送はキャンセルされません**。キャンセル確認モーダルには、取り消されずに残る配送の一覧（配送先・日付・種別・料金）が表示されます。**料金0円の配送（搬入予定など）も一覧に含まれます** — 0円でも物理配送予定として残り続けるため、不要な場合は配送のキャンセルを別途行ってください。

> **💡 キャンセル料の回収（BE [#2715](https://github.com/iziz-system/ease-rental-backend/issues/2715)・[#2710](https://github.com/iziz-system/ease-rental-backend/issues/2710)・[#2703](https://github.com/iziz-system/ease-rental-backend/issues/2703)）:** キャンセル料が発生するキャンセルでは、キャンセル確定時にキャンセル料の Draft Order が作成され、**支払リンク付きの請求メールが顧客へ自動送信**されます（銀行振込・店頭後払いの伝票が対象）。後から支払リンクが必要になった場合は、[請求書・領収書管理](/invoices-list/)の「⋮」メニュー「**支払いURL**」から開けます。

## 仮押さえ（仮予約）について

在庫を一時的に確保する「仮押さえ」機能があります。

### 機能の目的

「仮押さえ」は、商品の予約意向を確認中や、最終確定前の段階で在庫を確保しておくための機能です。

**主な使い道:**

- 顧客から「予約したい」という問い合わせがあったが、最終確定前の場合
- 複数の商品を比較検討中で、仮押さえしながら検討する場合
- 予算承認待ちで、承認後に正式予約する場合
- 在庫状況を確認しながら、詳細を詰める場合

### 設定・解除の手順

**設定手順:**

1. 伝票一覧または商品詳細画面で、**「仮」** 列のトグルをオンにします
2. ステータスが **「仮押さえ」** に変わります
3. 在庫が確保されます（他の予約から確保されます）

**解除手順:**

1. **「仮」** 列のトグルをオフにします
2. 伝票が削除されるか、ステータスが変わります
3. 確保されていた在庫が解放されます

### 確定予約との優先順位

仮押さえの在庫は、**確定予約よりも優先度が低い**です。

- 確定予約の依頼が来た場合は、仮押さえの顧客に確認した上で、確定予約を優先します
- 仮押さえ期間中に確定予約が入った場合、在庫確保は解除されます

> **⚠️ 重要:** 仮押さえは「確保」ではなく「仮押さえ」です。確定予約が入った場合、在庫は確保解除されます。

### 無期限保持

仮押さえには**期限がありません**（無期限保持）。

- 時間制限はないため、長期間仮押さえすることも可能です
- ただし、在庫を圧迫するため、早期に確定または解除することを推奨します
- 確定予約の依頼が来た場合は、手動でキャンセルするか、確定予約を優先してください

### 仮予約から確定予約への移行

仮押さえ状態から確定予約への移行手順:

1. 伝票の編集画面を開きます（そのまま編集できます）
2. 顧客情報・商品明細・配送情報を入力します
3. **「保存・計算」** ボタンをクリックします
4. 伝票が確定予約として保存されます

### ステータス表示

| ステータス | 説明 | 優先度 |
|----------|------|--------|
| 仮押さえ | 在庫仮確保中 | 低（確定予約に割り込まれる可能性あり） |
| 確定予約 | 在庫確保済み | 高（仮押さえより優先） |

> **💡 メモ:** 仮押さえ中の伝票は、ステータス列に **「仮」** マークで表示されます。

## 延長料金の計算

レンタル期間が延びた場合、日数に応じて料金が増えます。

**基本ルール:**
- **1〜6日目:** 前日比で基本料金の **20%** ずつ増加
- **7日目以降:** 6日目の金額（基本料金の200%）から、前日比で基本料金の **10%** ずつ増加

**計算例（基本料金 = 1,000円の場合）:**

| 日数 | 金額 | 増分 |
|------|------|------|
| 1日目 | 1,000円 | — |
| 2日目 | 1,200円 | +200円 |
| 3日目 | 1,400円 | +200円 |
| 4日目 | 1,600円 | +200円 |
| 5日目 | 1,800円 | +200円 |
| 6日目 | 2,000円 | +200円 |
| 7日目 | 2,100円 | +100円 |
| 8日目 | 2,200円 | +100円 |

## 伝票の状態の流れ

伝票は以下の順番で状態が進みます。

| 状態 | 説明 |
|------|------|
| 下書き | 仮予約の初期状態 |
| 確定 | 現金・クレジットカードの場合、作成直後にこの状態になります |
| 処理中 | 銀行振込・Shopify注文の場合、作成直後にこの状態になります |
| 金額確認待ち | 返却受付後の状態 |
| 金額確定 | 金額確定処理後の状態 |
| 請求待ち | 請求書の発行待ち |
| 入金待ち | 入金確認待ち |
| 完了 | すべての処理が終わった状態 |
| キャンセル | キャンセルされた状態 |

> **💡 重要:** ピッキングや出荷をしても、伝票の状態は変化しません。それぞれ別のステータスとして管理されます。詳しくは[ステータス遷移図](/appendix/status-flow/)をご覧ください。

## 注意事項

- 商品明細は1伝票につき **最大50件** まで登録できます
- 配送情報は1伝票につき **最大10件** まで登録できます
- SKU一括検索は **最大100個** まで入力できます
- 既存の伝票を開くと **編集モード** になり、そのまま編集できます（確定済みなどの編集できない伝票は除く）
- 銀行振込の場合、請求書は金額確定時に自動発行されます（手動作成不要・#2260）
- 明細の在庫ステータスが「仮」「△」「×」の場合、保存時に確認ダイアログが表示されます
- 前払金は保存前でも記録できます
