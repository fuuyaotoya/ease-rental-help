## 概要

配送先、スタッフ、休業日、展示会、配送業者、配送料金などのマスタデータを一元管理。

> **💡 Shopifyで管理する機能:** 以下の機能はShopify Adminで管理します。
> - **タグ管理**: 顧客タグ・商品タグは [Shopify Admin > 商品/顧客](https://admin.shopify.com) で管理
> - **在庫場所**: 在庫場所は商品マスタのロケーション情報で管理
> - **商品カテゴリ**: 商品カテゴリは商品マスタ内で管理

## アクセス方法

- サイドバー: **顧客・商品・マスタ** > **マスタ管理**
- 直接URL: `/master-data`

## タブ2: 配送先マスタ

伝票の配送先住所を管理します。

### CSVインポート機能

配送先マスタでは、CSVファイルから一括インポートが可能です。

#### 対応CSVフォーマット

| 項目 | 説明 | 必須 |
|------|------|------|
| 配送先コード | 配送先識別コード（重複チェック対象） | いいえ |
| 配送先名 | 配送先名称 | はい |
| 配送先名カナ | 配送先名称（フリガナ） | いいえ |
| 郵便番号 | 郵便番号 | いいえ |
| 住所 | 都道府県からの完全な住所 | はい |
| 電話番号 | 連絡先電話番号 | いいえ |
| FAX番号 | FAX番号 | いいえ |
| ホームページ | WebサイトURL | いいえ |
| 備考 | その他のメモ | いいえ |

#### 手順: CSVで配送先を一括インポート

1. **📥 CSVインポート** ボタンをクリック
2. CSVファイルをドラッグ&ドロップ、またはファイル選択
3. **CSVを解析** ボタンをクリック
4. プレビュー画面でインポート内容を確認
5. 重複コードがある場合、処理方法を選択（スキップ/上書き）
6. **インポート開始** ボタンをクリック
7. インポート完了を確認

#### 住所自動分割（CSVインポート時のみ）

- CSVの住所から都道府県・市区町村・番地を自動判定・保存（手動登録ではそれぞれ入力します）

### フィールド（手動登録・編集モーダル）

| 項目 | 説明 | 必須 |
|------|------|------|
| 配送先名 | 配送先名称 | はい |
| 配送先名カナ | 配送先名称（フリガナ） | いいえ |
| 担当者名 | 配送先の担当者 | いいえ |
| 郵便番号 | 郵便番号 | いいえ |
| 都道府県 | **東京都 / 神奈川県 の2択**（手動選択） | はい |
| 市区 | 市区町村 | はい |
| 住所 | 番地以降の住所 | はい |
| 電話番号 | 電話番号 | いいえ |
| 配送料 | 配送料金 | いいえ |

> **コード・建物名・FAX・ホームページ・備考はCSV経由のみ:** 手動モーダルにこれらの入力欄はありません。CSVインポートでのみ設定できます（既存データは保持されます）。

### 手順: 配送先を追加

1. **新規追加** ボタンをクリック
2. 配送先詳細を入力（都道府県は2択から選択）
3. **保存** をクリック

## タブ3: スタッフマスタ

伝票への割り当て用スタッフを管理します。

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| 担当者コード | 一意識別子（編集時は変更不可） | はい |
| 担当者名 | スタッフ名 | はい |
| メール | メールアドレス | いいえ |
| 電話番号 | 電話番号 | いいえ |
| パスワード | ログインパスワード（6文字以上・マスク表示）。**作成時は必須**・編集時は任意（[#1340](https://github.com/iziz-system/ease-rental-frontend/issues/1340)） | 作成時: はい |
| パスワード（確認） | 確認用にもう一度入力 | 作成時: はい |

> **カナ・ステータスはこの画面で編集できません:** フリガナはデータとして保持されますが入力欄がありません。また有効/無効を切り替えるUIもありません（一覧の「無効担当者を表示」は無効担当者の表示フィルタのみです）。

> **⚠️ パスワード未設定のスタッフはログインできません（[#1340](https://github.com/iziz-system/ease-rental-frontend/issues/1340)）:** スタッフ作成時にパスワードを設定します。プロフィール編集（マイページ）では自分のパスワードしか変更できないため、管理者が新スタッフの初期パスワードを設定するにはこの画面を使います。

### 手順: スタッフを追加

1. **新規担当者追加** ボタンをクリック
2. 担当者コード・担当者名を入力（必須）
3. **パスワードを入力（必須・6文字以上・確認欄にもう一度入力）**
4. 任意フィールド（メール・電話番号）を入力
5. **保存** をクリック

### 手順: スタッフを編集

1. スタッフ行の **編集** をクリック
2. フィールドを変更（パスワードは **変更する場合のみ入力** — 空欄なら変更されません）
3. **保存** をクリック

### 手順: スタッフを削除

1. スタッフ行の **削除** をクリック
2. 削除を確認

## タブ4: 営業日・休業日

休業日カレンダーと営業日設定を管理します。

### 表示

- **登録済み休業日**: 選択年の休業日数
- **営業日数**: その年の営業日数計算
- **年末年始設定**: 年末年始休業設定

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| 日付 | 休業日 | はい |
| 名称 | 休業日名 | はい |
| 営業日 | 営業する場合はチェック | いいえ |

### 手順: 休業日を追加

1. ドロップダウンから年を選択
2. **個別追加** をクリック
3. 日付と名称を入力
4. 営業日の場合は **営業日** にチェック
5. **保存** をクリック

## タブ7: 配送料金マスタ

カテゴリ・エリア別の配送料金体系を管理します。

### 料金カテゴリ

| カテゴリ | 説明 |
|----------|------|
| EASE | EASE内部配送 |
| BASIC | 基本配送 |
| TRUCK | トラック配送 |
| WIDE | 広域配送 |
| PORTER | ポーターサービス |
| PORTER_EXH | 展示会用ポーター |
| EXHIBITION | 展示会配送 |
| OTHER | その他配送 |

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| カテゴリ | 料金カテゴリ | はい |
| 種別 | 配送種別 | いいえ |
| エリア/詳細 | 配送エリア | いいえ |
| 備考 | 追加メモ | いいえ |
| 料金 | 配送料金（円） | いいえ |

### 手順: 配送料金を追加

1. **新規追加** ボタンをクリック
2. カテゴリを選択
3. 種別とエリアを入力
4. 料金を入力
5. **保存** をクリック

### 手順: 配送料金を編集

1. 該当行の **編集** ボタンをクリック
2. 変更するフィールドを修正
3. **保存** をクリック

### 手順: 配送料金を削除

1. 該当行の **削除** ボタンをクリック
2. 確認ダイアログで **削除** をクリック

### 注意事項（配送料金マスタ）

- 料金区分はフリー入力（datalist）です。既存データから候補が表示されますが、新しい値も直接入力できます
- 入力した値がそのまま保存されるため、入力内容にご注意ください

## 注意事項

- マスタデータの変更は伝票作成に即座に反映
- スタッフはメールでログインユーザーと紐付け可能
- 展示会バッファ日数は配送スケジュールに影響
- 配送料金は伝票原価計算に使用
