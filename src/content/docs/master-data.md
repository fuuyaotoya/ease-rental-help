## 概要

配送先、スタッフ、営業日・祝日、展示会、配送業者、配送料金などを管理する画面です。

> **💡 Shopifyで管理する機能:** 以下の機能はShopify Adminで管理します。
> - **タグ管理**: 顧客タグ・商品タグは [Shopify Admin > 商品/顧客](https://admin.shopify.com) で管理
> - **在庫場所**: 在庫場所は商品マスタのロケーション情報で管理
> - **商品カテゴリ**: 商品カテゴリは商品マスタ内で管理

## アクセス方法

- サイドバー: **顧客・商品・マスタ** > **マスタ管理**
- 直接URL: `/master-data`

## 画面構成

### タブ（8種類）

|------|------|

## タブ1: 商品マスタ

Shopifyから同期された商品の情報を確認し、レンタル在庫台数を設定します。

### 商品情報の確認

「詳細」でSKU・商品名・カテゴリ・在庫場所・日額などを確認できます。**「詳細」は商品情報を表示する操作で、日額の編集画面ではありません。**

### 各商品の操作（詳細・在庫台数・予約状況）

商品一覧の各行には、次の操作リンクがあります。

| 操作 | 説明 |
|------|------|
| **詳細** | 商品情報を表示します。日額の編集はできません |
| **在庫台数** | SKUごとの「レンタル在庫台数」を設定します（2026年9月追加・下記） |
| **予約状況** | [在庫カレンダー](/inventory-calendar/)を開き、この商品の予約・在庫状況を確認します |

#### レンタル在庫台数の設定（2026年9月追加）

**「在庫台数」** をクリックすると、設定ダイアログが開きます。

> 「Shopify在庫数とは別に、同時に予約できる実保有台数をSKUごとに設定します。」

- **SKU（サイズ・枝番）ごとに、同時に貸し出せる台数**を設定します（1〜1000の整数）
- **既定は1台** です。設定していないSKUは、これまでどおり1台として扱われます（既存商品の挙動は変わりません）
- 同じSKUを複数台保有している商品は、**枝番を個体ごとに切り直さず、実台数をここに設定**して運用します
- 空き状況の判定（⚪/△/×）は、同じSKUの予約数の合計がこの台数を下回っているかで行われます（[在庫カレンダー](/inventory-calendar/)もこの台数で表示されます）

## タブ2: 配送先管理

伝票の配送先住所を管理します。

### CSVインポート機能

配送先マスタでは、CSVファイルから一括インポートが可能です。

#### 対応CSVフォーマット

| 項目 | 説明 | 必須 |
|------|------|------|
| 配送先コード | 配送先識別コード（重複チェック対象） | いいえ |
| 配送先名 | 配送先名称 | はい |
| 配送先名カナ | 配送先名称（フリガナ） | いいえ |
| 郵便番号 | 郵便番号 | いいえ |
| 住所 | 都道府県からの完全な住所 | はい |
| 電話番号 | 連絡先電話番号 | いいえ |
| FAX番号 | FAX番号 | いいえ |
| ホームページ | WebサイトURL | いいえ |
| 備考 | その他のメモ | いいえ |

#### 手順: CSVで配送先を一括インポート

1. **📥 CSVインポート** ボタンをクリック
2. CSVファイルをドラッグ&ドロップ、またはファイル選択
3. **CSVを解析** ボタンをクリック
4. プレビュー画面でインポート内容を確認
5. 重複コードがある場合、処理方法を選択（スキップ/上書き）
6. **インポート開始** ボタンをクリック
7. インポート完了を確認

#### 住所自動分割（CSVインポート時のみ）

- CSVの住所から都道府県・市区町村・番地を自動判定・保存（手動登録ではそれぞれ入力します）

### フィールド（手動登録・編集モーダル）

| 項目 | 説明 | 必須 |
|------|------|------|
| 配送先名 | 配送先名称 | はい |
| 配送先名カナ | 配送先名称（フリガナ） | いいえ |
| 担当者名 | 配送先の担当者 | いいえ |
| 郵便番号 | 郵便番号 | いいえ |
| 都道府県 | **東京都 / 神奈川県 の2択**（手動選択） | はい |
| 市区 | 市区町村 | はい |
| 住所 | 番地以降の住所 | はい |
| 電話番号 | 電話番号 | いいえ |
| 配送料 | 配送料金 | いいえ |

> **コード・建物名・FAX・ホームページ・備考はCSV経由のみ:** 手動モーダルにこれらの入力欄はありません。CSVインポートでのみ設定できます（既存データは保持されます）。

### 手順: 配送先を追加

1. **新規追加** ボタンをクリック
2. 配送先詳細を入力（都道府県は2択から選択）
3. **保存** をクリック

## タブ3: 担当者管理

伝票への割り当て用スタッフを管理します。

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| 担当者コード | 一意識別子（編集時は変更不可） | はい |
| 担当者名 | スタッフ名 | はい |
| メール | メールアドレス | いいえ |
| 電話番号 | 電話番号 | いいえ |
| パスワード | ログインパスワード（6文字以上・マスク表示）。**作成時は必須**・編集時は任意 | 作成時: はい |
| パスワード（確認） | 確認用にもう一度入力 | 作成時: はい |

> **カナ・ステータスはこの画面で編集できません:** フリガナはデータとして保持されますが入力欄がありません。また有効/無効を切り替えるUIもありません（一覧の「無効担当者を表示」は無効担当者の表示フィルタのみです）。

> **⚠️ パスワード未設定のスタッフはログインできません:** スタッフ作成時にパスワードを設定します。プロフィール編集（マイページ）では自分のパスワードしか変更できないため、管理者が新スタッフの初期パスワードを設定するにはこの画面を使います。

### 手順: スタッフを追加

1. **新規担当者追加** ボタンをクリック
2. 担当者コード・担当者名を入力（必須）
3. **パスワードを入力（必須・6文字以上・確認欄にもう一度入力）**
4. 任意フィールド（メール・電話番号）を入力
5. **保存** をクリック

### 手順: スタッフを編集

1. スタッフ行の **編集** をクリック
2. フィールドを変更（パスワードは **変更する場合のみ入力** — 空欄なら変更されません）
3. **保存** をクリック

### 手順: スタッフを削除

1. スタッフ行の **削除** をクリック
2. 削除を確認

## タブ4: 営業日・祝日

祝日と営業日設定を管理します。

### 表示

- **登録済み祝日**: 選択年の登録済み祝日数
- **営業日数**: その年の営業日数計算
- **年末年始設定**: 年末年始休業設定

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| 日付 | 祝日の日付 | はい |
| 祝日名 | 祝日の名称 | はい |
| 営業日として扱う | その日を営業日として扱う場合はチェック | いいえ |

### 手順: 祝日を追加

1. ドロップダウンから年を選択
2. **個別祝日追加** をクリック
3. 日付と **祝日名** を入力
4. 営業日の場合は **営業日として扱う** にチェック
5. **保存** をクリック

## タブ5: 展示会マスタ

配送スケジュールに影響する展示会イベントを管理します。

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| 名称 | 展示会名 | はい |
| 開始日 | イベント開始日 | はい |
| 終了日 | イベント終了日 | はい |
| 搬入バッファ日数（営業日） | 展示会の前に在庫を確保する営業日数 | いいえ |
| 搬出バッファ日数（営業日） | 展示会の後に在庫を確保する営業日数 | いいえ |
| 会場 | イベント会場 | いいえ |
| 説明 | イベント説明 | いいえ |
| 有効 | 展示会の有効/無効 | いいえ |

### 手順: 展示会を追加

1. **新規追加** をクリック
2. 展示会詳細を入力
3. **搬入バッファ日数（営業日）** と **搬出バッファ日数（営業日）** を設定
4. **保存** をクリック

> **💡 バッファ日数はカートの在庫チェックにも使われます:** バッファは営業日で数えます。日曜と登録済みの休業日は数えません。展示会配送を選んだ場合は、展示会期間に搬入・搬出バッファを加えた期間の在庫を確保します。在庫を確保できない商品は、カートに理由が表示されます。お問い合わせを受けたら、展示会期間とバッファ設定を確認してください。空欄は1営業日、0はバッファなしです。

> **⚠️ 登録済み展示会のバッファは変更できません:** 日程や名称は更新できます。バッファを変える必要がある場合は、運用担当者へ確認してください。

> **💡 カートの「展示会配送」との連動（2026年9月変更）:** カート画面の展示会配送の選択肢は、このマスタで **「有効」にチェックがある展示会** から自動的に作成されます（展示会名＋開催期間の形式で表示）。お客様に新しい展示会を選んでもらうには、マスタへの登録と「有効」化が必要です。展示会を選ぶと会場の住所が自動的に入力されます。

## タブ7: 配送料金

カテゴリ・エリア別の配送料金体系を管理します。

### 料金カテゴリ

| カテゴリ | 説明 |
|----------|------|
| EASE | EASE内部配送 |
| BASIC | 基本配送 |
| TRUCK | トラック配送 |
| WIDE | 広域配送 |
| PORTER | ポーターサービス |
| PORTER_EXH | 展示会用ポーター |
| EXHIBITION | 展示会配送 |
| OTHER | その他配送 |

### フィールド

| 項目 | 説明 | 必須 |
|------|------|------|
| カテゴリ | 料金カテゴリ | はい |
| 種別 | 配送種別 | いいえ |
| エリア/詳細 | 配送エリア | いいえ |
| 備考 | 追加メモ | いいえ |
| 料金 | 配送料金（円） | いいえ |

### 手順: 配送料金を追加

1. **新規追加** ボタンをクリック
2. カテゴリを選択
3. 種別とエリアを入力
4. 料金を入力
5. **保存** をクリック

### 手順: 配送料金を編集

1. 該当行の **編集** ボタンをクリック
2. 変更するフィールドを修正
3. **保存** をクリック

### 手順: 配送料金を削除

1. 該当行の **削除** ボタンをクリック
2. 確認ダイアログで **削除** をクリック

### 注意事項（配送料金マスタ）

- 料金区分はフリー入力（datalist）です。既存データから候補が表示されますが、新しい値も直接入力できます
- 入力した値がそのまま保存されるため、入力内容にご注意ください

## タブ8: 請求書DL不可の会社

このタブに登録した会社は、お客様のマイページから請求書をダウンロードできません。

### 会社を登録する

1. **会社名** に、請求先マスタの表記どおりの会社名を入力します。
2. 必要に応じて **メモ** を入力します。
3. **登録する** をクリックします。

登録した会社は **有効（DL不可）** と表示されます。会社名を変更する場合は、現在の登録を無効にしてから登録し直します。

### ダウンロードを再開する

1. 対象会社の **無効にする** をクリックします。
2. 確認画面の内容を確認します。
3. 無効にすると **無効（DL可）** になり、この会社登録による制限が解除されます。

**まとめ請求の対象は、会社登録を無効にしてもダウンロードできません。** 請求書は請求先へメールで送付してください。

再び止める場合は **有効に戻す** をクリックします。無効な会社が見つからないときは、**無効な会社も表示する** にチェックを入れてください。

### 会社を探す・メモを編集する

1. **「会社名・メモで絞り込み」**に検索する文字を入力します。
2. 対象会社の**「メモ編集」**をクリックします。
3. メモを修正し、**「保存」**をクリックします。変更をやめる場合は**「取消」**をクリックします。

会社名は直接編集できません。請求書に印字される会社名が制限の対象かどうかを確認してください。

## 注意事項

- マスタデータの変更は伝票作成に即座に反映

- 展示会バッファ日数は配送スケジュールに影響
- 配送料金は伝票原価計算に使用
