> **パス:** `/product-reservation-inquiry`
> **メニュー:** 予約管理 > 商品予約状況照会

## 概要

商品ベースで在庫・予約状況を一括照会する画面です。3つのタブで異なる検索方法を提供します。

| タブ           | 用途                                                 |
| -------------- | ---------------------------------------------------- |
| 期間指定検索   | 期間を指定して全商品の予約・在庫状況を一括確認       |
| カレンダー照会 | 特定商品を選択して月間カレンダーで予約状況を視覚確認 |
| 複数SKU検索    | SKUコードを複数入力して在庫・予約状況を一括確認      |

## アクセス方法

- サイドバーから: 「予約管理」>「商品予約状況照会」をクリック
- URL直接: `/product-reservation-inquiry`

## タブ1: 期間指定検索

### 検索フォーム

| 項目                   | 種類             | 説明                                                                 | 必須     |
| ---------------------- | ---------------- | -------------------------------------------------------------------- | -------- |
| 開始日                 | 日付             | 検索期間の開始日                                                     | **はい** |
| 終了日                 | 日付             | 検索期間の終了日                                                     | **はい** |
| 商品コード             | テキスト         | 商品コード（SKU）で絞り込み                                          | -        |
| 商品名                 | テキスト         | 商品名で絞り込み                                                     | -        |
| 貸出可能なもののみ表示 | チェックボックス | `rental_is_rentable=true` の商品のみ表示（クライアント側フィルター） | -        |

**ボタン:**

| ボタン   | 動作                                                                       |
| -------- | -------------------------------------------------------------------------- |
| リセット | 全フィルターをデフォルトに戻す（今日〜30日後）。結果・選択・仮伝票もクリア |
| 検索     | 開始日・終了日が入力済みの場合のみ有効。Enter キーでも実行可               |

> **初期動作:** ページ初期表示時に今日〜30日後の範囲で自動検索が実行されます。

### 統計カード

| カード       | 説明                                                       |
| ------------ | ---------------------------------------------------------- |
| 対象商品数   | APIが返す検索結果の総件数（表示上限500件とは独立した総数） |
| 予約あり     | 表示中の商品うち `is_reserved=true` の件数                 |
| 予約競合あり | 表示中の商品うち `conflict_slip_numbers` が1件以上の件数   |
| 総在庫数     | 表示中の商品の `inventory_quantity` 合計                   |

> **注意:** 「貸出可能なもののみ表示」がONの場合、対象商品数はAPI総件数のまま（全体）ですが、予約あり・競合あり・総在庫数はフィルター後の数値になります。

### 検索結果テーブル

| 列               | 説明                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| チェックボックス | 仮伝票への一括追加用選択（貸出不可商品は選択しても仮伝票に追加されない） |
| 商品コード       | 商品のSKUコード                                                          |
| 商品名           | 商品の名称                                                               |
| 詳細コード       | 最初のバリアントコード（`variants[0].variant_code`）、なければ `-`       |
| 詳細名           | 最初のバリアント名（`variants[0].variant_name`）、なければ `-`           |
| 在庫数           | 現在の在庫数（0以下は赤表示）                                            |
| 貸出可否         | `rental_is_rentable=true` → 「可」（緑）/ それ以外 → 「貸出不可」（赤）  |
| 予約             | `is_reserved=false` → 「○」（緑）/ `is_reserved=true` → 「×」（赤）      |
| 予約被り伝票No.  | 重複する予約の伝票番号リスト（クリックで該当伝票を新しいタブで開く）     |
| 単価             | 商品の単価（`unit_price`）。未設定の場合は `-`                           |
| 操作             | 「+ 仮伝票」「伝票へ」（貸出不可の場合は両ボタン無効化・グレー表示）     |

**操作列のボタン:**

| ボタン   | 動作                                                   |
| -------- | ------------------------------------------------------ |
| + 仮伝票 | 商品を仮伝票パネルに追加（既存の場合は数量+1）         |
| 伝票へ   | `/booking-compact?product={商品コード}` を新タブで開く |

**ヘッダーのチェックボックス（全選択）:**

- 現在ページの `rental_is_rentable=true` の商品をすべて選択/解除
- 貸出可能商品が全件選択済みのとき checked 状態になる

**「選択済みを仮伝票に追加」ボタン:**

- 1件以上選択中のときのみ表示
- 選択中の貸出可能商品をまとめて仮伝票に追加（選択解除）

**ページネーション:**

- 「前へ」「次へ」ボタン（1ページ未満/最終ページでは無効化）
- ページ変更時に自動で再検索

**空状態のメッセージ:**

| 状況                                    | 表示メッセージ                               |
| --------------------------------------- | -------------------------------------------- |
| 開始日/終了日が未入力                   | 「検索条件を設定して検索してください」       |
| 検索実行済みだが0件                     | 「条件に一致する商品が見つかりませんでした」 |
| フィルター後に0件（API総件数は0より大） | 「貸出可能な商品がありません（全N件中）」    |

### 仮伝票パネル（ボトムシート）

「+ 仮伝票」ボタンで商品を追加すると画面下部に表示されます。期間指定検索タブのみ表示。

**パネルヘッダー（常時表示）:**

| 項目         | 説明                                                                |
| ------------ | ------------------------------------------------------------------- |
| 仮伝票 (N件) | 追加件数                                                            |
| 合計: ¥X     | 全アイテムの小計合計                                                |
| クリア       | 全アイテムを削除                                                    |
| 伝票に転送   | `/booking-compact?products={Base64エンコードデータ}` を新タブで開く |
| ▲/▼          | パネルを展開/折りたたみ                                             |

**パネル展開時（テーブル）:**

| 列         | 説明                               |
| ---------- | ---------------------------------- |
| 商品コード | SKUコード                          |
| 商品名     | 商品名称                           |
| 予約       | ○/×                                |
| 被り       | 被り伝票番号リンク（なければ `-`） |
| 在庫       | 在庫数                             |
| 貸出       | 可/不可                            |
| 単価       | ¥X                                 |
| 数量       | 数値入力（最小1）                  |
| 小計       | 単価 × 数量                        |
| 削除       | × ボタン                           |

**転送フォーマット:**
仮伝票の内容は `TransferProductData[]` として JSON → UTF-8 Base64 エンコードし、`products` クエリパラメータで渡します。

```typescript
type TransferProductData = {
  sku: string; // 商品コード
  quantity: number; // 数量
  unit_price: string; // 単価（文字列）
};
```

## タブ2: カレンダー照会

### 商品検索フォーム

| 項目              | 種類     | 説明                         | 必須 |
| ----------------- | -------- | ---------------------------- | ---- |
| 商品コード/商品名 | テキスト | 商品コードまたは商品名で検索 | ※1   |
| カテゴリ          | セレクト | カテゴリでフィルタリング     | -    |
| タグ              | テキスト | タグでフィルタリング         | -    |

※1: 検索条件がひとつも入力されていない場合はトースト警告を表示して検索しません。

**ボタン:**

| ボタン | 動作                                                                      |
| ------ | ------------------------------------------------------------------------- |
| 検索   | API `/products/search?q=...&category=...&tags=...` を呼び出す（最大50件） |
| クリア | 全入力・検索結果・カレンダーをリセット                                    |

### 検索結果テーブル

| 列         | 説明                                       |
| ---------- | ------------------------------------------ |
| 選択       | ラジオボタン（選択でカレンダーを表示）     |
| 商品コード | 商品のSKUコード                            |
| 商品名     | 商品の名称                                 |
| 名称カナ   | 商品名のカナ読み                           |
| カテゴリ   | 商品カテゴリ                               |
| タグ       | 商品タグ（2件超は「tag1, tag2...」と省略） |
| 貸出可否   | 「可」（緑）/ 「貸出不可」（赤）           |
| 操作       | 「照会」「伝票へ」                         |

**操作列のボタン:**

| ボタン | 動作                                                                       |
| ------ | -------------------------------------------------------------------------- |
| 照会   | カレンダーセクションを表示し、該当商品にスクロール                         |
| 伝票へ | `/booking-compact?product={商品コード}` を新タブで開く（貸出不可は無効化） |

### カレンダーセクション

検索結果から商品を選択（ラジオボタンまたは「照会」ボタン）すると表示されます。

**商品詳細パネル:**

| 項目                                  | 説明                                                                       |
| ------------------------------------- | -------------------------------------------------------------------------- |
| 商品画像                              | サムネイル（未設定の場合はプレースホルダー）                               |
| 商品コード / 商品名 / カテゴリ / タグ | 商品の基本情報                                                             |
| 伝票に追加                            | `/booking-compact?product={商品コード}` を新タブで開く（貸出不可は無効化） |

**カレンダー操作:**

| 項目             | 説明                                              |
| ---------------- | ------------------------------------------------- |
| ◀ / ▶            | 前月/次月へ移動                                   |
| 表示内容フィルタ | 予約 / 修理・メンテナンス / 在庫あり の表示ON/OFF |

**カレンダー凡例:**

| 色  | 種類               | 説明                   |
| --- | ------------------ | ---------------------- |
| 青  | 予約済み           | 既に予約が入っている日 |
| 赤  | 修理・メンテナンス | メンテナンス中の日     |
| 緑  | 在庫あり           | 貸出可能な日           |

**予約イベントクリック → 詳細モーダル:**

| 項目       | 説明                                 |
| ---------- | ------------------------------------ |
| 予約番号   | 予約の一意識別子                     |
| ステータス | 予約 / 修理・メンテナンス / 在庫あり |
| 依頼者     | 顧客名（ある場合）                   |
| 日付       | イベントの日付                       |
| メモ       | イベントのラベル                     |

## タブ3: 複数SKU検索

### 検索フォーム

| 項目                   | 種類             | 説明                                                   | 必須     |
| ---------------------- | ---------------- | ------------------------------------------------------ | -------- |
| 商品コード             | テキストエリア   | 1行につき1SKUを入力（最大100件）                       | **はい** |
| 開始日                 | 日付             | 貸出希望開始日                                         | -        |
| 終了日                 | 日付             | 貸出希望終了日                                         | -        |
| 利用可能な商品のみ表示 | チェックボックス | `availability_status ≠ '×'` かつ予約なしの商品のみ表示 | -        |

> **注意:** 開始日・終了日は任意です。SKUのみでも検索できます。日付を指定した場合のみ予約状況・在庫状況が計算されます。

**ボタン:**

| ボタン     | 動作                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 検索 (N件) | 入力SKU数を表示。SKUが0件の場合は無効化。10件以下はGET、11件以上はPOSTで送信 |
| クリア     | 全入力・結果をリセット                                                       |

### 見つからないSKU警告

入力したSKUの一部が見つからない場合、黄色ボックスに「⚠️ 見つからないSKU (N件)」として一覧表示されます。

### 検索結果テーブル

| 列           | ソート | 説明                                              |
| ------------ | ------ | ------------------------------------------------- |
| SKU          | ✅     | 商品コード                                        |
| 商品名       | ✅     | 商品の名称                                        |
| カテゴリ     | -      | 商品カテゴリ                                      |
| 在庫数       | ✅     | `inventory_quantity` または `total_inventory`     |
| 貸出可否     | -      | 「可」（緑）/ 「貸出不可」（赤）                  |
| 利用可能在庫 | ✅     | `available_quantity`                              |
| 予約状況     | -      | 重複予約なし → 「○」（緑）/ あり → 予約番号リスト |
| 単価         | ✅     | ¥X（未設定は `-`）                                |
| 操作         | -      | 「伝票に追加」ボタン（貸出不可は無効化・グレー）  |

**「伝票に追加」ボタン:** `/booking-compact?product={SKU}` を新タブで開く

## API

| タブ                         | エンドポイント                            | 方式                                                           |
| ---------------------------- | ----------------------------------------- | -------------------------------------------------------------- |
| 期間指定検索                 | `GET /products/batch-inventory-status`    | `start_date`, `end_date`, `search_code`, `search_name`, `page` |
| カレンダー照会（商品検索）   | `GET /products/search`                    | `q`, `category`, `tags`, `limit`                               |
| カレンダー照会（カレンダー） | `GET /products/{id}/reservation-calendar` | 月次カレンダーデータ                                           |
| 複数SKU検索（10件以下）      | `GET /products/search`                    | `skus[]`, `start_date`, `end_date`                             |
| 複数SKU検索（11件以上）      | `POST /products/search`                   | `{ skus, start_date, end_date, page, limit }`                  |

## 操作手順

### 手順1: 期間指定検索で在庫状況を確認する

1. 「期間指定検索」タブが選択されていることを確認（デフォルト）
2. 開始日・終了日を入力（初期値: 今日〜30日後）
3. 必要に応じて商品コード・商品名で絞り込み
4. 「検索」ボタンをクリック、またはフォームでEnterキー
5. 検索結果テーブルと統計カードが更新される

### 手順2: 仮伝票に商品を追加して伝票に転送する

1. 期間指定検索で商品を検索
2. 追加したい商品の「+ 仮伝票」ボタンをクリック（または複数選択して「選択済みを仮伝票に追加」）
3. 画面下部に仮伝票パネルが表示される
4. 数量を調整し、「伝票に転送」ボタンをクリック
5. `/booking-compact` が新タブで開き、商品が自動入力される

### 手順3: カレンダーで特定商品の予約状況を確認する

1. 「カレンダー照会」タブをクリック
2. 商品コード/商品名・カテゴリ・タグのいずれかを入力し「検索」
3. 検索結果テーブルから商品の「照会」ボタンをクリック
4. カレンダーセクションが表示される
5. ◀/▶で月を移動し、予約状況を確認
6. イベントをクリックすると詳細モーダルが表示される

### 手順4: 複数SKUの在庫状況を一括確認する

1. 「複数SKU検索」タブをクリック
2. テキストエリアに1行1SKUで商品コードを入力（最大100件）
3. 必要に応じて貸出希望日を入力
4. 「検索 (N件)」ボタンをクリック
5. 検索結果テーブルに在庫・予約状況が表示される
6. 見つからないSKUは黄色の警告ボックスに表示される

## 検証チェックリスト

### 共通

- [ ] タブ切り替えが正常に動作する

### 期間指定検索

- [ ] 開始日・終了日未入力では検索ボタンが無効化される
- [ ] Enterキーで検索が実行される（IME入力中は除く）
- [ ] 統計カードの「対象商品数」がAPI総件数（500件超でも正確に）表示される
- [ ] 「貸出可能なもののみ表示」でフィルタリングされる
- [ ] 0件時のメッセージが状況（未検索/検索済み0件/フィルター後0件）に応じて変わる
- [ ] 仮伝票パネルに商品が追加される（貸出不可は追加されない）
- [ ] 仮伝票の数量変更・削除・クリアが正常に動作する
- [ ] 「伝票に転送」で booking-compact に商品情報が引き継がれる
- [ ] 全選択チェックボックスが貸出可能商品のみ選択する
- [ ] ページ変更時に検索が再実行される
- [ ] リセット後に仮伝票・選択状態もクリアされる
