# 商品予約状況照会

![商品予約状況照会画面](/images/product-reservation-inquiry/main.png)

商品の在庫・予約状況を一括で照会する画面です。
1つの検索フォームで条件を指定し、結果一覧から **予約カレンダーの確認** と **伝票作成への遷移** ができます。

## この画面を開くには

- サイドバーの **「受注・予約」＞「商品予約状況照会」** をクリック

---

## 検索条件

| 項目 | 内容 |
|------|------|
| 開始日・終了日 | 貸出予定の期間（**任意**・未指定でも検索可） |
| 商品コード(複数可) | SKUをタグ形式で複数入力（Enter or 改行で追加。タグの **×** で削除） |
| 商品名 | 商品名の部分一致 |
| カテゴリ | カテゴリで絞り込み |
| タグ | タグで絞り込み |
| 貸出可能なもののみ表示 | チェックするとレンタル可能な商品だけに絞り込み |

**ボタン:** 「リセット」（条件クリア）/「検索」/「CSV出力」（現在の結果をCSVダウンロード）

> **⚠️ 見つからない商品コード:** 入力した商品コードの一部が見つからない場合、黄色い警告ボックスに一覧が表示されます。

---

## 統計バー

検索結果の上部に、以下の統計が1行で表示されます。

| 項目 | 説明 |
|------|------|
| 対象 ○件 | 検索条件に一致した商品数 |
| 予約あり（橙） | 期間中に予約が入っている商品数 |
| 競合あり（赤） | 予約が重複している商品数 |
| 合計 ¥○ | 期間指定時のみ表示（期間の金額総和） |

---

## 検索結果の見方

| 列 | 内容 |
|----|------|
| チェックボックス | 伝票作成対象として選択（ヘッダーで全選択） |
| 商品コード | 商品のSKUコード（クリックでソート） |
| 枝番 | バリエーションの枝番 |
| 商品名 | 商品の名称 |
| 貸出可否 | 「可」（緑）または「貸出不可」（赤） |
| 予約被り伝票No. | 重複している予約の伝票番号（クリックで該当伝票を開く） |
| 金額 / 単価 | 期間指定時は期間の金額、未指定時はレンタル単価 |
| カレンダー | **📅** ボタン（予約カレンダーを表示） |
| 操作 | **「伝票へ」** リンク（その商品だけで伝票作成へ進む） |

一覧はページネーション付きで、列ヘッダー（商品コード等）クリックでソートできます。

---

## 予約カレンダーで確認する

1. 確認したい商品の **📅** ボタンをクリックします
2. 予約状況カレンダーがモーダルで開きます
3. **◀ / ▶** で月を移動し、予約・在庫状況を確認します

### カレンダーの色

| 色 | 意味 |
|----|------|
| 青 | 予約済み（既に予約が入っている日） |
| 赤 | 修理・メンテナンス中 |
| 緑 | 在庫あり（貸出可能な日） |

### 商品の備考・特記事項を確認する

カレンダーモーダルの商品情報エリアに以下が表示されます。

| 項目 | 内容 |
|------|------|
| **備考** | 商品の一般備考（Shopifyメタフィールド `rental.general_notes`） |
| **特記事項** | 商品の注意事項（`rental.booking_notes`・キズ・破れ・取り扱い注意など） |

> **💡 ヒント:** 特記事項の有無はカレンダーを開いて確認してください。[伝票作成画面](/booking-compact/)では特記事項のある商品の📅アイコンが赤く表示されます。ピッキング時は [ピッキングPDF](/picking-delivery/) の特記事項列でも確認できます。

---

## 伝票作成へ進む

在庫を確認しながら、そのまま伝票作成に進むことができます。

1. 伝票に含めたい商品の **チェックボックス** を選択します（複数可）
2. 画面下部のフローティングバー **「伝票作成 (N件)」** をクリックします
3. **「伝票作成の確認」** モーダルで内容を確認します（競合・貸出不可の警告があれば表示されます）
4. 確定すると [貸し出し伝票作成](/booking-compact/) 画面に遷移し、選択した商品が明細に入力されます

> **💡 ヒント:** 1商品だけ伝票に含めたい場合は、行の **「伝票へ」** リンクから直接進められます。

> **⚠️ 数量の調整は伝票作成画面で:** 伝票作成への引き継ぎは各商品1点ずつです。数量の変更は[貸し出し伝票作成](/booking-compact/)画面で行ってください。

## よくある質問

### Q: 「貸出可能なもののみ表示」とは？
チェックを入れると、レンタル可能な商品だけに絞り込まれます。在庫切れや貸出不可の商品は表示されなくなります。

### Q: 検索結果が多くて見つからない
商品コード・商品名・カテゴリ・タグで絞り込むか、「貸出可能なもののみ表示」にチェックを入れてみてください。

### Q: 入力した商品コードを取り消したい
商品コードの入力タグごとに **×** が付いているので、クリックすると削除できます。

---

## 注意事項

- 期間（開始日・終了日）を指定すると、その期間の予約状況・金額で評価されます
- 「貸出不可」の商品は伝票作成の対象に選択できません
