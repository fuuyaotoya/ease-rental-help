# 商品予約状況照会

![商品予約状況照会画面](/images/product-reservation-inquiry/main.png)

商品の在庫・予約状況を一括で照会する画面です。
**3つのタブ**で異なる検索方法を切り替えられます。

| タブ | 用途 |
|------|------|
| 期間指定検索 | 期間を指定して全商品の予約・在庫状況を一括確認 |
| カレンダー照会 | 特定商品を選んで月間カレンダーで予約状況を視覚的に確認 |
| 複数SKU検索 | SKUコードを複数入力して在庫・予約状況を一括確認 |

## この画面を開くには

- サイドバーの **「予約管理」＞「商品予約状況照会」** をクリック

---

## タブ1: 期間指定検索

期間を指定して、全商品の予約・在庫状況を一覧で確認します。

### 操作手順

1. 「期間指定検索」タブが選択されていることを確認します（最初から選択されています）
2. **「開始日」** と **「終了日」** を入力します（初期値：今日〜30日後）
3. 必要に応じて商品コード・商品名で絞り込みます
4. **「検索」** ボタンをクリックします（Enterキーでも検索できます）
5. 検索結果と統計カードが更新されます

### 統計カードの見方

検索結果の上部に、以下の統計が表示されます。

| 項目 | 説明 |
|------|------|
| 対象商品数 | 検索条件に一致した商品の総数 |
| 予約あり | 予約が入っている商品の件数 |
| 予約競合あり | 複数の予約が重なっている商品の件数 |
| 総在庫数 | 対象商品の在庫数の合計 |

### 検索結果の見方

| 列 | 内容 |
|----|------|
| 商品コード | 商品のSKUコード |
| 商品名 | 商品の名称 |
| 在庫数 | 現在の在庫数（0以下は赤色） |
| 貸出可否 | 「可」（緑）または「貸出不可」（赤） |
| 予約 | 予約なし →「○」（緑）、予約あり →「×」（赤） |
| 予約被り伝票No. | 重複している予約の伝票番号（クリックで該当伝票を開く） |
| 単価 | 商品のレンタル単価 |

### 仮伝票に商品を追加して伝票に転送する

在庫を確認しながら、そのまま伝票作成に進むことができます。

1. 追加したい商品の **「+ 仮伝票」** ボタンをクリックします
2. 画面下部に仮伝票パネルが表示されます
3. 数量を調整します
4. **「伝票に転送」** ボタンをクリックします
5. [貸し出し伝票作成](/booking-compact/)画面が新しいタブで開き、商品が自動入力されます

> **💡 ヒント:** 複数商品をまとめて追加する場合は、チェックボックスで選択して **「選択済みを仮伝票に追加」** ボタンをクリックしてください。

## タブ2: カレンダー照会

特定の商品を選んで、月間カレンダーで予約状況を視覚的に確認します。

### 操作手順

1. **「カレンダー照会」** タブをクリックします
2. 商品コード/商品名、カテゴリ、タグのいずれかを入力します
3. **「検索」** ボタンをクリックします
4. 検索結果から確認したい商品の **「照会」** ボタンをクリックします
5. カレンダーが表示されます
6. **◀ / ▶** ボタンで月を移動して予約状況を確認します
7. カレンダー上のイベントをクリックすると詳細が表示されます

### カレンダーの色

| 色 | 意味 |
|----|------|
| 青 | 予約済み（既に予約が入っている日） |
| 赤 | 修理・メンテナンス中 |
| 緑 | 在庫あり（貸出可能な日） |

### 予約の詳細を確認する

カレンダー上の予約イベントをクリックすると、以下の情報が表示されます。

- 予約番号
- ステータス（予約 / 修理・メンテナンス / 在庫あり）
- 依頼者（顧客名）
- 日付
- メモ

### 商品の備考・特記事項を確認する

商品の 📅 アイコンをクリックして予約状況カレンダーを開くと、商品情報エリアに以下が表示されます。

| 項目 | 内容 |
|------|------|
| **備考** | 商品の一般備考（Shopifyメタフィールド `rental.general_notes`） |
| **特記事項** | 商品の注意事項（`rental.booking_notes`・キズ・破れ・取り扱い注意など） |

> **💡 ヒント:** 特記事項のある商品は、一覧の📅アイコンが赤く表示されるため一目で分かります（[伝票作成画面](/booking-compact/)でも同様）。ピッキング時は [ピッキングPDF](/picking-delivery/) の特記事項列でも確認できます。

## タブ3: 複数SKU検索

SKUコードを複数入力して、一括で在庫・予約状況を確認します。

### 操作手順

1. **「複数SKU検索」** タブをクリックします
2. テキストエリアに **1行に1つ** のSKUコードを入力します（最大100件）
3. 必要に応じて貸出希望の開始日・終了日を入力します（日付なしでも検索可能）
4. **「検索 (N件)」** ボタンをクリックします
5. 検索結果に在庫・予約状況が表示されます

> **⚠️ 注意:** 入力したSKUの一部が見つからない場合、黄色い警告ボックスに「見つからないSKU」の一覧が表示されます。

### 検索結果の見方

| 列 | 内容 |
|----|------|
| SKU | 商品コード |
| 商品名 | 商品の名称 |
| カテゴリ | 商品カテゴリ |
| 在庫数 | 総在庫数 |
| 貸出可否 | 「可」（緑）または「貸出不可」（赤） |
| 利用可能在庫 | 実際に利用可能な在庫数 |
| 予約状況 | 重複なし →「○」（緑）、重複あり → 予約番号の一覧 |
| 単価 | レンタル単価 |

## よくある質問

### Q: 「貸出可能なもののみ表示」とは？
チェックを入れると、レンタル可能な商品だけに絞り込まれます。在庫切れや貸出不可の商品は表示されなくなります。

### Q: 仮伝票に追加した商品を取り消したい
画面下部の仮伝票パネルで、商品ごとの **「×」** ボタンをクリックするか、**「クリア」** ボタンですべて取り消せます。

### Q: 検索結果が多くて見つからない
商品コードや商品名で絞り込むか、「貸出可能なもののみ表示」にチェックを入れてみてください。

---

## 注意事項

- ページ上部の **「更新」** ボタンで、現在表示中のタブのデータを再読み込みできます
- 期間指定検索では、**「貸出不可」** の商品は仮伝票に追加できません
- 複数SKU検索は最大 **100件** まで入力できます
