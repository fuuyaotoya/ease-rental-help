## 概要

レンタル予約システム全体の状況を一望できる統合管理画面です。システム統計情報と最近の活動履歴を確認できます。

## アクセス方法

- サイドバーから: サイドバーの「ダッシュボード」をクリック
- URL直接: `/dashboard` に直接アクセス

## 画面構成

### ページヘッダー

| 項目         | 説明                             |
| ------------ | -------------------------------- |
| タイトル     | 「ダッシュボード」               |
| サブタイトル | 「レンタル予約システム総合管理」 |
| 最終更新時刻 | データの最終更新日時             |
| 更新ボタン   | データを手動で再読み込み         |

### システム統計セクション

統計カードとして以下の4つの指標を表示します。

| 項目         | 種類 | 説明                                 | 色  |
| ------------ | ---- | ------------------------------------ | --- |
| 総予約数     | 数値 | システムに登録されている全予約の総数 | 青  |
| 進行中予約   | 数値 | 現在レンタル中または準備中の予約数   | 緑  |
| 未送信請求書 | 数値 | 送信待ちの請求書件数                 | 黄  |
| 今月売上     | 金額 | 当月の売上合計（日本円表示）         | 紫  |

### 最近の活動セクション

直近の操作履歴を時系列で表示します。

| 項目     | 説明                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| アイコン | 活動タイプに応じたアイコン（予約作成、キャンセル、請求書作成、入金、返却処理） |
| 説明     | 活動内容のテキスト                                                             |
| 実行者   | 操作を行ったユーザー名（システム自動の場合は「システム」）                     |
| 時刻     | 相対時間表示（例：「たった今」「5分前」「2時間前」「3日前」）                  |

#### 活動タイプとアイコン

| タイプ            | アイコン | 説明                   |
| ----------------- | -------- | ---------------------- |
| booking_created   | 📋       | 予約が作成された       |
| booking_cancelled | ❌       | 予約がキャンセルされた |
| invoice_created   | 📄       | 請求書が作成された     |
| payment_received  | 💰       | 入金が記録された       |
| return_processed  | ↩️       | 返却処理が完了した     |

## 操作手順

### 手順1: データの更新

1. ページ右上の更新ボタン（↻）をクリック
2. ローディング表示中にデータが再取得される

**期待される結果:**

- 最終更新時刻が更新される
- 統計カードと活動履歴に最新データが反映される

### 手順2: 活動履歴の確認

1. 「最近の活動」セクションをスクロール
2. 各活動の詳細を確認

**期待される結果:**

- 時系列順に活動が表示される
- 各活動の実行者と時刻が確認できる

## 検証チェックリスト

- [ ] 総予約数が正しく表示される
- [ ] 進行中予約の件数が現在の状況と一致する
- [ ] 未送信請求書の件数が正確である
- [ ] 今月売上が適切に計算されている
- [ ] 更新ボタンでデータが再取得できる
- [ ] 最近の活動が時系列順に表示される

## 備考

- ダッシュボードのデータは自動的に更新されないため、最新情報を確認するには更新ボタンを使用してください
- 活動履歴が表示されない場合は、まだシステム操作が行われていないことを示します
- 統計情報は読み込み中はスケルトンローディングが表示されます
