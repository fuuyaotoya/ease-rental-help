> **パス:** `/slip-search`
> **メニュー:** 伝票管理 > 伝票検索

## 概要

登録されているレンタル伝票を様々な条件で検索・一覧表示する画面です。ステータス、期間、顧客情報など多彩なフィルタ条件で伝票を絞り込み、詳細確認や他画面への遷移が可能です。

## アクセス方法

- サイドバーから: 「伝票管理」>「伝票検索」をクリック
- 他画面からの遷移:
  - 新規予約作成画面から保存完了後に自動遷移（伝票番号でフィルタリング済み）
  - 各種画面からリンク経由で遷移
- URL直接: `/slip-search` または `/slip-search?keyword=xxx` など

## 操作手順

### 手順1: 検索条件の入力

1. 検索条件を入力（最低1つの条件が必要）
   - キーワード検索: 顧客名や伝票番号を入力
   - フィルタ: ステータスや期間を指定
   - プリセット: 「本日」「処理中」などのボタンをクリック
2. 条件を入力すると自動的に検索が実行される

**期待される結果:**

- 検索結果がテーブルに表示される
- 検索条件に一致する伝票のみが表示される

### 手順2: 検索結果の確認

1. 検索結果テーブルで伝票一覧を確認
2. 列ヘッダーをクリックしてソート
3. 必要に応じてページネーションでページを移動

**期待される結果:**

- 指定した順序で伝票が並び替えられる
- ページ移動がスムーズに行える

### 手順3: 伝票詳細の確認

1. 確認したい伝票の行をクリック
2. または「詳細」ボタンをクリック
3. 詳細モーダルが表示される

**期待される結果:**

- 伝票の詳細情報がモーダルで表示される
- 顧客情報、明細、配送情報、金額情報が確認できる

### 手順4: 伝票の編集

1. 編集したい伝票の「編集」ボタンをクリック
2. 新規予約作成画面（編集モード）に遷移

**期待される結果:**

- 伝票編集画面が開く
- 既存の情報が入力済みで表示される

### ソート可能な列

| 列           | ソートキー  | 説明            |
| ------------ | ----------- | --------------- |
| 伝票番号     | slip_number | 昇順/降順       |
| ステータス   | status      | 昇順/降順       |

### デフォルトソート

- **初期表示:** 作成日時の降順（新しい順）
- **ソート変更時:** 選択した列で再検索が実行される

## URLパラメータ

検索条件はURLパラメータとして保持され、ブックマークや共有が可能です。

| パラメータ        | 説明               | 例                              |
| ----------------- | ------------------ | ------------------------------- |
| keyword           | キーワード検索     | `?keyword=山田`                 |
| slip_number       | 伝票番号           | `?slip_number=E-2024-0001`      |
| status            | ステータス         | `?status=PROCESSING`            |
| booking_type      | 予約種別           | `?booking_type=normal_order`    |
| start_date_from   | レンタル開始日From | `?start_date_from=2024-01-01`   |
| start_date_to     | レンタル開始日To   | `?start_date_to=2024-01-31`     |
| end_date_from     | 返却日From         | `?end_date_from=2024-01-01`     |
| end_date_to       | 返却日To           | `?end_date_to=2024-01-31`       |
| payment_method    | 支払方法           | `?payment_method=bank_transfer` |
| payment_date_from | 入金日From         | `?payment_date_from=2024-01-01` |
| payment_date_to   | 入金日To           | `?payment_date_to=2024-01-31`   |
| amount_min        | 金額（From）       | `?amount_min=10000`             |
| amount_max        | 金額（To）         | `?amount_max=50000`             |
| staff_name        | 担当者名           | `?staff_name=田中`              |
| invoice_number    | 請求書番号         | `?invoice_number=INV-001`       |
| billing_name      | 請求先名           | `?billing_name=○○商事`          |
| company           | 会社名             | `?company=ABC株式会社`          |
| phone             | 電話番号           | `?phone=090-0000-0000`          |

### 複合条件の例

```
/slip-search?status=PROCESSING&start_date_from=2024-01-01&start_date_to=2024-01-31
```

## トラブルシューティング

### 検索結果が表示されない

| 原因                 | 対処法                 |
| -------------------- | ---------------------- |
| 検索条件が厳しすぎる | 条件を緩和して再検索   |
| データが存在しない   | 期間やステータスを変更 |
| ネットワークエラー   | ページをリロード       |

### ステータス値について

本システムでは以下のステータス値を使用しています：

| 正しい値        | 説明           |
| --------------- | -------------- |
| PROCESSING      | 処理中         |
| BILLING_PENDING | 請求待ち       |
| PAYMENT_PENDING | 入金待ち       |
| COMPLETED       | 完了           |
| CANCELLED       | キャンセル済み |

**注意:** DRAFT、CONFIRMED、PREPARINGなどの値は旧ドキュメントのもので、現在は使用されていません。

## 備考

- 検索条件は入力後に自動的に検索が実行されます（検索ボタンを押す必要はありません）
- 1ページあたり20件の検索結果が表示されます
- 検索条件はURLに保持されるため、ブックマークやリンク共有が可能です
- 新規予約作成画面から保存完了後、自動的にこの画面に遷移し、作成した伝票がフィルタリング表示されます

## 行ごとの操作ボタン

検索結果の各行（操作カラム）には以下のボタンが表示されます:

| ボタン | 動作 | 用途 |
|-------|------|------|
| **詳細** | 伝票情報の閲覧用モーダルを開く | 編集せず内容を確認 |
| **伝票詳細** | `/booking-compact?id=...` で編集ページに遷移 | 編集する |
| **Shopify** | **新しいタブで Shopify Admin の対応 Draft Order を開く** | Shopify 側の状態を直接確認（決済状況・キャンセル状態など） |

### 「Shopify」ボタンの活用例

| ケース | 確認できること |
|--------|--------------|
| 通常伝票 | Shopify Admin で Draft Order の支払状況・line_item・タグを確認 |
| キャンセル済伝票 | URL アクセス後 **404「このアドレスに下書き注文はありません」** が出れば、Shopify 側でも完全削除済（自動キャンセル完了） |
| エラー伝票 | Shopify 側でエラー状態の場合、Draft Order の備考欄で原因を確認 |

> Shopify Admin へのログインが必要です（事前にログイン推奨）。
