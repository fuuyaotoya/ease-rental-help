# 伝票検索

![伝票検索画面](/images/slip-search/main.png)

登録されているレンタル伝票を様々な条件で検索し、一覧表示する画面です。
ステータス、期間、顧客情報などで伝票を絞り込み、詳細の確認や編集ができます。

## この画面を開くには

- サイドバーの **「伝票管理」＞「伝票検索」** をクリック
- [貸し出し伝票作成](/booking-compact/)画面で保存完了後に自動で移動
- 他の画面からリンク経由で遷移

---

## 操作手順

### ステップ1: 検索条件を入力する

検索条件は最低1つ入力してください。条件を入力すると自動的に検索が実行されます。

#### キーワードで探す

キーワード欄に伝票番号、顧客名、会社名、メール、電話番号を入力します。

#### 条件で絞り込む

| 絞り込み条件 | 説明 |
|------------|------|
| 伝票番号 | 特定の伝票番号で検索 |
| ステータス | 処理中 / 金額確認待ち / 請求待ち / 入金待ち / 完了 など |
| 予約種別 | 通常予約 / 展示会予約 |
| レンタル開始日 | 開始日の範囲を指定（From〜To） |
| 返却日 | 返却予定日の範囲を指定（From〜To） |
| 残高フィルタ | 残高あり / 残高なし |
| 支払方法 | 現金 / クレジットカード / 銀行振込 |
| 入金日 | 入金日の範囲を指定 |
| 金額 | 請求金額の範囲を指定 |
| 担当者名 | 作成・更新したスタッフ名で検索 |
| 請求書番号 | 請求書番号で検索 |
| 会社名 | 顧客の会社名で検索 |
| 電話番号 | 電話番号で検索 |

#### かんたん検索ボタン

よく使う条件がボタン一つで設定できます。

| ボタン | 検索内容 |
|--------|---------|
| **本日** | 今日レンタルが開始される伝票 |
| **処理中** | 現在処理中の伝票 |
| **今週** | 今週のレンタル伝票 |
| **延滞** | 返却が遅れている伝票 |

:::dev
#### ステータスの内部値

画面の表示名と内部ステータス値の対応（`SLIP_SEARCH_STATUS_LABELS`）:

| 表示名 | 内部値 | 備考 |
|--------|--------|------|
| 処理中 | `PROCESSING` | ピッキング完了後 |
| 金額確認待ち | `PRICE_CONFIRM_PENDING` | 返却後の金額調整中 |
| 請求待ち | `BILLING_PENDING` | 銀行振込など請求書発行待ち |
| 入金待ち | `PAYMENT_PENDING` | 請求書発行済・入金確認待ち |
| 完了 | `COMPLETED` | 入金確認済み |

全11ステータスの完全一覧は [ステータス遷移図](/appendix/status-flow/) を参照。
:::

### ステップ2: 検索結果を確認する

検索結果はテーブルで一覧表示されます。

#### 一覧の見方

| 列 | 内容 |
|----|------|
| 伝票番号 | システムが自動で付けた番号 |
| 顧客情報 | 会社名、担当者名、部署 |
| ステータス | 伝票の現在の状態（色付きラベル） |
| レンタル期間 | 開始日 〜 終了日（日数） |
| 金額情報 | 請求金額 / 入金済 / 残高 |
| 支払情報 | 支払方法と支払の状態 |
| 担当者 | スタッフ名 |
| 作成日時 | 伝票を作成した日時 |

#### ステータスの色

| 色 | 状態 |
|----|------|
| 青 | 処理中 |
| 黄 | 請求待ち |
| オレンジ | 入金待ち |
| 緑 | 完了 |
| 赤 | キャンセル済み |

> **💡 「処理中」と表示される範囲について**
>
> 「処理中」は**予約が確定してから返却されるまでの広い期間**を表します。現金や店頭受取で予約を作成した直後も「処理中」と表示されますが、これは**正常な動作**です（予約自体は確定済みですが、ピッキング・出荷・返却といった工程がまだ残っているため「処理中」になります）。
>
> ピッキング画面などで「この伝票は確定済みです」という案内が表示されることがありますが、これは**その工程での案内テキスト**であり、伝票検索のステータス（処理中）とは別の意味です。伝票の状態は伝票検索・伝票詳細のステータス（処理中 / 金額確認待ち / 請求待ち / 入金待ち / 完了）で確認してください。

> **💡 並べ替え:** 列の見出し（伝票番号、ステータス、レンタル期間など）をクリックすると、並び順を変えられます。初期表示は作成日時の新しい順です。

### ステップ3: 伝票の詳細を確認する

1. 確認したい伝票の **「詳細」** ボタンをクリックします
2. 詳細モーダルが開き、以下のタブで情報を確認できます

| タブ | 確認できる内容 |
|------|-------------|
| 基本情報 | 伝票番号、ステータス、顧客情報、支払方法 |
| 明細情報 | 商品のSKU、商品名、数量、単価、日数、金額 |
| 配送情報 | 配送スケジュール |
| 金額情報 | 料金の内訳（商品小計、値引き、配送料、消費税、請求金額、残高） |
| 請求情報 | 請求書・入金の情報 |

### ステップ4: 伝票を編集する

1. 編集したい伝票の **「伝票詳細」** ボタン（または「編集」ボタン）をクリックします
2. [貸し出し伝票作成](/booking-compact/)画面が編集モードで開きます

## Shopifyボタンについて

検索結果の各行には **「Shopify」** ボタンが表示される場合があります。
このボタンをクリックすると、新しいタブで Shopify 管理画面の該当ページが開き、決済状況やキャンセル状態を直接確認できます。

> **💡 注意:** Shopify 管理画面の利用には事前のログインが必要です。

## API・URLパラメータ仕様

### エンドポイント

```
GET /bookings/search
```

### クエリパラメータ

| パラメータ | 対応するUI | 例 |
|-----------|-----------|-----|
| `keyword` | キーワード | `keyword=山田` |
| `status` | ステータス | `status=PROCESSING` |
| `booking_type` | 予約種別 | `booking_type=normal_order` |
| `slip_number` | 伝票番号 | `slip_number=B-1234` |
| `start_date_from` | 開始日（From） | `start_date_from=2026-04-01` |
| `start_date_to` | 開始日（To） | `start_date_to=2026-04-30` |
| `end_date_from` | 返却日（From） | `end_date_from=2026-04-01` |
| `end_date_to` | 返却日（To） | `end_date_to=2026-04-30` |
| `payment_status` | 残高フィルタ | `UNPAID` / `PAID` |
| `payment_method` | 支払方法 | `payment_method=credit_card` |
| `payment_date_from` | 入金日（From） | `payment_date_from=2026-04-01` |
| `payment_date_to` | 入金日（To） | `payment_date_to=2026-04-30` |
| `amount_min` | 金額（下限） | `amount_min=10000` |
| `amount_max` | 金額（上限） | `amount_max=50000` |
| `staff_name` | 担当者名 | `staff_name=田中` |
| `invoice_number` | 請求書番号 | `invoice_number=INV-001` |
| `billing_name` | 請求先名 | `billing_name=株式会社〇〇` |
| `company` | 会社名 | `company=サンプル株式会社` |
| `phone_number` | 電話番号 | `phone_number=03-1234-5678` |
| `company_kana` | 会社名カナ | `company_kana=サンプル` |
| `customer_name_kana` | 担当者名カナ | `customer_name_kana=ヤマダ` |
| `product_name_kana` | 商品名カナ | `product_name_kana=テント` |
| `page` | ページ番号 | `page=2` |
| `limit` | 1ページあたり件数 | `limit=20`（固定） |
| `sort_by` | 並び順フィールド | `sort_by=created_at` |
| `sort_order` | 並び順（昇順/降順） | `sort_order=desc` |

### URLで検索条件を共有する

検索条件はURLに保持されるため、ブラウザのブックマークに登録すれば同じ条件でいつでも開けます。

例: 2026年4月の処理中伝票を検索
```
/slip-search?status=PROCESSING&start_date_from=2026-04-01&start_date_to=2026-04-30
```

### かんたん検索のパラメータ

| ボタン | 設定されるパラメータ |
|--------|-------------------|
| 本日 | `start_date_from=<今日>&start_date_to=<今日>` |
| 処理中 | `status=PROCESSING` |
| 今週 | `start_date_from=<月曜日>&start_date_to=<日曜日>` |
| 延滞 | `end_date_to=<昨日>&status=PROCESSING` |
:::

## よくある質問

### Q: 検索結果が表示されない
条件が厳しすぎる可能性があります。期間やステータスの条件を緩めて再度検索してみてください。それでも表示されない場合は、ページを再読み込みしてください。

### Q: 検索条件を保存できますか？
検索条件はURLに保持されるため、ブラウザのブックマークに登録すれば同じ条件でいつでも開けます。他のスタッフにURLを共有することもできます。

---

## 注意事項

- 1ページあたり **20件** の検索結果が表示されます
- 検索条件を入力すると自動的に検索が実行されます（検索ボタンを押す必要はありません）
- 新規予約作成画面で保存完了後、自動的にこの画面に遷移し、作成した伝票が表示されます
