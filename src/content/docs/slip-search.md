# 伝票検索

![伝票検索画面](/images/slip-search/main.png)

登録されているレンタル伝票を様々な条件で検索し、一覧表示する画面です。
ステータス、期間、顧客情報などで伝票を絞り込み、詳細の確認や編集ができます。

## この画面を開くには

- サイドバーの **「伝票管理」＞「伝票検索」** をクリック
- [貸し出し伝票作成](/booking-compact/)画面で保存完了後に自動で移動
- 他の画面からリンク経由で遷移

---

## 操作手順

### ステップ1: 検索条件を入力する

検索条件は最低1つ入力してください。検索条件モーダル内の **「🔍 検索」** ボタンを押してはじめて検索が実行されます（キーワードや各フィルタ入力欄の変更だけでは検索は走りません）。モーダルはこの画面を開いた時点でデフォルト表示されます。

#### キーワードで探す

キーワード欄に伝票番号・顧客名・会社名・顧客コード・電話番号を入力します。

#### 条件で絞り込む

| 絞り込み条件 | 説明 |
|------------|------|
| 伝票番号 | 特定の伝票番号で検索 |
| ステータス | 処理中 / 金額確認待ち / 未送信 / 請求済 / 完了 など |
| 予約種別 | 通常予約 / 展示会予約 |
| レンタル開始日 | 開始日の範囲を指定（From〜To） |
| 返却日 | 返却予定日の範囲を指定（From〜To） |
| 残高フィルタ | 残高あり / 残高なし |
| 支払方法 | 店頭支払い / 銀行振込 / Shopify |
| 入金日 | 入金日の範囲を指定 |
| 金額 | 請求金額の範囲を指定 |
| 担当者名 | 作成・更新したスタッフ名で検索 |
| 請求書番号 | 請求書番号で検索 |
| 会社名 | 顧客の会社名で検索 |
| 電話番号 | 電話番号で検索 |

#### かんたん検索ボタン

よく使う条件がボタン一つで設定できます。

| ボタン | 検索内容 |
|--------|---------|
| **本日の出荷** | 今日レンタルが開始される（出荷予定の）伝票 |
| **本日の返却** | 今日返却予定の伝票 |
| **検索項目を選択** | 検索条件モーダルを開き、詳細な条件で検索 |

:::dev
#### ステータスの内部値

画面の表示名と内部ステータス値の対応（`SLIP_SEARCH_STATUS_LABELS`）:

| 表示名 | 内部値 | 備考 |
|--------|--------|------|
| 処理中 | `PROCESSING` | 予約作成後〜出荷前（cart/theme/webhook/bank_transfer では初期状態・#2397） |
| 金額確認待ち | `PRICE_CONFIRM_PENDING` | 返却後の金額調整中 |
| 未送信 | `BILLING_PENDING` | 金額確定済みで請求書が未送信（銀行振込など） |
| 請求済 | `PAYMENT_PENDING` | 請求書発行済・入金確認待ち |
| 完了 | `COMPLETED` | 入金確認済み |

全11ステータスの完全一覧は [ステータス遷移図](/appendix/status-flow/) を参照。
:::

### ステップ2: 検索結果を確認する

検索結果はテーブルで一覧表示されます。

#### 一覧の見方

| 列 | 内容 |
|----|------|
| 伝票番号 | システムが自動で付けた番号 |
| 顧客情報 | 会社名、担当者名、部署 |
| ステータス | 伝票の現在の状態（色付きラベル） |
| レンタル期間 | 開始日 〜 終了日（日数） |
| 金額情報 | 請求金額 / 入金済 / 残高 |
| 支払情報 | 支払方法と支払の状態 |
| 担当者 | スタッフ名 |
| 作成日時 | 伝票を作成した日時 |

#### ステータスの色

| 色 | 状態 |
|----|------|
| 青 | 処理中 |
| 黄 | 未送信 |
| オレンジ | 請求済 |
| 緑 | 完了 |
| 赤 | キャンセル済み |
| 濃い赤 | 超過中（返却期限超過） |

> **💡 「処理中」と表示される範囲について**
>
> 「処理中」は**予約が確定してから返却されるまでの広い期間**を表します。現金や店頭受取で予約を作成した直後も「処理中」と表示されますが、これは**正常な動作**です（予約自体は確定済みですが、ピッキング・出荷・返却といった工程がまだ残っているため「処理中」になります）。
>
> ピッキング画面などで「この伝票は確定済みです」という案内が表示されることがありますが、これは**その工程での案内テキスト**であり、伝票検索のステータス（処理中）とは別の意味です。伝票の状態は伝票検索・伝票詳細のステータス（処理中 / 金額確認待ち / 未送信 / 請求済 / 完了）で確認してください。

> **💡 並べ替え:** 列の見出し（伝票番号、ステータス、レンタル期間など）をクリックすると、並び順を変えられます。初期表示は作成日時の新しい順です。

### ステップ3: 伝票の詳細を確認する

1. 確認したい伝票の **「詳細」** ボタンをクリックします
2. 詳細モーダルが開き、以下のセクションが縦に連なるスクロール形式で情報を確認できます

| セクション | 確認できる内容 |
|----------|-------------|
| 伝票情報 | 伝票番号、ステータス、予約種別、支払方法、注文方法 |

> **💡 注文方法が「-」（未選択）の伝票:** 旧システム（@Suite）から転記した伝票は、注文方法の情報が引き継がれず **「-」（未選択）** と表示されます（2026年9月時点の仕様）。不具合ではありません。新しく作成した伝票には注文方法（WEB / TEL / FAX / EMAIL / 来店 など）が表示されます。
| 顧客情報 | 顧客名、会社名、担当者、連絡先 |
| 予約商品 | 商品のSKU、商品名、数量、単価、日数、金額 |
| 配送情報 | 配送スケジュール、配送先 |
| 金額情報 | 料金の内訳（商品小計、値引き、配送料、消費税、請求金額、残高） |
| Shopify参照情報 | Shopify注文への参照情報 |
| システム情報 | 作成日時・更新日時・担当者などシステム記録 |

> **💡 金額確定済みバッジ:** 後払いクレジットカード伝票で配送料を含む全額が確定済みの場合、「伝票情報」セクションに緑の「**金額確定済み**」バッジと確定日時（JST）が表示されます。商品の追加・変更は別途「追加料金」として手続きしてください。

### ステップ4: 伝票を編集する

1. 編集したい伝票の **「伝票詳細」** ボタン（または「編集」ボタン）をクリックします
2. [貸し出し伝票作成](/booking-compact/)画面が編集モードで開きます

---

## Shopifyボタンについて

検索結果の各行には **「Shopify」** ボタンが表示される場合があります。
このボタンをクリックすると、新しいタブで Shopify 管理画面の該当ページが開き、決済状況やキャンセル状態を直接確認できます。

> **💡 注意:** Shopify 管理画面の利用には事前のログインが必要です。

---

## まとめて選択する

一覧のチェックボックスで伝票を選択できます。

- 個別にチェックを入れる
- ヘッダーのチェックボックスで現在のページを全選択

選択するとツールバーに以下のアクションが表示されます。

| アクション | 内容 |
|----------|------|
| 選択した予約を削除 | 選択した伝票を一括削除 |
| コピーして新規伝票作成 | 選択した伝票の内容をコピーして新規伝票作成画面を開く |
| CSV出力 | 選択した伝票をCSV形式で出力 |

## API・URLパラメータ仕様

### エンドポイント

```
GET /bookings/search
```

### クエリパラメータ

| パラメータ | 対応するUI | 例 |
|-----------|-----------|-----|
| `keyword` | キーワード | `keyword=山田` |
| `status` | ステータス | `status=PROCESSING` |
| `booking_type` | 予約種別 | `booking_type=normal_order` |
| `slip_number` | 伝票番号 | `slip_number=B-1234` |
| `start_date_from` | 開始日（From） | `start_date_from=2026-04-01` |
| `start_date_to` | 開始日（To） | `start_date_to=2026-04-30` |
| `end_date_from` | 返却日（From） | `end_date_from=2026-04-01` |
| `end_date_to` | 返却日（To） | `end_date_to=2026-04-30` |
| `balance_filter` | 残高フィルタ | `has_balance` / `no_balance` |
| `payment_method` | 支払方法 | `payment_method=store_payment` |
| `payment_date_from` | 入金日（From） | `payment_date_from=2026-04-01` |
| `payment_date_to` | 入金日（To） | `payment_date_to=2026-04-30` |
| `amount_min` | 金額（下限） | `amount_min=10000` |
| `amount_max` | 金額（上限） | `amount_max=50000` |
| `staff_name` | 担当者名 | `staff_name=田中` |
| `invoice_number` | 請求書番号 | `invoice_number=INV-001` |
| `billing_name` | 請求先名 | `billing_name=株式会社〇〇` |
| `company` | 会社名 | `company=サンプル株式会社` |
| `phone_number` | 電話番号 | `phone_number=03-1234-5678` |
| `company_kana` | 会社名カナ | `company_kana=サンプル` |

| `product_name_kana` | 商品名カナ | `product_name_kana=テント` |
| `page` | ページ番号 | `page=2` |
| `limit` | 1ページあたり件数 | `limit=20`（固定） |
| `sort_by` | 並び順フィールド | `sort_by=created_at` |
| `sort_order` | 並び順（昇順/降順） | `sort_order=desc` |

### URLで検索条件を共有する

検索条件はURLに保持されるため、ブラウザのブックマークに登録すれば同じ条件でいつでも開けます。

例: 2026年4月の処理中伝票を検索
```
/slip-search?status=PROCESSING&start_date_from=2026-04-01&start_date_to=2026-04-30
```

### かんたん検索のパラメータ

| ボタン | 設定されるパラメータ |
|--------|-------------------|
| 本日の出荷 | `start_date_from=<今日>&start_date_to=<今日>` |
| 本日の返却 | `end_date_from=<今日>&end_date_to=<今日>` |
:::

## よくある質問

### Q: 検索結果が表示されない
条件が厳しすぎる可能性があります。期間やステータスの条件を緩めて再度検索してみてください。それでも表示されない場合は、ページを再読み込みしてください。

### Q: 検索条件を保存できますか？
検索条件はURLに保持されるため、ブラウザのブックマークに登録すれば同じ条件でいつでも開けます。他のスタッフにURLを共有することもできます。

---

## 注意事項

- 1ページあたり **20件** の検索結果が表示されます
- 検索を実行するには、検索条件モーダル内の **「🔍 検索」** ボタンを押してください（入力だけでは検索は走りません）
- 新規予約作成画面で保存完了後、自動的にこの画面に遷移し、作成した伝票が表示されます
