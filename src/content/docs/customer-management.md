## 概要

顧客一覧、会社グループを含む顧客管理システム。顧客データの検索、閲覧、編集、整理が可能。タグ管理はShopify Adminで行います。

**Shopify Admin一本化**: 新規顧客登録はShopify Adminで行い、同期ボタンでバックエンドに反映します。

## アクセス方法

- サイドバー: **顧客管理** > **顧客管理**
- 直接URL: `/customer-management`

## 手順

### 手順1: 新規顧客を登録（Shopify Admin）

> **重要**: 顧客データはShopifyがマスターです。新規登録はShopify Adminで行います。

1. **新規登録** ボタンをクリック
2. Shopify Adminの顧客登録画面が新しいタブで開きます
3. 必要な情報を入力:
   - 標準フィールド: メール、名前、電話、住所
   - メタフィールド: 会社情報、レンタル関連情報
4. **保存** をクリック
5. 管理画面に戻り、**Shopify同期** ボタンをクリック
6. 同期完了後、顧客データがバックエンドに反映されます
7. 必要に応じて、顧客を選択して請求先を登録してください

**期待される結果:** Shopifyで登録した顧客が管理画面に表示されます。

### 手順2: Shopify同期

**Shopify Adminで顧客を登録・更新した後**、同期ボタンで最新データを反映します。

1. **Shopify同期** ボタンをクリック
2. 同期が完了すると、反映件数が通知されます
3. 顧客一覧が自動的に更新されます
4. 必要に応じて請求先登録を促すメッセージが表示されます

**注意:** 同期はShopify APIから全顧客データを取得して処理するため、数千件の顧客がいる場合は数分かかることがあります。

### 手順3: 顧客を検索

1. 検索ボックスにキーワードを入力
   - 会社名 / 担当者 / 電話 / メール / 会社コード
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果が下のテーブルに表示

**期待される結果:** 条件に一致する顧客が結果一覧に表示。

### 手順4: 顧客詳細を閲覧

1. テーブルの顧客行をクリック
2. 下部パネルに顧客詳細が表示
3. または、操作列の情報アイコンをクリックしてモーダル表示

**期待される結果:** 顧客詳細パネルに以下が表示:

- 基本情報（会社、担当者、電話、メール、会社コード）
- 住所情報（郵便番号、都道府県、市区町村、番地）

### 手順5: 顧客を編集

1. 操作列の編集アイコン（緑の鉛筆）をクリック
2. 顧客編集モーダルが開く
3. 必要に応じてフィールドを変更
4. **保存** をクリック

**期待される結果:** 顧客データが更新され、通知で成功が確認。

### 手順6: 顧客をグループに追加

1. 操作列のユーザープラスアイコン（紫）をクリック
2. グループ追加モーダルが開く
3. 対象の会社グループを選択
4. **追加** をクリック

**期待される結果:** 選択したグループに顧客が追加。

### 手順7: 顧客を一括削除

1. チェックボックスで顧客を選択
2. **全て選択** チェックボックスでページ内全件を選択
3. **選択した顧客を削除** ボタンをクリック
4. モーダルで削除を確認
5. **削除** をクリック

**期待される結果:** 選択した顧客がシステムから削除。

## タグ管理

## 請求先管理

### 概要

顧客ごとに複数の請求先を登録・管理できる機能。スタイリストなど案件ごとに請求先が変わるケースに対応。

### 手順10: 請求先を追加

1. 顧客詳細パネルの **請求先** タブをクリック
2. **+ 新規請求先** ボタンをクリック
3. 請求先情報を入力:
   - 会社名（必須）
   - 別名（例：「案件A用」）
   - 部署名、役職、スタッフコード
   - 担当者名
   - メールアドレス、電話番号、FAX番号
   - 郵便番号、都道府県、市区町村、番地
   - 支払い方法、請求サイクル
   - 銀行口座情報（銀行名、支店名、口座種別、口座番号、口座名義）
   - 支払サイト（日数）、法人番号、CCメール
   - 請求タイプ（個人/部署）、メモ
   - 備考
4. **保存** をクリック

### 手順11: 請求先を編集・削除

1. 請求先カードの編集アイコンをクリック
2. 必要な項目を変更
3. **保存** または **削除** をクリック

### 手順12: デフォルト請求先を設定

1. 請求先カードの星アイコンをクリック
2. 確認ダイアログで **OK** をクリック

**期待される結果:** 選択した請求先がデフォルトとして設定され、予約作成時に自動選択。

## API エンドポイント

請求先管理API（完全パス）:

| 操作     | メソッド | 完全パス                                                               |
| -------- | -------- | ---------------------------------------------------------------------- |
| 一覧取得 | GET      | `/api/v1/master-data/admin/billing-addresses?shopify_customer_id={id}` |
| 作成     | POST     | `/api/v1/master-data/admin/billing-addresses`                          |
| 更新     | PUT      | `/api/v1/master-data/admin/billing-addresses/{id}`                     |
| 削除     | DELETE   | `/api/v1/master-data/admin/billing-addresses/{id}`                     |

> **注意**: フロントエンドからは `apiClient` 経由で呼ぶため、Global Prefix `/api/v1` は省略可能です。
