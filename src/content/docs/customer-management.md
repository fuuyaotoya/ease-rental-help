## 概要

顧客の登録・検索・閲覧・更新・削除を行う画面です。新規顧客は **この画面の「+ 新規登録」ボタン**から登録でき、登録と同時に Shopify とレンタルシステム（customer_master）の両方へ反映されます。Shopify Admin で直接登録した顧客は **「Shopify同期」ボタン**で取り込みます。

> **顧客データの所在（重要）**
> - 顧客の基本情報（氏名・メール・電話・住所・タグ）は **Shopify がマスター** です。
> - レンタル業務用の追加情報（請求先・社内メモ等）は **システムのデータベース（顧客マスタ・請求先）** で管理します。
> - タグ（「銀行振込可」など）は登録時に付与できるほか、Shopify Admin で編集して同期で反映できます。

## アクセス方法

- サイドバー: **顧客管理** > **顧客管理**
- 直接URL: `/customer-management`

## 手順

### 手順1: 新規顧客を登録（画面内モーダル）

> この画面の **「+ 新規登録」** から登録します。登録すると **Shopify顧客の作成** と **レンタルシステムへの登録（customer_master）** が自動で行われます（2段階処理）。

1. **+ 新規登録** ボタンをクリック → 「新規顧客登録」モーダルが開く
2. 必要な情報を入力:
   - **基本情報**: 種別（法人/個人）、会社名（＋カナ）、担当者名（＋カナ）
   - **業種**: ドロップダウンから選択（建設業・製造業・サービス業 等）。2026-07改定で **映像制作会社（34）**・**芸能/クリエイター事務所（36）** を追加し、フリーランスの `01フリー` を先頭スペースなしに正規化しました
   - **連絡先**: メールアドレス（**必須**）、携帯電話（**必須**）、会社電話（任意）、FAX、Webサイト
   - **住所**: 郵便番号（入力すると都道府県・市区町村を自動補完）、都道府県（セレクトボックス）、市区町村、番地、建物名
   - **所属**: 部署、役職
   - **タグ**: カンマ区切りで入力。「銀行振込可」はチェックボックスで付与可能
   - **免税**: 必要に応じてチェック
   - **顧客メモ**: スタッフ間で共有するメモ（伝票画面と連動）
   - **請求先**: 会社名・担当者・部署・住所・電話・メール・支払月・支払日等。「顧客情報と同じ」にチェックすると顧客住所をコピー
3. **登録** をクリック

**処理の流れ（内部）:**
1. `POST /customers` … Shopify顧客 + `shopify_customers` を作成
2. `POST /customers/{shopifyId}/register-to-rental` … `customer_master` へ登録

> **補足**:
> - 会社名は Shopify の姓（last_name）に同期されます。部署名は含まれません。
> - メールまたは電話の重複時はエラー通知が出ます（8秒表示）。
> - Shopify標準の `phone` は使用しません。携帯電話=`rental_mobile`（**必須**）・会社電話=`rental_company_phone`（任意）を使い分けます。

**期待される結果:** 登録した顧客が一覧（登録済み顧客）に表示され、「顧客を登録しました」と通知されます。

### 手順2: Shopify同期

**Shopify Adminで顧客を登録・更新した後**、同期ボタンで最新データを反映します。

1. **Shopify同期** ボタンをクリック
2. 同期が完了すると、反映件数が通知されます
3. 顧客一覧が自動的に更新されます
4. 必要に応じて請求先登録を促すメッセージが表示されます

**注意:** 同期はShopify APIから全顧客データを取得して処理するため、数千件の顧客がいる場合は数分かかることがあります。

### 手順3: 顧客を検索

1. 検索ボックスにキーワードを入力
   - 会社名 / 担当者 / 電話 / メール / 顧客コード
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果が下のテーブルに表示

**期待される結果:** 条件に一致する顧客が結果一覧に表示。

### 手順4: 顧客詳細を閲覧

1. テーブルの顧客行（または操作列の詳細アイコン）をクリック
2. 顧客詳細が表示されます

**期待される結果:** 顧客詳細モーダルに以下が表示:

- 基本情報（会社、担当者、種別、業種、部署、電話、メール、顧客コード）
- **銀行振込可** トグル（編集モード時）
- **顧客メモ**（伝票画面と連動する共有メモ）
- 住所情報（郵便番号、都道府県=セレクトボックス、市区町村、番地）
- 請求先タブ（会社名・担当者・部署・住所・支払月・支払日・銀行口座情報）

### 手順5: 顧客を更新（編集）

1. 顧客詳細を開き、**編集** をクリック
2. 編集可能なフィールドを変更し、**保存** をクリック

**編集できる項目 / できない項目:**

| 区分                  | 例                                                             | 可否 |
| --------------------- | -------------------------------------------------------------- | ---- |
| 管理項目（ADMIN）     | レンタル種別、業種、請求関連、顧客メモ、銀行振込可 など        | ✅ 編集可 |
| 補完項目（FILL_NULL） | 未設定（空）の会社情報・住所などを補完入力                     | ✅ 空欄のみ補完可 |
| Shopify権限項目       | 氏名・メール・標準住所など Shopify がマスターの項目            | 🔒 読み取り専用 |

> 内部的には `PATCH /customers/{id}`（ADMIN/FILL_NULL フィールド + 社内メモのみ）を呼びます。Shopify権限の項目は読み取り専用です。
> ※ 旧データを持つ顧客のみ「電話番号(旧)」が編集可能として表示されます（Shopify標準phoneは廃止）。
> ※ 管理画面で会社名を更新すると、Shopify の `last_name` にも自動同期されます。

**期待される結果:** 顧客データが更新され、成功通知が表示されます。

> **🔁 すでに保存されている伝票には反映されません:** ここで顧客情報を更新しても、**すでに保存されている伝票（伝票作成画面）には自動反映されません**。伝票は作成・保存時点の顧客情報を**スナップショット**として保持する仕組みのためです。特定の伝票を最新の顧客情報に更新したい場合は、[貸し出し伝票作成](/booking-compact/)画面でその伝票を編集モードで開き、「顧客を選択」から同じ顧客を再選択して保存し直してください。
>
> **⚠️「Shopify同期」を押すタイミングの注意:** 「Shopify同期」（手順2）は **Shopify Admin 側で直接編集した内容を取り込む**ためのボタンで、この画面での編集とは反対方向のデータの流れです。この画面で顧客情報を編集した直後は、その内容が実際の Shopify 側（メタフィールド等）へ反映されるまでわずかにタイムラグが生じることがあります。編集した直後に「Shopify同期」を実行すると、Shopify側への反映が間に合わず**編集前の古い値で上書きされてしまう**ことがあるため、顧客情報を編集した直後の同期操作は避け、必要な場合は少し時間を置いてから実行してください。

### 手順6: 顧客を無効化（一括・可逆）

1. チェックボックスで顧客を選択（ヘッダーのチェックでページ内全件を選択）
2. **選択した顧客を無効化** ボタンをクリック
3. 確認モーダルで「**無効化**」をクリック（**この操作は後から取り消せます**）

**動作（ステータス無効化）:**

- `customer_master.is_active = false` に更新します（データの論理削除は行わず、**可逆**な無効化です）
- Shopify 側の顧客に **「無効」タグを付与** します（Shopify の顧客アカウント自体は削除されません）
- 成功・失敗の件数が通知されます

**無効化を取り消す（再有効化）:**

1. 検索トグル **「無効も表示」** をオンにします（無効化済み顧客が一覧に表示されます）
2. 対象顧客の行にある **「再有効化」** ボタンをクリックします

> **⚠️ 請求先（`billing_addresses`）は無効化されません:** 顧客を無効化しても、その顧客に紐づく請求先マスタ（`billing_addresses`）は無効化の対象外で残ります（GAP-CUST-2）。これは過去伝票の請求先履歴を保全するためですが、まれに無効化済み顧客の請求先が [会社まとめ請求](/consolidated-invoices/) の候補に混入することがあります。まとめ請求の発行前は必ず内容を確認してください。

**期待される結果:** 選択した顧客が一覧から消え、件数が通知されます。注文履歴のある顧客でも無効化できます。

> **内部処理（参考）**: `PATCH /customers/batch-status`。送信する `customer_ids` は一覧の ID（= Shopify Customer ID）です。

## Shopify連携と削除時の挙動

この画面の「無効化」ボタン（手順6 / 内部 API は `batch-status`）はレンタルシステム上の **ステータス無効化（可逆）** であり、Shopify の顧客アカウント自体は削除しません（「無効」タグの付与のみ行います）。これは Shopify Admin API の制約と仕様判断によるものです。

### Shopify 側に対して外部（API）からできること・できないこと

| 操作                                   | 可否       | 理由 / 補足                                                                 |
| -------------------------------------- | ---------- | -------------------------------------------------------------------------- |
| 顧客を**アーカイブ**にする             | ❌ 不可     | Shopify に「顧客アーカイブ」という機能・APIが存在しない                     |
| アカウント**状態（state）を変更**      | ❌ 不可     | `state`（ENABLED/DISABLED 等）は読み取り専用。`customerUpdate` で変更不可。招待・有効化のライフサイクルでのみ自動遷移 |
| 顧客を**物理削除**（customerDelete）    | △ 限定的   | **注文のない顧客のみ**削除可。注文があると失敗するため、レンタル顧客はほぼ削除不可 |
| **タグ**の付与/削除                    | ✅ 可       | 「ソフトな印付け」手段。**無効化時に「無効」タグを自動付与します** |
| 氏名・メール・電話・メモ等の**更新**   | ✅ 可       | `customerUpdate` で可能（state は対象外）                                   |

### つまり

- レンタル画面で顧客を無効化しても、**Shopify には同じ顧客がそのまま残ります**（state は変わらず、「無効」タグが付くのみです）。
- 一覧から消えるのは `customer_master.is_active=false` によるもので、**Shopify再同期でも復活しません**（同期は `is_active` を書き戻さないため。元に戻すには「無効も表示」→「再有効化」）。
- 注文履歴のある顧客でも無効化が成功するのは、Shopify の顧客を削除しない（＝`customerDelete` を呼ばない）ためです。

> **実機検証済み**: 削除後も対象顧客は Shopify に存在し（注文4件を持つ顧客も含む）、`state` は変化していないことを確認済み。

## タグ管理

> タグは登録時にこの画面で付与できます（「銀行振込可」チェック含む）。既存顧客のタグ編集は **Shopify Admin** で行い、**Shopify同期**でシステムに反映されます。

> **💡 システム内部タグについて:** Shopify Admin で顧客のタグ一覧を見ると、`sync_metafields` のような **システムが内部用途で付与したタグ** が混ざっていることがあります（GAP-CUST-7）。これらは業務タグではなく削除しないでください（「銀行振込可」などの業務タグと区別して運用してください）。

## 請求先管理

### 概要

顧客ごとに複数の請求先を登録・管理できる機能。スタイリストなど案件ごとに請求先が変わるケースに対応。

### 承認時の自動作成（初期請求先）

[会員申込](/membership-apply/) を承認したタイミングで、申請者の基本情報（会社名・担当者名・担当者住所・担当者メール等）から **デフォルト請求先が1件自動作成** されます（2176）。これは **伝票作成（フロントエンド）に請求先が必須** なための初期フォールバックです。

:::note[自動作成の仕様]
- **無条件コピー（同一判定なし）** — 申請者情報をそのまま請求先へコピーします。
- **必須8項目** — `company_name` / `billing_contact_name` / `billing_email` / `billing_phone` / `postal_code` / `prefecture` / `city` / `address1` が揃っている場合のみ作成。個人顧客や情報不全の申請はスキップされます。
- **`billing_email` には担当者メールが入ります**（本社経理のメールではありません）。
- **冪等** — 同じ内容のデフォルト請求先が既にあれば再作成しません。
:::

> **⚠️ 請求先がズレるケース（申請住所は「担当者のいる住所」）**
> 会員申込の住所は **担当者がいる住所（営業所・現場）** を想定しています。そのため **請求先が本社** の場合、自動作成された請求先（担当者住所・担当者メール）と実態がズレます。後述の「振込可能タグ付与時の請求先確認」で修正してください。

### 銀行振込可タグ：付与基準とカート表示への影響

「銀行振込可」タグは、**月末締めの請求書払い（銀行振込）をご利用いただける顧客** に付与するマーカーです。タグの有無で **顧客のカート画面の表示と決済フロー全体** が切り替わります。フローを誤って伝えると顧客混乱に直結するため、まずはここを押さえてください。

#### 付与のタイミングと基準

- **初回は付与しない** — すべての顧客は **初回クレジットカード決済** から始まります。会員申込の承認時点ではタグを付けないでください（自動付与されません）。
- **2回目以降の審査で付与** — 法人顧客が振込希望を申し出た場合、与信判断の上でタグを付与します。個人顧客は原則クレジットカードのまま（例外のみ上長判断）。
- **付与手順** — Shopify Admin の顧客タグに「銀行振込可」を追加 → Shopify同期でシステムへ反映。本画面の **銀行振込可** チェックボックス（編集モード時）でも編集できます。

#### カート表示への影響（タグあり／なしで何が変わるか）

| 顧客状態 | カート右側 | 予約確定モーダル | 利用可能な決済 |
|---------|-----------|---------------|--------------|
| **タグなし**（初回・振込不可） | 請求先セクション **非表示** | 「60分以内にお支払いが確認できないとキャンセル」の警告 | クレジットカード決済のみ |
| **タグあり**（振込可） | 請求先セクション **表示** | 「月末締め請求書払い・チェックアウト不要」の注記 | クレジットカード **または** 銀行振込（後払い） |

:::tip[タグなし ＝ クレジットカード専用]
タグがない顧客は **クレジットカード決済しか選べません**。顧客から「振込にしたい」と問い合わせがあった場合は、審査の上でタグを付与してください。タグなしのままでは振込導線がカートに出ません。
:::

#### 顧客から「振込できますか？」と聞かれたら

1. **初回顧客** — 「初回はクレジットカード決済でお願いしております。2回目以降、審査の上でご案内可能です」と案内
2. **2回目以降・法人** — 与信確認の上でタグを付与 → 下記「振込可能タグ付与時の請求先確認」に従い請求先（特に `billing_email`）を確認
3. **個人顧客** — 原則クレジットカード。特段の事情がある場合のみ上長判断

### 振込可能タグ付与時の請求先確認（運用ルール）

法人は原則 **銀行振込**（2回目以降）、個人 **クレジットカード**（少数）でご利用いただいます。初回は全員クレジットカード決済のため、申請時点では請求先は使われません。

:::caution[請求書は DL / メール送付のみ — billing_email が重要]
請求書は **マイアカウントからのダウンロード** または **メール送付** のみで、**郵送は行いません**。したがって請求先住所のズレよりも **`billing_email`（請求書送付先メールアドレス）** の正確さが重要です。本社経理宛てに送るべき請求書が担当者個人に送られないよう、**振込を開始する前に必ず確認** してください。
:::

**確認チェックリスト（銀行振込可タグ付与時）:**

- [ ] 請求先はご登録担当者情報と同じか？
  - **同じ** → 自動作成済み（内容確認のみ）
  - **違う（本社請求等）** → 請求先を編集：本社の **住所** ＋ **請求書送付先メール（`billing_email`）** を正しく設定

> **顧客側は読み取り専用:** お客様自身は請求先の追加・編集ができません（マイアカウントでは参照のみ）。請求先の修正はすべてこの画面（スタッフ管理画面）で行います。

### 手順A: 請求先を追加

1. 顧客詳細パネルの **請求先** タブをクリック
2. **+ 新規請求先** ボタンをクリック
3. 請求先情報を入力:
   - 会社名（必須）
   - 別名（例：「案件A用」）
   - 部署名、役職、スタッフコード
   - 担当者名
   - メールアドレス、電話番号、FAX番号
   - 郵便番号、都道府県、市区町村、番地
   - 支払い方法、請求サイクル
   - 銀行口座情報（銀行名、支店名、口座種別、口座番号、口座名義）
   - 支払サイト（日数）、法人番号、CCメール
   - 請求タイプ（個人/部署）、メモ
   - **まとめ請求対象**（月次まとめ請求に含める・個別送信しない）
   - 備考
4. **保存** をクリック

> **💡 まとめ請求対象チェック:** 「まとめ請求対象」にチェックを入れた請求先は、月次のまとめ請求（[会社まとめ請求](/consolidated-invoices/)）に含まれ、個別の請求書送信対象から除外されます。チェックは保存後も維持されます。

> **自動デフォルト化:** 顧客に請求先が1件も登録されていない状態で新規請求先を作成すると、その請求先が自動的にデフォルトに設定されます。また、ある請求先をデフォルトにすると、以前のデフォルトは自動的に解除されます（常に1件のみデフォルト）。

### 手順B: 請求先を編集・削除

1. 請求先カードの編集アイコンをクリック
2. 必要な項目を変更
3. **保存** または **削除** をクリック

### 手順C: デフォルト請求先を設定

1. 請求先カードの星アイコンをクリック
2. 確認ダイアログで **OK** をクリック

**期待される結果:** 選択した請求先がデフォルトとして設定され、予約作成時に自動選択。

## 注意事項

- 新規顧客はこの画面の「+ 新規登録」から登録でき、Shopify顧客の作成とレンタルシステム登録が自動で行われます
- Shopify Admin で直接作成した顧客は「Shopify同期」で取り込みます
- 顧客の削除はレンタルシステム上の**論理削除**で、Shopify顧客は削除されません（「Shopify連携と削除時の挙動」参照）
- 顧客コード（旧称: 会社コード）はレガシーシステム連携に使用
- 請求先はシステムのデータベースで管理（Shopifyメタフィールドとは別）
