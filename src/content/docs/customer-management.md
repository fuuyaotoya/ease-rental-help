## 概要

顧客の登録・検索・閲覧・更新・無効化を行う画面です。新規顧客は **+ 新規登録** から登録します。Shopify管理画面で直接登録した顧客は **Shopify同期** で取り込みます。

> **顧客データの所在（重要）**
> - 顧客の基本情報（氏名・メール・電話・住所・タグ）は、Shopify管理画面の情報が基準です。
> - 請求先と社内メモは、EASEの顧客管理画面で管理します。
> - 「銀行振込可」などのタグは登録時に付けられます。Shopify管理画面で編集した場合は、**Shopify同期**で反映します。

## アクセス方法

- サイドバー: **顧客管理** > **顧客管理**

## 手順

### 手順1: 新規顧客を登録（画面内モーダル）

> この画面の **+ 新規登録** から登録します。ShopifyとEASEの両方へ自動で登録されます。

1. **+ 新規登録** ボタンをクリック → 「新規顧客登録」モーダルが開く
2. 必要な情報を入力:
   - **基本情報**: 種別（法人/個人）、会社名（＋カナ）、担当者名（＋カナ）
   - **業種**: ドロップダウンから選択（建設業・製造業・サービス業 等）。2026-07改定で **映像制作会社（34）**・**芸能/クリエイター事務所（36）** を追加し、フリーランスの `01フリー` を先頭スペースなしに正規化しました
   - **連絡先**: メールアドレス（**必須**）、携帯電話（**必須**）、会社電話（任意）、FAX、Webサイト
   - **住所**: 郵便番号（入力すると都道府県・市区町村を自動補完）、都道府県（セレクトボックス）、市区町村、番地、建物名
   - **所属**: 部署、役職
   - **タグ**: カンマ区切りで入力。「銀行振込可」はチェックボックスで付与可能
   - **免税**: 必要に応じてチェック
   - **顧客メモ**: スタッフ間で共有するメモ（伝票画面と連動）
   - **請求先**: 会社名・担当者・部署・住所・電話・メール・支払月・支払日等。「顧客情報と同じ」にチェックすると顧客住所をコピー
3. **登録** をクリック

> **補足**:
> - メールまたは電話の重複時はエラー通知が出ます（8秒表示）。
> - 携帯電話は必須です。会社電話は任意です。

**期待される結果:** 登録した顧客が一覧（登録済み顧客）に表示され、「顧客を登録しました」と通知されます。

### 手順2: Shopify同期

**Shopify管理画面で顧客を登録・更新した後**、同期ボタンで最新データを反映します。

1. **Shopify同期** ボタンをクリック
2. 同期が完了すると、反映件数が通知されます
3. 顧客一覧が自動的に更新されます
4. 必要に応じて請求先登録を促すメッセージが表示されます

**注意:** 顧客数が多い場合は、同期に数分かかることがあります。

### 手順3: 顧客を検索

1. 検索ボックスにキーワードを入力
   - 会社名 / 担当者 / 電話 / メール / 顧客コード
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果が下のテーブルに表示

**期待される結果:** 条件に一致する顧客が結果一覧に表示。

### 手順4: 顧客詳細を閲覧

1. テーブルの顧客行（または操作列の詳細アイコン）をクリック
2. 顧客詳細が表示されます

**期待される結果:** 顧客詳細モーダルに以下が表示:

- 基本情報（会社、担当者、種別、業種、部署、電話、メール、顧客コード）
- **銀行振込可** トグル（編集モード時）
- **顧客メモ**（伝票画面と連動する共有メモ）
- 住所情報（郵便番号、都道府県=セレクトボックス、市区町村、番地）
- 請求先タブ（会社名・担当者・部署・住所・支払月・支払日・銀行口座情報）

### 手順5: 顧客を更新（編集）

1. 顧客詳細を開き、**編集** をクリック
2. 編集可能なフィールドを変更し、**保存** をクリック

**編集できる項目 / できない項目:**

顧客詳細の **「編集」** から、入力済みの情報も変更できます。

| 区分 | 項目 | 可否 |
| --- | --- | --- |
| 基本情報 | 会社名、顧客コード、会社名カナ、担当者名、担当者カナ、部署、役職、業種 | 編集可 |
| 連絡先 | メールアドレス、電話番号、携帯番号、FAX、Webサイト | 編集可 |
| 住所 | 郵便番号、都道府県、市区町村、番地、建物名 | 編集可 |
| 請求先・業務情報 | 請求先、顧客メモ、銀行振込可 | 編集可 |
| 識別情報 | Shopify Customer ID、種別 | 表示のみ |

> ※ 旧データを持つ顧客だけに「電話番号(旧)」が表示され、編集できます。

**期待される結果:** 顧客データが更新され、成功通知が表示されます。

> **🔁 すでに保存されている伝票には反映されません:** ここで顧客情報を更新しても、**すでに保存されている伝票（伝票作成画面）には自動反映されません**。伝票は作成・保存時点の顧客情報を**スナップショット**として保持する仕組みのためです。特定の伝票を最新の顧客情報に更新したい場合は、[貸し出し伝票作成](/booking-compact/)画面でその伝票を編集モードで開き、「顧客を選択」から同じ顧客を再選択して保存し直してください。
>
> **⚠️「Shopify同期」を押すタイミングの注意:** 「Shopify同期」（手順2）は、**Shopify管理画面で直接編集した内容を取り込む**ボタンです。顧客情報をこの画面で編集した直後は、「Shopify同期」を押さないでください。Shopifyへの反映が終わる前に同期すると、編集前の内容に戻ることがあります。同期が必要な場合は、少し時間を置いてから実行してください。

### 手順6: 顧客を無効化（一括・可逆）

1. チェックボックスで顧客を選択（ヘッダーのチェックでページ内全件を選択）
2. **選択した顧客を無効化** ボタンをクリック
3. 確認モーダルで「**無効化**」をクリック（**この操作は後から取り消せます**）

**動作（ステータス無効化）:**

- EASEの顧客を無効にします。後から再有効化できます
- Shopify 側の顧客に **「無効」タグを付与** します（Shopify の顧客アカウント自体は削除されません）
- 成功・失敗の件数が通知されます

**無効化を取り消す（再有効化）:**

1. 検索トグル **「無効も表示」** をオンにします（無効化済み顧客が一覧に表示されます）
2. 対象顧客の行にある **「再有効化」** ボタンをクリックします

> **⚠️ 請求先は無効化されません:** 顧客を無効化しても、過去伝票の記録を守るため請求先は残ります。無効化した顧客の請求先が [会社まとめ請求](/consolidated-invoices/) の候補に出ることがあります。発行前に内容を確認してください。

**期待される結果:** 選択した顧客が一覧から消え、件数が通知されます。注文履歴のある顧客でも無効化できます。

## Shopify連携と削除時の挙動

この画面の無効化は後から取り消せます。Shopifyの顧客アカウントは削除せず、**無効**タグを付けます。

### 無効化で変わること

| 操作                                   | 可否       | 理由 / 補足                                                                 |
| -------------------------------------- | ---------- | -------------------------------------------------------------------------- |
| 顧客を**アーカイブ**にする             | ❌ 不可     | Shopify管理画面に「顧客アーカイブ」機能がない                               |
| アカウントの状態を直接変更             | ❌ 不可     | Shopify側で管理されるため |
| 顧客を完全に削除                       | △ 限定的   | 注文のない顧客だけ削除できるため |
| **タグ**の付与/削除                    | ✅ 可       | 「ソフトな印付け」手段。**無効化時に「無効」タグを自動付与します** |
| 氏名・メール・電話・メモ等の**更新**   | ✅ 可       | 項目ごとの編集権限に従います                                                  |

### つまり

- 顧客を無効化しても、Shopifyには同じ顧客が残り、**無効**タグが付きます。
- 無効化した顧客は、**Shopify同期**をしても自動では再有効化されません。
- 元に戻すときは **無効も表示** をオンにし、**再有効化**を押します。

## タグ管理

> タグは登録時にこの画面で付与できます（「銀行振込可」チェック含む）。既存顧客の **「銀行振込可」** は顧客詳細の「編集」で変更できます。それ以外のタグ編集は **Shopify管理画面** で行い、**Shopify同期**でシステムに反映されます。

> **💡 システム用のタグについて:** Shopify管理画面には、システムが自動で付けたタグが表示されることがあります。**銀行振込可**などの業務タグ以外は削除しないでください。

## 請求先管理

### 概要

顧客ごとに複数の請求先を登録・管理できる機能。スタイリストなど案件ごとに請求先が変わるケースに対応。

### 承認時の自動作成（初期請求先）

[会員申込](/membership-apply/) の承認時に「申込者情報を請求先にコピーする」にチェックがあり、必要な情報がそろっていれば、申請者情報から初期の請求先を作成します。

:::note[自動作成される請求先]
- 申請者の会社名・担当者名・住所などを使用します。
- 会社名、担当者名、メールアドレス、電話番号、郵便番号、都道府県、市区町村、番地がそろっている場合だけ作成されます。
- 請求書送付先メールには、申請した担当者のメールアドレスが入ります。
- 同じ請求先がすでにある場合は重複して作成しません。
:::

> **⚠️ 請求先がズレるケース（申請住所は「担当者のいる住所」）**
> 会員申込の住所は **担当者がいる住所（営業所・現場）** を想定しています。そのため **請求先が本社** の場合、自動作成された請求先（担当者住所・担当者メール）と実態がズレます。後述の「振込可能タグ付与時の請求先確認」で修正してください。

### 銀行振込可タグ：付与基準とカート表示への影響

「銀行振込可」タグは、**月末締めの請求書払い（銀行振込）をご利用いただける顧客** に付与するマーカーです。タグの有無で **顧客のカート画面の表示と決済フロー全体** が切り替わります。フローを誤って伝えると顧客混乱に直結するため、まずはここを押さえてください。

#### 付与のタイミングと基準

- **初回は付与しない** — すべての顧客は **初回クレジットカード決済** から始まります。会員申込の承認時点ではタグを付けないでください（自動付与されません）。
- **2回目以降の審査で付与** — 法人顧客が振込希望を申し出た場合、与信判断の上でタグを付与します。個人顧客は原則クレジットカードのまま（例外のみ上長判断）。
- **付与手順** — Shopify管理画面の顧客タグに「銀行振込可」を追加し、**Shopify同期**で反映します。この画面の編集時に **銀行振込可** を変更することもできます。

#### カート表示への影響（タグあり／なしで何が変わるか）

| 顧客状態 | カート右側 | 予約確定モーダル | 利用可能な決済 |
|---------|-----------|---------------|--------------|
| **タグなし**（初回・振込不可） | 請求先セクション **非表示** | 返却後に金額を確定し、支払い案内をメール送信 | クレジットカード |
| **タグあり**（振込可） | 請求先セクション **表示** | 返却後に請求書をメール送信。予約時の支払いは不要 | 銀行振込（後払い） |

:::tip[タグなし ＝ クレジットカード専用]
タグがない顧客は **クレジットカード決済しか選べません**。顧客から「振込にしたい」と問い合わせがあった場合は、審査の上でタグを付与してください。タグなしのままでは振込導線がカートに出ません。
:::

#### 顧客から「振込できますか？」と聞かれたら

1. **初回顧客** — 「初回はクレジットカード決済でお願いしております。2回目以降、審査の上でご案内可能です」と案内
2. **2回目以降・法人** — 与信確認の上でタグを付与し、下記の手順で請求書送付先メールを確認
3. **個人顧客** — 原則クレジットカード。特段の事情がある場合のみ上長判断

---

### 振込可能タグ付与時の請求先確認（運用ルール）

法人は原則 **銀行振込**（2回目以降）、個人は **クレジットカード**（少数）でご利用いただきます。初回は全員クレジットカード決済のため、申請時点では請求先は使われません。

:::caution[請求書送付先メールを確認]
請求書は **マイアカウントからのダウンロード** または **メール送付** です。郵送は行いません。本社経理へ送る請求書が担当者個人に届かないよう、振込を開始する前に **請求書送付先メール** を確認してください。
:::

**確認チェックリスト（銀行振込可タグ付与時）:**

- [ ] 請求先はご登録担当者情報と同じか？
  - **同じ** → 自動作成済み（内容確認のみ）
  - **違う（本社請求等）** → 請求先を編集し、本社の **住所** と **請求書送付先メール** を設定

> **顧客側は読み取り専用:** お客様自身は請求先の追加・編集ができません（マイアカウントでは参照のみ）。請求先の修正はすべてこの画面（スタッフ管理画面）で行います。

### 手順A: 請求先を追加

1. 顧客詳細パネルの **請求先** タブをクリック
2. **+ 新規請求先** ボタンをクリック
3. 請求先情報を入力:
   - 会社名（必須）
   - 別名（例：「案件A用」）
   - 部署名、役職、スタッフコード
   - 担当者名
   - メールアドレス、電話番号、FAX番号
   - 郵便番号、都道府県、市区町村、番地
   - 支払い方法、請求サイクル
   - 銀行口座情報（銀行名、支店名、口座種別、口座番号、口座名義）
   - 支払サイト（日数）、法人番号、CCメール
   - 請求タイプ（個人/部署）、メモ
   - **まとめ請求対象**（月次まとめ請求に含める・個別送信しない）
   - 備考
4. **保存** をクリック

> **💡 まとめ請求対象チェック:** 「まとめ請求対象」にチェックを入れた請求先は、月次のまとめ請求（[会社まとめ請求](/consolidated-invoices/)）に含まれ、個別の請求書送信対象から除外されます。チェックは保存後も維持されます。

> **自動デフォルト化:** 顧客に請求先が1件も登録されていない状態で新規請求先を作成すると、その請求先が自動的にデフォルトに設定されます。また、ある請求先をデフォルトにすると、以前のデフォルトは自動的に解除されます（常に1件のみデフォルト）。

### 手順B: 請求先を編集・削除

1. 請求先カードの編集アイコンをクリック
2. 必要な項目を変更
3. **保存** または **削除** をクリック

### 手順C: デフォルト請求先を設定

1. 請求先カードの星アイコンをクリック
2. 確認ダイアログで **OK** をクリック

**期待される結果:** 選択した請求先がデフォルトとして設定され、予約作成時に自動選択。

## API エンドポイント

顧客API（完全パス）:

| 操作                 | メソッド | 完全パス                                          |
| -------------------- | -------- | ------------------------------------------------- |
| 登録済み一覧         | GET      | `/api/v1/customers/registered?page={n}&limit={n}` |
| 登録済みID一覧       | GET      | `/api/v1/customers/registered/ids`                |
| 詳細取得             | GET      | `/api/v1/customers/{id}`                           |
| 新規作成（登録①）   | POST     | `/api/v1/customers`                               |
| レンタル登録（登録②）| POST     | `/api/v1/customers/{shopifyId}/register-to-rental` |
| 更新（管理項目）     | PATCH    | `/api/v1/customers/{id}`                           |
| 銀行振込可設定       | POST     | `/api/v1/customers/{id}/bank-transfer-eligibility` |
| 一括削除（論理）     | POST     | `/api/v1/customers/batch-delete`                   |
| Shopify同期          | POST     | `/api/v1/webhooks/receiving/customers/sync`        |

請求先管理API（完全パス）:

| 操作     | メソッド | 完全パス                                                               |
| -------- | -------- | ---------------------------------------------------------------------- |
| 一覧取得 | GET      | `/api/v1/master-data/admin/billing-addresses?shopify_customer_id={id}` |
| 作成     | POST     | `/api/v1/master-data/admin/billing-addresses`                          |
| 更新     | PUT      | `/api/v1/master-data/admin/billing-addresses/{id}`                     |
| 削除     | DELETE   | `/api/v1/master-data/admin/billing-addresses/{id}`                     |

> **注意**: フロントエンドからは `apiClient` 経由で呼ぶため、Global Prefix `/api/v1` は省略可能です。

## 注意事項

- 新規顧客はこの画面の「+ 新規登録」から登録でき、Shopify顧客の作成とレンタルシステム登録が自動で行われます
- Shopify管理画面で直接作成した顧客は「Shopify同期」で取り込みます
- 顧客の無効化ではShopify顧客は削除されません
- 顧客コード（旧称: 会社コード）はレガシーシステム連携に使用
- 請求先はEASEの顧客管理画面で管理します
