## 概要

顧客の登録・検索・閲覧・更新・削除を行う画面です。新規顧客は **この画面の「+ 新規登録」ボタン**から登録でき、登録と同時に Shopify とレンタルシステム（customer_master）の両方へ反映されます。Shopify Admin で直接登録した顧客は **「Shopify同期」ボタン**で取り込みます。

> **顧客データの所在（重要）**
> - 顧客の基本情報（氏名・メール・電話・住所・タグ）は **Shopify がマスター** です。
> - レンタル業務用の追加情報（請求先・社内メモ等）は **バックエンドDB（customer_master / 請求先テーブル）** で管理します。
> - タグ（「銀行振込可」など）は登録時に付与できるほか、Shopify Admin で編集して同期で反映できます。

## 手順

### 手順1: 新規顧客を登録（画面内モーダル）

> この画面の **「+ 新規登録」** から登録します。登録すると **Shopify顧客の作成** と **レンタルシステムへの登録（customer_master）** が自動で行われます（2段階処理）。

1. **+ 新規登録** ボタンをクリック → 「新規顧客登録」モーダルが開く
2. 必要な情報を入力:
   - **基本情報**: 種別（法人/個人）、会社名（＋カナ）、担当者名（＋カナ）、名/姓
   - **連絡先**: メールアドレス（**必須**）、会社電話、携帯、FAX、Webサイト
   - **住所**: 郵便番号（入力すると都道府県・市区町村を自動補完）、都道府県、市区町村、番地、建物名
   - **所属**: 部署、役職
   - **タグ**: カンマ区切りで入力。「銀行振込可」はチェックボックスで付与可能
   - **免税**: 必要に応じてチェック
   - **請求先（任意）**: 会社名・担当者・住所・電話・メール等。「顧客情報と同じ」にチェックすると顧客住所をコピー
3. **登録** をクリック

**処理の流れ（内部）:**
1. `POST /customers` … Shopify顧客 + `shopify_customers` を作成
2. `POST /customers/{shopifyId}/register-to-rental` … `customer_master` へ登録

> **補足**:
> - 会社名と部署名は Shopify の姓（last_name）に `会社名 部署名` の形で結合されます（テーマ整合性 / INVARIANTS §4-5）。
> - メールまたは電話の重複時はエラー通知が出ます（8秒表示）。
> - Shopify標準の `phone` は使用しません（会社電話=`rental_company_phone` が主）。

**期待される結果:** 登録した顧客が一覧（登録済み顧客）に表示され、「顧客を登録しました」と通知されます。

### 手順2: Shopify同期

**Shopify Adminで顧客を登録・更新した後**、同期ボタンで最新データを反映します。

1. **Shopify同期** ボタンをクリック
2. 同期が完了すると、反映件数が通知されます
3. 顧客一覧が自動的に更新されます
4. 必要に応じて請求先登録を促すメッセージが表示されます

**注意:** 同期はShopify APIから全顧客データを取得して処理するため、数千件の顧客がいる場合は数分かかることがあります。

### 手順3: 顧客を検索

1. 検索ボックスにキーワードを入力
   - 会社名 / 担当者 / 電話 / メール / 会社コード
2. **検索** ボタンをクリック、またはEnterキーを押下
3. 結果が下のテーブルに表示

**期待される結果:** 条件に一致する顧客が結果一覧に表示。

### 手順4: 顧客詳細を閲覧

1. テーブルの顧客行（または操作列の詳細アイコン）をクリック
2. 顧客詳細が表示されます

**期待される結果:** 顧客詳細に以下が表示:

- 基本情報（会社、担当者、種別、部署、電話、メール、会社コード）
- 住所情報（郵便番号、都道府県、市区町村、番地）
- 請求先（請求先タブ）

### 手順5: 顧客を更新（編集）

1. 顧客詳細を開き、**編集** をクリック
2. 編集可能なフィールドを変更し、**保存** をクリック

**編集できる項目 / できない項目:**

| 区分                  | 例                                                             | 可否 |
| --------------------- | -------------------------------------------------------------- | ---- |
| 管理項目（ADMIN）     | レンタル種別、請求関連、社内メモ など                          | ✅ 編集可 |
| 補完項目（FILL_NULL） | 未設定（空）の会社情報・住所などを補完入力                     | ✅ 空欄のみ補完可 |
| Shopify権限項目       | 氏名・メール・標準住所など Shopify がマスターの項目            | 🔒 読み取り専用（「Shopify Adminで編集」リンクから編集） |

> 内部的には `PATCH /customers/{id}`（ADMIN/FILL_NULL フィールド + 社内メモのみ）を呼びます。Shopify権限の項目は Shopify Admin 側で編集し、同期で反映します。
> ※ 旧データを持つ顧客のみ「電話番号(旧)」が編集可能として表示されます（Shopify標準phoneは廃止）。

**期待される結果:** 顧客データが更新され、成功通知が表示されます。

### 手順6: 顧客を削除（一括・論理削除）

1. チェックボックスで顧客を選択（ヘッダーのチェックでページ内全件を選択）
2. **選択した顧客を削除** ボタンをクリック
3. 確認モーダル「選択された N 件の顧客を削除します。この操作は取り消せません。」で **削除** をクリック

**動作（重要・論理削除）:**

- バックエンドの3テーブルを**論理削除**します（物理削除はしません / INVARIANTS §6-2）:
  - `customer_master.is_active = false`（→ 登録済み顧客一覧から除外）
  - `shopify_customers.deleted_at` をセット
  - `customer_extensions.deleted_at` をセット（個人情報の論理削除 / #861）
- 成功・失敗の件数が通知されます（例：「2件の削除に成功しました」）。
- **Shopify 側の顧客は削除されません**（後述「Shopify連携と削除時の挙動」を参照）。

**期待される結果:** 選択した顧客が一覧から消え、「N件の削除に成功しました」と通知されます。注文履歴のある顧客でも削除できます（Shopifyを操作しないため）。

> **内部処理（参考）**: `POST /customers/batch-delete`（#1077 / BE #1970）。送信する `customer_ids` は一覧の ID（= Shopify Customer ID）です。

## Shopify連携と削除時の挙動

顧客の「削除」はレンタルシステム上の**論理削除**であり、Shopify の顧客アカウントには一切影響しません。これは Shopify Admin API の制約と仕様判断によるものです。

### Shopify 側に対して外部（API）からできること・できないこと

| 操作                                   | 可否       | 理由 / 補足                                                                 |
| -------------------------------------- | ---------- | -------------------------------------------------------------------------- |
| 顧客を**アーカイブ**にする             | ❌ 不可     | Shopify に「顧客アーカイブ」という機能・APIが存在しない                     |
| アカウント**状態（state）を変更**      | ❌ 不可     | `state`（ENABLED/DISABLED 等）は読み取り専用。`customerUpdate` で変更不可。招待・有効化のライフサイクルでのみ自動遷移 |
| 顧客を**物理削除**（customerDelete）    | △ 限定的   | **注文のない顧客のみ**削除可。注文があると失敗するため、レンタル顧客はほぼ削除不可 |
| **タグ**の付与/削除                    | ✅ 可       | 唯一の「ソフトな印付け」手段（現状は削除時に付与していない）                |
| 氏名・メール・電話・メモ等の**更新**   | ✅ 可       | `customerUpdate` で可能（state は対象外）                                   |

### つまり

- レンタル画面で顧客を「削除」しても、**Shopify には同じ顧客がそのまま残ります**（state も変わりません）。
- 一覧から消えるのは `customer_master.is_active=false` によるもので、**Shopify再同期でも復活しません**（同期は `is_active` を書き戻さないため）。
- 注文履歴のある顧客でも削除が成功するのは、Shopify を操作しない（＝`customerDelete` を呼ばない）ためです。

> **実機検証済み（#1077）**: 削除後も対象顧客は Shopify に存在し（注文4件を持つ顧客も含む）、`state` は変化していないことを確認済み。

## タグ管理

> タグは登録時にこの画面で付与できます（「銀行振込可」チェック含む）。既存顧客のタグ編集は **Shopify Admin** で行い、**Shopify同期**でバックエンドに反映されます。

## 請求先管理

### 概要

顧客ごとに複数の請求先を登録・管理できる機能。スタイリストなど案件ごとに請求先が変わるケースに対応。

### 手順A: 請求先を追加

1. 顧客詳細パネルの **請求先** タブをクリック
2. **+ 新規請求先** ボタンをクリック
3. 請求先情報を入力:
   - 会社名（必須）
   - 別名（例：「案件A用」）
   - 部署名、役職、スタッフコード
   - 担当者名
   - メールアドレス、電話番号、FAX番号
   - 郵便番号、都道府県、市区町村、番地
   - 支払い方法、請求サイクル
   - 銀行口座情報（銀行名、支店名、口座種別、口座番号、口座名義）
   - 支払サイト（日数）、法人番号、CCメール
   - 請求タイプ（個人/部署）、メモ
   - 備考
4. **保存** をクリック

### 手順B: 請求先を編集・削除

1. 請求先カードの編集アイコンをクリック
2. 必要な項目を変更
3. **保存** または **削除** をクリック

### 手順C: デフォルト請求先を設定

1. 請求先カードの星アイコンをクリック
2. 確認ダイアログで **OK** をクリック

**期待される結果:** 選択した請求先がデフォルトとして設定され、予約作成時に自動選択。

顧客API（完全パス）:

| 操作                 | メソッド | 完全パス                                          |
| -------------------- | -------- | ------------------------------------------------- |
| 登録済み一覧         | GET      | `/api/v1/customers/registered?page={n}&limit={n}` |
| 登録済みID一覧       | GET      | `/api/v1/customers/registered/ids`                |
| 詳細取得             | GET      | `/api/v1/customers/{id}`                           |

| 一括削除（論理）     | POST     | `/api/v1/customers/batch-delete`                   |
| Shopify同期          | POST     | `/api/v1/webhooks/receiving/customers/sync`        |

- 新規顧客はこの画面の「+ 新規登録」から登録でき、Shopify顧客の作成とレンタルシステム登録が自動で行われます
