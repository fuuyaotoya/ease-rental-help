# ピッキング・出荷登録

![ピッキング・出荷登録画面](/images/picking-delivery/main.png)

配送予定の伝票を一覧表示し、伝票ごとの「即出荷」ボタンでピッキングから出荷までを一括実行する画面です。
**「即出荷」ボタン1回でピッキング完了と出荷登録が両方完了します。**

## この画面を開くには

- サイドバーの **「出荷管理」＞「ピッキング・出荷登録」** をクリック

---

## 画面上部の統計

| 項目 | 色 | 説明 |
|------|-----|------|
| 本日の予定 | 青 | 当日配送予定の総件数 |
| 未ピッキング | 黄 | まだピッキングを始めていない件数 |
| ピッキング中 | 青 | 現在ピッキング作業中の件数 |
| 完了 | 緑 | ピッキングが完了した件数 |
| 出荷済み | 紫 | 出荷登録が完了した件数 |

---

## 操作手順

### ステップ1: 商品明細を確認する

1. 確認したい伝票の行頭にある **▲/▼** ボタンをクリックします
2. 商品明細がインライン展開され、以下が表示されます:
   - SKU、商品名、在庫場所、数量、担当者

> **💡 検索:** 「検索条件を設定」ボタンで、伝票番号・出荷日・ステータス・配送タイプ・顧客名で絞り込めます。

### ステップ2: 「即出荷」でピッキングから出荷まで一括実行する

1. 対象伝票の行にある **「即出荷」** ボタンをクリックします
2. ピッキング開始 → ピッキング完了 → 出荷登録までが **1アクションで自動実行** されます
3. ステータスが **「出荷済み」** に変わります

**自動で設定される内容:**
- 追跡番号が自動生成されます
- 配送会社は伝票に設定されているものが使われます（未設定の場合は「未指定」）

> **💡 ワンアクション完了:** 「即出荷」ボタン1回でピッキングから出荷まで完了します。ステータスが「出荷済み」になるとボタンは非表示になります。

### ステップ3: 複数の伝票をまとめて出荷する

1. 複数の伝票をチェックボックスで選択します
2. 選択中に表示される **「一括出荷完了」** ボタンをクリックします
3. 選択した伝票のピッキング完了と出荷登録が一括で行われます

### ステップ4: ピッキングリストを印刷する

1. 印刷したい伝票を選択します
2. 選択中に表示される **「選択分を印刷」** ボタンをクリックします
3. PDFが新しいタブで開きます

> **⚠️ 注意:** 配送情報（駐車場・エレベーター・建物名・連絡先）が未入力の伝票を含む場合、印刷前に警告が表示されます。配送先で荷受けが困難になる可能性があるため、必要に応じて配送情報を入力してください。

> **📋 特記事項列:** ピッキングPDFには「特記事項」列があり、商品ごとの注意事項（キズ・破れ・取り扱い上の注意など）が表示されます。ピッキング・梱包時に特記事項のある商品はこの列で確認してください。特記事項は商品マスタ（Shopifyメタフィールド `rental.booking_notes`）に登録された内容が反映されます（お客様向けのカタログ画面やレンタル伝票PDFには表示されません）。

## 一覧の見方

| 列 | 内容 |
|----|------|
| 伝票No. | 伝票番号（クリックで伝票詳細画面へ） |
| 顧客No. | 顧客コード |
| 担当者名 | 顧客の担当者 |
| 会社名 | 顧客の会社名 |
| 部署名 | 顧客の部署 |
| 貸出開始日 | レンタル期間の開始日 |
| ステータス | ピッキングの進行状況 |
| 操作 | 「即出荷」ボタン（出荷済みでは非表示） |

### ステータスの流れ

| ステータス | 色 | 次のアクション |
|-----------|-----|-------------|
| 未ピッキング | 黄 | 「即出荷」ボタン |
| ピッキング中 | 青 | 「即出荷」ボタン |
| 完了 | 緑 | 「即出荷」ボタン（出荷登録を再試行） |
| 出荷済み | 紫 | —（完了） |

## よくある質問

### Q: 「完了」ステータスで止まった伝票がある
出荷登録が一時的に失敗した場合など、「完了」ステータスで残ることがあります（正常系では「出荷済み」まで一気に進みます）。該当伝票の「即出荷」ボタンを再度クリックすると、出荷登録を再試行できます。

### Q: 追跡番号はどこで確認できますか？
ピッキング完了時に自動生成されます。伝票詳細画面で確認できます。
