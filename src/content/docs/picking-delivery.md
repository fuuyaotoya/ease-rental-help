![ピッキング・出荷登録画面](/images/picking-delivery.png)

## 概要

ピッキングリストの作成と出荷管理を行う画面です。配送予定の伝票を一覧表示し、ピッキング開始〜完了〜出荷登録までの一連の作業を管理します。

## アクセス方法

- サイドバーから: 「出荷管理」>「ピッキング・出荷登録」をクリック
- URL直接: `/picking-delivery`

## 画面構成

| 項目         | 説明                      | 色  |
| ------------ | ------------------------- | --- |
| 本日の予定   | 当日配送予定の総件数      | 青  |

## 操作手順

### 手順1: ピッキングを開始する

1. ステータスが「未ピッキング」の伝票を探す
2. 「開始」ボタンをクリック
3. ステータスが「ピッキング中」に変更されます

**期待される結果:**

- 伝票のステータスが「ピッキング中」に変わる
- 統計サマリーが更新される

### 手順2: ピッキング詳細を確認する

1. 「詳細」ボタンをクリック
2. ピッキング詳細モーダルが表示されます
3. 以下の情報を確認できます:
   - 担当者名、配送日、配送先、配送メモ
   - 伝票No.（編集・保存可能）
   - 商品リスト（SKU、商品名、在庫場所、数量、備考）

**期待される結果:**

- 選択した伝票の詳細情報がモーダルで表示される
- 商品リストにチェックボックス、在庫場所バッジが表示される

### 手順3: ピッキングを完了する（出荷登録も自動実行）

1. ステータスが「ピッキング中」の伝票で「完了」ボタンをクリック
2. ピッキング完了APIが実行され、続けて出荷登録APIが自動で実行されます
3. ステータスが「出荷済み」に変更されます

**自動処理される内容:**

- 追跡番号: 自動生成（`TRACK-タイムスタンプ-伝票末尾4桁`）
- 配送会社: 伝票に設定されている会社名、未設定場合は「未指定」
- 出荷担当者: admin

**期待される結果:**

- 伝票のステータスが「出荷済み」に変わる
- 成功メッセージ「ピッキング完了・出荷登録が完了しました」が表示される

### 手順4: 一括完了を行う

1. 複数の伝票をチェックボックスで選択
2. 画面下部の「一括完了」ボタンをクリック
3. ピッキング完了APIが実行され、続けて出荷登録APIが自動で実行されます

**自動処理される内容:**

- 追跡番号: 自動生成（`TRACK-タイムスタンプ-伝票末尾4桁`）
- 配送会社: 伝票に設定されている会社名、未設定場合は「未指定」
- 出荷担当者: admin

**期待される結果:**

- 選択した伝票のピッキングが一括で完了する
- 出荷登録も自動で実行される
- 選択がクリアされる

### 手順5: 出荷登録を手動実行する（完了後に自動で出荷登録されなかった場合）

1. ステータスが「完了」の伝票で「出荷登録」ボタンをクリック
2. 出荷登録APIが実行されます
3. ステータスが「出荷済み」に変更されます

**期待される結果:**

- 伝票のステータスが「出荷済み」に変わる
- 成功メッセージ「出荷登録が完了しました」が表示される

### 手順6: ピッキングリストを印刷する

1. 印刷したい伝票を選択（未選択の場合は全件印刷）
2. 「ピッキングリスト印刷」ボタンをクリック
3. PDFが新しいタブで開きます

**期待される結果:**

- 選択した伝票のピッキングリストPDFが開く

### ~~手順7: CSV出力~~ ※不要

> 現行システムにCSV出力機能はありません。ピッキングリストはPDF印刷（手順6）のみです。

## 商品詳細モーダル

### 項目一覧

| 項目     | 説明                                              |
| -------- | ------------------------------------------------- |
| チェック | ピッキング済みフラグ                              |
| SKU      | 商品のSKUコード（「その他」商品は黄色バッジ表示） |
| 商品名   | 商品の名称                                        |
| 在庫場所 | PR(ピンク)/NY(藍)/その他(青)のバッジで表示        |
| 数量     | 商品数量                                          |
| 備考     | ライン備考                                        |

### 伝票No.の編集

1. 伝票No.入力欄を編集
2. 「保存」ボタンをクリック
3. 伝票No.が更新されます
