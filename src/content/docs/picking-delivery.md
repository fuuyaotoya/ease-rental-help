# ピッキング・出荷登録

![ピッキング・出荷登録画面](/images/picking-delivery/main.png)

配送予定の伝票を一覧表示し、ピッキング開始〜完了〜出荷登録までの一連の作業を管理する画面です。
**ピッキング完了と同時に出荷登録も自動で行われます。**

## この画面を開くには

- サイドバーの **「出荷管理」＞「ピッキング・出荷登録」** をクリック

---

## 画面上部の統計

| 項目 | 色 | 説明 |
|------|-----|------|
| 本日の予定 | 青 | 当日配送予定の総件数 |
| 未ピッキング | 黄 | まだピッキングを始めていない件数 |
| ピッキング中 | 青 | 現在ピッキング作業中の件数 |
| 完了 | 緑 | ピッキングが完了した件数 |
| 出荷済み | 紫 | 出荷登録が完了した件数 |

---

## 操作手順

### ステップ1: ピッキングを開始する

1. ステータスが **「未ピッキング」** の伝票を探します
2. **「開始」** ボタンをクリックします
3. ステータスが **「ピッキング中」** に変わります

> **💡 検索:** 「検索条件を設定」ボタンで、伝票番号・出荷日・ステータス・配送タイプ・顧客名で絞り込めます。

### ステップ2: ピッキング詳細を確認する

1. **「詳細」** ボタンをクリックします
2. モーダルに以下の情報が表示されます：
   - 担当者名、配送日、配送先、配送メモ
   - 伝票番号（編集・保存可能）
   - 商品リスト（SKU、商品名、在庫場所、数量、備考）

### ステップ3: ピッキングを完了する（出荷登録も自動で行われる）

1. ステータスが **「ピッキング中」** の伝票で **「完了」** ボタンをクリックします
2. ピッキング完了と同時に、**出荷登録も自動で行われます**
3. ステータスが **「出荷済み」** に変わります

**自動で設定される内容:**
- 追跡番号が自動生成されます
- 配送会社は伝票に設定されているものが使われます（未設定の場合は「未指定」）

> **💡 重要:** 「完了」ボタンを押すだけで、ピッキング完了と出荷登録が両方完了します。別々に操作する必要はありません。

### ステップ4: 複数の伝票をまとめて完了する

1. 複数の伝票をチェックボックスで選択します
2. 画面下部の **「一括完了」** ボタンをクリックします
3. 選択した伝票のピッキング完了と出荷登録が一括で行われます

### ステップ5: ピッキングリストを印刷する

1. 印刷したい伝票を選択します（未選択の場合は全件印刷）
2. **「ピッキングリスト印刷」** ボタンをクリックします
3. PDFが新しいタブで開きます

> **⚠️ 注意:** 配送情報（駐車場・エレベーター・建物名・連絡先）が未入力の伝票を含む場合、印刷前に警告が表示されます。配送先で荷受けが困難になる可能性があるため、必要に応じて配送情報を入力してください。

## 一覧の見方

| 列 | 内容 |
|----|------|
| 伝票No. | 伝票番号（クリックで伝票詳細画面へ） |
| 顧客No. | 顧客コード |
| 担当者名 | 顧客の担当者 |
| 会社名 | 顧客の会社名 |
| 部署名 | 顧客の部署 |
| 配送先 | 配送先の住所 |
| ステータス | ピッキングの進行状況 |

### ステータスの流れ

| ステータス | 色 | 次のアクション |
|-----------|-----|-------------|
| 未ピッキング | 黄 | 「開始」ボタン |
| ピッキング中 | 青 | 「完了」ボタン |
| 完了 | 緑 | 「出荷登録」ボタン（通常は不要） |
| 出荷済み | 紫 | —（完了） |

---

## よくある質問

### Q: ピッキング完了後に「出荷登録」ボタンが表示される
通常はピッキング完了と同時に出荷登録も自動で行われます。何らかの理由で自動登録されなかった場合のみ、手動で「出荷登録」ボタンを押してください。

### Q: 追跡番号はどこで確認できますか？
ピッキング完了時に自動生成されます。伝票詳細画面で確認できます。
