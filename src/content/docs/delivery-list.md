# 配送一覧

![配送一覧画面](/images/delivery-list/main.png)

配送スケジュールの一覧表示と管理を行う画面です。
**配送** と **返却** の2つのタブを切り替えて、配送予定の確認や配送情報の編集ができます。

## この画面を開くには

- サイドバーの **「出荷管理」＞「配送一覧」** をクリック

---

## 画面上部の統計

| 項目 | 説明 |
|------|------|
| 配送合計 | フィルタ適用後の配送の総件数 |
| 準備中 | 配送が完了していない件数 |
| 配送済み | 配送が完了した件数 |

---

## 操作手順

### ステップ1: 配送一覧を確認する

1. 画面を開くと、当日以降の配送予定が表示されます
2. **「配送」** タブで搬入予定、**「返却」** タブで搬出予定を確認します
3. 列の見出しをクリックすると並び順を変えられます

#### 一覧の見方

| 列 | 内容 |
|----|------|
| 日付 | 配送日 |
| 伝票No. | 伝票番号（クリックで詳細画面へ） |
| 顧客情報 | 担当者名 / 会社名 / 部署名 |
| 配送先 | 配送先の住所 |
| 時間指定 | 指定時間帯 |
| 配送会社 | 配送会社（変更可能） |
| メモ | 配送に関するメモ（編集可能） |

### ステップ2: 配送予定を絞り込む

1. **「検索条件を設定」** ボタンをクリックします
2. 以下の条件で絞り込みます：

| 絞り込み条件 | 説明 |
|------------|------|
| 日付（開始・終了） | 配送日の範囲を指定 |
| ステータス | 配送の状態でフィルタ |
| 配送タイプ | 搬入 / 搬出 / 移動 / 店頭受取 |
| 顧客名 | 顧客名または会社名で検索 |
| 配送会社 | 配送会社でフィルタ |
| 時間指定 | AM / PM / 指定なし |
| 優先度 | 高 / 通常 / 低 |
| 伝票番号 | 伝票番号で検索 |

3. **「更新」** ボタンをクリックします
4. 設定したフィルタ条件がタグとして表示されます

### ステップ3: フィルタを削除する

- 個別に削除: フィルタの **「×」** をクリック
- 全てクリア: **「リセット」** ボタンをクリック

### ステップ4: 配送会社を変更する

1. 配送会社の列のドロップダウンをクリックします
2. 配送会社を選びます
3. 自動的に保存されます

> **⚠️ 注意:** 過去日付の配送は編集できません。

### ステップ5: メモを編集する

1. メモ欄の **「編集」** アイコンをクリックします
2. メモを入力します
3. **「保存」** をクリックします

### ステップ6: 配送詳細を確認する

1. **「詳細」** ボタンまたは伝票番号のリンクをクリックします
2. 配送の詳細情報がモーダルで表示されます

### PDF印刷（配達表）

配送一覧のPDF（配達表）は A4 1ページ10件・配達順（左端太字）で印刷されます。フォント9pt・カード式レイアウトで、右上にページ番号が表示されます（[#2561](https://github.com/iziz-system/ease-rental-backend/issues/2561)）。顧客名・現場担当・駐車場/ELV/ポーター情報が1カードにまとめて表示されます。

## よくある質問

### Q: 過去の配送予定を確認できますか？
はい。日付フィルタで過去の日付を指定すれば確認できます。ただし、過去日付の配送情報は編集できません。

### Q: 配送会社を変更しても伝票には反映されますか？
はい。配送会社の変更は即座に保存され、伝票情報にも反映されます。
