> **パス:** `/delivery-list`
> **メニュー:** 出荷管理 > 配送一覧

## 概要

配送スケジュールの一覧表示と管理を行う画面です。配送/返却の2つのタブを切り替えて、配送予定の確認、フィルタリング、配送情報の編集などができます。

## アクセス方法

- サイドバーから: 「出荷管理」>「配送一覧」をクリック
- URL直接: `/delivery-list`

## 画面構成

### タブナビゲーション

| タブ | 説明                   |
| ---- | ---------------------- |
| 配送 | 配送（搬入）予定の一覧 |
| 返却 | 返却（搬出）予定の一覧 |

### 統計サマリー

| 項目     | 説明                              |
| -------- | --------------------------------- |
| 総件数   | フィルタ適用後の総件数            |
| 未処理   | pending/confirmedステータスの件数 |
| 確定済み | confirmedステータスの件数         |
| 出荷済み | shippedステータスの件数           |

### フィルタ機能

「検索条件を設定」ボタンまたは「詳細検索」でフィルタを設定できます。

| 項目       | 種類     | 説明                     |
| ---------- | -------- | ------------------------ |
| 日付(開始) | 日付     | 配送日の範囲指定（開始） |
| 日付(終了) | 日付     | 配送日の範囲指定（終了） |
| ステータス | セレクト | 配送ステータスでフィルタ |
| 配送タイプ | セレクト | 搬入/搬出/移動/店頭受取  |
| 顧客名     | テキスト | 顧客名または会社名で検索 |
| 配送会社   | セレクト | 配送会社でフィルタ       |
| 時間指定   | セレクト | AM/PM/指定なし           |
| 優先度     | セレクト | 高/通常/低               |
| 伝票番号   | テキスト | 伝票番号で検索           |

### フィルタチップ

アクティブなフィルタ条件がチップとして表示され、個別に削除できます。

### 配送一覧テーブル

| 項目     | 種類             | 説明                         |
| -------- | ---------------- | ---------------------------- |
| 選択     | チェックボックス | 一括操作用の選択             |
| 日付     | テキスト         | 配送日                       |
| 伝票No.  | リンク           | 伝票番号（クリックで詳細へ） |
| 顧客情報 | テキスト         | 担当者名/会社名/部署名       |
| 配送先   | テキスト         | 配送先住所                   |
| 時間指定 | テキスト         | 指定時間帯                   |
| 配送会社 | セレクト         | 配送会社（変更可能）         |
| メモ     | テキスト         | 配送メモ（編集可能）         |
| 操作     | ボタン           | 詳細                         |

### ソート機能

テーブルヘッダーをクリックしてソート可能です。

## 操作手順

### 手順1: 配送一覧を確認する

1. 画面を開くと当日以降の配送予定が表示されます
2. 「配送」または「返却」タブを切り替えて内容を確認
3. フィルタを使用して絞り込み

**期待される結果:**

- 配送予定が一覧表示される
- タブ切り替えで配送/返却が切り替わる

### 手順2: フィルタを設定する

1. 「検索条件を設定」ボタンをクリック
2. フィルタ条件を入力
3. 「更新」ボタンをクリック

**期待される結果:**

- フィルタ条件が適用され、結果が更新される
- アクティブなフィルタがチップで表示される

### 手順3: フィルタを削除する

1. フィルタチップの「×」をクリック
2. そのフィルタ条件のみが削除されます

**または:**

1. 「検索条件を設定」>「リセット」をクリック
2. すべてのフィルタがクリアされます

### 手順4: 配送会社を変更する

1. 配送一覧の「配送会社」列のドロップダウンをクリック
2. 配送会社を選択
3. 自動的に保存されます

**注意:** 過去日付の配送は編集できません

**期待される結果:**

- 配送会社が即座に更新される
- 成功時はそのまま、エラー時は元に戻る

### 手順5: メモを編集する

1. メモ欄の「編集」アイコンをクリック
2. メモを入力
3. 「保存」をクリック

**期待される結果:**

- メモが保存され、一覧に反映される

### 手順6: 配送詳細を確認する

1. 「詳細」ボタンまたは伝票No.リンクをクリック
2. 詳細モーダルが表示されます

**期待される結果:**

- 配送の詳細情報がモーダルで表示される

## バリデーション

### 入力チェック

配送作成・編集時に入力チェックが行われます。

| 項目           | ルール                     | エラーメッセージ                             |
| -------------- | -------------------------- | -------------------------------------------- |
| 配送順         | 数値のみ入力可能           | 「配送順は数値のみ入力できます」             |
| 連絡先電話番号 | 数値とハイフンのみ入力可能 | 「電話番号は数値とハイフンのみ入力できます」 |
| 日付範囲       | 開始日≦終了日              | 「開始日が終了日より前である必要があります」 |

### エラー表示

- 入力エラー時はエラーメッセージが表示されます
- フィルタの日付範囲が不正な場合、フィルタ適用時にToast通知でエラーが表示されます

## UI改善

### Toast通知

処理結果は画面右上にToast通知で表示されます。

| 種類   | 説明                     | 色  |
| ------ | ------------------------ | --- |
| 成功   | 処理が正常に完了した場合 | 緑  |
| エラー | 処理が失敗した場合       | 赤  |
| 情報   | その他の通知             | 青  |

**通知例:**

- 「配送会社を更新しました」（成功）
- 「過去日付の配送は編集できません」（エラー）
- 「配送順の更新に失敗しました」（エラー）
