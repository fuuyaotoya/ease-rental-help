## 概要

企業グループ単位で月次請求書を一括生成・送信します。3フェーズの処理フロー（プレビュー → 生成 → 送信）に従って安全に処理を行います。

> **未払いbookingの抽出単位（#1102）:** 一括請求の対象となる未払い伝票は、**会社名単位**で抽出されます。同じ会社名の伝票は同一請求書にまとめられ、支払サイトの照合も `shopify_customer_id` 単位で行われます。

## アクセス方法

- サイドバーから: **請求・入金 > 一括請求処理**
- URL直接: `/bulk-invoices`

### フォームセクション

| 項目                     | 種類             | 説明                         | 必須 |
| ------------------------ | ---------------- | ---------------------------- | ---- |
| 対象月                   | セレクト         | 請求対象月（YYYY-MM形式）    | Yes  |
| 企業グループ             | セレクト         | 対象の企業グループ           | -    |
| 銀行振込可タグでフィルタ | チェックボックス | 銀行振込可能な請求先のみ対象 | -    |

### アクションボタン

| ボタン     | 色       | 説明                                 |
| ---------- | -------- | ------------------------------------ |
| プレビュー | 青       | 処理内容のプレビュー（dry_run=true） |
| 請求書生成 | 緑       | 請求書の実際の生成                   |
| 請求書送信 | オレンジ | 生成済み請求書のメール送信           |

生成完了後に以下のサマリーが表示されます:

- 企業グループ名

## 3フェーズ処理フロー

```
┌──────────────────────────────────────────────────────────────┐
│  Phase 1: プレビュー                                          │
│  - dry_run=true で安全に処理内容を確認                         │
│  - 請求書は作成されない                                        │
│  - 対象件数・金額の確認                                        │
└──────────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────────┐
│  Phase 2: 請求書生成                                          │
│  - dry_run=false で実際の請求書を作成                          │
│  - ドラフト状態で保存される                                     │
│  - まだメールは送信されない                                     │
└──────────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────────┐
│  Phase 3: 請求書送信                                          │
│  - 生成された請求書をメール送信                                 │
│  - ステータスが「送信済み」に変更                               │
│  - 処理完了                                                   │
└──────────────────────────────────────────────────────────────┘
```

## 操作手順

### 手順1: 条件設定

1. **対象月**を選択
   - 過去12ヶ月〜未来3ヶ月から選択可能
   - 当月は「(当月)」ラベル付き
2. **企業グループ**を選択（任意）
   - 「すべてのグループ」を選択すると全企業が対象
   - 特定のグループを選択して絞り込み可能
3. **銀行振込可タグでフィルタ**にチェック（必要な場合）
   - チェックすると、銀行振込での支払いが可能な請求先のみが対象

### 手順2: プレビュー実行

1. 「プレビュー」ボタンをクリック
2. 処理中はボタンにローディング表示
3. プレビュー結果が表示されます

**期待される結果:**

- 対象となる請求書の一覧が表示
- 各企業グループの請求件数・金額
- **請求書はまだ作成されていません**

### 手順3: 請求書生成

1. プレビュー内容を確認
2. 「請求書生成」ボタンをクリック
3. 確認ダイアログで「生成する」をクリック
4. 処理完了まで待機

**期待される結果:**

- 請求書がドラフト状態で作成される
- 生成結果がテーブルに表示
- 「請求書送信」ボタンが有効化

### 手順4: 請求書送信

1. 生成された請求書の内容を確認
2. 「請求書送信」ボタンをクリック
3. 確認ダイアログで「送信する」をクリック
4. メール送信処理が実行されます

**期待される結果:**

- 各請求先にメールが送信される
- 請求書ステータスが「送信済み」に変更
- 送信結果が表示される

### 手順5: リセット（次の処理へ）

1. 「リセット」ボタンをクリック
2. フォームと結果がクリアされます
3. 次の月次処理に備える

## 使用例

### 月次一括請求の典型的なワークフロー

```
月初（翌月1-5日頃）:
1. 前月分の返却・金額確定がすべて完了していることを確認
2. 「一括請求処理」画面を開く
3. 対象月 = 前月 を選択
4. 企業グループ = すべてのグループ
5. 「プレビュー」で対象を確認
6. 内容を確認後、「請求書生成」
7. 生成された請求書を確認
8. 問題なければ「請求書送信」
9. 送信完了を確認
```

### 特定企業グループのみ処理

```
1. 企業グループで特定のグループを選択
2. 「プレビュー」で確認
3. 通常通り「生成」→「送信」を実行
```

## ヘルプ情報

画面下部に使い方のガイドが表示されます:

1. 対象月と企業グループを選択してください
2. 「銀行振込可タグでフィルタ」を有効にすると、銀行振込での支払いが可能な請求先のみを対象にします
3. まず「プレビュー」で処理内容を確認してください
4. 内容を確認後、「請求書生成」で請求書を作成します
5. 生成された請求書はドラフト状態で保存されます
6. 「請求書送信」でメール送信を行います

エラーが発生した場合、画面上部に赤いアラートが表示されます:

```

```

**主なエラー:**

| エラー                   | 原因             | 対処方法           |
| ------------------------ | ---------------- | ------------------ |
| 未入金データがありません | 対象データなし   | 対象月・企業を確認 |
| API通信エラー            | ネットワーク問題 | 再度実行           |
| - 認証エラー             | トークン期限切れ | 再ログイン         |
| - バリデーションエラー   | データ不整合     | 個別に対応         |

## 検証チェックリスト

### プレビュー前

- [ ] 対象月が正しい
- [ ] 企業グループの選択が意図通り
- [ ] フィルタ条件が適切

### 生成前

- [ ] プレビュー結果の件数が想定通り
- [ ] 請求金額が妥当
- [ ] 前月分の返却・金額確定が完了している

### 送信前

- [ ] 生成された請求書の内容を確認
- [ ] 請求先メールアドレスが正しい
- [ ] 送信しても問題ない状態か確認

## 注意事項

### 安全性の仕組み

- **プレビューは必須**: 生成前に必ずプレビューで確認
- **dry_run=true**: プレビューは実際のデータを作成しない
- **ドラフト保存**: 生成直後はドラフト状態（送信されない）
- **確認ダイアログ**: 生成・送信前に確認を要求

### 処理タイミング

- 月次処理は月初に行うことを推奨
- 前月分の返却・金額確定が完了してから実行
- 送信は業務時間内に行う（問い合わせ対応のため）

## API仕様（参考）

### エンドポイント

| 処理       | エンドポイント           | dry_run |
| ---------- | ------------------------ | ------- |
| プレビュー | POST /bulk-invoices      | true    |
| 生成       | POST /bulk-invoices      | false   |
| 送信       | POST /bulk-invoices/send | -       |

### パラメータ

```typescript
{
  invoice_month: string;      // YYYY-MM形式
  filter_bank_transfer?: boolean;  // 銀行振込可タグでフィルタ
  dry_run: boolean;           // true: プレビュー, false: 生成
}
```
