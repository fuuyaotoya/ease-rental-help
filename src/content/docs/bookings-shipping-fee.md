**後払いの伝票では、配送料を伝票画面で入力・修正してください。** 返却時の金額確定でレンタル料とまとめて請求します。この画面から先に送信する操作はありません。

過去に前払いで本体分を支払い済みの伝票では、この画面から配送料を別に請求します。銀行振込の伝票は対象外です。

このページの「本体分」は、商品を予約したときのレンタル料の請求を指します。後払いでは配送料などもまとめます。

## 一覧で伝票を探す

![配送料確定一覧（請求欄は更新前の表示です）](/images/bookings-shipping-fee.png)

1. サイドバーの**「配送料確定（クレカ）」**を開きます。
2. 伝票番号・顧客名で対象を探します。
3. **「配送料確認」**をクリックします。

| 列 | 内容 |
|---|---|
| 伝票No. | クリックすると伝票の内容を確認できます。 |
| 顧客No.・顧客名・会社名 | 予約したお客様の情報。 |
| 開始日 | レンタル開始日。 |
| 請求 | 後払いの伝票には「返却時に請求」と表示します。 |
| 配送数 | 搬入・搬出などの配送件数。 |

一覧が取得できなかった場合は、画面を再読み込みしてください。対象件数が多い場合も、すべての対象伝票を取得して表示します。

## 後払いの伝票

詳細画面に次の案内が表示されます。

> 後払いクレカの伝票です。配送料は返却時の金額確定でレンタル料と一緒に請求され、請求メールが自動送信されます。それまで伝票は編集でき、配送料の修正は伝票画面で行ってください。

1. **「最初の伝票を開く」**から伝票を開きます。
2. 配送内容と配送料を確認・修正し、保存します。
3. 返却後に[返却・金額確定](/bookings-return/)で金額を確定します。

以前の「前日請求」「請求書送付」は廃止されました。返却前の請求が必要な場合は、伝票の[前倒し請求](/booking-compact/)を使います。

## 本体分を支払い済みの伝票で、配送料を請求する

![配送料確認画面（後払い伝票の操作は本文を参照）](/images/uat/shipping-fee-detail.png)

**「Shopifyへ送信」**が表示される伝票で操作します。配送日・住所・配送業者などを直す場合は、先に伝票画面で修正してください。

### 料金を入力する

1. 各配送の料金区分を選びます。料金が自動入力されます。
2. 配送料を確認します。必要に応じて手入力で修正できます。
3. 小計・消費税・合計を確認します。
4. 必要があれば「メモ」を入力します。

| 料金区分 | 自動入力の内容 |
|---|---|
| BASIC・WIDE・TRUCK | 配送先住所の区名に対応する料金。 |
| PORTER・EASE・その他 | マスタに登録された料金。 |

住所から料金が見つからない場合は、配送料を手入力してください。未確定の配送では画面を開いたときにも自動計算します。手入力した金額は優先されます。

- 配送料が1円以上の配送だけが送信対象です。
- 配送料0円の配送は送信対象外です。すべて0円の場合は送信できません。
- 駐車場代・高速代の入力欄はありません。
- 小計は配送料の税抜合計です。消費税は小計の10%で、1円未満を切り捨てます。

### 送信する

1. **「Shopifyへ送信」**をクリックします。
2. 確認画面で配送ごとの金額と税込合計を確認します。
3. **「送信する」**をクリックします。
4. 受付完了の表示を確認します。一覧へ戻ったら、伝票側でも請求の状況を確認してください。

お客様には決済リンク付きメールが届きます。お客様が支払うと、入金が自動で反映されます。

**受付完了の表示は、請求の作成処理を受け付けたことを示します。** お客様が支払ったことを示す表示ではありません。

## 困ったとき

| 状況 | 対応 |
|---|---|
| 後払いで送信ボタンがない | 通常の動作です。配送料は伝票画面で修正し、返却後に金額確定してください。 |
| 配送料を請求したはずなのに本体分の残高にも含まれているように見える | 配送料の請求状況を確認してください。別に請求した配送料は本体分へ重ねて請求しません。不一致が残る場合は管理者に確認を依頼してください。 |
| メールが届いていない | 登録メールアドレスと送信履歴を確認し、迷惑メールフォルダも確認してもらってください。再送の操作は伝票の請求状況を確認してから行ってください。 |
| データの不整合が表示される | 画面を再読み込みしてください。解消しない場合は管理者に確認を依頼してください。 |
| 金額がマイナスで請求が止まる | 値引き・調整項目・配送料を確認し、修正してから請求してください。 |
