## 概要

出荷済みのクレジットカード顧客伝票について、配送料金を確定し Shopify Draft Order② を作成する画面です。
Shopify へ送信すると、顧客宛に請求書メールが自動送信され、メール内リンクから決済できるようになります。

### 業務フローにおける位置づけ

本画面は Draft Order②（配送料確定請求）を担当します。

| Draft Order | タイミング | 内容 | 操作画面 |
|------------|-----------|------|---------|
| ① | 注文時 | 商品レンタル料金 | （Shopify ストア側） |
| **②** | **配送料確定時** | **配送料金** | **このページ** |
| ③ | 金額確定時 | 延長料金・破損料金・調整項目 | [返却・金額確定](/bookings-return/) |

## 前提条件

- 対象伝票は出荷済みであること
- 顧客の支払方法がクレジットカードであること（銀行振込の伝票は一覧に表示されません）
- 顧客のメールアドレスが Shopify に登録されていること

## アクセス方法

- サイドバーから: **出荷管理 > 配送料確定（クレカ顧客）** をクリック
- URL直接: `/bookings-shipping-fee`

## 画面2: 配送料確認・金額入力

![配送料確定詳細画面](/images/uat/shipping-fee-detail.png)

「配送料確認」ボタン押下後に遷移する専用ページ（`/bookings-shipping-fee/[id]`）です。

### 情報バナー

画面上部に「この画面は配送料の金額確定専用です」という案内が表示されます。配送情報（配送日・住所・配送業者など）の修正は、伝票詳細ページで行ってください。

### 伝票情報カード

| 項目 | 説明 |
|------|------|
| 伝票番号 | 対象伝票の番号 |
| 顧客名 | 顧客名 |
| 会社名 | 会社名 |
| レンタル期間 | 開始日 → 終了日 |
| 配送先 | 配送先住所 |
| 電話番号 | 顧客電話番号（登録時のみ表示） |

右上の「最初の伝票を開く」ボタンで、伝票詳細ページを別タブで開けます。

### 配送明細・料金確定

伝票に紐づく各配送（搬入・搬出等）ごとにカードが表示されます。

#### 配送カードの表示項目

| 項目 | 説明 |
|------|------|
| 配送タイプ | 往路（搬入）/ 復路（搬出）などのバッジ表示 |
| 配送先名 | 配送先名称 |
| 配送日・時間 | 配送日と時間指定 |
| 住所 | 郵便番号 + 都道府県 + 市区町村 + 番地 |
| クライアント名 | 現場担当クライアント名 |
| 電話番号 | 配送先電話番号 |
| 料金区分（旧） | すでに設定されている料金区分（読み取り専用） |
| 配送業者 | 配送業者名 |
| 駐車場 | ある / ない |
| エレベーター | ある / ない / 1階（不要） |
| 現場担当者 | 現場担当者名 |
| PORTERサービス | PORTER利用状況 |
| 含む商品 | 配送に含まれる商品情報 |
| メモ | 配送メモ |

#### 料金入力セクション

各配送カードの下部に、料金の設定欄があります。

**料金区分（ドロップダウン）**

配送料金区分を選択します。選択すると料金が自動計算されます。

| 区分の種類 | 説明 |
|-----------|------|
| グループ区分（BASIC / WIDE / TRUCK） | 配送先の区（wards）から自動で料金を検索・設定 |
| 個別区分（PORTER / EASE / その他） | マスターデータに登録された固定料金を設定 |

> **注意:** グループ区分（BASIC / WIDE / TRUCK）を選択した場合、配送先住所から区名を自動抽出して料金を検索します。住所に区名が含まれていない場合は自動計算されないため、手動で金額を入力してください。

**配送料（数値入力）**

配送料を直接入力できます。料金区分の自動計算結果を上書きすることも可能です。
配送料が未設定（¥0）の場合は「未設定」ラベルが表示されます。

> 送信対象は配送料が¥1以上の配送のみです。¥0の配送は「送信対象外」となります。

#### 追加料金（駐車場・高速）— 廃止済み

> **⚠️ 駐車場代・高速代の請求は廃止しました（[#1205](https://github.com/iziz-system/ease-rental-frontend/issues/1205)）:** 配送料確定画面では **配送料本体のみ** を集計・送信します。駐車場代・高速代の入力欄はありません（過去に遡って請求が変わるものではありません）。

### 合計金額の自動計算

入力した配送料から、合計金額が自動計算されます。

| 項目 | 計算方法 |
|------|---------|
| 小計（税抜） | 送信対象配送の配送料合計 |
| 消費税（10%） | 小計 × 10%（端数切捨て） |
| 合計（税込） | 小計 + 消費税 |

### メモ

特記事項がある場合に入力します。Shopify Draft Order② のメモとして保存されます。

### 送信操作

#### Shopifyへ送信

1. 各配送の料金区分・配送料を設定
2. 「Shopifyへ送信」ボタンをクリック
3. 確認ダイアログで内容を確認し「送信する」をクリック

**確認ダイアログの内容:**

- 送信対象の配送と金額
- 送信対象外（¥0）の配送
- 小計・消費税・合計（税込）

> **注意:** 配送料がすべて¥0の場合、「Shopifyへ送信」ボタンは無効化されます。最低1件の配送料を設定してください。

#### 送信完了

- 「Shopifyへの送信が完了しました（Draft Order②作成予約）」と表示
- 約1.5秒後に一覧画面へ自動遷移
- Shopifyから顧客宛に請求書メールが自動送信される

## よくある質問

### Q: 銀行振込の顧客の配送料はどう処理する？

銀行振込の顧客は本画面の対象外です。銀行振込注文の配送料は別途処理してください。

### Q: 配送料を修正したい場合は？

Shopifyへ送信前であれば、配送料入力欄を直接編集できます。料金区分を再選択すると自動再計算されます。

Shopifyへ送信済みの場合は、Shopify管理画面から Draft Order を編集してください。

### Q: 顧客が請求書メールを受け取っていない場合は？

1. 顧客のメールアドレスが Shopify に正しく登録されているか確認
2. 迷惑メールフォルダを確認するよう顧客へ連絡
3. Shopify管理画面から請求書を再送信

### Q: 送信対象外の配送はどうなる？

配送料が¥0の配送は送信対象外となり、Shopify Draft Order② には含まれません。
後日、配送料が判明した場合は [返却・金額確定](/bookings-return/) の追加請求（Draft Order③）で対応してください。

### Q: 料金区分を選択したのに金額が自動入力されない

グループ区分（BASIC / WIDE / TRUCK）は配送先住所から区名を抽出して料金を検索します。住所に区名が含まれていない場合は自動計算されません。その場合は手動で配送料を入力してください。

## 業務ルール

| ルール | 説明 |
|--------|------|
| 対象顧客 | クレジットカード顧客のみ |
| 送信単位 | 伝票単位（1伝票につき1つの Draft Order②） |
| 送信条件 | 最低1件の配送料が¥1以上であること |
| 税率 | 消費税 10%（端数切捨て） |
| 集計対象 | 配送料本体のみ（駐車場代・高速代は廃止・#1205） |
| メモ | 任意入力。Draft Order のメモとして保存 |
