> **💡 運用者向け:** EASE Rental のメールは Shopify と Backend で役割が分かれて送信されます（注文確認は Shopify、リマインダー・督促・自動キャンセル通知は Backend）。システム間の責任分界・送信ロジックの技術詳細は開発者モード（ページ右上のトグル）を ON にしてご確認ください。

:::dev

## 前提

- 全ての予約（銀行振込・クレジットカード・店頭支払い）は Shopify Draft Order を経由して作成される
- 「仮押さえ（tentative）」は **Backend 固有の概念** であり、Shopify はこのステータスを認知しない
- したがって tentative に関するメールは、支払方法に関わらず Backend から送信する必要がある

---

## 責任分界表

| メール種別             | 銀行振込       | クレジットカード | 店頭支払い     |
| ---------------------- | -------------- | ---------------- | -------------- |
| 注文確認メール         | Shopify        | Shopify          | Shopify        |
| Draft Order Invoice（決済リンク・DO①） | Shopify（Order化時にも送信） | Shopify | Shopify |
| 追加決済請求（DO②〜⑤） | —              | **Backend**（SMTP直送・#2217） | — |
| 請求書発行メール       | **Backend**    | 該当なし         | 該当なし       |
| 督促メール（請求）     | **Backend**    | 該当なし         | 該当なし       |
| キャンセル通知         | **Backend**（手動キャンセル実行時のみ） | 同左 | 同左 |
| 返金通知               | **Backend**    | **Backend**      | **Backend**    |
| 仮予約リマインダー     | **廃止**（#2692） | **廃止**（#2692） | **廃止**（#2692） |
| 自動キャンセル前日催促 | **廃止**（#2692） | **廃止**（#2692） | **廃止**（#2692） |
| 自動キャンセル通知     | **廃止**（#2692） | **廃止**（#2692） | **廃止**（#2692） |
| 仮→確定通知メール      | **送信しない** | **送信しない**   | **送信しない** |

## 判定ルール

```
メール送信が必要か？
├─ Shopify の通常フローに含まれるか？
│   ├─ YES → Shopify から自動送信（Backend では送信しない）
│   └─ NO  → Backend から送信
│       ├─ 請求関連（請求書発行・督促）
│       │   → 銀行振込のみ Backend から送信（請求先 billing_email 宛・#2322）
│       └─ 追加決済（DO②〜⑤）
│           → クレカ顧客のみ Backend SMTP 直送（#2217）
```

> ※ 仮予約系（仮予約リマインダー・自動キャンセル前日催促・自動キャンセル通知）は 2026-08 に cron ごと撤去・送信廃止（#2692）。キャンセルはスタッフ手動運用で、手動キャンセル実行時のみ通知メールが飛ぶ。仮→確定通知メールは送信しない（2026-04-21 決定）。

## Shopify のメールフロー（参考）

Shopify では以下のメールが自動送信される:

| トリガー                   | メール内容     |
| -------------------------- | -------------- |
| Draft Order → Order 変換時 | 注文確認メール |
| 注金確認時                 | 領収書メール   |
| 配送完了時                 | 配送完了メール |

> **注意:** Shopify は「仮押さえ（tentative）」の概念を持たないため、仮→確定のタイミングで Shopify 側にメールをトリガーすることはできない。

## Backend メール一覧

### 実装済み

| メール             | メソッド                       | トリガー                   | 対象             |
| ------------------ | ------------------------------ | -------------------------- | ---------------- |
| 請求書発行         | `sendInvoice()`                | 請求書作成時               | 銀行振込         |
| 督促メール         | `sendReminder()`               | Cron（REMINDER_INTERVALS） | 銀行振込         |
| 返金通知           | `sendRefundNotification()`     | 返金処理時                 | 全決済方法       |
| キャンセル通知     | `sendBookingCancellation` 系   | スタッフの手動キャンセル実行時 | 全決済方法    |
| 予約受付確認       | `sendBookingConfirmation()`    | 予約確定時                 | 全決済方法       |

（他の BE 送信メールの一覧・本文は [自動送信メール一覧](../email-notifications) ・ [メール本文テンプレート（BE送信）](../email-templates) を参照）

### 廃止済み（コード撤去済み・#2692・2026-08）

| メール                 | 旧トリガー                     | 現在の扱い                                |
| ---------------------- | ------------------------------ | ----------------------------------------- |
| 仮予約リマインダー     | Cron（開始9日前・8日前）       | 送信廃止（cron ごと撤去）                 |
| 自動キャンセル前日催促 | Cron（開始7日前）              | 未実装のまま頓挫                          |
| 自動キャンセル通知     | Cron（開始6日前）              | 送信廃止・キャンセルはスタッフ手動運用    |

### 送信しない（決定済み）

| メール      | 決定日     | 理由                                                     |
| ----------- | ---------- | -------------------------------------------------------- |
| 仮→確定通知 | 2026-04-21 | 仮予約・確定予約の伝票作成時にメールは送らない仕様に決定 |
