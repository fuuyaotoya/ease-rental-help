> **💡 運用者向け:** お客様の支払方法（クレジットカード・銀行振込・店頭支払い）によって、**伝票の作り方・請求書の発行タイミング・返金の方法**が異なります。このページでは「どんなケースでどう伝票を作成するか」を一覧表で整理しています。迷ったときはこの表を参照してください。

## 支払方法と請求のタイミング

| 支払方法 | 対象 | 請求・入金の流れ |
|---|---|---|
| **クレジットカード（後払い）** | 現在の通常のカード払い | 返却後に金額確定 → 決済リンク付きメールを自動送信 → お客様が決済。入金は自動反映。 |
| **銀行振込** | 銀行振込が可能なお客様 | 返却後に金額確定 → 請求書を自動発行・送信 → 振込を確認して入金登録。まとめ請求対象は月次のまとめ請求で処理。 |
| **店頭支払い** | 現金・PayPay・店頭でのカード等 | 金額確定 → 代金を受け取って入金登録。 |

カートの「今すぐ払う」は利用できません。貸出前日のカード請求も廃止されています。返却前に請求が必要なときは、伝票に表示される**「前倒しで請求する」**を使います。詳しくは[貸し出し伝票作成](/booking-compact/)を参照してください。

## 料金ごとの扱い

| 何を支払うか | 後払いクレジットカード | 銀行振込・店頭支払い |
|---|---|---|
| **レンタル料・配送料** | 返却後の金額確定でまとめて請求。過去に配送料を別に請求済みなら、その配送料は再度含めません。 | 伝票に計上して請求・入金処理。 |
| **延長料金・破損料金・調整項目** | 未決済なら本体分とまとめて請求。本体分を支払い済みなら、画面の案内に従って追加請求。 | 伝票に計上して精算。 |
| **金額確定後に追加する商品** | 追加商品の請求として分けて処理。 | 伝票の編集可能な範囲で追加。 |
| **配送キャンセル料** | 後払いでは本体分に含めます。過去の前払い伝票では別の請求になる場合があります。 | 伝票に計上して精算。 |
| **返金** | 「返金を記録」で「Shopify(クレカ)」を選ぶと、カードへの返金も行います。 | 振込・現金等で返金した内容をEASEに記録。 |

> **追加料金をカードで回収したい場合（銀行振込・店頭精算の伝票）**: 下記「[追加料金を後からカードで回収する](#追加料金を後からカードで回収する銀振店頭精算伝票)」の手順で Shopify の決済リンクを使えます。**クレカ伝票で店頭の現金・PayPay等を受け取る場合**は「[クレカ伝票のお客様が店頭で現金・PayPay等で支払う場合](#クレカ伝票のお客様が店頭で現金paypay等で支払う場合)」を参照してください。

## 追加料金を後からカードで回収する（銀振・店頭精算伝票）

店頭で精算済み（現金・PayPay・店頭カード）や銀行振込の伝票で、**返却後に発生した追加料金（延長料・損料など）をお客様がカードで支払いたい**場合の手順です。

> クレカ伝票（Shopify決済）の場合は、伝票画面の**追加請求（請求チャネル③）**が決済リンク付きメールを自動送信するため、この手順は不要です。

:::warning
**暫定運用です。** この手順で作った請求は、EASEの伝票に入金が自動反映されません。最後に入金登録が必要です。
:::

### 手順

1. **Shopify管理画面** → 販売 → 下書き注文 →「下書き注文を追加」
2. 顧客を指定し、**カスタム品目**で「延長料金（伝票番号 B…）」などの品目名と金額を入力
3. 「請求書を送る」でお客様に決済リンク付きメールを送信（リンクをコピーしてメール・電話で案内してもOK）
4. お客様がカードで決済
5. **EASE管理画面「未入金一覧・入金処理」で対象伝票に手動入金登録**（Shopifyでの入金はEASE伝票へ自動反映されません）

### 注意事項

- **品目は必ず「カスタム品目」のみにする**: レンタル商品（商品マスタの品目）を入れると、決済完了時にEASEが新規伝票として自動取り込みし、在庫を二重に押さえる恐れがあります
- マイアカウントの「未払い」には表示されません（EASE発行の追加請求ではないため）
- 決済方法がクレカの伝票には使わない（伝票画面の「追加請求」を使う）

## クレカ伝票のお客様が店頭で現金・PayPay等で支払う場合

クレジットカード（Shopify決済）の伝票で、お客様が返却時に店頭で**現金・PayPay等**で支払いたいと言うことがあります。EASEの入金画面はクレカ伝票の入金登録を受け付けない設計（Shopify決済との二重計上防止）のため、**Shopify側で支払いを完了**させます。EASEへの入金反映は自動です。

### 手順

1. Shopify管理画面で該当の伝票を開く
   - 追加料金の場合: EASEの「追加請求」で作成された**下書き注文**（販売 → 下書き注文）
   - 本体分の場合: 先にEASEで金額確定（Shopifyへ送信）を行い、Shopify側の金額を確定額に合わせてから
2. 「支払いを受け取る」で**現金等の手動決済方法**を選んで支払いを完了する（金額は変更しない）
3. 完了すると自動で連携し、**伝票が入金済みになる**（EASEでの入力作業は不要）。領収書も自動発行（お支払い方法の記載は無いため問題なし）
4. EASE側で必要な手動作業は、**伝票備考に実態を記録するのみ**（例: 「延長料は店頭現金で受領」）

### 注意事項

- EASEの伝票上は「Shopify（クレカ）」扱いのままのため、**決済手段別の売上集計ではクレカに計上**されます。実態は伝票備考で担保してください（実際の入金方法はShopify注文側に記録が残ります）
- 事前にShopifyの「手動決済方法」（現金など）が設定されている必要があります（未設定の場合はShopify設定で追加）

## 受注から完了まで

1. 伝票を作成し、商品・期間・配送内容を確認します。
2. ピッキング・出荷を行います。
3. 商品の返却を受け付けます。
4. 延長料金・破損料金・調整項目を確認し、金額を確定します。
5. 支払方法に応じて請求し、入金を確認します。

返却前に請求する場合も、出荷・返却の作業は必要です。前倒し請求後や入金後でも、返却前なら伝票の**「期間を延長する」**から延長できます。前倒し請求後に増えた料金は、別途精算します。

## 返金フロー（重要）

### 返金は必ずEASE管理画面から行う

:::warning
**Shopify admin で直接返金しないでください。** EASE に記録が残らず、顧客への請求表示と実際の返金がズレます。
:::

| 決済方法 | 返金方法 | Shopify連携 |
|---|---|---|
| **クレカ**（前払/後払） | EASE管理画面「返金を記録」で「Shopify(クレカ)」を選ぶ（過払いは下記手順） → カードへの返金も実行 | ✅ 連携（1アクションで完結） |
| **銀行振込** | お客様へ振込返金したあと、「返金を記録」で「現金」を選び、返金を記録 | ❌ 連携なし |
| **店頭現金** | EASE管理画面で現金返金を記録 | ❌ 連携なし（現金で返した後、EASEに記録） |

### 万が一 Shopify admin で直接返金してしまった場合

EASE 側には記録されないため、**「返金を記録」で返金方法を「現金」（記録のみ）にして実績を記録**してください。「Shopify(クレカ)」を選ぶと再度カード返金が実行されるため、選ばないでください。未選択のままにもせず、「現金」を選びます。

### 過払い返金（商品削除等）

商品削除・減額後に「料金・支払」セクションで **「返金可能額」** が表示されたカード伝票は、次の手順で返金します。

1. **「過払い返金」** を押します。
2. **「返金額（過払い分）」** を確認します。
3. **「返金を実行」** を押します。カードへ返金され、顧客に通知メールが送信されます。

すでにShopifyで返金済みの場合は、この操作を行わず、上記のとおり **「現金」で記録のみ**を行います。詳しくは[返金処理](/refund/)を参照してください。

### 二重決済の検知

振込入金済み伝票に顧客がクレカ決済してしまった場合、二重入金の疑いがある旨を知らせます。自動返金しないため、スタッフが手動で返金処理を行ってください。

## 過去の前払い伝票をキャンセルするときの返金

過去に前払いでカード決済済みの伝票をキャンセルした場合、**キャンセルと返金は別ステップ**です。キャンセルしても自動では返金されないため、スタッフが別途「返金を記録」を行う必要があります（7/23定例 B項）。

### 返金額の計算式

```
返金額 = お客様が支払った金額 − キャンセル料
```

- 返金額が **0以下** の場合 → 返金不要（キャンセル料が支払額を上回る・追加請求の可能性）
- 返金額が **0より大きい** 場合 → その金額を「返金を記録」で処理

### 具体例

#### パターン1: 部分キャンセル料（差額返金）

| 項目 | 金額 |
|---|---|
| お客様の支払額 | ¥10,000 |
| キャンセル料 | ¥5,000 |
| **返金額** | **¥5,000** |

**操作ステップ:**
1. 伝票をキャンセル→ キャンセル料 ¥5,000 が計上される
2. **別途**「返金を記録」ボタン → 返金額 ¥5,000 を入力
3. EASEからの操作で **クレジットカードに ¥5,000 返金**
4. 完了（EASE + Shopify 両方に記録・ズレなし）

#### パターン2: キャンセル料なし（全額返金）

| 項目 | 金額 |
|---|---|
| お客様の支払額 | ¥10,000 |
| キャンセル料 | ¥0（規定日前・または全額免除） |
| **返金額** | **¥10,000** |

→ 「返金を記録」で ¥10,000 を入力 → Shopify が全額返金。

#### パターン3: キャンセル料が支払額を上回る（返金なし・追加請求）

| 項目 | 金額 |
|---|---|
| お客様の支払額 | ¥10,000 |
| キャンセル料 | ¥15,000 |
| **返金額** | **¥0**（−¥5,000 = 返金不要・¥5,000 追加請求） |

→ 返金は不要。¥5,000 の差額は追加請求（請求チャネル③ または調整項目）で回収。

### ⚠️ 「手動2度手間」とは

:::warning
**キャンセル ≠ 自動返金。** クレカ伝票をキャンセルしても、システムは**自動では返金しません**。スタッフが別途「返金を記録」を操作する必要があります（2ステップ目）。これが「手動2度手間」の意味です。
:::

| ステップ | 操作 | 自動か |
|---|---|---|
| ①キャンセル | 伝票のキャンセル操作（キャンセル料計上） | スタッフ手動 |
| ②返金 | 「返金を記録」ボタン（カードへの返金も実行） | スタッフが②を押す必要あり・押せばShopify返金は自動 |

> **銀行振込の場合**は、実際の振込返金を行ったあと、EASEに返金を記録します。

:::dev
> **現行運用:** BE #3113 / #3125 / #3126 / #3127。以下の番号体系は既存伝票との互換を含みます。

> **過去の経緯:** BE #2409（DO①一本化）/ #2441（旧・前日自動請求）/ #2330（後払い基本化）/ #2408（請求書抑制前払い限定）/ #2218（DO⑤）/ 7/23定例 B項（返金＝手動2度手間）/ #2762（追加入金導線統一・手動DO手順は暫定・2606_B076）

## 技術詳細: Draft Order 番号体系

| DO | 用途 | mirror カラム | 作成メソッド |
|---|---|---|---|
| **DO①** | 本体（レンタル料＋配送料） | `shopify_draft_order_gid` / `shopify_order_id` | cart / booking-returns の金額確定・前倒し請求 |
| **DO②** | 配送料（前払いクレカのみ） | `shipping_fee_*` | createShippingFeeDraftOrder |

## 伝票closeの2種類

| 種類 | トリガー | 効果 |
|---|---|---|
| **hard close** | 本体のカード決済が完了（Shopify で注文化） | 本体への金額追加は不可。追加系はすべて別のカード請求に |
| **soft close** | 後払いクレカで金額が確定（返却時の全件確定または前倒し請求・支払いはまだ） | 商品の追加・削除はロック。追加商品は別のカード請求へ |
