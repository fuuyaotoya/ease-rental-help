クレジットカード払いは**後払いが基本**です。通常は返却後に金額を確定し、決済リンク付きメールでお客様に支払いをお願いします。

このページの「本体分」は、商品を予約したときのレンタル料の請求を指します。後払いでは配送料などもまとめます。

## 現在の運用

| 場面 | スタッフが行うこと |
|---|---|
| 予約時 | 商品・期間・配送内容を確認して伝票を保存します。カートの「今すぐ払う」は利用できません。 |
| 貸出前 | 配送料を含めて伝票の内容を確認します。貸出前日の自動請求はありません。 |
| 返却前に請求が必要 | 伝票に「前倒しで請求する」が表示される場合は、理由を入力して請求します。 |
| 返却時 | 返却受付を行い、延長料金・破損料金・調整項目を確認して「金額を確定」をクリックします。 |
| 金額確定後 | 後払いクレジットカードは決済リンク付きメールが自動送信されます。通常の請求書PDFは発行しません。 |
| 支払い後 | 入金は自動で反映されます。EASEでの手動入金登録は不要です。 |

配送料はレンタル料とまとめて請求します。過去に配送料を別に請求した伝票では、その配送料を再度本体分へ加えません。

## 過去の運用から変わった点

- **貸出前日の自動請求は廃止されました。** 「前日請求」のセットや「請求書送付」の操作は不要です。
- **返却前の請求には、前倒し請求を使います。** 請求後も、返却前の伝票は完了にならず、レンタル期間を延長できます。
- 過去の前払い伝票や、すでに本体分を支払い済みの伝票では、配送料・追加料金を別に請求する場合があります。画面の案内に従ってください。
