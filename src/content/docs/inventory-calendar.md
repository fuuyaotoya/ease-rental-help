:::dev
> **パス:** `/inventory-calendar?productId={id}`
> **メニュー:** 顧客・商品・マスタ > マスタ管理 > 商品マスタ の「予約状況」リンクから遷移（新規タブで開く）
:::

## 概要

商品ごとの月間予約状況をカレンダー形式で表示する画面です。指定した商品が1ヶ月間でどの日程に予約が入っているか、利用可能か、メンテナンス等で利用不可かを一目で確認できます。

主な用途:

- 問い合わせ対応時の在庫確認
- 伝票作成前の空き状況確認
- メンテナンス・修理による利用不可期間の把握

## アクセス方法

[マスタ管理](/master-data/) の **商品マスタ** タブから遷移します。在庫カレンダーへの直接のサイドバーメニュー項目はありません（[商品管理](/products/) 画面からの導線はありません）。

1. **顧客・商品・マスタ** > **マスタ管理** に移動
2. **商品マスタ** タブを開く
3. 対象商品の操作列から **予約状況** をクリック
4. `?productId={id}` パラメータ付きで当画面が **新しいタブ** で開く

> **注意:** URLに `productId` パラメータを含めずに直接アクセスした場合、「商品IDが指定されていません」というメッセージが表示されます。商品マスタの「予約状況」リンクから遷移してください。

## 画面構成

### ページヘッダー

| 項目 | 説明 |
|------|------|
| タイトル | `{商品名} - 在庫カレンダー` |
| サブタイトル | `SKU: {SKUコード}`（SKU設定済みの場合のみ表示） |

### カレンダー操作バー

| 項目 | 説明 |
|------|------|
| 前月 | 表示月を1ヶ月前に変更 |
| 年月表示 | 現在表示中の年月（例: `2026年 6月`） |
| 次月 | 表示月を1ヶ月後に変更 |
| 今日 | 当月に戻る（今日の日付にリング表示） |

### カレンダーグリッド

日曜始まりの7列カレンダーで、最大6週（42日）を表示します。

**各日付セルの表示内容:**

| 条件 | 背景色 | 表示内容 |
|------|--------|----------|
| 利用可能（予約なし） | 緑 | 「利用可能」 |
| 予約済み | 黄 | 顧客名 + 伝票番号 |
| 利用不可（メンテ・破損等） | 赤 | 「× 不可」+ 理由 |
| データなし | 白 | 日付のみ |
| 当月以外の日 | グレー | 日付のみ（前月・翌月の日） |
| 今日 | 青リング | 日付セルに青い枠線 |

### 凡例

カレンダー下部に表示色の凡例があります。

| 色 | 種類 | 説明 |
|----|------|------|
| 緑 | 利用可能 | その日に予約がなく、貸出可能な状態 |
| 黄 | 予約済み | 既に予約が入っている日 |
| 赤 | 利用不可 | メンテナンス・修理・破損等で貸出不可 |
| 白 | データなし | 在庫情報が存在しない日 |

## 操作手順

### 手順1: 在庫カレンダーを開く

1. **在庫管理** > **商品** に移動
2. 確認したい商品を探す
3. 「在庫カレンダー」リンクをクリック
4. カレンダーが当月表示で開く

**期待される結果:**
- ページヘッダーに商品名とSKUが表示
- 当月のカレンダーが在庫データ付きで表示

### 手順2: 月を変更して確認する

1. **前月** または **次月** ボタンをクリック
2. カレンダーが指定月に更新
3. 必要に応じて繰り返し

**期待される結果:**
- 表示年月が更新される
- 指定月の在庫データが読み込まれる
- 読み込み中は「読み込み中...」と表示

### 手順3: 今日に戻る

1. 任意の月を表示後、**今日** ボタンをクリック

**期待される結果:**
- 当月のカレンダーに戻る
- 今日の日付に青いリングが表示

### 手順4: 予約状況を確認する

1. カレンダーの各日付セルを確認
2. 緑色セル = その日は空きあり
3. 黄色セル = 顧客名と伝票番号を確認可能
4. 赤色セル = 利用不可理由を確認

## カレンダー表示のビジネスルール

### 在庫判定の仕組み

カレンダーに表示されるデータは、Backend の `inventory_calendar` テーブルに基づいています。Shopify の在庫数ではなく、Backend が管理する実在庫情報が真実のソース（SSOT）です。

> **参考:** Shopify の在庫数は参照のみであり、実際の予約可否判定とは異なる場合があります。詳しくは「商品管理」ヘルプの「在庫ロックの仕様」を参照してください。

### 利用不可の理由

赤色で「× 不可」と表示される場合、以下のような理由が表示されることがあります:

| 理由 | 説明 |
|------|------|
| メンテナンス中 | 商品がメンテナンスまたは修理中 |
| 破損 | 商品に破損があり貸出不可 |
| 予約重複 | 同一商品に複数の予約が入っている |
| 返却確認中 | 前の予約の返却期限が過ぎているのに未返却（overdue）で在庫を占有中。[返却受領処理](/bookings-return/)で解消する |

> **💡 お客様への影響:** 返却確認中（overdue）の商品は、お客様のカート画面で「前のご予約の返却確認中のため、この日程はご利用いただけません」と表示され予約できません。返却受領処理（[返却・金額確定処理](/bookings-return/)）を完了すると即座に解消します。スタッフが日々の返却受領処理を漏れなく行うことで未然に防げます。

### 予約済みセルの表示

黄色セルには以下の情報が表示されます:

- **顧客名**: 予約を入れた顧客の名前（緑色テキスト）
- **伝票番号**: 紐づく伝票番号

### 日付の取り扱い

カレンダーはすべて **JST（日本標準時）** 基準で表示されます。日付の計算・比較も JST で行われます。

## API

| エンドポイント | 方式 | 説明 |
|---------------|------|------|
| `GET /products/{id}` | GET | 商品基本情報の取得 |
| `GET /products/{id}/inventory-calendar?start_date={YYYY-MM-DD}&end_date={YYYY-MM-DD}` | GET | 指定期間の在庫カレンダーデータ取得 |

### カレンダーAPI レスポンス構造

```typescript
{
  productId: string;
  shop: string;
  calendar: [
    {
      date: string;           // YYYY-MM-DD (JST)
      isAvailable: boolean;   // 利用可能か
      bookingId?: string;     // 予約ID
      bookingStatus?: string; // 予約ステータス
      booking?: {             // 予約情報（null の場合あり）
        id: string;
        slipNumber: string;
        customerName: string;
        status: string;
      } | null;
      unavailableReason?: string;  // 利用不可理由
      variantId?: string;          // バリアントID（バリアント別在庫管理）
    }
  ];
  count: number;
}
```

## 確認チェックリスト

- [ ] 商品管理から在庫カレンダーに正常に遷移
- [ ] ページヘッダーに商品名とSKUが正しく表示
- [ ] 当月のカレンダーが在庫データ付きで表示
- [ ] 今日の日付に青いリングが表示
- [ ] 前月/次月ボタンで月が切り替わる
- [ ] 今日ボタンで当月に戻る
- [ ] 凡例が正しく表示（緑/黄/赤/白）
- [ ] 予約済みセルに顧客名と伝票番号が表示
- [ ] 利用不可セルに理由が表示
- [ ] productIdなしでアクセス時に適切なメッセージが表示

## 注意事項

- **遷移専用画面**: この画面は商品管理画面からの遷移専用です。サイドバーに直接のメニュー項目はありません
- **リアルタイム更新なし**: カレンダー表示後、別画面で予約が追加されても自動更新されません。月を切り替えるか、画面を再読み込みしてください
- **月単位の表示**: カレンダーは月単位でデータを取得します。月をまたぐ長期予約は両方の月で表示されます
- **データなしの日**: 在庫情報が登録されていない日は白（データなし）として表示されます。利用可否の確定判定には使用できません
- **より詳細な確認**: 複数商品を横断的に確認する場合は「商品予約状況照会」のカレンダー照会タブを、伝票作成時のリアルタイム在庫確認には伝票作成画面の在庫チェック機能を使用してください
