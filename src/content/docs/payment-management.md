> **パス:** `/payment-management`
> **メニュー:** 請求・入金 > 未入金一覧・入金処理

## 概要

支払方法が「店頭支払」または「銀行振込」の未入金伝票を検索し、入金処理を行います。振込（請求書）の入金処理は「請求書・領収書管理」画面で行います。

**対象となる支払方法:**

- 店頭支払（`store_payment`, `cash`, `credit_card`）— 店頭での現金・カード払い
- 銀行振込（`bank_transfer`）

## アクセス方法

- サイドバーから: **請求・入金 > 未入金一覧・入金処理**
- URL直接: `/payment-management`

---

## 画面構成

この画面は4つのセクションで構成されています:

| #   | セクション名   | 表示条件                      |
| --- | -------------- | ----------------------------- |
| 1   | 未入金伝票検索 | 常時                          |
| 2   | 未入金伝票一覧 | 検索実行後、結果がある場合    |
| 3   | 入金処理       | 伝票を1件以上選択している場合 |
| 4   | CSV出力        | 検索結果がある場合            |

---

## セクション1: 未入金伝票検索

検索条件を指定して未入金伝票を絞り込みます。全条件はAND検索です。

### 検索フィルター一覧

| 項目               | 種類             | 説明                           | 備考                      |
| ------------------ | ---------------- | ------------------------------ | ------------------------- |
| 伝票番号           | テキスト         | 伝票番号（部分一致）           | 例: `INV-001`             |
| 貸出先コード       | テキスト         | 顧客コード（前方一致）         | Shopify顧客ID等           |
| 担当者コード       | テキスト         | 予約担当者コードで絞り込み     | 担当者未指定の場合は除外  |
| 電話番号           | テキスト         | 顧客の固定電話番号（部分一致） |                           |
| 携帯番号           | テキスト         | 顧客の携帯電話番号（部分一致） |                           |
| 支払予定日（開始） | 日付             | 支払予定日の範囲（From）       |                           |
| 支払予定日（終了） | 日付             | 支払予定日の範囲（To）         |                           |
| 貸出年月（開始）   | 日付             | 貸出日の範囲（From）           |                           |
| 貸出年月（終了）   | 日付             | 貸出日の範囲（To）             |                           |
| 返却年月（開始）   | 日付             | 返却日の範囲（From）           |                           |
| 返却年月（終了）   | 日付             | 返却日の範囲（To）             |                           |
| 支払方法           | チェックボックス | 店頭支払 / 銀行振込            | 店頭支払は3値を一括トグル |

### 検索ボタン

| ボタン | 動作                                   |
| ------ | -------------------------------------- |
| 検索   | 条件に一致する未入金伝票を取得         |
| クリア | 全フォームフィールドを初期値にリセット |

## セクション2: 未入金伝票一覧

### サマリー表示

一覧の上部に以下のサマリーが表示されます。

| 項目       | 説明                                 |
| ---------- | ------------------------------------ |
| 検索結果   | 検索で見つかった伝票の総件数         |
| 選択中     | チェックボックスで選択した伝票数     |
| 未入金合計 | 全伝票の未入金額合計（円）           |
| 選択合計   | 現在選択中の伝票の未入金額合計（円） |

### テーブルカラム

| #   | カラム名     | 説明                                                   | ソート |
| --- | ------------ | ------------------------------------------------------ | ------ |
| 1   | （チェック） | 入金処理対象の選択。ヘッダーで全選択/解除              | -      |
| 2   | 伝票番号     | 伝票番号と予約ID（2行）                                | -      |
| 3   | 貸出先       | 顧客名と顧客コード（2行）                              | -      |
| 4   | 担当者名     | 予約に割り当てられた担当スタッフ名。未設定の場合は `-` | -      |
| 5   | 貸出日       | 貸出開始日（YYYY-MM-DD形式）                           | -      |
| 6   | 返却日       | 返却予定日（YYYY-MM-DD形式）                           | -      |
| 7   | 商品・数量   | 商品名と数量の一覧（複数商品はすべて表示）             | -      |
| 8   | 金額計算     | 合計金額 / 税込 / 調整額（3行）                        | -      |
| 9   | 前払い金     | 前払いとして受領済みの金額。未設定の場合は `-`         | -      |
| 10  | 未入金額     | 未収の金額（強調表示）                                 | -      |
| 11  | 支払方法     | 店頭支払 / 銀行振込                                    | -      |
| 12  | 支払予定日   | 支払予定日と超過日数（2行）                            | -      |

**超過日数の表示:**

- 0日以下: 通常色
- 1日以上: 赤色で警告表示

### 表示件数

一覧の下部のセレクトで1ページあたりの表示件数を変更できます。

| 選択肢                     | 説明             |
| -------------------------- | ---------------- |
| 20件ずつ表示（デフォルト） | 標準表示         |
| 40件ずつ表示               |                  |
| 60件ずつ表示               |                  |
| 90件ずつ表示               |                  |
| 120件ずつ表示              | 大量処理時に推奨 |

表示件数を変更すると自動的に1ページ目に戻ります。

### ページネーション

| 操作       | 説明                            |
| ---------- | ------------------------------- |
| 前へ       | 前のページへ移動                |
| ページ番号 | 現在のページ / 総ページ数を表示 |
| 次へ       | 次のページへ移動                |

## セクション3: 入金処理

選択した伝票に対して入金処理を実行します。入金処理セクションは1件以上選択した場合のみ表示されます。

### 入力フォーム

| 項目       | 種類           | 説明                                 | 必須 |
| ---------- | -------------- | ------------------------------------ | ---- |
| 入金日     | 日付           | 入金があった日付（デフォルト: 本日） | Yes  |
| 処理担当者 | セレクト       | 処理を行うスタッフ                   | Yes  |
| 参照番号   | テキスト       | 振込番号・参照伝票番号等             | -    |
| 備考       | テキストエリア | 入金処理に関する備考                 | -    |

### 選択済み伝票の確認

入金処理フォームの下に選択中の伝票一覧が表示されます。

- 各伝票の伝票番号・貸出先名・未入金額が確認可能
- 合計金額が最下部に表示
- 間違いがある場合は一覧セクションに戻って選択を変更

### 実行ボタン

| ボタン                       | 条件                                     | 動作                 |
| ---------------------------- | ---------------------------------------- | -------------------- |
| 入金処理実行                 | 入金日・担当者が入力済みかつ伝票選択あり | 一括入金処理を実行   |
| 入金処理実行（グレーアウト） | 必須項目未入力または伝票未選択           | 無効（クリック不可） |

## 操作手順

### 手順1: 未入金伝票の検索

1. 検索条件を入力する
   - 担当者コードで絞り込む場合: 「担当者コード」フィールドに入力
   - 支払方法でフィルタリング: 「店頭支払」「銀行振込」のチェックボックスを選択
   - 日付範囲で絞り込む場合: 「支払予定日」「貸出年月」「返却年月」のFrom/Toを入力
2. 「検索」ボタンをクリック
3. 検索結果が一覧に表示される
4. サマリーで総件数・未入金合計を確認

**表示件数の調整:**

- 処理件数が多い場合は表示件数セレクトで 60〜120件を選択
- ページ移動が不要になり、一括での確認・選択が容易になる

### 手順2: 入金処理対象の選択

1. 一覧から入金処理する伝票を選択する
   - チェックボックスをクリックで個別選択/解除
   - ヘッダーのチェックボックスで**現在ページの全件**を選択/解除（全ページではない）
2. サマリーの「選択中」「選択合計」で選択状況を確認する

**注意事項:**

- 一度に複数の伝票を選択可能
- 選択した伝票は入金処理セクションに一覧表示される

### 手順3: 入金処理の実行

1. 入金処理セクションで以下を入力する:
   - **入金日** （必須）: 実際に入金された日付。デフォルトは本日
   - **処理担当者** （必須）: ドロップダウンからスタッフを選択
   - **参照番号** （任意）: 振込番号・証憑番号など
   - **備考** （任意）: 特記事項
2. 「入金処理実行」ボタンをクリック
3. 処理完了後、成功トーストが表示され、処理済みの伝票は一覧から除外される

**期待される結果:**

- 選択した伝票のステータスが「入金済み」に更新される
- 処理件数を示すトーストが表示される（例: `2件の入金処理が完了しました`）

### 手順4: CSV出力

1. 検索を実行して結果を表示する
2. 「CSV出力（N件）」ボタンをクリック
3. `未入金一覧_{YYYY-MM-DD}.csv` がダウンロードされる

## 通知・エラー

### トースト通知

| メッセージ                        | タイプ | タイミング     |
| --------------------------------- | ------ | -------------- |
| N件の未入金伝票が見つかりました   | 成功   | 検索完了時     |
| N件の入金処理が完了しました       | 成功   | 入金処理完了時 |
| CSVファイルをダウンロードしました | 成功   | CSV出力時      |
| データを更新しました              | 成功   | リフレッシュ時 |

### エラーメッセージ

| メッセージ                     | 原因                       | 対処方法                         |
| ------------------------------ | -------------------------- | -------------------------------- |
| 検索に失敗しました             | API通信エラー              | ネットワーク確認後、再検索       |
| 必須項目を入力してください     | 入金日または担当者が未入力 | 入金日・担当者を入力             |
| 処理する伝票を選択してください | 伝票が未選択               | 一覧からチェックボックスで選択   |
| 入金処理に失敗しました         | API通信エラー              | 再度実行。連続失敗時はサポートへ |
| 出力するデータがありません     | 検索結果なし               | 検索条件を確認し再検索           |

## 業務ロジック

### 支払方法の対応関係

| 画面表示 | システム内部値                         | 説明                                      |
| -------- | -------------------------------------- | ----------------------------------------- |
| 店頭支払 | `store_payment`, `cash`, `credit_card` | 店頭での現金・カード払い（3値を一括表示） |
| 銀行振込 | `bank_transfer`                        | 銀行振込払い                              |

> **注意:** `store_payment` / `cash` / `credit_card` はすべて「店頭支払」として扱われます。検索チェックボックスでは1つのトグルで3値を一括指定します。

### 前払い金の扱い

- `prepaid_amount` が設定されている伝票は、既に一部金額を受領済みであることを示す
- CSV出力時も前払い金額が含まれる
- `未入金額 = 合計金額 - 前払い金額`（バックエンドで計算済み）

### 担当者コードフィルタ

- 担当者コードを入力すると、該当コードの担当スタッフが割り当てられた予約のみが表示される
- 担当者コードが未割り当ての伝票は、フィルタに引っかからず除外される

## 追加機能（マニュアル改訂時の実装差分）

> 実装済みだが旧マニュアルに記載がなかった機能

| 機能               | 説明                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| 一括再請求         | 期限超過の請求書がある場合、オレンジ色の警告バーが表示。「一括再請求」ボタンで新しい請求書番号で再発行 |

## 注意事項

- この画面は「店頭支払」「銀行振込」の未入金伝票が対象
- 「振込（請求書払い）」の伝票は請求書作成 → 入金処理のフロー（[請求書・領収書管理](11_invoices-list.md)）
- 一度の入金処理で複数伝票をまとめて処理可能
- 部分入金には対応していない（全額入金のみ）
- 一括再請求機能: 選択した伝票に対して一括で再請求メールを送信可能
