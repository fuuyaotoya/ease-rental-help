## 概要

お客様がログイン後に利用する**マイページ**の説明です。レンタル伝票の確認、未払いのお支払い、履歴の閲覧、配送先・請求先の管理ができます。

> このページは**お客様向け**の操作説明です。管理者（スタッフ）自身のアカウント設定は [マイページ（スタッフプロフィール）](/my-page/) とは別物です。

---

## 最大6つのタブ

マイページには最大6つのタブがあります。**「未払い」は、銀行振込可のお客様や、対象の未払い料金がある場合に表示されます。**

| タブ | 対象・できること |
| --- | --- |
| **貸出予定** | これから貸出予定の伝票（予約確定前〜レンタル中）。仮予約のキャンセル、レンタル伝票の確認ができます |
| **未払い** | 未払いの伝票・配送キャンセル料の確認とお支払い |
| **全履歴** | これまでのすべてのレンタル履歴（キャンセル含む） |
| **配送先管理** | 配送先住所の確認・管理 |
| **請求先管理** | 請求先住所の確認・管理 |
| **アカウント詳細** | ご登録情報の確認（読み取り専用） |

---

## レンタル伝票のバッジ（表示ステータス）

伝票には現在の状態を示すバッジが表示されます。

| バッジ | 意味 |
| --- | --- |
| **仮予約** | 店舗で仮押さえ中の伝票（ご希望の日付を一時的に確保している状態です） |
| **予約確定** | 貸出前の確定済み予約 |
| **レンタル中** | 貸出中の伝票 |
| **超過中** | 返却予定日を過ぎた未返却の伝票 |
| **返却済み（精算中）** | 返却済み・金額精算中 |
| **お支払い待ち** | 請求書送付済み・お支払い待ち |
| **完了** | 精算・お支払いまで完了 |
| **キャンセル** | キャンセル済み |

> バッジは、返却・精算などを含む現在の状態で決まります。**貸出開始日だけでは判断しません。**

## 各タブの詳細

### 1. 貸出予定

進行中のレンタル伝票が表示されます。伝票ごとに商品・期間・バッジを確認できます。

**仮予約の伝票**には以下のボタンが表示されます:

- **キャンセル** — 伝票全体をキャンセルします（確認ダイアログあり）。開始日までの営業日数に応じた[キャンセル料](/appendix/fee-calculation/#キャンセル料率)が発生する場合があります
- **内容を変更** — 一部の商品だけをやめたい場合はこちらから。削除する前に、キャンセル料を含めた削除後の伝票合計が表示されます

**確定済み（予約確定）の伝票**には以下が表示されます:

- **レンタル伝票** — レンタル伝票PDFをダウンロード
- **内容を変更** — 伝票の内容を変更（商品の削除など。変更可否は伝票の状態により異なります）

> **キャンセルについて:** 確定済み（予約確定）の伝票は、マイページからは伝票全体のキャンセルができません。キャンセルが必要な場合は、お問い合わせフォーム・お電話にてスタッフへご相談ください（開始日までの営業日数に応じた[キャンセル料](/appendix/fee-calculation/#キャンセル料率)が発生する場合があります）。

> ※ レンタル中の伝票へ**商品を追加**したい場合は、カート画面の「既存の伝票に追加する」から行ってください（マイページからは追加できません）。

### 2. 未払い

未払いの伝票や配送キャンセル料を確認・お支払いいただけます。

- **銀行振込でのお支払いが可能なお客様**（銀行振込可タグ保有）: 金額が確定した未払い伝票に以下のボタンが表示されます
  - **請求書PDF** — 請求書をダウンロード
  - **支払う** — カード決済などでお支払い（カートに進みます）
  - **内容を変更** — 伝票内容の変更（変更可否は別途判定されます）
  - **レンタル伝票** — レンタル伝票PDF
- **配送キャンセル料**（後日課金・全お客様）: 配送キャンセルに伴う料金があればこちらに表示されます

まとめ請求の対象、またはマスタの「請求書DL不可の会社」に有効登録された会社の場合、**請求書PDF**は表示されません。代わりに「請求書はメールでお送りしています。」と表示されます。カード払いの伝票では、この案内も表示されません。

複数の伝票を含む請求書PDFでは、1件でもダウンロード制限の対象があると、PDF全体をダウンロードできません。請求先に届くメールを確認するよう案内してください。

> ※ 0円の伝票は未払いタブに表示されません。

### 3. 全履歴

これまでのすべてのレンタル履歴（キャンセル済みを含む）を確認できます。

- **レンタル伝票** — 各伝票のレンタル伝票PDFをダウンロード

まとめ請求の対象や、請求書のダウンロードが制限された会社の銀行振込伝票には、「請求書はメールでお送りしています。」と表示されます。請求書が必要な場合は、受信メールを確認してください。

一部入金がある伝票では、**「残額」**と、配送料を含めた**「ご請求額」**を確認できます。請求額の情報がない古い伝票では、補足が「伝票総額」と表示されます。

### 4. 配送先管理

配送先住所の確認・管理を行います。

### 5. 請求先管理

請求先住所の確認・管理を行います。

### 6. アカウント詳細

ご登録情報（会社名・担当者名・連絡先など）を確認できます。変更が必要な場合はお問い合わせください（読み取り専用）。

## よくある質問

### 領収書はどこでダウンロードできますか？

領収書は**決済完了後に自動発行**されます。決済完了後、少し時間をおいてから該当伝票をご確認ください（自動発行まで少々お時間をいただく場合があります）。

### 未払いタブが表示されません

銀行振込でのお支払いが可能なお客様にのみ、伝票ベースの未払い一覧が表示されます（カード決済のお客様には基本的に未払いは発生しません）。配送キャンセル料などのお支払いがある場合は、該当時のみ未払いタブが開示されます。

### 伝票の内容を変更したい

未払いタブの「内容を変更」ボタンから変更画面に進めます（変更可否は伝票の状態により異なります）。貸出予定タブのレンタル中伝票へ商品を追加したい場合は、カート画面から「既存の伝票に追加する」をご利用ください。

### 予約をキャンセルしたい

- **一部の商品だけやめたい**場合は、伝票の「内容を変更」から該当商品を削除できます（削除する前に、キャンセル料を含めた削除後の伝票合計が表示されます）。
- **仮予約の伝票（店舗で仮押さえ中のもの）は、ご自身で伝票全体をキャンセルできます**。貸出予定タブの「キャンセル」ボタンからどうぞ（開始日までの営業日数に応じた[キャンセル料](/appendix/fee-calculation/#キャンセル料率)が発生する場合があります）。
- **確定済み（予約確定）の伝票は、マイページから伝票全体のキャンセルができません**。キャンセルが必要な場合は、お問い合わせフォーム・お電話にてスタッフへご相談ください。開始日が近いほど[キャンセル料](/appendix/fee-calculation/#キャンセル料率)が高くなります（前日50%・当日100% など）。
