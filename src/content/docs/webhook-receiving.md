## 概要

ShopifyからのWebhookで受信したデータを、**エンティティ別のタブ**で確認・管理する画面です。受信データの取捨選択（レンタルシステムへの登録・削除）や、手動のShopify同期を行えます。

---

## 画面構成

画面上部に **4つのタブ** があります。

| タブ | 内容 |
|------|------|
| 顧客 | 受信したShopify顧客データ |
| 商品 | 受信したShopify商品データ |
| 下書き注文 | 受信したDraft Orderデータ |
| 注文 | 受信したShopify注文データ |

### 共通の操作

| 操作 | 説明 |
|------|------|
| **Shopifyから同期** | タブごとにShopifyから手動でデータを同期します |
| 検索ボックス | フリーテキスト検索（**クリア** ボタンで解除） |
| チェックボックス | 行を選択（ヘッダーで全件選択） |

> **⚠️ 検索はフリーテキストのみ:** トピック別・ステータス別・日時範囲のフィルタUIはありません。

### 各タブの表示項目

| タブ | 主なカラム |
|------|-----------|
| 顧客 | Shopify ID / メール / 名前 / 電話番号 / 会社名 / 更新日時 / 詳細 |
| 商品 | Shopify ID / タイトル / ベンダー / 商品タイプ / 更新日時 / 詳細 |
| 下書き注文 | Draft Order ID / 顧客 / 合計金額 / ステータス / 予約情報 / 作成日時 |
| 注文 | Order ID / 顧客 / 金額 / ステータス / 予約情報 / 作成日時 / 詳細 |

---

## 主な操作

### 顧客をレンタルシステムに登録（顧客タブ）

受信したShopify顧客を、レンタルシステムの顧客（customer_master）に登録します。

1. **顧客** タブで登録する顧客を選択（チェックボックス・全件選択も可）
2. **「選択した顧客をレンタルシステムに登録」** ボタンをクリック
3. 登録結果が通知されます（登録済み顧客数が画面に表示されます）

> **💡 この後の流れ:** 登録した顧客は [顧客管理](/customer-management/) に表示されます。レンタル利用には別途レンタル登録が必要です。

### 受信データを削除

タブごとに、選択した受信データを削除できます。

1. 削除するデータをチェックボックスで選択
2. **「選択した○○を削除」** ボタンをクリック
3. 確認後、削除されます

> **⚠️ 商品の全件選択削除には対応していません:** 商品タブでは、全件選択からの削除は行えません（個別に選択してください）。

## Shopify Webhookトピック（参考）

EASE Rentalで使用する主なWebhookトピック：

### 顧客関連
| トピック | 説明 |
|---------|------|
| `customers/create` | 新規顧客作成 |
| `customers/update` | 顧客情報更新 |
| `customers/delete` | 顧客削除 |

### 商品関連
| トピック | 説明 |
|---------|------|
| `products/create` | 新規商品作成 |
| `products/update` | 商品情報更新 |
| `products/delete` | 商品削除 |

### 注文関連
| トピック | 説明 |
|---------|------|
| `draft_orders/create` | Draft Order作成 |
| `draft_orders/update` | Draft Order更新 |
| `orders/create` | 注文作成 |
| `orders/update` | 注文更新 |
| `orders/fulfilled` | 注文履行完了 |

## トラブルシューティング

### データが表示されない場合

1. **「Shopifyから同期」** ボタンで手動同期を試す
2. Shopify管理画面の **設定 > 通知 > Webhook** でWebhook設定を確認（URL・最近の送信履歴）
3. [Shopifyデータ管理](/shopify-data/) から手動同期を実行する

### 顧客がレンタルシステムに登録できない場合

- 選択した顧客にShopify IDがない場合は登録できません（通知で件数が表示されます）
- Webhook受信データを一度削除して再同期すると、最新データで再受信されます
